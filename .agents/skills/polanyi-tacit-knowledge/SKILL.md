# Polanyi 默会知识技能

> 基于 Michael Polanyi "我们知道的比我们能说出来的更多" 理论
> 融合 Five Questions Method（Agent Factory/Panaversity）

## 核心定位

本 Skill 做两件事：

1. **知识提取**：帮助用户将专家脑中"知道但说不清"的默会知识提炼成显性文档
2. **AI 优化**：将提炼出的默会知识注入 AI Prompt，让 AI 输出具备专业"感"

## 提取模式流程

### Step 1：确定领域

问用户：

```
你要提取哪个领域的默会知识？
例如：动画分镜连贯性判断 / 瓷器釉色鉴定 / 销售谈判策略

这个领域的从业者通常怎么说他们"知道"一件事是对的？
是"看得出来"还是"说得出来"？
```

**记录：领域名称 + 判断类型（感知型 / 分析型 / 体感型）**

---

### Step 2：五问提取（Five Questions Method）

按顺序执行，每个问题至少提取 3 个案例：

#### Q1：成功案例

```
给我讲一个这件事做得很好的近期案例——从头到尾完整讲一遍。

包含：
- 背景（什么情况）
- 当时的判断（怎么决定这样做）
- 结果（后来怎么样了）
- 为什么这样做是对的（判断依据）

格式：
背景：[]
判断：[]
结果：[]
原因：[为什么这是对的]
```

**追问：**
- "当时是什么让你觉得这样做是对的？"
- "这个判断是在多短时间内做出的？"
- "有没有犹豫过？还是直接就知道？"

---

#### Q2：失败案例

```
现在讲一个，这件事没做好的例子——哪里出了问题？

包含：
- 背景（什么情况）
- 当时的判断（怎么决定的）
- 问题（哪里出错了）
- 根本原因（为什么会错）

格式：
背景：[]
判断：[]
问题：[]
原因：[根本原因——为什么会错]
```

**追问：**
- "重来一次，你会怎么调整？"
- "新手通常在哪里犯错？"
- "有没有一个'时刻'，如果抓住就能避免？"

---

#### Q3：专家 vs 新手

```
做这件事，初级和资深的人有什么区别？
资深的人"看到"了什么新手机不会注意到的？

格式：
资深→[他们能看到什么]
新手→[他们只能看到什么]
判断速度：[资深用了多久做出这个判断]
```

**追问：**
- "这个判断能在多短的时间内完成？"
- "有办法把这个'看得出来'教给一个新手机器吗？"
- "资深的人和新人最关键的差距在哪一层？"

---

#### Q4：核心操作原则

```
给一个要做这个决定的人写一页指南——
如果只能告诉他三件事，是什么？

格式：
原则1：[内容] — 适用于 [什么条件]
原则2：[内容] — 适用于 [什么条件]
原则3：[内容] — 适用于 [什么条件]
```

**追问：**
- "有没有边界情况？什么条件下这三条就不适用了？"
- "如果只能选一条，最核心的是哪条？"
- "有什么错误是很多人觉得没问题但其实错的？"

---

#### Q5：自动化红线

```
在什么情况下，这件事绝对不能交给自动化系统，只能人来做？

格式：
🚫 永远不要自动化：[场景描述]
⚠️ 必须人工复核：[场景描述]
✅ 可以安全自动化：[场景描述]
```

**追问：**
- "有没有任何 AI 可以处理的层级？"
- "人和 AI 合作的话，各自负责什么部分？"
- "当你不确定的时候，你通常怎么决定？"

---

### Step 3：生成默会知识文档

提取完成后，根据收集的案例和原则，生成结构化文档：

**输出路径**：`knowledge/{领域slug}-默会知识.md`

**文档结构**：

```markdown
# {领域} 默会知识库

> 基于 Michael Polanyi 默会知识理论
> 提炼时间：{日期}
> 判断类型：{感知型 / 分析型 / 体感型}

---
```

## 注入模式流程

当用户要增强现有 AI Prompt 时：

### Step 1：读取目标 Prompt/文档

找到用户现有的 AI 角色定义或 Prompt 文件。

### Step 2：提取默会知识注入层

将默会知识文档中的关键内容，转化为 Prompt 注入格式：

```markdown
## 默会知识补充（来自 Five Questions 提炼）

### 核心判断特征
"我做这个判断时，通常先看这三个地方..."
"新手最容易忽略的是..."

### 专家 vs 新手判断差异
- 资深→[判断方式]
- 新手→[遗漏了什么]

### 必须遵守的原则
1. [不可妥协的规则]
2. [边界情况处理]

### 🚫 自动化红线
[绝对不能自动化的判断类型]

### 给 AI 的判断标准
- ✅ 正确的判断：[标准]
- ❌ 错误的判断：[常见错误模式]
```

### Step 3：追加到目标文件

使用 Edit 工具，将注入层追加到目标文件的适当位置（角色定义末尾，或 Prompt 末尾）。

## 动画 VideoPrompt 场景专用注入模板

当用户要在 animation-v3 项目中使用时：

### 分镜连贯性自检 Prompt

```
## Animation-VideoPrompt 默会知识自检

在生成每个分镜时，必须先过一遍以下默会判断：

### 节奏感自检
[当前情绪类型] → [应该"快"还是"慢"?]
如果"憋着"的情绪类型：
  → 停顿要故意过头，实际留5秒，感觉像6秒
  → 切点如果再晚半秒，力量感会更强
如果"释放"的情绪类型：
  → 动作镜头不拖，到顶点立刻切

### 视线引力自检
[当前镜头中角色的权力关系]：
  A质问B → A俯视，B下垂（视线：上→下）
  A安慰B → A平视，B微抬（视线：平→上）
  A暗恋B → 视线想靠近但错开（视线：接近但不相遇）
确认当前镜头和上下镜的视线引力方向是连贯的。

### 情绪落幅自检
本镜结束时的情绪点在哪个位置？
下一镜从哪个位置接？
如果落差超过一个"情绪单位"——加Reaction镜头过渡。
身体状态连续吗？

### 跳切感自检
同一个人连续两个镜头，角度差够吗？
如果同一人近景角度差 < 30度，中间Reaction镜头要≥5秒。
```

## 关键原则

1. **默会知识无法 100% 传递**：身体性/体感型知识（如手感、镜头节奏直觉）只能部分捕获，设置合理预期
2. **案例 > 规则**：提取时优先收集真实案例，案例是默会知识的最佳载体
3. **判断 ≠ 规则**：记录的是"在什么条件下判断这是对的"，不是"必须这样做"
4. **持续迭代**：默会知识文档是活的，每次 AI 使用中的修正都应该追加进去
