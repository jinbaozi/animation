# 默会知识库

本目录存放通过 Five Questions Method 提取的各领域默会知识。

## 文件命名规范

`{领域slug}-默会知识.md`

示例：
- `动画分镜连贯性-默会知识.md`
- `瓷器釉色鉴定-默会知识.md`
- `销售谈判策略-默会知识.md`

## 目录结构

```
knowledge/
├── README.md                  # 本文件
├── 动画分镜连贯性-默会知识.md  # 示例
└── {领域}-默会知识.md          # 按需添加
```

## 使用方式

1. 当需要为某领域建立 AI Prompt 时，先检查 `knowledge/` 是否有相关文档
2. 如有，将文档中的"默会知识注入手册"内容追加到目标 Prompt
3. 如无，使用 `/polanyi` 提取该领域的默会知识
4. AI 使用过程中发现新的判断模式，随时追加到对应文档

## 质量维护

每次追加时，在文档末尾的"版本历史"中添加变更记录。
案例评分持续更新，质量差的案例标记并可考虑删除。
