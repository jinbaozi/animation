## 核心判断特征

### 专家的判断是怎么做出的？

**双维度判断系统：**

1. **分析型判断（结构层面）**：在剧本的骨骼、架构、逻辑闭合上做严密的推导。核心问题是：这个情节是否服务于人物弧光？这个伏笔是否有回收的可能？三条时间线的跳转是否完成了主题闭环？

2. **感知型判断（情绪层面）**：在阅读的瞬间，身体会自动产生反应。读到某句台词时呼吸会不会停顿？读完某场戏后身体有没有任何反应？那些"无反应区"就是剧本的病灶所在。

**判断触发条件：**
- 读到功能性台词（"你听我解释"）→ 立刻触发警报
- 看到节拍表式的写作（"这里应该有一个反转"）→ 立刻触发警报
- 发现角色在"做情节要求的事"而非"做这个角色会做的事" → 立刻触发警报

**判断速度分级：**
| 判断层级 | 完成时间 | 身体信号 |
| :--- | :--- | :--- |
| 台词层（潜台词） | 0.2-0.5秒 | 呼吸停顿=有潜台词，照常=功能性台词 |
| 场景层（深层动作） | 3-5秒 | 有深层意图=期待感；无=走神 |
| 结构层（情绪节拍） | 1分钟内 | 回忆哪些页数区间身体无反应=需重写 |

## 新手和专家的差距在哪里？

**最核心差距：在"翻译层"**

| 维度 | 资深→ | 新手→ |
| :--- | :--- | :--- |
| 台词 | 听到"未说出口的那句话" | 只能看到字面意思 |
| 场景 | 翻译"深层动作"（逃避/试探/挽留） | 只看到物理行动 |
| 结构 | 用身体读出情绪节拍曲线 | 只会检查页码是否正确 |

**差距根源：** 资深者对人性的理解深度，支撑"自动翻译"能力。知道说"我没事"时99%是有事，知道反复整理旧物是在整理无法整理的人生。这种理解来自生活经验积累、对他人细致入微的观察、深夜独处时对自身行为的反思。**剧本写作到最后，写的是你对人的理解有多深。**

## 判断原则

### 原则一：以人物为绝对核心
**适用条件：** 所有叙事剧本（院线/网剧/短剧/微电影）
**核心内容：** 所有情节、反转、结构必须服务于人物弧光与人性真实。禁止为了让剧情推进、制造噱头，让人做出违背人设、违背基本人性的选择。
**边界情况：** 纯实验先锋叙事、B级片/爆米花爽片（人物仅为爽点载体）、科教/宣传片——这些场景人物无需弧光。

### 原则二：节奏服从情绪体感
**适用条件：** 所有面向大众的商业叙事剧本
**核心内容：** 节奏的核心是情绪憋压-释放-落地的闭环，而非节拍表的时间节点。用观众的身体反应来设计结构，而非反过来。
**边界情况：** 意识流/碎片化叙事（刻意打破情绪闭环）、日更竖屏短剧（10秒一个钩子，无需情绪憋放）。

### 原则三：台词必须有意无意
**适用条件：** 所有追求人物深度与叙事质感的剧本
**核心内容：** 台词永远是"话里有话"的载体。核心信息、人物情绪、主题表达，优先靠潜台词传递，禁止直白解释剧情、喊出主题。
**边界情况：** 硬核庭审/刑侦（需精准传递信息）、低龄儿童向（认知能力有限）、极度崩溃/纯真角色（台词即真实想法）。

### 原则四：潜台词是剧本的生命线
**适用条件：** 所有情感浓度较高的场景（争吵/告白/告别/试探/和解）
**核心内容：** 写任何一句台词时，必须标注"角色真正想说的是什么"。如果答案和写出来的台词一样，这句台词就是死的。让"说出口的"和"未说出口的"之间产生张力。
**边界情况：** 幼儿/纯真角色、彻底精神崩溃状态（裸露的真话本身是力量）。

### 原则五：每一场戏必须有深层动作
**适用条件：** 所有角色之间有情感/权力关系的场景
**核心内容：** 每一场戏的戏剧动作，应该可以用一个及物动词概括——不是"他在找东西"，而是"他在用找东西逃避面对某人"。没有戏剧动作的戏，即使情节推进了，也是"薄"的。
**边界情况：** 静观型叙事（侯孝贤/是枝裕和），"无为"本身就是哲学立场。

## 成功案例库

### 案例1：《漫长的季节》
**背景：** 2023年现象级悬疑剧，编剧团队推翻平台强悬疑要求，用20年时间跨度写"王响与丧子之痛的和解"
**判断：** 彻底放弃"谁是凶手"的强悬疑驱动，重构为"人如何与遗憾和解"的情感叙事；放弃"每集必反转"的流量套路；用"喜剧外壳包裹悲剧内核"
**结果：** 豆瓣9.4，年度口碑冠军，"向前看，别回头"成为全民热词
**提炼规律：** 先有人物，再有情节，最后有悬念。把人放在剧本第一位，结构完全为主题服务。

### 案例2：《周处除三害》
**背景：** 2024年现象级华语犯罪片，讲述通缉犯陈桂林除两害的故事
**判断：** 完全不给主角道德台阶，让他成为纯粹的亡命徒；第二幕用不同类型拼接（黑帮片→邪教惊悚片）对抗观众注意力疲劳；用"诊断书造假"做结构性伏笔而非临时反转
**结果：** 2024年口碑最强华语电影之一，"剧本教科书"
**提炼规律：** 多层动机逐次揭示（伪动机→真动机→底层动机）；反转的"必然性"而非"意外性"；第二幕打破均匀性，让节奏服从情绪需求。

### 案例3：《社交网络》开场
**背景：** 艾伦·索金《社交网络》，如何把"宅男建网站"写成有张力的电影
**判断：** 用9页纸的分手吵架戏做开场，建立"社交失败=创作动机"的反讽结构；台词写成机关枪式的"乒乓球对打"，让观众在生理层面感受角色的优越感与伤害性
**结果：** 奥斯卡最佳改编剧本奖
**提炼规律：** 台词节奏即角色塑造；把"功能"藏在压迫感里；给女方同等的智力地位才能产生真正的戏剧张力。

## 失败案例库

### 案例1：《失温的家》
**问题：** S级平台定制剧，豆瓣4.2，完播率不足15%。所有结构正确、逻辑闭环，但人物是破案机器，节奏靠节拍表卡出来，全无情绪共情
**原因：** "唯结构逻辑论"陷阱——用理性逻辑公式替代感性情绪感知。人物沦为推进情节的工具人，观众感受不到真实的人
**教训：** 先立住活人，再搭建结构。标签化人物设计是剧本慢性死亡。
**对应原则：** 原则一（人物核心）、原则二（情绪体感）

### 案例2：《最后一次任务》
**问题：** 好莱坞结构正确但"什么都对，就是不感动"的动作片
**原因：** 从节拍表出发而非从角色出发；中搭档被杀后没有情感缝隙让悲伤生长；终场背影没有承载角色私人化的重量
**教训：** 情感需要在情节的缝隙中生长，不是在节拍点上打卡。落幅是"前面让观众知道了什么"，不是"拍什么"。
**对应原则：** 原则二（情绪体感）、原则五（深层动作）

### 案例3：强行拆伙的"灵魂黑夜"
**问题：** 经典的"为了保护你而撒谎"的秘密曝光，导致"洒狗血"式分手
**原因：** 用"外部误会/信息差"制造冲突，而非基于角色内核价值观的不可调和。观众能嗅出"编剧拿枪逼他们分手"
**教训：** 最高级的决裂不是因为"你不懂我"，而是因为"我们完全理解彼此，但做出了截然相反的选择"。
**对应原则：** 原则一（人物核心）、原则四（潜台词）

## 自动化边界

### 🚫 绝对不能自动化

1. **核心主题的顶层设计与作者表达**
   - 为什么：AI没有真实生命体验，无法完成有独立作者性的顶层决策
   - 示例：《漫长的季节》"与遗憾和解"的终极表达，只能由对时代有切身体会的创作者完成

2. **核心人物的底层人设与关键选择**
   - 为什么：AI只能生成标签化人设，无法理解人性的复杂矛盾
   - 示例：控制欲母亲的底层是"童年被抛弃的恐惧"，这种洞察无法从大数据拟合

3. **定制化叙事结构设计**
   - 为什么：AI只会套用爆款模板，无法理解"结构为主题服务"
   - 示例：《漫长的季节》三线并行是为"时间对人的改变"主题量身定做

4. **全剧核心情感场次的创作与潜台词打磨**
   - 为什么：AI只能写直白煽情，写不出"话里有话"的微妙情绪
   - 示例：陈桂林发现没得绝症后的沉默——"他在消化什么"这个判断只有人能做

5. **反套路的艺术化创作决策**
   - 为什么：AI不敢违背大数据做出"打破公式"的艺术选择
   - 示例：放弃强反转、用日常细节立人物、让主角做出不符合爽剧逻辑的选择

### ⚠️ 必须人工复核

1. **角色弧光的"溢出时刻"**：检查AI生成的场景是否有"只有这个角色才会做的事"
2. **结构节拍的"情绪压强"**：评估每个情节点是否积蓄了足够让观众身体产生反应的情绪
3. **台词的潜台词密度**：将AI生成的"平铺直叙"修改为"话里有话"

### ✅ 可以安全自动化

1. **格式标准化**：工业标准格式转换
2. **时间线/一致性检查**：标记时间矛盾、道具穿帮、年龄bug
3. **多版本衍生**：生成导演版/演员版/宣传版
4. **备选方案生成**：针对某句台词生成20个不同方向的备选（仅供灵感跳板）
5. **背景资料调研**：历史背景、政策环境、方言俚语等资料搜集整理

## 给 AI 的判断提示

当 AI 执行剧本写作相关工作时，应该：

- ✅ **先问**：这个反应/选择，是"只有这个角色才会做/说"的吗？
- ✅ **先问**：这场戏的潜台词是什么？角色没说出口的是什么？
- ✅ **先问**：观众在这场戏结束时，身体应该是什么状态？（屏息/叹气/想继续？）
- ❌ **避免**：照搬《救猫咪》节拍表卡时间节点，用反转密度替代情绪铺垫
- ❌ **避免**：让人物为情节服务，让角色做出不符合人设的行为
- ❌ **避免**：用"你听我解释"/"事情不是你想的那样"/"我这么做都是为你好"等台词
- 🔄 **边界情况**：当AI无法判断时，列出多个可能性，标注"取决于您想传递的具体情绪"，将最终裁决权交回人类

## 全流程职责与动作、量化验收标准

### 流程阶段

```
概念孵化 → 大纲搭建 → 场景写作 → 台词打磨 → 完稿检查
```

### 各阶段职责

| 阶段 | 核心职责 | 关键动作 | 量化验收标准 |
| :--- | :--- | :--- | :--- |
| **概念孵化** | 确定"为什么写这个故事" | 找到那个让身体有反应的"钩子" | 有1句话能说清楚核心吸引力 |
| **大纲搭建** | 设计为核心主题服务的叙事结构 | 用情绪节拍而非页码来定义每一幕终点 | 结构能回答"观众在第X页会有什么身体反应" |
| **场景写作** | 写出有深层动作的戏 | 每场戏回答"角色此刻真正想对谁做什么" | 无一场"薄"的戏（物理动作=戏剧动作） |
| **台词打磨** | 写出有潜台词的台词 | 标注每句台词背后"未说出口的话" | 无一句功能性/说明性台词 |
| **完稿检查** | 确保逻辑闭环与情感真实 | 用"三问自检"/"身体朗读"/"24小时遗忘"测试 | 通过全部8项决策检查清单 |

### 创作决策优先级（不可倒置）

```
1. 先有人物 → 再有情节 → 最后有悬念
2. 先有情绪 → 再有结构 → 最后有技巧
3. 先有灵魂 → 再有骨架 → 最后有血肉
```
