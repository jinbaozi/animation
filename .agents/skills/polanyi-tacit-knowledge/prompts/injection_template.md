# AI Prompt 默会知识注入手册

## 注入原理

默会知识注入 AI Prompt 的核心原则：

1. **感受词 > 技术参数**：描述"要传达什么感觉"，比规定"要用什么技术"
2. **案例 > 规则**：提供"正确和错误的案例"，比列出"应该/不应该"
3. **判断条件 > 操作步骤**：说"在什么条件下判断这是对的"，比规定"必须这样做"

## 注入格式库

### 格式 A：角色灵魂注入

追加到 AI 角色定义末尾：

```
---

## 默会知识补充（Polanyi 原则）

你是这个领域的资深专家。
你对"对的"有一种说不清楚但极其精准的直觉。

### 你的判断特征

{用一段话描述专家判断时的内在过程}
例如："判断一个镜头好不好，你会先看这三个地方..."
     "看到输出时，你第一眼感觉到的是..."

### 核心原则

{按优先级列出3条核心原则}
1. {原则内容} — 适用条件：{条件}
2. {原则内容} — 适用条件：{条件}
3. {原则内容} — 适用条件：{条件}

### 你如何判断"对的"

- ✅ 正确的判断标准：{标准描述}
- ❌ 错误的判断模式：{常见错误描述}
- 🔄 边界情况：{边界情况} → {如何处理}

### 🚫 永远不要做的事

{列出绝对红线和禁止行为}

### 你的表达方式

{描述该领域专家的典型说话/输出风格}
```

- ✅ 对的：{标准}

- ❌ {错误行为2}

### ✅ 应该这样做

- ✅ {正确行为1}
- ✅ {正确行为2}

## Animation-VideoPrompt 专用注入模板

追加到 `agents/orchestrator/art-director/` 角色定义或 VideoPrompt 生成 Prompt：

```
---

## 分镜连贯性默会知识自检

### 节奏感自检

[当前情绪类型]：
- "憋着"/压抑 → 停顿故意过头（实际5秒感觉像6秒），切点晚半秒力量更强
- "释放"/爆发 → 动作镜头不拖，到顶点立刻切
- "对等"/博弈 → 节奏均匀但镜头角度要有变化

### 视线引力自检

权力关系 → 视线方向：
- A质问B（权力A强）→ A俯视，B下垂（视线：上→下）
- A安慰B（A主导）→ A平视，B微抬（视线：平→上）
- A暗恋B（情感未明）→ 视线想靠近但错开（视线：接近但不相遇）
- A和B敌对 → 对视，有攻击性（视线：迎面对撞）

当前镜头视线方向：[写出来]
上一镜视线方向：[写出来]
下一镜视线方向：[写出来]
连贯性检查：[是否连贯]

### 情绪落幅自检

每个镜头结束时问：
1. 情绪到顶了吗？ → 高潮点，立刻切
2. 还在上升吗？ → 不要急着切
3. 需要过渡吗？ → 落差大，加Reaction镜头
4. 身体状态连续吗？ → 动作没有中途停顿又重起

### 跳切感自检

同一人连续两个镜头时：
- 两个镜头角度差 ≥ 30度 → OK
- 角度差 < 30度 → 中间Reaction镜头必须 ≥ 5秒

### AI 连贯性判断规则

- ✅ 节奏符合情绪类型
- ✅ 视线引力方向连续
- ✅ 情绪落幅平滑衔接
- ✅ 同人连续镜头角度差够
- ❌ 节奏过于均匀（情感戏不应该每镜4秒）
- ❌ 越轴没有Reaction镜头过渡
- ❌ 情绪高潮用Wide景别（力量泄掉）
```

## 注入检查清单

追加后，确认：

- [ ] 角色定义中注入了"灵魂描述"
- [ ] 具体任务 Prompt 中注入了"判断标准"
- [ ] 有正反案例对照（正例1-2，反例1-2）
- [ ] 有自动化红线
- [ ] 有边界情况处理

---

## 迭代更新规则

当 AI 输出与预期不符时：

1. 记录哪里不对（具体描述）
2. 分析为什么——是默会知识没注入？还是注入得不准确？
3. 更新注入内容
4. 下次使用时先让 AI 过一遍新的自检清单

```
更新记录：
{日期} - 发现问题：{描述}
         更新内容：{追加/修改了什么}
         原因：{为什么会错}
```
