# 默会知识提取 — 初始信息录入

## 开场白

```
我来帮你提取这个领域的默会知识。
只需要回答几个问题，每个都可以跳过。
```

---

## 问题序列

### Q1：领域名称

```
这个领域叫什么？
例如：动画 VideoPrompt / 瓷器釉色鉴定 / 销售谈判策略

用一句话描述这个领域是做什么的：
```

---

### Q2：判断类型

这个领域的专家通常怎么说他们"知道"一件事是对的？

- **感知型**：一看就知道，不解释
- **分析型**：能说出为什么，但需要时间
- **体感型**：身体有感觉，手/眼睛会自动反应
- **混合型**：以上多种都有

```
这个领域的专家判断通常属于哪种类型？
还是几种混合？
```

---

### Q3：有没有现有材料

```
有没有现有的文档、案例、对话记录、聊天记录等材料？
可以提供文件、截图、粘贴文字，或者直接描述。
没有也没关系，有则更好。
```

**接受：** 文档、截图、聊天记录、语音转文字、PDF、Markdown 等任何格式

---

### Q4：典型使用场景

```
这个默会知识主要用来做什么？

例如：
- 让 AI 生成更符合专业的 VideoPrompt
- 训练新员工判断标准
- 建立专家知识库
- 制作 AI 角色定义
```
