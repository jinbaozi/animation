# 默会知识文档生成模板

## 任务

根据 Five Questions Method 提取的原始材料，生成结构化的默会知识文档。

## 输入

- Five Questions 提取的原始问答记录
- intake.md 中记录的领域信息
- 用户提供的任何现有材料

## 输出

文档路径：`knowledge/{领域slug}-默会知识.md`

## 生成模板

```markdown
# {领域} 默会知识库

> 基于 Michael Polanyi 默会知识理论
> 提炼时间：{ISO日期}

## 默会知识注入手册

### 如何注入到 AI Prompt

将以下内容追加到目标 AI 角色的定义末尾：

```
## 默会知识补充

### 核心判断特征
专家的判断方式：{核心判断特征的简述}

### 必须遵守的原则
1. {原则1的核心内容}
2. {原则2的核心内容}
3. {原则3的核心内容}

### 🚫 自动化红线
{绝对不能自动化的场景}

### AI 判断标准
- ✅ 应该：{正确判断标准}
- ❌ 不应该：{错误判断模式}
```

### 注入位置建议

- AI 角色 Skill：追加到 `## 职责` 或 `## 判断标准` 之后
- 通用 Prompt：追加到 `## 约束` 或 `## 输出规范` 之后
- 系统级 Prompt：追加到 `## 行为规范` 之后
```
