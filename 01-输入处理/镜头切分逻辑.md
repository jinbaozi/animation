# 镜头切分逻辑

---

## 概述

本文档定义如何将小说片段划分为8-10镜，包括：
- 切分原则
- 切分依据
- 镜头分配策略
- 镜头调整规则

---

## 一、切分原则

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| 情节完整 | 每镜完成一个完整动作/事件 |
| 情绪递进 | 镜头随情绪变化调整 |
| 节奏控制 | 快慢结合，张弛有度 |
| 视觉连贯 | 确保跨镜头连续性 |

### 1.2 切分数量

| 小说字数 | 推荐镜数 | 说明 |
|----------|----------|------|
| 500-800字 | 6-8镜 | 精简镜头，聚焦核心 |
| 800-1200字 | 8-10镜 | 标准配置 |
| 1200-2000字 | 10-12镜 | 可适当增加 |

---

## 二、切分依据

### 2.1 事件节点

每个事件可产生1-2镜：

```
事件 → 判断重要性 → 确定镜头数
```

| 事件重要性 | 镜头数 | 判断标准 |
|------------|--------|----------|
| 核心 | 2镜 | 关键情节/情绪爆发点 |
| 重要 | 1-2镜 | 推动情节/展示人物 |
| 辅助 | 0-1镜 | 过渡/铺垫 |

### 2.2 情绪节点

情绪强度决定镜头类型和数量：

| 情绪强度 | 镜头策略 |
|----------|----------|
| 1-2（微弱/轻度） | 1镜远景/全景，建立氛围 |
| 3（中度） | 1镜中景，展示状态 |
| 4（强烈） | 1-2镜近景/特写，强化情绪 |
| 5（极强） | 2镜特写/大特写，情绪爆发 |

### 2.3 场景切换

场景变化时必须切分：

```
同一场景内 → 可用运镜连接
场景切换 → 必须新镜头
```

### 2.4 人物变化

新人物出场时考虑新镜头：

| 情况 | 处理方式 |
|------|----------|
| 新人物出场 | 新镜头（介绍镜头） |
| 多人物对话 | 按说话者切分 |
| 人物消失 | 可跳过或用空镜过渡 |

---

## 三、镜头分配策略

### 3.1 起承转合分配

```
起（1-2镜）：建立场景 + 引入人物
承（3-4镜）：发展情节 + 情绪铺垫
转（2-3镜）：冲突升级 + 情绪爆发
合（1-2镜）：收束/悬念
```

### 3.2 示例分析

原文：
```
烈日当空，李云弓着背，在焦灼的灵原上挥舞着一把冰冷的铁锄。
汗水顺着他的额头滑落，滴入干裂的泥土中，瞬间被干渴的大地吞噬。
远处，巍峨的主峰在云雾中若隐若现，那里是外门弟子梦寐以求的地方。
而李云，只是一个杂役弟子，日复一日地在灵原上劳作，期待着那渺茫的机缘。
"李云！你又在偷懒！"王师兄的声音从身后传来，带着几分轻蔑。
李云直起身，擦了擦额头的汗水，没有辩解。
王师兄走近，看到李云手中的铁锄，冷笑道："还在用这种凡铁？看来你这辈子注定是个杂役了。"
李云握紧铁锄，眼中闪过一丝不易察觉的锋芒。他体内那股奇异的力量，正在缓缓涌动...
```

### 3.3 切分过程

#### Step 1: 识别事件

| 序号 | 事件 | 阶段 | 情绪 | 强度 |
|------|------|------|------|------|
| 1 | 烈日下劳作 | 起 | 压抑 | 2 |
| 2 | 汗水滴落 | 起 | 压抑 | 2 |
| 3 | 远眺主峰 | 承 | 希望 | 2 |
| 4 | 王师兄指责 | 承 | 愤怒 | 3 |
| 5 | 李云隐忍 | 承 | 愤怒 | 3 |
| 6 | 王师兄嘲讽 | 转 | 愤怒 | 4 |
| 7 | 李云握锄 | 转 | 愤怒 | 4 |
| 8 | 力量涌动 | 合 | 爆发 | 5 |

#### Step 2: 合并相关事件

| 合并 | 原事件 | 理由 |
|------|--------|------|
| 镜头1 | 1+2 | 同一动作连续 |
| 镜头2 | 3 | 单独强调"远眺" |
| 镜头3 | 4 | 新人物出场 |
| 镜头4 | 5 | 李云反应 |
| 镜头5 | 6 | 王师兄特写 |
| 镜头6 | 7 | 李云特写 |
| 镜头7 | 8 | 力量爆发 |

#### Step 3: 调整镜头数（目标8镜）

当前7镜，需要增加1镜：
- 可将事件8拆分为两镜：握锄特写 + 眼神特写

最终镜头分配：

| 镜头 | 内容 | 景别 | 情绪 |
|------|------|------|------|
| 01 | 李云在烈日下挥锄 | 全景→中景 | 压抑 |
| 02 | 李云远眺主峰 | 中景→近景 | 希望 |
| 03 | 王师兄出现，指责 | 中景 | 愤怒 |
| 04 | 李云直身，擦汗 | 近景 | 隐忍 |
| 05 | 王师兄走近，嘲讽 | 近景 | 轻蔑 |
| 06 | 李云握紧铁锄 | 特写 | 愤怒 |
| 07 | 李云眼神特写 | 大特写 | 坚毅 |
| 08 | 体内力量涌动（特效） | 特写 | 爆发 |

## 四、镜头类型选择

### 4.1 景别选择

| 情境 | 推荐景别 | 理由 |
|------|----------|------|
| 场景建立 | 远景/全景 | 展示环境全貌 |
| 人物动作 | 全景/中景 | 展示完整动作 |
| 人物状态 | 中景/近景 | 展示表情和姿态 |
| 情绪特写 | 近景/特写 | 放大情绪细节 |
| 爆发点 | 特写/大特写 | 最大情绪冲击 |

### 4.2 运镜选择

| 情境 | 推荐运镜 | 理由 |
|------|----------|------|
| 场景建立 | 推进 | 引导观众进入 |
| 静态观察 | 固定 | 稳定、客观 |
| 紧张感 | 跟踪/摇镜 | 不稳定感 |
| 情绪递进 | 推进 | 放大情绪 |
| 释放/退场 | 拉远 | 拉开距离 |

### 4.3 角度选择

| 情境 | 推荐角度 | 理由 |
|------|----------|------|
| 正常视角 | 平视 | 客观、自然 |
| 弱势/压迫 | 俯视 | 压迫感 |
| 强势/威严 | 仰视 | 崇高感 |
| 不安/紧张 | 斜角 | 不稳定感 |

## 五、镜头调整规则

### 5.1 数量调整

| 情况 | 调整方式 |
|------|----------|
| 镜头过多(>12) | 合并相似事件，删减辅助事件 |
| 镜头过少(<6) | 拆分核心事件，增加反应镜头 |

### 5.2 节奏调整

| 问题 | 解决方案 |
|------|----------|
| 节奏太快 | 增加全景镜头，延长镜头时间 |
| 节奏太慢 | 增加特写镜头，缩短镜头时间 |
| 缺乏变化 | 调整景别组合，增加运镜变化 |

### 5.3 情绪调整

| 问题 | 解决方案 |
|------|----------|
| 情绪平淡 | 增加情绪节点，使用特写强化 |
| 情绪跳跃 | 增加过渡镜头，平滑情绪曲线 |

### 6.2 镜头详情输出

每个镜头需要输出：
- 镜头基本信息
- 人物动作描述
- 场景描述
- 情绪关键词
- 完整Prompt（参考分镜Prompt模板）
