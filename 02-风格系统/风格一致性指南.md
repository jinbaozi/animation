# 风格一致性指南

---

## 概述

本文档定义如何确保分镜间风格统一，避免同一作品中出现风格漂移。

---

## 一、风格一致性原则

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| 风格锁定 | 选定风格后，全程使用相同风格关键词 |
| 前缀统一 | 每镜Prompt开头使用相同风格前缀 |
| 禁止词一致 | 所有Prompt使用相同的禁止词列表 |
| 色调统一 | 保持相同的色调风格 |

### 1.2 一致性检查项

| 检查项 | 说明 |
|--------|------|
| 风格关键词 | 每镜是否包含核心风格关键词 |
| 色调描述 | 色调是否与选定风格一致 |
| 线条风格 | 是否保持相同的线条特征 |
| 光影风格 | 光影处理是否一致 |
| 禁止词 | 是否避免了风格禁止词 |

---

| 欧美卡通风格 | 鲜艳多彩 | 红黄蓝绿 | 灰暗色 |

## 六、禁止词一致性

### 6.1 使用方式

在Prompt中使用否定约束来避免风格漂移：

```
Negative prompt: [禁止词列表]
```

或在Prompt末尾添加：

```
, no [禁止词], no [禁止词]
```

### 6.2 各风格禁止词示例

**中国奇幻动漫-凌厉热血**：
```
, no soft edges, no cute style, no pastel colors, no watercolor effect
```

**中国仙侠唯美-水墨淡雅**：
```
, no sharp lines, no blood, no dark atmosphere, no mechanical elements
```

## 七、跨镜头检查清单

### 7.1 每镜检查项

```markdown
## 镜头风格检查清单

- [ ] 风格前缀是否正确
- [ ] 色调关键词是否包含
- [ ] 线条风格关键词是否包含
- [ ] 光影风格关键词是否包含
- [ ] 是否避免了禁止词
- [ ] 与上一镜风格是否一致
```

### 7.2 全局检查项

```markdown
## 全局风格一致性检查

- [ ] 所有镜头使用相同的风格前缀
- [ ] 所有镜头色调一致
- [ ] 所有镜头线条风格一致
- [ ] 所有镜头光影风格一致
- [ ] 无禁止词出现
```

## 八、常见风格漂移问题

### 8.1 问题类型

| 问题 | 表现 | 解决方案 |
|------|------|----------|
| 色调漂移 | 镜头间色调不一致 | 每镜添加色调关键词 |
| 线条漂移 | 线条风格不统一 | 每镜添加线条关键词 |
| 光影漂移 | 光影处理不一致 | 每镜添加光影关键词 |
| 细节缺失 | 后续镜头缺少风格词 | 使用风格前缀模板 |

### 8.2 修复方法

**问题Prompt**：
```
广角镜头，李云在灵原劳作，烈日当空...
```

**修复后**：
```
标题：中国奇幻动漫风格，线条凌厉，情感强烈，电影级3D渲染，虚幻引擎5，PBR材质，电影级CG品质。
广角镜头，平视，缓慢推进，时间：[0-3秒]，@图片1 弓着背，在烈日下挥舞着一把冰冷的铁锄。
焦灼的灵原背景，刺眼的阳光，高对比度的阴影，黄褐色调...
```
