# 三视图生成Prompt

---

## 概述

三视图（正面、侧面、背面）是确保角色一致性的关键参考图。本文档定义Gemini专用的三视图生成Prompt模板。

---

## 一、三视图概念

### 1.1 什么是三视图

```
正面图 | 侧面图 | 背面图
```

一张图片包含角色的三个视角，用于：
- 展示完整外观特征
- 作为后续生成的参考图
- 锁定角色设计

### 1.2 三视图用途

| 用途 | 说明 |
|------|------|
| 角色参考 | 后续生成时引用 `@图片1` |
| 特征锁定 | 确保发型、服装、配饰一致 |
| 多角度展示 | 满足不同镜头角度需求 |

---

## 二、Prompt模板

### 2.1 标准模板

#### 中文模板

```
[风格前缀]，[角色基础描述]，[角色外观详情]，[服装描述]，
正面|侧面|背面视角，三视图，角色参考图，一致性设计，高质量
```

### 2.2 模板组成

| 组成部分 | 说明 | 示例 |
|----------|------|------|
| 风格前缀 | 选定风格的核心关键词 | 中国奇幻动漫风格，线条凌厉 |
| 角色基础描述 | 年龄、性别、体型 | 18岁少年，瘦削体型 |
| 角色外观详情 | 头部、面部特征 | 黑色短发，丹凤眼，剑眉 |
| 服装描述 | 完整服装描述 | 灰色粗布长袍，灰色布裤 |
| 三视图指令 | 固定格式 | 正面|侧面|背面视角，三视图 |
| 质量关键词 | 固定格式 | 角色参考图，一致性设计，高质量 |

## 四、Prompt优化技巧

### 4.1 特征词顺序

**重要特征放前面**：
```
正确：黑色短发，丹凤眼...（头部特征在前）
错误：灰色布裤...服装描述在前
```

### 4.2 一致性关键词

在三视图Prompt中必须包含：

```
一致性设计，高质量，角色参考图
```

### 4.3 避免的词汇

| 避免 | 原因 | 替代 |
|------|------|------|
| "美丽"/"帅气" | 主观，AI理解不一 | 具体特征描述 |
| "普通人" | 模糊 | 具体描述或省略 |
| "好看" | 主观 | 具体特征描述 |

### 4.4 必须包含的信息

| 信息 | 重要性 | 说明 |
|------|--------|------|
| 年龄 | 高 | 决定整体外观 |
| 性别 | 高 | 决定身体特征 |
| 体型 | 高 | 决定身材轮廓 |
| 发型发色 | 高 | 最重要的识别特征 |
| 眼睛 | 高 | 第二重要的识别特征 |
| 服装 | 高 | 整体外观关键 |

## 五、生成与使用流程

### 5.1 生成流程

```
1. 根据人物卡信息填写Prompt模板
2. 复制Prompt到Gemini
3. 生成三视图
4. 保存图片作为角色参考图
```

### 5.2 使用流程

```
1. 在生成镜头图时，上传三视图
2. 在Prompt中引用 @图片1
3. AI会参考三视图生成一致的角色
```

### 5.3 引用示例

```
广角镜头，平视，缓慢推进，@图片1 弓着背，在烈日下挥舞着一把冰冷的铁锄...
```

## 七、特殊情况处理

### 7.1 角色状态变化

当角色外观发生变化时：

| 变化类型 | 处理方式 |
|----------|----------|
| 服装变化 | 更新版本，重新生成三视图 |
| 受伤/破损 | 在镜头Prompt中描述变化，无需重生成 |
| 变身/变形 | 视为新角色，生成新三视图 |

### 7.2 特殊视角需求

如果需要特殊视角（如仰视、俯视）：

1. 三视图仍为标准视角
2. 在镜头Prompt中指定视角
3. AI会根据三视图调整
