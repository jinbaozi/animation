# 人物卡模板

---

## 概述

人物卡是确保角色一致性的核心文档。本文档定义人物卡的标准结构和填写规范。

---

## 一、人物卡结构

### 1.1 完整模板

```markdown

## 基本信息

- **人物编号**：[如：人物1]

- **身份**：[主角/配角/反派/路人]
```

---

## 二、字段填写规范

### 2.1 基本信息

| 字段 | 填写规范 | 示例 |
|------|----------|------|
| 人物编号 | 按出场顺序编号 | 人物1、人物2 |
| 姓名 | 角色名称 | 李云 |
| 身份 | 主角/配角/反派/路人 | 主角 |
| 年龄 | 数字+岁 或 描述 | 18岁 / 少年 |
| 性别 | 男/女/其他 | 男 |

### 2.2 体型特征

| 字段 | 填写规范 | 示例 |
|------|----------|------|
| 身高 | 具体数值 或 相对描述 | 170cm / 中等偏高 / 比主角高一个头 |
| 体型 | 标准术语 | 瘦削/标准/健壮/肥胖/纤细/魁梧 |
| 肤色 | 标准描述 | 白皙/小麦色/古铜色/黝黑 |

### 2.3 头部特征

| 字段 | 填写规范 | 示例 |
|------|----------|------|
| 发型 | 发型名称 + 长度 | 短发/长发束起/披肩长发/寸头 |
| 发色 | 标准色名 | 黑色/棕色/金色/白色/红色 |
| 发饰 | 无/具体描述 | 无 / 红色发带/玉簪 |
| 眼睛 | 眼形+眼色+眼神 | 丹凤眼，黑色，坚毅的眼神 |
| 眉毛 | 眉形+眉色 | 剑眉，黑色 |

### 2.4 服装穿搭

| 字段 | 填写规范 | 示例 |
|------|----------|------|
| 上衣 | 款式+颜色+材质 | 灰色粗布长袍 |
| 下装 | 款式+颜色 | 黑色布裤 |
| 鞋子 | 款式+颜色 | 黑色布鞋 |
| 配饰 | 无/具体描述 | 无 / 腰间挂着玉佩 |
| 特殊标记 | 无/具体描述 | 无 / 额头有火焰印记 |

### 2.5 性格气质

| 字段 | 填写规范 | 示例 |
|------|----------|------|
| 核心性格 | 3-5个关键词 | 坚韧、隐忍、有野心 |
| 气质类型 | 单一描述 | 冷酷/温柔/傲慢/坚韧/阳光 |
| 说话方式 | 方式描述 | 简短有力/彬彬有礼 |
| 习惯动作 | 动作描述 | 握紧拳头/摸下巴 |

## 四、提及角色处理规范

### 4.1 提及角色定义

提及角色是指在小说中出现、对剧情有影响、但戏份较少的角色。

**判定标准**：
| 条件 | 是否建立人物卡 |
|------|----------------|
| 有台词、有形象描述 | ✅ 需要 |
| 仅被提及、无形象描述 | ❌ 不需要 |
| 剧情关键人物（如凶手） | ✅ 需要 |
| 背景路人 | ❌ 不需要 |

### 4.2 提及角色人物卡结构

提及角色的人物卡可以简化，但必须包含以下核心内容：

```markdown
### 人物卡：[角色名] @[编号]

#### 基本信息
- **编号**：@[编号]
- **姓名**：[角色名]
- **身份**：[身份]
- **年龄**：[年龄]
- **体型**：[体型]

#### 外貌特征
- **发型**：[发型描述]
- **面部**：[面部特征]
- **服装**：[主要服装]

#### 三视图Prompt
```
[风格前缀]，[年龄][性别]，[体型]，[肤色]，
[发型发色]，[面部特征]，
[服装描述]，
正面|侧面|背面视角，三视图，角色参考图，一致性设计，高质量
```
```

### 4.3 提及角色编号规则

| 编号范围 | 用途 |
|----------|------|
| @001-@010 | 主要角色 |
| @011-@050 | 次要角色 |
| @051-@100 | 提及角色 |

## 五、从小说提取人物信息

### 5.1 提取规则

| 提取方式 | 适用情况 |
|----------|----------|
| 直接提取 | 文本中有明确描述 |
| 推断提取 | 根据身份、行为推断 |
| 默认值 | 无任何信息时使用 |

### 5.2 推断规则

| 情况 | 推断 |
|------|------|
| 称"少年" | 年龄15-20岁 |
| 称"少女" | 年龄15-20岁 |
| 杂役身份 | 服装朴素 |
| 外门弟子 | 服装为弟子服 |
| 有体力劳动 | 体型不肥胖 |

### 5.3 默认值

| 字段 | 默认值 |
|------|--------|
| 发色 | 黑色（亚洲人） |
| 眼睛颜色 | 黑色 |
| 肤色 | 亚洲人肤色 |
| 体型 | 标准 |
