## 二、锁定词使用方法

### 2.1 基础使用

在每镜Prompt中包含：

```
@图片1 [动作描述]，[身体特征锁定词]，[服装锁定词]
```

**示例**：
```
@图片1 弓着背挥舞铁锄，瘦削体型，黑色短发，灰色粗布长袍
```

### 2.2 强化锁定

当角色容易漂移时，添加强化锁定词：

```
@图片1 [动作]，同一角色，一致设计，相同外观，
[特征1], [特征2], [特征3]
```

**示例**：
```
@图片1 弓着背挥舞铁锄，同一角色，一致设计，
黑色短发凌乱，坚毅眼神，灰色粗布长袍，瘦削体型
```

### 2.3 否定约束

添加否定词避免变化：

```
@图片1 [动作]，[特征锁定]，服装不变，发型不变
```

## 四、常见漂移问题与解决

### 4.1 发型漂移

**问题**：长发变短发，或发色变化

**解决**：
```
添加：黑短发（不变）或 黑长发（不变）
强化：发型不变，发色不变
```

### 4.2 服装漂移

**问题**：服装颜色或款式变化

**解决**：
```
添加：灰色粗布长袍（具体描述）
强化：服装不变，颜色不变
```

### 4.3 体型漂移

**问题**：瘦削变健壮

**解决**：
```
添加：瘦削体型，纤细身材
强化：保持体型
```

### 4.4 面部漂移

**问题**：面部特征不一致

**解决**：
```
添加：丹凤眼，面部轮廓分明
强化：面部一致，相同面部特征
```

## 八、精简表达使用指南

### 8.1 何时使用精简表达

| 场景 | 建议使用 | 说明 |
|------|----------|------|
| Token限制紧张时 | 强烈推荐 | 有效节省Prompt长度 |
| 多角色场景 | 推荐 | 减少角色描述冲突 |
| 快速迭代测试 | 推荐 | 简洁便于修改 |
| 最终渲染输出 | 可选完整表达 | 确保细节完整 |
| 新角色首次出现 | 完整表达优先 | 建立清晰基准 |

### 8.2 精简表达优先级

| 优先级 | 精简内容 | 节省效果 | 使用建议 |
|--------|----------|----------|----------|
| 1 | 风格词汇 | 高（5-8字） | 每镜必用 |
| 2 | 体型特征 | 中（6字） | 角色首次后可用 |
| 3 | 头部特征 | 中（5字） | 熟悉角色后可用 |
| 4 | 眼睛特征 | 低（4-5字） | 眼神关键场景保留完整 |
| 5 | 服装特征 | 中（5-6字） | 换装场景保留完整 |

### 8.3 注意事项

1. **首次出现使用完整表达**：角色首次登场时使用完整表达建立清晰特征基准，后续镜次可逐步精简。

2. **关键场景保留完整**：特写镜头、情绪变化等重要场景建议保留完整表达，确保细节准确。

3. **避免过度精简**：精简表达应保留核心识别特征，过度精简可能导致角色漂移。

4. **版本迭代更新**：根据实际生成效果持续优化精简词表，记录有效的精简表达。
