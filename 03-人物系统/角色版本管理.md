# 角色版本管理

---

## 概述

在故事发展过程中，角色外观可能发生变化（服装变化、受伤、变身等）。本文档定义如何追踪和管理这些变化。

---

## 一、版本定义

### 1.1 什么情况需要新版本

| 变化类型 | 是否需要新版本 | 说明 |
|----------|----------------|------|
| 服装完全更换 | 是 | 如：换装、换季节衣物 |
| 服装局部破损 | 否 | 在Prompt中描述即可 |
| 受伤/血迹 | 否 | 在Prompt中描述即可 |
| 发型变化 | 是 | 如：剪发、染色 |
| 变身/形态变化 | 是 | 视为新角色处理 |
| 年龄成长 | 是 | 时间跨度大的情况 |
| 配饰变化 | 视情况 | 重要配饰变化需要 |

### 1.2 版本命名规则

```
v[主版本].[次版本]

主版本：重大外观变化
次版本：小变化（如服装破损程度）
```

**示例**：
```
v1.0 - 初始状态
v1.1 - 服装轻微破损
v1.2 - 服装严重破损
v2.0 - 换装（新服装）
```

## 四、跨镜头状态继承

### 4.1 状态继承规则

```
镜头N的状态 = 镜头N-1的状态 + 本镜头的变化
```

### 4.2 状态继承表

```markdown
## 状态继承表

| 镜头 | 服装状态 | 面部状态 | 配饰状态 | 变化说明 |
|------|----------|----------|----------|----------|
| 01 | 完整 | 干净 | 无 | 初始 |
| 02 | 完整 | 汗水 | 无 | 劳作中 |
| 03 | 完整 | 汗水+污垢 | 无 | 继续 |
| 04 | 沾尘土 | 汗水+污垢 | 无 | 变化 |
| 05 | 沾尘土 | 汗水+污垢 | 无 | 继承 |
| 06 | 轻微破损 | 汗水+污垢 | 无 | 变化 |
| 07 | 严重破损 | 伤痕+血迹 | 无 | 战斗 |
| 08 | 严重破损 | 伤痕+血迹 | 无 | 继承 |
```

### 4.3 状态变化触发词

| 变化类型 | 触发词 |
|----------|--------|
| 服装破损 | 战斗、摔倒、被击中、穿越丛林 |
| 面部损伤 | 被打、跌倒、战斗 |
| 服装沾污 | 劳作、爬行、泥地、雨水 |
| 服装换新 | 晋升、换装、时间跳跃 |

## 六、版本更新流程

### 6.1 判断是否需要更新

```
1. 检查本镜头是否有状态变化
2. 判断变化程度（轻微/重大）
3. 轻微变化 → 更新Prompt描述，不更新版本号
4. 重大变化 → 更新版本号，考虑重新生成三视图
```

### 6.2 更新步骤

```markdown
## 版本更新步骤

### 步骤1：记录变化
在状态继承表中记录本镜头的状态变化

### 步骤2：更新Prompt
在镜头Prompt中添加状态描述

### 步骤3：判断是否需要新三视图
- 服装完全更换 → 需要
- 发型变化 → 需要
- 其他轻微变化 → 不需要

### 步骤4：更新版本追踪表
如有重大变化，更新版本追踪表
```

## 八、特殊情况处理

### 8.1 快速连续变化

当镜头间状态快速变化时：

| 情况 | 处理方式 |
|------|----------|
| 变化太频繁 | 合并变化，减少版本数 |
| 变化不明显 | 保持上一状态 |
| 变化对剧情重要 | 单独记录 |

### 8.2 闪回/回忆

当出现闪回时：

```markdown
## 闪回处理

| 镜头 | 类型 | 角色状态 | 版本 |
|------|------|----------|------|
| 05 | 正常 | 李云 v1.1 | 当前 |
| 06-08 | 闪回 | 李云 v0.0 | 过去 |
| 09 | 正常 | 李云 v1.1 | 当前 |

**处理方式**：
- 闪回使用旧版本或单独版本
- 清晰标注闪回镜头
- 闪回结束后回到当前版本
```

### 8.3 多时间线

当存在多条时间线时：

```markdown
## 多时间线版本管理

| 时间线 | 版本前缀 | 说明 |
|--------|----------|------|
| 主时间线 | v1.x | 当前故事 |
| 过去时间线 | v0.x | 回忆/闪回 |
| 未来时间线 | v2.x | 预言/梦境 |
```
