# 全景生成Prompt

---

## 概述

全景图是确保场景一致性的关键参考图。本文档定义Gemini专用的全景生成Prompt模板。

---

## 一、全景图概念

### 1.1 什么是全景图

```
全景图 = 展示完整场景的广角视角图
```

用途：
- 作为场景参考图
- 锁定场景中的关键元素
- 确保后续镜头场景一致

### 1.2 全景图用途

| 用途 | 说明 |
|------|------|
| 场景参考 | 后续生成时引用场景特征 |
| 元素锁定 | 确保场景元素位置一致 |
| 氛围基调 | 确定场景整体氛围 |
| 多角度基础 | 为不同镜头角度提供参考 |

---

## 二、Prompt模板

### 2.1 标准模板

```
[风格前缀]，[场景类型]，[主要元素描述]，[空间布局]，
[时间光影]，[配色氛围]，全景视角，场景参考图，高质量
```

### 2.2 模板组成

| 组成部分 | 说明 | 示例 |
|----------|------|------|
| 风格前缀 | 选定风格的核心关键词 | 中国奇幻动漫风格，线条凌厉 |
| 场景类型 | 场景的基本类型 | 开阔的灵原，山门广场 |
| 主要元素描述 | 前中后景元素 | 干裂土地，灵草，主峰 |
| 空间布局 | 元素的空间关系 | 前景...中景...背景... |
| 时间光影 | 时间和光影效果 | 正午阳光，高对比 |
| 配色氛围 | 色调和氛围 | 黄褐色调，压抑氛围 |
| 全景指令 | 固定格式 | 全景视角，场景参考图 |

## 四、Prompt优化技巧

### 4.1 元素层次

**按照前-中-后景顺序描述**：

```
正确：前景是...，中景是...，背景是...
错误：主峰在远处，土地在前方...
```

### 4.2 一致性关键词

在全景Prompt中必须包含：

```
全景视角，场景参考图，高质量
```

### 4.3 空间关系关键词

| 关键词 | 说明 |
|--------|------|
| 延伸至远方 | 表示深度 |
| 高楼林立 | 表示密集 |
| 开阔的 | 表示宽敞 |
| 巍峨的 | 表示高度 |

### 4.4 必须包含的信息

| 信息 | 重要性 | 说明 |
|------|--------|------|
| 场景类型 | 高 | 决定整体基调 |
| 主要元素 | 高 | 场景特征 |
| 空间布局 | 高 | 元素位置关系 |
| 时间光影 | 高 | 氛围关键 |
| 配色氛围 | 高 | 视觉统一 |

## 六、生成与使用流程

### 6.1 生成流程

```
1. 根据场景卡信息填写Prompt模板
2. 复制Prompt到Gemini
3. 生成全景图
4. 保存图片作为场景参考图
```

### 6.2 使用流程

```
1. 在生成镜头图时，记住场景元素位置
2. 在Prompt中描述场景时，保持元素一致性
3. 保持光影、配色与全景一致
```

### 6.3 多场景管理

| 场景 | 场景卡 | 备注 |
|------|--------|------|
| 场景A | 灵原 | 主场景 |
| 场景B | 主峰 | 次场景 |

## 七、时间变化处理

### 7.1 时间变化类型

| 变化类型 | 光影变化 | Prompt调整 |
|----------|----------|------------|
| 早晨→正午 | 柔和→强烈 | 调整光源描述 |
| 正午→黄昏 | 顶光→侧光 | 调整光源方向和色温 |
| 白天→夜晚 | 自然光→人工光 | 完全重新描述 |

### 7.2 时间变化Prompt示例

**正午**：
```
烈日当空，刺眼的阳光，高对比度阴影...
```

**黄昏**：
```
夕阳西下，金红色光芒，长长的影子，温暖色调...
```

**夜晚**：
```
月光如水，冷色调光源，朦胧光影，星空...
```

## 八、常见问题与解决

### 8.1 场景过于空旷

**问题**：生成的场景缺乏细节

**解决**：
```
添加更多元素描述：
前景是...，中景是...，背景是...
添加装饰元素：石头，草，云，鸟...
```

### 8.2 场景元素位置漂移

**问题**：不同镜头中元素位置不一致

**解决**：
```
使用视觉锚点：锁定核心元素位置
在每镜Prompt中重复元素位置描述
```

### 8.3 氛围不匹配

**问题**：场景氛围与故事不符

**解决**：
```
添加氛围关键词：压抑/温馨/神秘...
添加情绪关键词：绝望/希望/恐惧...
```
