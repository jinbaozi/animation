# 时间光影变化指南

---

## 概述

本文档定义如何追踪和处理跨镜头的时间变化和光影变化，确保场景的时间连续性和光影一致性。

---

## 一、时间变化类型

### 1.1 时间段划分

| 时间段 | 光影特征 | 色温 |
|--------|----------|------|
| 黎明 | 柔和，低对比 | 冷→暖 |
| 早晨 | 柔和，侧光 | 暖色 |
| 正午 | 强烈，顶光 | 中性/暖 |
| 下午 | 中等，侧光 | 暖色 |
| 黄昏 | 柔和，低角度光 | 暖色（金黄/橙红） |
| 夜晚 | 微弱，月光/人工光 | 冷色 |

### 1.2 时间变化方式

| 变化方式 | 说明 | 处理方式 |
|----------|------|----------|
| 逐渐变化 | 时间自然流逝 | 渐变调整光影 |
| 时间跳跃 | 剧情需要跳时间 | 重新设置光影 |
| 闪回 | 回忆过去 | 标注时间变化 |

## 三、光影变化规则

### 3.1 同一时间段内

```
规则：光影保持一致，仅在角度微调

变化范围：
- 光源方向：±15度
- 光影强度：±10%
- 色温：±5%
```

### 3.2 跨时间段变化

```
规则：随时间逐步变化

变化幅度：
- 每30分钟：光源方向变化约15度
- 每30分钟：色温渐变
- 正午→黄昏：约6小时，大幅变化
```

### 3.3 时间跳跃

```
规则：重新设置光影

处理方式：
1. 明确标注时间跳跃
2. 设置新的光影参数
3. 保持场景其他元素一致
```

## 四、各时间段光影描述

### 4.1 黎明（5:00-7:00）

**光影特征**：
- 光源：东侧，低角度
- 强度：弱→中
- 色温：冷→暖（蓝→金黄）
- 阴影：长，柔和

**Prompt关键词**：
```
中文：黎明，柔和的晨光，东方泛白，金色光芒穿透云层
English: dawn, soft morning light, eastern sky brightening, golden rays through clouds
```

### 4.2 早晨（7:00-10:00）

**光影特征**：
- 光源：东侧，中等角度
- 强度：中等
- 色温：暖色（金黄）
- 阴影：中等长度，清晰

**Prompt关键词**：
```
中文：早晨，温暖的阳光，侧光，中等对比
English: morning, warm sunlight, side lighting, moderate contrast
```

### 4.3 正午（10:00-14:00）

**光影特征**：
- 光源：顶部
- 强度：强
- 色温：中性/暖（白/黄）
- 阴影：短，强对比

**Prompt关键词**：
```
中文：正午，烈日当空，顶光，高对比度阴影
English: noon, scorching sun overhead, top lighting, high contrast shadows
```

### 4.4 下午（14:00-17:00）

**光影特征**：
- 光源：西侧，中等角度
- 强度：中等
- 色温：暖色（金黄）
- 阴影：中等长度

**Prompt关键词**：
```
中文：下午，斜阳，侧光，温暖色调
English: afternoon, slanting sunlight, side lighting, warm tones
```

### 4.5 黄昏（17:00-19:00）

**光影特征**：
- 光源：西侧，低角度
- 强度：弱→微弱
- 色温：暖色（橙红）
- 阴影：长，柔和

**Prompt关键词**：
```
中文：黄昏，夕阳西下，金红色光芒，长长的影子
English: dusk, sunset, golden-red glow, long shadows
```

### 4.6 夜晚（19:00-5:00）

**光影特征**：
- 光源：月光/星光/人工光
- 强度：弱
- 色温：冷色（蓝）
- 阴影：柔和，朦胧

**Prompt关键词**：
```
中文：夜晚，月光如水，冷色调，朦胧光影
English: night, moonlight like water, cool tones, hazy lighting
```

| 天气 | 光影特征 | Prompt关键词 |
|------|----------|--------------|
| 晴天 | 强光，高对比 | bright sunlight, high contrast |
| 多云 | 柔光，低对比 | overcast, soft diffused light |
| 阴天 | 弱光，极低对比 | cloudy, dim light |

## 八、跨镜头光影一致性检查

### 8.1 检查清单

```markdown
## 光影一致性检查清单

- [ ] 时间段是否一致或合理变化
- [ ] 光源方向是否一致
- [ ] 光影强度是否一致
- [ ] 色温是否一致
- [ ] 阴影方向是否合理
- [ ] 天气是否一致
```

### 8.2 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 光源方向跳变 | 未追踪时间 | 建立时间线追踪 |
| 阴影方向错误 | 忽略光源方向 | 确定光源位置 |
| 色温不一致 | 未考虑时间段 | 统一色温描述 |
