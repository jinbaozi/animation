# 视觉锚点规范

---

## 概述

视觉锚点是场景中不可变化的核心元素，用于锁定场景识别和确保跨镜头一致性。

---

## 一、视觉锚点定义

### 1.1 什么是视觉锚点

```
视觉锚点 = 场景中位置固定、外观固定的核心元素
```

### 1.2 锚点作用

| 作用 | 说明 |
|------|------|
| 场景识别 | 通过锚点快速识别场景 |
| 位置定位 | 为其他元素提供位置参考 |
| 一致性保障 | 跨镜头保持场景一致 |
| 氛围营造 | 核心元素定调氛围 |

---

## 二、锚点分类

### 2.1 核心锚点

**定义**：场景中最具识别度、不可变化的元素

| 场景类型 | 核心锚点示例 |
|----------|--------------|
| 山景 | 主峰、特殊山形 |
| 建筑 | 标志性建筑、塔楼 |
| 广场 | 中央雕塑、喷泉 |
| 室内 | 主家具、门窗位置 |
| 城市 | 标志性建筑、塔楼 |

### 2.2 辅助锚点

**定义**：帮助定位、增强识别的次要元素

| 场景类型 | 辅助锚点示例 |
|----------|--------------|
| 山景 | 特殊岩石、古树 |
| 建筑 | 装饰、灯具 |
| 广场 | 石柱、台阶 |
| 室内 | 挂画、摆设 |
| 城市 | 广告牌、路灯 |

## 四、锚点位置规范

### 4.1 位置描述方式

| 描述方式 | 说明 | 示例 |
|----------|------|------|
| 景别位置 | 前/中/背景 | 背景中央 |
| 方向位置 | 东南西北 | 北侧 |
| 相对位置 | 相对于其他元素 | 主峰右侧 |
| 画面位置 | 画面区域 | 左上角 |

### 4.2 位置固定规则

```
核心锚点：位置必须固定，不允许变化
辅助锚点：位置基本固定，可微调
```

## 五、锚点外观规范

### 5.1 外观描述要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 形状 | 整体形态 | 三角形山峰 |
| 颜色 | 主色调 | 雪白色 |
| 质感 | 材质特征 | 粗糙岩石 |
| 特征 | 独特之处 | 云雾缭绕 |

### 5.2 外观固定规则

```
核心锚点：外观必须固定，不允许变化
辅助锚点：外观基本固定，可受光影影响
```

## 六、锚点一致性检查

### 6.1 每镜检查清单

```markdown
## 锚点一致性检查清单

- [ ] 核心锚点位置是否正确
- [ ] 核心锚点外观是否一致
- [ ] 辅助锚点位置是否大致正确
- [ ] 辅助锚点外观是否一致
- [ ] 锚点与人物位置关系是否合理
```

### 6.2 检查方法

**位置检查**：
```
对比各镜头中锚点的位置是否一致
核心锚点应始终在相同位置
```

**外观检查**：
```
对比各镜头中锚点的外观是否一致
除光影变化外，外观应保持不变
```

## 七、锚点与镜头角度

### 7.1 不同角度的锚点可见性

| 镜头角度 | 核心锚点可见性 | 处理方式 |
|----------|----------------|----------|
| 远景/全景 | 全部可见 | 正常描述 |
| 中景 | 部分可见 | 描述可见部分 |
| 近景/特写 | 可能不可见 | 如有锚点，确保一致 |
| 仰视 | 背景锚点变化 | 调整位置描述 |
| 俯视 | 背景锚点变化 | 调整位置描述 |

### 7.2 角度变化处理

**远景→近景**：
```
远景：主峰在背景中央
近景：主峰可能不出镜，如出镜需保持位置正确
```

**仰视**：
```
正常视角：主峰在背景
仰视：主峰在上方，天空更多
```

## 八、锚点在Prompt中的应用

### 8.1 Prompt中的锚点描述

在镜头Prompt中包含锚点：

```
广角镜头，平视，@图片1 [人物动作]，
[场景描述包含锚点]...
```

**示例**：
```
广角镜头，平视，@图片1 弓着背挥舞铁锄，
焦灼的灵原，干裂的土地，远处是雪白的主峰云雾缭绕...
```

|--------|----------|
| 1 | 核心锚点（必须描述） |

| 3 | 其他元素（可选） |

3. 确保新场景锚点一致性

## 十、常见问题与解决

### 10.1 锚点位置漂移

**问题**：不同镜头中锚点位置不一致

**解决**：
```
1. 在每镜Prompt中重复锚点位置描述
2. 使用固定位置词：背景中央、左侧等
3. 检查镜头角度变化
```

### 10.2 锚点外观变化

**问题**：锚点外观在不同镜头中变化

**解决**：
```
1. 固定锚点外观描述词
2. 仅允许光影变化
3. 使用一致的形容词
```

### 10.3 锚点缺失

**问题**：镜头中锚点未出现

**解决**：
```
1. 检查镜头角度是否允许锚点出现
2. 如角度不允许，可不描述
3. 如角度允许但缺失，在Prompt中补充
```
