# Prompt压缩策略

---

## 概述

本文档定义Prompt字数控制与智能压缩策略，确保在AI绘图平台（如Midjourney、Gemini等）的字数限制内，最大化保留关键信息，实现高质量图像生成。

---

## 一、P0-P5重要性分层排序

### 1.1 分层原则

Prompt元素按重要性分为6个层级，P0最重要（不可删除），P5最不重要（可优先删除）。

### 1.2 分层详解

| 层级 | 重要性 | 元素类型 | 具体内容 | 删除建议 |
|------|--------|----------|----------|----------|
| P0 | 不可删除 | 核心要素 | 风格前缀、人物引用、核心动作、参数 | 永不删除 |
| P1 | 最高优先 | 人物特征 | 发型发色、眼睛特征、服装颜色、色调 | 仅在极端情况下删减 |
| P2 | 高优先 | 形象特征 | 体型、表情、背景锚点、主光源 | 字数紧张时精简表述 |
| P3 | 中优先 | 场景细节 | 姿态、中景元素、阴影强度、质量词 | 可适当精简 |
| P4 | 低优先 | 氛围细节 | 前景细节、材质质感、氛围修饰词 | 字数超标时优先删除 |
| P5 | 可删除 | 冗余内容 | 冗余形容词、重复描述、可选细节 | 优先删除 |

### 1.3 分层可视化

```
P0 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 不可删除
    风格前缀 | 人物引用 | 核心动作 | 参数

P1 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 极端情况删减
    发型发色 | 眼睛特征 | 服装颜色 | 色调

P2 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 字数紧张时精简
    体型 | 表情 | 背景锚点 | 主光源

P3 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 可适当精简
    姿态 | 中景元素 | 阴影强度 | 质量词

P4 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 优先删除
    前景细节 | 材质感 | 氛围修饰词

P5 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 优先删除
    冗余形容词 | 重复描述 | 可选细节
```

## 二、智能压缩策略矩阵

### 2.1 策略总览

| 策略 | 压缩效果 | 适用场景 | 风险等级 |
|------|----------|----------|----------|
| 同义词替换 | 10-20% | 所有场景 | 低 |
| 省略连接词 | 5-10% | 中英文混合 | 低 |
| 合并相似描述 | 10-15% | 有重复描述时 | 低 |
| 删除低优先词 | 15-25% | 字数超标时 | 中 |
| 缩写技术术语 | 5-10% | 技术类描述 | 低 |

### 2.2 策略详解

#### 策略1：同义词替换

**原理**：用更短的词汇替换长词汇

| 原词 | 替换词 | 节省字数 |
|------|--------|----------|
| 电影级3D渲染 | cinematic 3D | 4字 |
| 虚幻引擎5 | UE5 | 3字 |
| 高对比度的锐利阴影 | sharp shadows | 5字 |
| 柔和的渐变阴影 | soft shadows | 4字 |
| 极其详细的细节 | detailed | 5字 |

**示例**：

```
压缩前：
中国奇幻动漫风格，线条凌厉，情感强烈，电影级3D渲染，虚幻引擎5，PBR材质，电影级CG品质
（38字）

压缩后：
中国奇幻动漫风格，凌厉线条，情感强烈，cinematic 3D，UE5，PBR，CG quality
（32字，节省6字）
```

#### 策略2：省略连接词

**原理**：删除"和"、"以及"、"与"等连接词，使用逗号分隔

| 原表述 | 压缩后 | 节省字数 |
|--------|--------|----------|
| 黑色短发和凌乱的发型 | 黑色短发，凌乱 | 3字 |
| 瘦削体型以及消瘦的面容 | 瘦削体型，消瘦面容 | 2字 |
| 前景是土地和中景是草丛 | 前景土地，中景草丛 | 5字 |

**示例**：

```
压缩前：
前景是干裂的土地和枯萎的灵草，中景是散落的红色火焰石，以及背景是远处主峰雪白的峰顶
（40字）

压缩后：
前景干裂土地，枯萎灵草，中景红色火焰石，背景远山雪白峰顶
（26字，节省14字）
```

#### 策略3：合并相似描述

**原理**：将意思相近的描述合并为单一表述

| 原描述 | 合并后 | 节省字数 |
|--------|--------|----------|
| 瘦削体型 + 消瘦身材 | slim build | 5字 |
| 眼神坚毅 + 目光坚定 | determined gaze | 4字 |
| 破旧不堪 + 有补丁 | worn, patched | 4字 |
| 酷热难耐 + 高温炎热 | scorching heat | 5字 |

**示例**：

```
压缩前：
瘦削体型，消瘦身材，黑色短发，凌乱的发型，灰色粗布长袍，破旧不堪，有补丁
（33字）

压缩后：
slim build，黑色短发凌乱，灰色粗布长袍破旧带补丁
（22字，节省11字）
```

#### 策略4：删除低优先词

**原理**：按照P0-P5分层，优先删除P4/P5层级词汇

| 删除层级 | 预期节省 | 示例删除词 |
|----------|----------|------------|
| P5 | 10-15% | "非常"、"极其"、"相当" |
| P4 | 15-20% | "空气中弥漫着"、"隐约可见" |
| P3 | 20-25% | 部分氛围描述、次要光影 |

**示例**：

```
压缩前（98字）：
中国奇幻动漫风格，线条凌厉，情感强烈，电影级3D渲染，虚幻引擎5，PBR材质，电影级CG品质。
全景镜头，平视，缓慢推进。@图片1 李云，瘦削体型，黑色短发凌乱，灰色粗布长袍破旧不堪，神情疲惫但眼神坚毅，弓着背站立。
在烈日下挥舞着一把冰冷的铁锄，用力砸向坚硬的土地，汗水顺着脸颊滑落。
前景是干裂的土地和枯萎的灵草，中景是散落的红色火焰石，背景是远处主峰雪白的峰顶云雾缭绕。
酷热难耐的氛围，空气中热浪扭曲。

压缩后（72字，节省26字）：
中国奇幻动漫风格，凌厉线条，cinematic 3D，UE5。
全景，平视，推进。@图片1 李云，slim build，黑发凌乱，灰袍破旧，疲惫坚毅。
挥铁锄砸地，汗滴脸颊。
前景干裂土地，中景火焰石，背景远峰云绕。
酷热，热浪扭曲。
```

#### 策略5：缩写技术术语

**原理**：使用行业通用缩写

| 原术语 | 缩写 | 节省字数 |
|--------|------|----------|
| Unreal Engine 5 | UE5 | 12字符 |
| Physical Based Rendering | PBR | 20字符 |
| High Definition | HD | 12字符 |
| Close-up Shot | CU | 8字符 |
| Extreme Wide Shot | EWS | 14字符 |
| Medium Shot | MS | 8字符 |

## 三、字数控制技巧

### 3.1 字数预估公式

```
预估字数 = 风格前缀(30-40) + 镜头语言(10-15) + 人物描述(40-60) +
           动作环境(30-50) + 光影材质(20-30) + 风格渲染(15-25) + 参数(20-25)

预估范围：165-245字（中文）
```

### 3.2 压缩优先级决策树

```
开始
  │
  ├─ 当前字数 > 410字？
  │   │
  │   ├─ 是 → 删除P5层级词汇
  │   │       │
  │   │       ├─ 仍 > 410字？→ 删除P4层级词汇
  │   │       │                 │
  │   │       │                 ├─ 仍 > 410字？→ 精简P3层级词汇
  │   │       │                 │                 │
  │   │       │                 │                 ├─ 仍 > 410字？→ 精简P2层级词汇
  │   │       │                 │                 │                 │
  │   │       │                 │                 │                 └─ 输出警告：核心信息已最小化
  │   │       │                 │                 │
  │   │       │                 │                 └─ 输出压缩版
  │   │       │                 │
  │   │       │                 └─ 输出压缩版
  │   │       │
  │   │       └─ 输出压缩版
  │   │
  │   └─ 否 → 检查信息完整性
  │            │
  │            ├─ P0完整？→ 输出原版
  │            │
  │            └─ P0不完整 → 补充核心信息
  │
  └─ 结束
```

## 四、压缩流程

### 4.1 标准压缩流程

```
输入：完整版Prompt（无字数限制）
        │
        ▼
┌─────────────────────────────────┐
│ 步骤1：计算当前字数              │
│ 统计中文字数或英文字符数          │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│ 步骤2：识别P4/P5层级词汇         │
│ 标记可删除/可精简的词汇           │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│ 步骤3：按策略逐层压缩            │
│ 同义词替换 → 省略连接词 →        │
│ 合并相似 → 删除低优先 → 缩写术语  │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│ 步骤4：校验字数是否达标          │
│ 目标：≤410字（中文）             │
│      ≤500字符（英文）            │
└─────────────────────────────────┘
        │
        ├─ 达标 → 输出压缩版
        │
        └─ 未达标 → 返回步骤3，删除更高优先级词汇
```

### 4.2 流程实例演示

**原始Prompt（156字）**：

```
【段落1-镜头语言】
中国奇幻动漫风格，线条凌厉，情感强烈，电影级3D渲染，虚幻引擎5，PBR材质，电影级CG品质
全景镜头，平视，缓慢推进

【段落2-主体描述】
@图片1 李云，瘦削体型，黑色短发凌乱，灰色粗布长袍破旧不堪，神情疲惫但眼神坚毅，弓着背站立

【段落3-动作与环境】
在烈日下挥舞着一把冰冷的铁锄，用力砸向坚硬的土地。前景是干裂的土地和枯萎的灵草，中景是散落的红色火焰石，背景是远处主峰雪白的峰顶云雾缭绕。酷热难耐的氛围。

【段落4-光影与材质】
烈日当空，刺眼的阳光直射，高对比度的锐利阴影，粗糙的麻布和干裂土地质感。

【段落5-风格渲染】
中国奇幻动漫风格，凌厉热血，电影级CG品质，高细节。
--ar 16:9 --v 6 --style raw --s 300
```

**压缩步骤**：

| 步骤 | 操作 | 节省字数 | 当前字数 |
|------|------|----------|----------|
| 初始 | - | - | 156 |
| 1 | 同义词替换 | 6字 | 150 |
| 2 | 省略连接词 | 8字 | 142 |
| 3 | 合并相似描述 | 10字 | 132 |
| 4 | 删除P5层级 | 15字 | 117 |
| 5 | 删除P4层级 | 20字 | 97 |
| 6 | 缩写技术术语 | 5字 | 92 |

**压缩后Prompt（92字）**：

```
中国奇幻动漫风格，凌厉线条，cinematic 3D，UE5，PBR。
全景，平视，推进。@图片1 李云，slim build，黑发凌乱，灰袍破旧，疲惫坚毅，弓背站立。
挥铁锄砸地。前景干裂土地，中景火焰石，背景远峰云绕。酷热氛围。
烈日刺眼，锐利阴影，粗麻布质感。
凌厉热血，CG品质。
--ar 16:9 --v 6 --style raw --s 300
```
