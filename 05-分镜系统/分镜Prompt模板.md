# 分镜Prompt模板

---

## 概述

本文档定义每个分镜的完整Prompt模板，采用标准五段式结构。

**核心规范**：
- 每个分镜Prompt字数范围：**250-400字**（不含参数行）
- 每个分镜时长：**固定3秒**

---

## 一、Prompt结构

### 1.1 五段式结构（标准版）

```
【段落1-镜头语言】
[风格前缀]
[景别]，[角度]，[运镜] [起始-结束s]

【段落2-主体描述】
@编号-人物名，特征描述，[外貌]，[服装]，[表情]，[姿态]

【段落3-动作与环境】
[动作描述]，[环境细节]，[氛围描述] @场景编号-场景名称

【段落4-光影与材质】
[主光源]，[辅助光]，[阴影]，[材质描述]

【段落5-风格渲染】
[动漫主风格]，[子风格]，[质量词]
--ar 16:9 --v 6 --style raw --s 300
```

### 1.2 简化结构（快速版）

适用于快速原型或简单场景：

```
[风格前缀]
[镜头信息]，@编号-人物名，特征描述，[人物动作]，[角色特征锁定]
[场景描述]，[光影氛围]
```

## 三、五段式详解

### 3.1 段落1：镜头语言

#### 时间标注说明

时间标注格式：`[起始-结束s]`，表示镜头在视频中的时间范围。

**重要规范**：每个分镜固定3秒时长，确保节奏统一。

**示例**：
- `[0-3s]` - 第0秒到第3秒（第1镜）
- `[3-6s]` - 第3秒到第6秒（第2镜）
- `[6-9s]` - 第6秒到第9秒（第3镜）

时间标注放在运镜之后，用于标识镜头时长，便于后期剪辑和时间轴管理。

### 3.2 段落2：主体描述

#### 人物引用格式

```
格式：@编号-人物名，特征描述
示例：@001-李云，瘦削体型，黑短发凌乱，灰袍
```

**格式说明**：
- `@编号`：人物基准图编号（如 @001、@002）
- `人物名`：角色名称
- `特征描述`：该人物的核心视觉特征，用于锁定角色一致性

### 3.3 段落3：动作与环境

#### 动作描述结构

```
[主要动作] + [动作细节] + [动作目的/状态]
```

**示例**：
- 挥舞着一把冰冷的铁锄，用力砸向坚硬的土地，汗水顺着脸颊滑落

#### 环境描述结构

```
前景 → 中景 → 背景
```

**示例**：
- 前景是干裂的土地和枯萎的灵草，中景是散落的红色火焰石，背景是远处主峰雪白的峰顶

#### 氛围描述

| 氛围类型 | 中文 |
|----------|------|
| 压抑 | 酷热难耐的氛围 |
| 紧张 | 紧绷的对峙氛围 |
| 宁静 | 宁静祥和的氛围 |
| 神秘 | 神秘莫测的氛围 |

#### 场景引用规范

**格式**：`@场景编号-场景名称`

**示例**：
- `@S01-汀兰水榭闺房` - 内景闺房
- `@S02-汀兰水榭庭院` - 外景庭院
- `@S03-荷花池` - 回忆场景

**使用规则**：
1. 每个分镜Prompt必须在环境描述后添加场景引用
2. 跨场景镜头需标注所有涉及场景
3. 场景引用确保画面元素一致性

**完整示例**：
```
藕荷色纱帐轻飘，海棠刺绣精致，鎏金帐钩闪耀 @S01-汀兰水榭闺房
```
