---

## 概述

分镜表是AI漫剧的核心输出文档。本文档定义分镜表的标准结构和填写规范。

## 二、字段定义

### 2.1 镜头号

```
格式：01, 02, 03...（两位数字）
```

### 2.2 时间

```
格式：[开始秒]-[结束秒]
示例：0-3秒

重要规范：每个分镜固定3秒时长，确保节奏统一
标准间隔：[0-3s] → [3-6s] → [6-9s] → [9-12s] ...
```

### 2.3 景别

| 景别 | 说明 | 适用场景 |
|------|------|----------|
| 远景 | 环境为主，人物很小 | 场景建立，气势展现 |
| 全景 | 人物全身+环境 | 人物登场，动作展示 |
| 中景 | 人物膝盖以上 | 对话，日常动作 |
| 近景 | 人物胸部以上 | 情绪展示，对话 |
| 特写 | 人物面部或局部 | 情绪强化，细节强调 |
| 大特写 | 单一特征放大 | 极端情绪，关键细节 |

### 2.4 运镜

| 运镜 | 说明 | 适用场景 |
|------|------|----------|
| 固定 | 镜头不动 | 静态观察，对话 |
| 推进 | 镜头向前 | 引导关注，情绪递进 |
| 拉远 | 镜头后退 | 释放，展示全貌 |
| 摇镜 | 镜头转动 | 跟随运动，环境展示 |
| 跟踪 | 跟随人物移动 | 运动场面 |
| 升降 | 垂直方向移动 | 视角变化 |

### 2.5 角度

| 角度 | 说明 | 适用场景 |
|------|------|----------|
| 平视 | 与人物视线平齐 | 正常视角，客观 |
| 仰视 | 从下往上看 | 威严，强大 |
| 俯视 | 从上往下看 | 压迫，渺小 |
| 斜角 | 倾斜角度 | 不安，紧张 |

### 2.6 出场人物

```
格式：@图片X 人物名
示例：@图片1 李云
```

### 2.7 场景

```
格式：@场景编号-场景名称
示例：@S01-灵原
```

**场景引用规范**：
- 分镜表中使用场景编号引用
- 确保与场景卡编号一致
- 便于追踪场景使用情况

### 2.8 情绪

```
格式：单一情绪词
示例：压抑、愤怒、爆发
```

## 四、分镜数量调整

### 4.1 标准镜数

| 字数 | 推荐镜数 |
|------|----------|
| 500-800字 | 6-8镜 |
| 800-1200字 | 8-10镜 |
| 1200-2000字 | 10-12镜 |

### 4.2 增减规则

| 情况 | 处理方式 |
|------|----------|
| 情节密集 | 增加镜数 |
| 情节稀疏 | 减少镜数 |
| 情绪高潮 | 增加特写镜头 |
| 场景展示 | 增加全景镜头 |
