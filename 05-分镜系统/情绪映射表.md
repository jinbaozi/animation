# 情绪映射表

---

## 概述

本文档定义情绪与镜头语言的对应关系，帮助选择合适的景别、运镜、角度来表达情绪。

---

## 一、情绪分类

### 1.1 基础情绪

| 情绪类型 | 细分情绪 | 情绪特征 |
|----------|----------|----------|
| 压抑 | 压抑、沉重、窒息 | 情绪被压制，无法释放 |
| 悲伤 | 悲伤、痛苦、绝望 | 情绪低落，消极 |
| 愤怒 | 愤怒、怒火、仇恨 | 情绪激烈，对外释放 |
| 恐惧 | 恐惧、紧张、不安 | 情绪紧张，危机感 |
| 惊喜 | 惊喜、震惊、意外 | 情绪突然变化 |
| 温馨 | 温馨、幸福、感动 | 情绪温暖，积极 |
| 希望 | 希望、期待、向往 | 情绪向上，期待未来 |
| 爆发 | 爆发、释放、宣泄 | 情绪极致释放 |

### 1.2 情绪强度

| 等级 | 强度 | 描述 | 镜头处理 |
|------|------|------|----------|
| 1 | 微弱 | 隐含情绪，需推断 | 远景/全景，含蓄表达 |
| 2 | 轻度 | 有情绪迹象 | 全景/中景，正常表达 |
| 3 | 中度 | 明确情绪表达 | 中景/近景，明确表达 |
| 4 | 强烈 | 情绪明显，有动作 | 近景/特写，强化表达 |
| 5 | 极强 | 情绪爆发，极端表现 | 特写/大特写，极致表达 |

## 二、情绪→镜头映射

### 2.1 压抑情绪

| 强度 | 推荐景别 | 推荐运镜 | 推荐角度 | 说明 |
|------|----------|----------|----------|------|
| 1-2 | 远景/全景 | 固定 | 平视/俯视 | 环境压抑感 |
| 3 | 全景/中景 | 固定 | 平视 | 人物状态压抑 |
| 4 | 中景/近景 | 固定 | 俯视 | 压迫感加强 |
| 5 | 近景/特写 | 固定 | 俯视 | 极致压抑 |

**Prompt关键词**：
```
中文：压抑，沉重，窒息感，无法释放
English: oppressive, heavy, suffocating, suppressed
```

## 三、情绪组合映射

### 3.1 常见情绪组合

| 情绪组合 | 镜头处理 | 示例场景 |
|----------|----------|----------|
| 压抑→爆发 | 远景→全景→中景→近景→特写 | 长期压抑后的爆发 |
| 悲伤→希望 | 特写→近景→中景→全景 | 绝望中出现希望 |
| 愤怒→平静 | 特写→近景→中景→全景 | 怒火平息 |
| 恐惧→勇气 | 斜角→平视，近景→中景 | 战胜恐惧 |
| 希望→绝望 | 仰视→俯视，推进→拉远 | 希望破灭 |

### 3.2 情绪曲线与镜头

```
情绪强度
  5 |                         ● 爆发
  4 |                   ●
  3 |       ●     ●
  2 | ●     ●
  1 |
    +---------------------------→ 镜头
      全景 中景 中景 近景 近景 特写
```

## 四、人物状态映射

### 4.1 人物状态与镜头

| 人物状态 | 推荐景别 | 推荐角度 | 说明 |
|----------|----------|----------|------|
| 强势/主导 | 全景/仰视 | 仰视 | 展示威严 |
| 弱势/被动 | 中景/俯视 | 俯视 | 展示弱小 |
| 正常/平静 | 中景 | 平视 | 客观自然 |
| 紧张/戒备 | 近景 | 斜角 | 不稳定感 |
| 自信/从容 | 中景/仰视 | 平视/仰视 | 稳定感 |

### 4.2 人物关系与镜头

| 人物关系 | 镜头处理 | 说明 |
|----------|----------|------|
| 对峙 | 交替近景，仰俯切换 | 强弱对比 |
| 亲密 | 双人中景，平视 | 平等关系 |
| 疏远 | 远景，留白 | 距离感 |
| 压迫 | 俯视A，仰视B | 强弱对比 |

## 五、场景情绪映射

### 5.1 场景氛围与情绪

| 场景氛围 | 关联情绪 | 镜头处理 |
|----------|----------|----------|
| 压抑环境 | 压抑、绝望 | 远景，俯视 |
| 温馨环境 | 温馨、幸福 | 中景，平视 |
| 危险环境 | 恐惧、紧张 | 近景，斜角 |
| 辉煌环境 | 敬畏、希望 | 远景，仰视 |
| 孤独环境 | 孤独、悲伤 | 远景，留白 |

### 5.2 场景情绪Prompt

**压抑场景**：
```
压抑的环境，低角度光照，浓重阴影，空间狭窄，压迫氛围
oppressive environment, low angle lighting, heavy shadows, cramped space, oppressive atmosphere
```

**温馨场景**：
```
温馨的环境，柔和光照，温暖色调，舒适空间，幸福氛围
warm environment, soft lighting, warm tones, comfortable space, happy atmosphere
```
