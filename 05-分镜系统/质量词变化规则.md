# 质量词变化规则

---

## 概述

质量词是提升图像品质和风格表现的关键词。本文档定义根据场景类型调整质量词组合的规则。

---

## 一、基础质量词

所有Prompt必须包含的基础质量词：

| 类别 | 质量词 | 说明 |
|------|--------|------|
| 渲染品质 | 电影级CG品质 | 提升整体渲染质量 |
| 细节程度 | 高细节 | 确保细节丰富 |
| 材质表现 | PBR材质 | 增强材质真实感 |

---

## 二、场景类型与质量词对应

### 2.1 动作/战斗场景

| 质量词 | 用途 | 效果 |
|--------|------|------|
| 动态模糊 | 运动效果 | 表现速度感 |
| 运动线 | 动作强化 | 增强动感 |
| 冲击感 | 打击效果 | 强化冲击力 |

**适用情况**：战斗、追逐、动作场面

**示例Prompt片段**：
```
中国奇幻动漫风格，凌厉热血，电影级CG品质，高细节，PBR材质，
动态模糊，运动线，冲击感
```

### 2.2 情感/特写场景

| 质量词 | 用途 | 效果 |
|--------|------|------|
| 柔光 | 柔化效果 | 温柔氛围 |
| 细腻皮肤质感 | 面部细节 | 增强真实感 |
| 眼神光 | 眼睛表现 | 突出情绪 |

**适用情况**：情绪表达、面部特写

**示例Prompt片段**：
```
中国仙侠唯美风格，水墨淡雅，电影级CG品质，高细节，PBR材质，
柔光，细腻皮肤质感，眼神光
```

### 2.3 风景/全景场景

| 质量词 | 用途 | 效果 |
|--------|------|------|
| 大景深 | 景深控制 | 前后景清晰 |
| 细节丰富 | 环境细节 | 增强画面信息 |
| 氛围感 | 环境氛围 | 强化场景情绪 |

**适用情况**：场景展示、环境渲染

**示例Prompt片段**：
```
中国奇幻动漫风格，凌厉线条，电影级CG品质，高细节，PBR材质，
大景深，细节丰富，氛围感
```

### 2.4 室内/日常场景

| 质量词 | 用途 | 效果 |
|--------|------|------|
| 柔和光影 | 光线处理 | 自然温馨 |
| 生活质感 | 细节表现 | 增强真实感 |

**适用情况**：日常场景、室内对话

**示例Prompt片段**：
```
清新治愈系风格，温暖柔和，电影级CG品质，高细节，PBR材质，
柔和光影，生活质感
```

---

## 三、质量词选择流程

```
1. 确定场景类型（动作/情感/风景/室内）
2. 选择对应质量词组合
3. 添加基础质量词（电影级CG品质、高细节、PBR材质）
4. 根据风格添加风格强化词
```

---

## 五、注意事项

1. **基础质量词必须保留**：电影级CG品质、高细节、PBR材质是所有Prompt的基础
2. **场景质量词按需添加**：根据场景类型选择2-3个场景质量词
3. **避免过度堆砌**：质量词总数建议控制在5-7个
4. **风格一致性**：质量词应与主风格协调
