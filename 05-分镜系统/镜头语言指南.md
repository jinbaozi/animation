# 镜头语言指南

---

## 概述

镜头语言是AI漫剧视觉表达的核心。本文档定义景别、运镜、角度、构图等镜头语言要素。

---

## 一、景别系统

### 1.1 景别定义

| 景别 | 取景范围 | 人物占比 | 画面特点 |
|------|----------|----------|----------|
| 远景 | 广阔环境 | <25% | 环境为主，气势恢宏 |
| 全景 | 全身+环境 | 50%-75% | 人物全身，环境可见 |
| 中景 | 膝盖以上 | 75% | 动作清晰，表情可见 |
| 近景 | 胸部以上 | 90% | 表情清晰，情绪突出 |
| 特写 | 面部或局部 | 100% | 细节放大，情绪极致 |
| 大特写 | 单一特征 | - | 极端强调，视觉冲击 |

### 1.2 景别选择规则

| 场景类型 | 推荐景别 | 理由 |
|----------|----------|------|
| 场景建立 | 远景/全景 | 展示环境全貌 |
| 人物登场 | 全景 | 展示完整形象 |
| 动作展示 | 全景/中景 | 展示完整动作 |
| 对话交流 | 中景/近景 | 表情和姿态 |
| 情绪展示 | 近景/特写 | 放大情绪 |
| 情绪爆发 | 特写/大特写 | 最大冲击力 |
| 细节强调 | 特写/大特写 | 强调关键细节 |

### 1.3 景别与情绪

| 情绪 | 推荐景别 | 说明 |
|------|----------|------|
| 压抑 | 远景/全景 | 展示环境的压迫感 |
| 孤独 | 远景/全景 | 人物在环境中显得渺小 |
| 温馨 | 中景/近景 | 亲近感，温暖氛围 |
| 紧张 | 近景/特写 | 放大紧张感 |
| 愤怒 | 近景/特写 | 情绪强烈 |
| 爆发 | 特写/大特写 | 情绪极致释放 |
| 希望 | 中景→近景 | 渐进式推进 |

## 二、运镜系统

### 2.1 运镜定义

| 运镜 | 动作 | 视觉效果 | 适用场景 |
|------|------|----------|----------|
| 固定 | 不动 | 稳定，客观 | 对话，静态观察 |
| 推进 | 向前 | 聚焦，引导 | 进入场景，关注人物 |
| 拉远 | 向后 | 释放，展示 | 展示全貌，退场 |
| 摇镜 | 水平转动 | 跟随，展示 | 跟随运动，环境展示 |
| 俯仰 | 垂直转动 | 视角变化 | 高低切换 |
| 跟踪 | 跟随移动 | 陪伴，参与 | 运动场面 |
| 升降 | 垂直移动 | 视角变化 | 气势展现 |

### 2.2 运镜选择规则

| 场景类型 | 推荐运镜 | 理由 |
|----------|----------|------|
| 场景建立 | 推进 | 引导观众进入 |
| 静态观察 | 固定 | 稳定，客观 |
| 人物运动 | 跟踪/摇镜 | 跟随人物 |
| 情绪递进 | 推进 | 放大情绪 |
| 释放/退场 | 拉远 | 拉开距离 |
| 气势展现 | 升降 | 视角宏大 |

### 2.3 运镜与节奏

| 节奏 | 运镜特点 | 示例 |
|------|----------|------|
| 慢 | 缓慢，少变化 | 缓慢推进，固定镜头 |
| 正常 | 适度变化 | 固定+推进组合 |
| 快 | 快速，多变 | 快速摇镜，频繁切换 |

## 三、角度系统

### 3.1 角度定义

| 角度 | 视线关系 | 视觉效果 | 适用场景 |
|------|----------|----------|----------|
| 平视 | 与人物平齐 | 客观，自然 | 正常叙事 |
| 仰视 | 从下往上 | 威严，强大 | 展示力量，英雄 |
| 俯视 | 从上往下 | 压迫，渺小 | 展示弱势，俯瞰 |
| 斜角 | 倾斜画面 | 不安，紧张 | 危机，异常 |

### 3.2 角度选择规则

| 人物状态 | 推荐角度 | 理由 |
|----------|----------|------|
| 正常状态 | 平视 | 客观自然 |
| 强势/威严 | 仰视 | 显得高大 |
| 弱势/被压迫 | 俯视 | 显得渺小 |
| 危机/紧张 | 斜角 | 不稳定感 |
| 对峙 | 交替仰俯 | 强弱对比 |

### 3.3 角度与情绪

| 情绪 | 推荐角度 | 说明 |
|------|----------|------|
| 自信 | 平视/仰视 | 稳定或高大 |
| 压迫 | 俯视 | 被压迫感 |
| 崇拜 | 仰视 | 对象高大 |
| 不安 | 斜角 | 不稳定感 |
| 平静 | 平视 | 客观自然 |

## 四、构图系统

### 4.1 构图类型

| 构图 | 描述 | 视觉效果 | 适用场景 |
|------|------|----------|----------|
| 三分法 | 人物在1/3线 | 平衡，自然 | 通用 |

| 对称 | 左右对称 | 平衡，庄重 | 正式场景 |
| 框中框 | 通过框架看 | 聚焦，层次 | 室内，窥视 |
| 留白 | 大量空白 | 情绪，意境 | 情绪表达 |

### 4.2 构图选择规则

|----------|----------|------|

| 动作场面 | 对角线 | 动感，张力 |
| 对话 | 三分法 | 双方平衡 |
| 正式场景 | 对称 | 庄重感 |
| 情绪表达 | 留白 | 意境感 |

### 4.3 构图与人物位置

| 人物位置 | 构图效果 | 适用 |
|----------|----------|------|
| 画面中央 | 聚焦，主导 | 主角强调 |

## 五、镜头组合

### 5.1 镜头序列模式

#### 渐进式（推进情绪）
```
远景 → 全景 → 中景 → 近景 → 特写
```
适用：情绪递进，从环境到人物内心

#### 释放式（拉开距离）
```
特写 → 近景 → 中景 → 全景 → 远景
```
适用：情绪释放，退场，结局

#### 交替式（对话/对峙）
```
中景A → 近景B → 近景A → 中景B
```
适用：对话，对峙

#### 环绕式（环境展示）
```
远景 → 全景 → 中景 → 全景 → 远景
```
适用：场景建立

### 5.2 镜头组合示例

**情绪递进序列**：
```
镜头01：全景，建立场景
镜头02：中景，展示人物状态
镜头03：近景，展示表情
镜头04：特写，情绪爆发
```

**对话序列**：
```
镜头01：中景，两人对话
镜头02：近景，人物A反应
镜头03：近景，人物B反应
镜头04：中景，两人互动
```

## 七、镜头节奏控制

### 7.1 镜头时长

| 情绪/场景 | 推荐时长 | 理由 |
|-----------|----------|------|
| 情绪展示 | 2-4秒 | 让观众感受 |
| 动作展示 | 1-3秒 | 动感 |
| 对话 | 2-4秒 | 信息传达 |
| 场景建立 | 3-5秒 | 环境展示 |
| 高潮爆发 | 1-2秒 | 快速冲击 |

### 7.2 节奏变化

| 节奏类型 | 镜头时长 | 运镜速度 |
|----------|----------|----------|
| 慢节奏 | 4-5秒 | 缓慢 |
| 正常节奏 | 3秒 | 适中 |
| 快节奏 | 1-2秒 | 快速 |

### 7.3 节奏设计原则

```
原则：起承转合，节奏起伏

起：慢节奏，建立场景
承：正常节奏，推进故事
转：节奏加快，冲突升级
合：节奏回落或爆发
```
