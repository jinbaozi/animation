# Prompt一致性技巧

---

## 概述

本文档总结Gemini专用的一致性技巧，帮助在Prompt中确保角色和场景的一致性。

---

## 一、特征前置技巧

### 1.1 核心原则

```
重要信息放前面 = AI优先处理
```

### 1.2 前置顺序

```
顺序：风格前缀 > 角色特征 > 动作 > 场景
```

### 1.3 示例对比

**错误（特征后置）**：
```
广角镜头，李云在灵原劳作，他是个瘦削的少年，黑发，穿灰色长袍...
```

**正确（特征前置）**：
```
中国奇幻动漫风格，瘦削体型少年，黑色短发，灰色粗布长袍，
广角镜头，@图片1 在灵原劳作...
```

---

## 二、重复锚定技巧

### 2.1 核心原则

```
多角度重复核心特征 = 强化记忆
```

### 2.2 重复位置

```
位置1：风格前缀中（风格锁定）
位置2：人物特征描述中（外观锁定）
位置3：场景描述中（环境锁定）
```

### 2.3 示例

```
标题：中国奇幻动漫风格，线条凌厉...（风格锁定）
中景镜头，@图片1 瘦削体型，黑色短发，灰色粗布长袍...（外观锁定）
焦灼的灵原背景，干裂的土地，远处主峰雪白峰顶...（环境锁定）
```

---

## 三、风格锁定技巧

### 3.1 核心原则

```
每镜开头重复风格前缀 = 风格一致
```

### 3.2 风格前缀模板

每个镜头必须以风格前缀开头：

```
标题：[风格前缀]
```

### 3.3 示例

**镜头01**：
```
标题：中国奇幻动漫风格，线条凌厉，情感强烈，电影级3D渲染...
```

**镜头02**：
```
标题：中国奇幻动漫风格，线条凌厉，情感强烈，电影级3D渲染...
```

（每镜都使用相同前缀）

---

## 四、否定约束技巧

### 4.1 核心原则

```
添加禁止词 = 避免不需要的元素
```

### 4.2 常用否定约束

| 避免内容 | 否定词 |
|----------|--------|
| 服装变化 | no clothing change, same clothing |
| 发型变化 | no hairstyle change, same hairstyle |
| 外观变化 | no appearance change, consistent appearance |
| 背景变化 | no background change, same background |
| 颜色变化 | no color change |

### 4.3 使用位置

```
位置：Prompt末尾

示例：
..., no clothing change, no hairstyle change
```

### 4.4 示例

```
标题：中国奇幻动漫风格，线条凌厉...
中景镜头，@图片1 瘦削体型，黑色短发，灰色粗布长袍，擦汗动作，
焦灼的灵原背景，no clothing change, same hairstyle, consistent appearance
```

---

## 五、参考图引用技巧

### 5.1 核心原则

```
上传参考图 + Prompt引用 = 高度一致
```

### 5.2 引用格式

```
格式：@[图片编号]
示例：@图片1, @图片2
```

### 5.3 引用位置

```
位置：镜头信息之后，动作描述之前

示例：
中景镜头，平视，@图片1 动作描述...
```

### 5.4 多角色引用

```
格式：@图片1 人物A，@图片2 人物B

示例：
中景镜头，@图片1 李云握紧铁锄，@图片2 王师兄傲慢站立...
```

## 七、Prompt模板优化

### 7.1 标准模板

```
标题：[风格前缀]
[景别]，[角度]，[运镜]，时间：[秒数]，@[图片编号] [动作]，[特征锁定词]，same character, consistent design。
[场景描述]，[光影氛围]，no clothing change。
```

### 7.2 强化模板（高一致性需求）

```
标题：[风格前缀]
[景别]，[角度]，[运镜]，时间：[秒数]，@[图片编号] [动作]，
[体型]，[发型发色]，[服装]，[面部特征]，
same character, identical appearance, consistent design, maintain all features。
[场景描述]，[光影氛围]，no clothing change, no hairstyle change, consistent background。
```

### 7.3 示例对比

**普通模板**：
```
标题：中国奇幻动漫风格，线条凌厉，情感强烈，电影级3D渲染。
中景镜头，@图片1 擦汗，灰色长袍。
灵原背景，正午阳光。
```

**优化模板**：
```
标题：中国奇幻动漫风格，线条凌厉，情感强烈，电影级3D渲染，虚幻引擎5，PBR材质，电影级CG品质。
中景镜头，平视，固定镜头，@图片1 擦去额头的汗水，
瘦削体型，黑色短发略显凌乱，灰色粗布长袍沾满尘土，丹凤眼眼神坚毅，
same character, consistent design, identical appearance。
焦灼的灵原背景，干裂的土地，远处主峰雪白峰顶，烈日当空，刺眼的阳光，
高对比度阴影，热浪扭曲空气，黄褐色调，
no clothing change, same hairstyle。
```

## 八、常见问题修复

### 8.1 角色外观漂移

**问题**：角色发型、服装、体型变化

**修复**：
```
1. 特征前置
2. 重复锚定
3. 添加否定约束
4. 使用参考图
```

### 8.2 场景元素变化

**问题**：背景元素位置或外观变化

**修复**：
```
1. 场景描述详尽
2. 锚定核心元素位置
3. 添加"same background"
```

### 8.3 风格不一致

**问题**：画面风格变化

**修复**：
```
1. 每镜重复风格前缀
2. 包含风格关键词
3. 添加风格否定约束
```

## 十、三重校验流程

### 10.1 校验层级概览

本项目采用三重校验机制确保Prompt质量：

| 校验层级 | 触发时机 | 核心检查项 |
|----------|----------|------------|
| 单镜校验 | 每镜生成后 | 结构完整性、字数控制、角色一致性、质量词 |
| 场次校验 | 每场戏完成后 | 时间连贯、空间连贯、角色连贯、情绪连贯 |
| 全篇校验 | 全部完成后 | 风格一致率、角色一致率、场景一致率 |

### 10.2 单镜校验流程

```
每镜Prompt生成完成
    ↓
执行四项检查
    │
    ├─ 结构完整性检查
    │   └─ 五段式结构是否完整
    │
    ├─ 字数控制检查
    │   └─ 总字数 ≤ 410字
    │
    ├─ 角色一致性检查
    │   └─ 核心特征匹配人物卡
    │
    └─ 质量词检查
        └─ 至少包含3个质量词
    ↓
全部通过 → 进入下一流程
有项不通过 → 返回修复
```

### 10.3 场次校验流程

```
场次内所有单镜校验通过
    ↓
执行连贯性检查
    │
    ├─ 时间连贯性
    │   └─ 光线、服装、发型是否一致
    │
    ├─ 空间连贯性
    │   └─ 场景锚点位置是否固定
    │
    ├─ 角色连贯性
    │   └─ 位置、状态、道具是否合理继承
    │
    └─ 情绪连贯性
        └─ 情绪变化是否有触发事件
    ↓
全部通过 → 进入全篇队列
有项不通过 → 批量修复
```

### 10.4 全篇校验流程

```
所有场次校验通过
    ↓
执行三率检查
    │
    ├─ 风格一致率
    │   └─ 标准：> 90%
    │
    ├─ 角色一致率
    │   └─ 标准：> 85%
    │
    └─ 场景一致率
        └─ 标准：> 85%
    ↓
输出校验报告
```

### 10.5 校验与一致性技巧的结合

| 一致性技巧 | 对应校验项 | 校验层级 |
|------------|------------|----------|
| 特征前置技巧 | 角色一致性检查 | 单镜校验 |
| 重复锚定技巧 | 角色连贯性检查 | 场次校验 |
| 风格锁定技巧 | 风格一致率 | 全篇校验 |
| 否定约束技巧 | 角色一致性检查 | 单镜校验 |
| 参考图引用技巧 | 角色一致性检查 | 单镜校验 |

### 10.6 校验失败处理

```markdown
## 校验失败处理流程

### 单镜校验失败
1. 定位问题项（结构/字数/一致性/质量）
2. 参考对应技巧进行修复
3. 重新执行校验

### 场次校验失败
1. 识别连贯性问题类型
2. 检查状态追踪表
3. 批量调整相关镜头
4. 重新执行校验

### 全篇校验失败
1. 查看三率报告
2. 定位问题场次和镜头
3. 制定修复优先级
4. 逐项修复并记录
```
