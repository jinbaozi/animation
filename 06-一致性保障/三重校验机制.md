# 三重校验机制

---

## 概述

本文档定义AI漫剧项目的三重校验机制，通过单镜校验、场次校验、全篇校验三个层级，确保生成内容的一致性和质量。

---

## 一、校验层级定义

### 1.1 三层校验体系

```
┌─────────────────────────────────────────────────────────┐
│                    全篇校验（第三层）                      │
│              触发时机：全部内容完成后                       │
│              检查范围：整体一致性、风格统一                  │
├─────────────────────────────────────────────────────────┤
│                    场次校验（第二层）                      │
│              触发时机：每场戏完成后                         │
│              检查范围：场次内连贯性                         │
├─────────────────────────────────────────────────────────┤
│                    单镜校验（第一层）                      │
│              触发时机：每镜生成后                           │
│              检查范围：单个分镜完整性                       │
└─────────────────────────────────────────────────────────┘
```

### 1.2 校验层级总览

| 校验层级 | 触发时机 | 核心检查项 | 不通过处理 |
|----------|----------|------------|------------|
| 单镜校验 | 每镜生成后 | 结构完整性、字数控制、一致性、质量 | 返工修复 |
| 场次校验 | 每场戏完成后 | 时间连贯、空间连贯、角色连贯、情绪连贯 | 批量修复 |
| 全篇校验 | 全部完成后 | 风格一致率、角色一致率、场景一致率 | 输出报告，重点修复 |

## 二、单镜校验详细规则

### 2.1 校验触发

```
单镜Prompt生成完成
    ↓
自动触发单镜校验
    ↓
执行四项检查
    ↓
全部通过 → 进入场次队列
有项不通过 → 返回修复
```

### 2.3 检查项二：字数控制检查

#### 字数限制

| 项目 | 限制 | 说明 |
|------|------|------|
| 单镜Prompt总字数 | **250-400字** | 中英文分别计算 |
| 单段字数 | 20-100字 | 保持简洁 |
| 参数行字数 | 不计入总字数 | --ar等参数单独计算 |

#### 字数检查规则

```
规则1：总字数超过400字 → 必须精简
规则2：总字数少于250字 → 必须扩充
规则3：任一段落字数超过100字 → 提示精简
规则4：任一段落字数少于20字 → 提示补充
```

#### 字数检查示例


## 四、全篇校验详细规则

### 4.1 校验触发

```
所有场次校验通过
    ↓
全篇完成标记
    ↓
自动触发全篇校验
    ↓
执行三率检查
    ↓
输出校验报告
```

### 4.2 检查项一：风格一致率

#### 计算方法

```
风格一致率 = (风格关键词一致的镜头数 / 总镜头数) x 100%

风格关键词包括：
- 主风格（如"中国奇幻动漫风格"）
- 子风格（如"凌厉热血"）
- 技术风格（如"虚幻引擎5"、"PBR材质"）
```

#### 风格一致率检查表
