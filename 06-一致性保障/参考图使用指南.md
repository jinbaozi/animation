# 参考图使用指南

---

## 概述

参考图是确保一致性的关键工具。本文档定义如何生成和使用参考图。

---

## 一、参考图类型

### 1.1 角色参考图

| 类型 | 用途 | 生成时机 |
|------|------|----------|
| 三视图 | 角色全貌参考 | 角色首次出场前 |
| 表情参考 | 表情变化参考 | 需要 |
| 服装参考 | 服装变化参考 | 服装变化时 |

### 1.2 场景参考图

| 类型 | 用途 | 生成时机 |
|------|------|----------|
| 全景图 | 场景全貌参考 | 场景首次出场前 |
| 特写视角 | 局部细节参考 | 需要 |

### 1.3 道具参考图

| 类型 | 用途 | 生成时机 |
|------|------|----------|
| 道具图 | 道具外观参考 | 重要道具首次出场前 |

---

## 二、角色参考图生成

### 2.1 三视图生成

#### Prompt模板

```
[风格前缀]，[角色完整描述]，
正面|侧面|背面视角，三视图，角色参考图，一致性设计，高质量
```

#### 示例

```
中国奇幻动漫风格，线条凌厉，情感强烈，电影级3D渲染，
一个18岁少年，瘦削体型，健康小麦色皮肤，
黑色短发略显凌乱，丹凤眼黑色眼珠眼神坚毅，剑眉，
身穿灰色粗布长袍沾满尘土，灰色布裤，黑色磨损布鞋，
正面|侧面|背面视角，三视图，角色参考图，一致性设计，高质量
```

### 2.2 三视图要求

| 要求 | 说明 |
|------|------|
| 视角 | 正面、侧面、背面三视角 |
| 姿态 | 站立，双手自然下垂 |
| 表情 | 中性表情 |
| 背景 | 简单纯色背景 |

### 2.3 生成流程

```
1. 根据人物卡填写Prompt
2. 在Gemini中生成三视图
3. 保存图片，编号为"图片1"
4. 后续镜头引用 @图片1
```

## 三、场景参考图生成

### 3.1 全景图生成

#### Prompt模板

```
[风格前缀]，[场景完整描述]，
全景视角，场景参考图，高质量
```

#### 示例

```
中国奇幻动漫风格，线条凌厉，电影级3D渲染，
开阔的焦灼灵原全景，干裂的土地延伸至远方，
枯萎的灵草田，散落的红色火焰石，远处的巍峨主峰雪白峰顶，
烈日当空，刺眼的阳光，高对比度阴影，热浪扭曲空气，黄褐色调为主，
压抑灼热的氛围，全景视角，场景参考图，高质量
```

### 3.2 全景图要求

| 要求 | 说明 |
|------|------|
| 视角 | 全景/广角 |
| 时间 | 故事时间点的光影 |
| 元素 | 包含所有核心元素 |
| 氛围 | 符合场景氛围 |

### 3.3 生成流程

```
1. 根据场景卡填写Prompt
2. 在Gemini中生成全景图
3. 保存图片作为参考
4. 后续镜头参考全景图的元素位置
```

---

## 四、参考图使用方法

### 4.1 在Gemini中使用

```
步骤1：上传参考图
步骤2：在Prompt中引用 @图片X
步骤3：AI根据参考图生成
```

### 4.2 引用格式

| 引用方式 | 格式 | 说明 |
|----------|------|------|
| 单角色 | @图片1 | 引用图片1的角色 |
| 多角色 | @图片1, @图片2 | 引用多个角色 |
| 场景参考 | 描述中参考场景图 | 不直接引用，但描述需一致 |

### 4.3 引用位置

```
位置：镜头信息之后

示例：
中景镜头，平视，@图片1 动作描述...
```

## 六、参考图更新

### 6.1 需要更新的情况

| 情况 | 处理方式 |
|------|----------|
| 服装完全更换 | 生成新三视图，新编号 |
| 发型变化 | 生成新三视图，新编号 |
| 年龄成长 | 生成新三视图，新编号 |
| 服装破损 | 不需要更新，在Prompt中描述 |
| 受伤/血迹 | 不需要更新，在Prompt中描述 |

### 6.2 版本管理

```markdown
## 角色参考图版本管理

| 角色 | 版本 | 编号 | 状态 | 适用镜头 |
|------|------|------|------|----------|
```

## 八、常见问题与解决

### 8.1 三视图不一致

**问题**：三视角角色外观不一致

**解决**：
```
1. 强化Prompt一致性关键词
2. 重新生成
3. 选择最一致的视角单独使用
```

### 8.2 参考图风格不符

**问题**：参考图风格与目标不符

**解决**：
```
1. 检查风格前缀是否正确
2. 强化风格关键词
3. 重新生成
```

### 8.3 参考图细节缺失

**问题**：参考图缺少重要细节

**解决**：
```
1. 在Prompt中补充细节描述
2. 重新生成更详细的参考图
3. 使用多个参考图（如：全身图+面部特写）
```
