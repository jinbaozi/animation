# 常见问题修复

---

## 概述

本文档总结常见的一致性问题及其修复方法。

---

## 一、角色一致性问题

### 1.1 发型变化

#### 问题表现
- 发型在不同镜头间变化
- 发色不一致
- 发型长度变化

#### 问题原因
- Prompt中发型描述不一致
- 未使用参考图
- 缺乏锁定关键词

#### 修复方法

**方法1：统一发型描述**
```
每镜使用相同的发型描述：
黑色短发略显凌乱 → 黑色短发略显凌乱
```

**方法2：添加锁定关键词**
```
..., same hairstyle, no hairstyle change
```

**方法3：使用参考图**
```
@图片1 ... (参考图中发型已固定)
```

---

### 1.2 服装变化

#### 问题表现
- 服装款式变化
- 服装颜色变化
- 服装细节不一致

#### 问题原因
- 服装描述不统一
- 未追踪服装状态
- 缺乏锁定关键词

#### 修复方法

**方法1：统一服装描述**
```
每镜使用相同的服装描述：
灰色粗布长袍沾满尘土 → 灰色粗布长袍沾满尘土
```

**方法2：建立服装状态追踪**
```
镜头01：灰色粗布长袍，完整
镜头02：灰色粗布长袍，完整（继承）
镜头03：灰色粗布长袍，沾尘土（变化）
```

**方法3：添加锁定关键词**
```
..., same clothing, no clothing change
```

---

### 1.3 体型变化

#### 问题表现
- 瘦削变健壮
- 身高不一致
- 整体轮廓变化

#### 问题原因
- 体型描述缺失或不一致
- 未使用参考图

#### 修复方法

**方法1：每镜包含体型描述**
```
..., 瘦削体型, slender build, ...
```

**方法2：使用参考图**
```
参考图中体型已固定，直接引用
```

---

### 1.4 面部不一致

#### 问题表现
- 眼睛形状/颜色变化
- 面部特征不一致
- 表情与情绪不符

#### 问题原因
- 面部描述不一致
- 缺乏面部特征锁定

#### 修复方法

**方法1：锁定眼睛特征**
```
丹凤眼黑色眼珠 → 丹凤眼黑色眼珠（每镜一致）
```

**方法2：添加面部锁定词**
```
..., 丹凤眼黑色眼珠, 剑眉, same facial features
```

---

## 二、场景一致性问题

### 2.1 背景元素变化

#### 问题表现
- 背景元素位置变化
- 背景元素消失/出现
- 背景元素外观变化

#### 问题原因
- 场景描述不完整
- 未建立视觉锚点
- 缺乏场景锁定词

#### 修复方法

**方法1：完整场景描述**
```
每镜包含相同的背景元素描述：
远处主峰雪白峰顶云雾缭绕，散落的红色火焰石
```

**方法2：建立视觉锚点**
```
核心锚点：主峰（背景中央偏左）
辅助锚点：火焰石群（中景右侧）
```

**方法3：添加场景锁定词**
```
..., same background, consistent scene
```

---

### 2.2 光影不一致

#### 问题表现
- 光源方向变化
- 光影强度变化
- 色温变化

#### 问题原因
- 未追踪时间
- 光影描述不一致

#### 修复方法

**方法1：建立时间光影追踪**
```
镜头01-08：正午，顶部光源，强光，暖黄色
```

**方法2：统一光影描述**
```
每镜使用相同的光影描述：
烈日当空，刺眼的阳光，高对比度阴影
```

---

### 2.3 场景氛围不一致

#### 问题表现
- 氛围与设定不符
- 色调不一致
- 情绪氛围偏差

#### 问题原因
- 氛围关键词缺失
- 色调描述不一致

#### 修复方法

**方法1：添加氛围关键词**
```
..., 压抑灼热的氛围, oppressive scorching atmosphere
```

**方法2：统一色调描述**
```
每镜使用相同的色调描述：
黄褐色调为主, yellow-brown color palette
```

---

## 三、风格一致性问题

### 3.1 风格漂移

#### 问题表现
- 画面风格变化
- 线条风格变化
- 渲染质量变化

#### 问题原因
- 风格前缀缺失或不一致
- 风格关键词不完整

#### 修复方法

**方法1：每镜使用相同风格前缀**
```
标题：中国奇幻动漫风格，线条凌厉，情感强烈，电影级3D渲染，虚幻引擎5，PBR材质，电影级CG品质。
```

**方法2：添加风格锁定词**
```
..., consistent style, same art style
```

---

### 3.2 质量不一致

#### 问题表现
- 画面质量变化
- 细节程度变化
- 清晰度变化

#### 问题原因
- 质量关键词缺失

#### 修复方法

**方法1：添加质量关键词**
```
..., 高质量, high quality, detailed
```

---

## 四、连续性问题

### 4.1 位置跳变

#### 问题表现
- 人物位置突然变化
- 道具位置突然变化

#### 问题原因
- 未追踪位置
- 镜头切换逻辑问题

#### 修复方法

**方法1：建立位置追踪**
```
镜头01：画面中央
镜头02：画面中央（继承）
镜头03：画面中央（继承）
```

**方法2：添加位置描述**
```
..., 位于画面中央, in center of frame
```

---

### 4.2 状态跳变

#### 问题表现
- 情绪突然变化
- 动作突然变化
- 服装状态突然变化

#### 问题原因
- 缺乏过渡
- 未追踪状态

#### 修复方法

**方法1：添加过渡镜头**
```
镜头05：愤怒表情
镜头06：[过渡] 深呼吸，表情渐渐平静
镜头07：平静表情
```

**方法2：状态渐变描述**
```
..., 表情从愤怒逐渐转为平静
```

## 五、问题诊断流程

### 5.1 诊断步骤

```
步骤1：明确问题类型（角色/场景/风格/连续性）
步骤2：对比相邻镜头的Prompt
步骤3：找出描述不一致的地方
步骤4：应用对应的修复方法
步骤5：重新生成验证
```

### 5.2 问题对照表

| 问题类型 | 检查项 | 修复方法 |
|----------|--------|----------|
| 发型变化 | 发型描述是否一致 | 统一描述 + 锁定词 |
| 服装变化 | 服装描述是否一致 | 状态追踪 + 锁定词 |
| 体型变化 | 体型描述是否一致 | 每镜包含体型 |
| 面部变化 | 面部特征是否锁定 | 锁定眼睛+面部特征 |
| 背景变化 | 场景描述是否完整 | 锚点 + 场景描述 |
| 光影变化 | 时间是否追踪 | 时间追踪 + 光影描述 |
| 风格变化 | 风格前缀是否一致 | 每镜相同前缀 |
| 位置跳变 | 位置是否追踪 | 位置追踪表 |

## 六、预防措施

### 6.1 建立检查清单

```markdown

- [ ] 风格前缀是否正确
- [ ] 角色特征是否完整
- [ ] 参考图是否引用
- [ ] 场景描述是否完整
- [ ] 锁定词是否添加

```

### 6.2 建立追踪表

```markdown
## 状态追踪表

| 镜头 | 角色 | 服装 | 场景 | 光影 | 检查 |
|------|------|------|------|------|------|
| 01 | [状态] | [状态] | [状态] | [状态] | ✓ |
| 02 | → | → | → | → | ✓ |
```

### 6.3 版本控制

```
每次Prompt修改保存版本
问题发生时可以回溯
```
