# 跨镜头连续性

---

## 概述

本文档定义如何追踪跨镜头的状态继承，确保人物、场景、道具等元素在镜头间保持连续。

---

## 一、连续性概念

### 1.1 什么是连续性

```
连续性 = 镜头N的状态 = 镜头N-1的状态 + 本镜头的变化
```

### 1.2 连续性要素

| 要素 | 说明 | 变化频率 |
|------|------|----------|
| 人物位置 | 人物在场景中的位置 | 每镜可能变化 |
| 人物状态 | 姿态、表情、情绪 | 每镜可能变化 |
| 人物服装 | 服装外观、破损程度 | 渐变或不变 |
| 场景状态 | 场景元素状态 | 渐变或不变 |
| 光影状态 | 光线、阴影 | 渐变 |
| 道具状态 | 道具位置、状态 | 每镜可能变化 |

---

## 二、状态追踪表

### 2.1 状态追踪模板

```markdown
## 跨镜头状态追踪表

| 镜头 | 人物位置 | 人物状态 | 服装状态 | 场景状态 | 光影状态 | 道具状态 | 变化说明 |
|------|----------|----------|----------|----------|----------|----------|----------|
| 01 | [位置] | [状态] | [服装] | [场景] | [光影] | [道具] | [变化] |
| 02 | → | [状态] | → | → | → | [道具] | [变化] |
```

### 2.2 符号说明

| 符号 | 含义 |
|------|------|
| → | 与上一镜相同 |
| ↓ | 逐渐变化 |
| ✗ | 不存在/消失 |

### 2.3 示例：李云场景追踪

```markdown
## 李云场景 - 状态追踪表

| 镜头 | 人物位置 | 人物状态 | 服装状态 | 场景状态 | 光影状态 | 道具状态 | 变化说明 |
|------|----------|----------|----------|----------|----------|----------|----------|
| 01 | 画面中央 | 弓背挥锄 | 完整 | 灵原 | 正午强光 | 铁锄在手 | 初始 |
| 02 | → | 擦汗 | 完整+汗水 | → | → | → | 无移动 |
| 03 | → | 直立望远 | → | → | → | → | 直立 |
| 04 | → | 转身 | → | → | → | → | 转身 |
| 05 | → | 被俯视 | → | → | → | → | 被动 |
| 06 | → | 握紧铁锄 | → | → | → | 铁锄握紧 | 动作 |
| 07 | → | → | → | → | → | → | 眼神特写 |
| 08 | → | 能量涌动 | → | → | 能量光芒 | → | 觉醒 |
```

## 三、人物连续性

### 3.1 人物位置追踪

#### 位置描述方式

| 描述方式 | 示例 |
|----------|------|
| 画面区域 | 画面中央、画面左侧、画面右侧 |
| 相对位置 | 前景、中景、背景 |
| 相对人物 | 在王师兄前方 |

#### 位置变化规则

```
规则1：位置变化需有动作支持
规则2：无明显移动则位置不变
规则3：镜头切换后位置应合理继承
```

### 3.2 人物状态追踪

#### 状态类型

| 状态类型 | 说明 | 示例 |
|----------|------|------|
| 姿态 | 身体姿态 | 站立、坐、跪、躺 |
| 动作 | 正在进行的动作 | 挥锄、擦汗、握拳 |
| 表情 | 面部表情 | 疲惫、坚毅、愤怒 |
| 情绪 | 内在情绪状态 | 压抑、希望、愤怒 |

#### 状态变化规则

```
规则1：状态变化需有触发事件
规则2：无明显触发则状态继承
规则3：情绪变化应有表情支持
```

### 3.3 服装状态追踪

#### 服装状态类型

| 状态 | 描述 | Prompt关键词 |
|------|------|--------------|
| 完好 | 无破损 | intact, undamaged |
| 沾污 | 沾尘土/污渍 | covered in dust, stained |
| 轻微破损 | 轻微撕裂/磨损 | slightly torn, worn |
| 严重破损 | 明显撕裂/破损 | severely damaged, torn |
| 沾血 | 有血迹 | blood-stained |

#### 服装状态继承

```markdown
## 服装状态继承规则

| 上镜状态 | 本镜动作 | 本镜状态 |
|----------|----------|----------|
| 完好 | 劳作 | 完好→沾污 |
| 沾污 | 战斗 | 沾污→轻微破损 |
| 轻微破损 | 激烈战斗 | 轻微破损→严重破损 |
| 严重破损 | 受伤 | 严重破损+沾血 |
```

## 四、场景连续性

### 4.1 场景元素追踪

```markdown
## 场景元素追踪表

| 元素 | 初始状态 | 镜头02 | 镜头03 | ... | 变化说明 |
|------|----------|--------|--------|-----|----------|
| 主峰 | 云雾缭绕 | → | → | ... | 固定锚点 |
| 灵草 | 枯萎 | → | → | ... | 固定状态 |
| 火焰石 | 散落 | → | → | ... | 固定位置 |
```

### 4.2 场景状态继承

```
规则1：核心锚点位置固定不变
规则2：辅助元素状态继承
规则3：时间变化影响光影状态
```

## 五、光影连续性

### 5.1 光影状态追踪

```markdown
## 光影状态追踪表

| 镜头 | 时间 | 光源方向 | 光影强度 | 色温 | 变化说明 |
|------|------|----------|----------|------|----------|
| 01 | 正午 | 顶部 | 强 | 暖黄 | 初始 |
| 02 | 正午 | 顶部 | 强 | 暖黄 | → |
| 03 | 正午 | 顶部 | 强 | 暖黄 | → |
```

### 5.2 光影变化规则

```
规则1：同一时间段内光影保持一致
规则2：光源方向变化不超过15度
规则3：强度和色温渐变
```

## 六、道具连续性

### 6.1 道具状态追踪

```markdown
## 道具状态追踪表

| 镜头 | 道具 | 位置 | 状态 | 持有者 | 变化说明 |
|------|------|------|------|--------|----------|
| 01 | 铁锄 | 手中 | 完好 | 李云 | 初始 |
| 02 | 铁锄 | 手中 | 完好 | 李云 | → |
| 03 | 铁锄 | 手中 | 完好 | 李云 | → |
| 04 | 铁锄 | 手中 | 完好 | 李云 | → |
| 05 | 铁锄 | 手中 | 完好 | 李云 | 握紧 |
```

### 6.2 道具变化规则

```
规则1：道具位置变化需有动作支持
规则2：道具状态渐变或不变
规则3：道具消失需有合理原因
```

## 七、连续性检查

### 7.1 检查清单

```markdown
## 连续性检查清单

### 人物连续性
- [ ] 人物位置是否合理继承
- [ ] 人物状态是否合理继承
- [ ] 服装状态是否合理继承
- [ ] 情绪变化是否有触发

### 场景连续性
- [ ] 场景锚点位置是否一致
- [ ] 场景元素状态是否一致
- [ ] 时间是否合理流逝

### 光影连续性
- [ ] 光源方向是否一致
- [ ] 光影强度是否合理
- [ ] 色温是否一致

### 道具连续性
- [ ] 道具位置是否合理
- [ ] 道具状态是否合理
- [ ] 道具消失/出现是否合理
```

### 7.2 常见连续性问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 位置跳变 | 未追踪位置 | 建立位置追踪表 |
| 服装突变 | 未追踪服装状态 | 建立服装状态追踪 |
| 光影不一致 | 未追踪时间 | 建立时间光影追踪 |
| 道具消失 | 未追踪道具 | 建立道具追踪表 |

## 八、Prompt中的连续性描述

### 8.1 状态继承描述

在Prompt中明确状态：

```
@图片1 [动作]，[继承的状态]，[新变化]
```

**示例**：
```
@图片1 握紧铁锄，灰色粗布长袍沾满尘土（继承），手背青筋暴起（新变化）
```

### 8.2 变化描述

| 变化类型 | 描述方式 |
|----------|----------|
| 渐变 | "逐渐..." "慢慢..." |
| 突变 | "突然..." "瞬间..." |
| 状态更新 | "现在的状态是..." |
