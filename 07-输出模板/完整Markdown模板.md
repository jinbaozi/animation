## 使用说明

### 1. 填写顺序

```
1. 文档信息
2. 风格推荐
3. 人物卡
4. 场景卡
5. 分镜Prompt
6. 状态追踪
7. 检查清单
8. 附录
```

### 2. 必填项

| 部分 | 必填项 |
|------|--------|
| 文档信息 | 作品名称、片段标题、风格、镜数 |
| 风格推荐 | 5种推荐风格 |
| 人物卡 | 所有人物的三视图Prompt |
| 场景卡 | 所有场景的全景Prompt |
| 分镜Prompt | 所有镜头的完整Prompt |

### 3. 可选项

| 部分 | 可选项 |
|------|--------|
| 文档信息 | 生成日期 |
| 状态追踪 | 详细状态追踪表 |
| 附录 | 参考图列表、禁止词列表 |
