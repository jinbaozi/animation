## 四、质检流程速查

### 三层检查机制

```
阶段N完成
    ↓
【第一层】输出前自检
    核心项全部✅？ → 否 → 返回修改
    ↓ 是
【第二层】下游验收
    交付物完整？ → 否 → 退回上游
    ↓ 是
【第三层】质检抽检
    打分≥阈值？ → 否 → 退回修改
    ↓ 是
阶段通过
```

### 阻塞规则

| 级别 | 缺失处理 | 修复时限 |
|------|----------|----------|
| 🔴 核心项 | 阻塞流程，立即修复 | 2小时 |
| 🟡 推荐项 | 标记缺陷，限期修复 | 24小时 |
| 🟢 可选项 | 记录缺失，不阻塞 | 不限 |

## 六、常见问题速答

### Q1：单镜打分不合格怎么办？

**A**：检查五段式结构是否完整，角色/场景引用是否正确，Prompt是否双语完整。常见扣分项：
- 五段式结构不规范（-2分/镜）
- 参数配置缺失（-1分/镜）
- 角色引用错误（-3分/镜）

### Q2：如何判断是核心项还是推荐项？

**A**：核心项满足任一条件：
1. 下游角色依赖此字段才能开始工作
2. 缺失会导致最终输出严重不完整
3. 缺失会导致一致性控制失效

### Q3：质检不通过能继续下一阶段吗？

**A**：不能。必须满足：
- 所有核心项全部✅
- 单镜打分均≥75分
- 文档打分≥85分
- 无合规高风险

### Q4：推荐项缺失如何处理？

**A**：
1. 标记缺陷到质检检查总表
2. 指定责任人
3. 24小时内修复
4. 不阻塞流程继续

### Q5：如何引用角色基准图？

**A**：使用 `@图片X` 格式，例如：
```
@图片1 为李云的黄金标准图，使用 --cref @图片1 --cw 100
```

### Q6：风格决策卡如何确定默认子风格？

**A**：参考题材类型：
- 仙侠/玄幻 → 古风动漫
- 都市/言情 → 现代动漫
- 悬疑/惊悚 → 暗黑动漫
- 搞笑/日常 → 萌系动漫
