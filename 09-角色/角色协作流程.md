# 角色协作流程

## 一、概述

本文档定义了AI漫剧项目中5个核心角色之间的协作关系、输入输出标准和交付规范。

---

## 二、角色与模块对应矩阵

| 模块 | 主要负责角色 | 协作角色 | 核心产出 |
|------|--------------|----------|----------|
| 01-输入处理 | 总导演 | 项目协调员 | 结构化解析结果 |
| 02-风格系统 | 美术总监 | 总导演 | 风格推荐、风格卡 |
| 03-人物系统 | 美术总监 | 总导演、技术主管 | 人物卡、三视图Prompt |
| 04-场景系统 | 美术总监 | 总导演、技术主管 | 场景卡、全景Prompt |
| 05-分镜系统 | 总导演 | 美术总监 | 分镜脚本 |
| 06-一致性保障 | 技术主管 | 美术总监 | 一致性检查清单 |
| 07-输出模板 | 项目协调员 | 所有角色 | 完整Markdown文档 |
| 08-示例 | 质检合规官 | 所有角色 | 验收标准示例 |

## 三、角色详细分工与输入输出标准

### 3.1 AI总导演（Director）

#### 职责范围
- 接收原始小说文本
- 执行结构化解析（01-输入处理）
- 生成分镜脚本（05-分镜系统）
- 输出故事圣经

#### 输入定义

| 输入项 | 格式 | 来源 | 必填 |
|--------|------|------|------|
| 小说原文 | 纯文本/Markdown | 用户 | ✅ |
| 已知人物 | JSON | 用户（可选） | ❌ |
| 已知场景 | JSON | 用户（可选） | ❌ |
| 风格偏好 | 文本 | 用户（可选） | ❌ |

#### 输出定义

| 输出项 | 格式 | 目标角色 | 验收标准 |
|--------|------|----------|----------|
| 结构化解析结果 | JSON | 美术总监 | 人物清单完整、场景清单完整、事件序列清晰 |
| 分镜脚本 | Markdown | 美术总监、技术主管 | 8-10镜完整，五维描述 |
| 故事圣经 | Markdown | 美术总监、质检合规官 | 人物设定完整、核心矛盾明确、世界观清晰 |

#### 验收标准

```markdown
- [ ] 人物清单：所有出场人物已提取
- [ ] 场景清单：所有场景已识别
- [ ] 分镜数量：8-10镜（默认）或 24镜（扩展）
- [ ] 情绪曲线：有明确起伏
- [ ] 五维描述：每镜完整（视角+主体+动作+环境+情绪）
```

#### 协作输出模板

```markdown

### 3.2 AI美术总监（Art Director）

#### 职责范围
- 接收总导演交付物
- 确定项目风格（02-风格系统）
- 生成人物卡和三视图Prompt（03-人物系统）
- 生成场景卡和全景Prompt（04-场景系统）
- 编写完整分镜Prompt

#### 输入定义

| 输入项 | 格式 | 来源 | 必填 |
|--------|------|------|------|
| 结构化解析结果 | JSON | 总导演 | ✅ |
| 分镜脚本 | Markdown | 总导演 | ✅ |
| 视觉意图输入 | Markdown | 总导演 | ✅ |

#### 输出定义

| 输出项 | 格式 | 目标角色 | 验收标准 |
|--------|------|----------|----------|
| 风格推荐 | Markdown | 技术主管、质检合规官 | 5种风格，匹配度计算 |
| 风格决策卡 | Markdown | 所有角色 | 完整字段，双语关键词 |
| 人物卡 | Markdown | 技术主管、质检合规官 | 完整字段，三视图Prompt双语 |
| 场景卡 | Markdown | 技术主管、质检合规官 | 完整字段，全景Prompt双语 |
| 分镜Prompt集 | Markdown | 技术主管 | 每镜完整Prompt，五段式结构 |

#### 验收标准

```markdown
- [ ] 风格推荐：5种风格，每种有匹配度计算
- [ ] 风格决策卡：核心关键词双语、禁止词列表完整
- [ ] 人物卡：每个角色完整，三视图Prompt双语
- [ ] 场景卡：每个场景完整，全景Prompt双语
- [ ] 分镜Prompt：符合五段式结构，双语完整
```
