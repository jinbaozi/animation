# MPV验证计划

---

## 一、验证目标

### 1.1 项目目标

验证「小说文本 → AI漫剧Prompt」智能生成系统的完整流程可行性。

### 1.2 验证范围

- 角色分工协作流程
- Prompt压缩策略（P0-P5分层、410字控制）
- 三重校验机制（单镜/场次/全篇）

### 1.3 验证标准

| 维度 | 通过标准 |
|------|----------|
| 单镜Prompt字数 | ≤ 410字 |
| 压缩信息保留 | P0-P1层信息100%保留 |
| 单镜校验 | 4项全通过 |
| 场次校验 | 4项全通过 |
| 全篇三率 | > 85% |
