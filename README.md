# 长文小说转AI漫剧 - Prompt生成系统

## 项目简介

这是一个全自动的「小说文本 → AI漫剧Prompt」生成系统，专为个人创作者设计，使用 Gemini 网页版进行图像生成。

## 核心功能

| 功能模块 | 说明 |
|----------|------|
| 输入处理 | 将500-2000字小说片段解析为结构化数据 |
| 风格推荐 | AI分析小说内容，推荐5种匹配风格 |
| 人物系统 | 生成角色卡和三视图Prompt，确保角色一致性 |
| 场景系统 | 生成场景卡和全景Prompt，确保场景一致性 |
| 分镜系统 | 自动划分8-10镜，生成完整双语Prompt（五段式结构） |
| 一致性保障 | 跨镜头状态追踪和修复指南 |

## 角色分工系统

本项目采用5角色分工协作模式，确保流程规范、质量可控。

| 角色 | 核心职责 | 对应模块 |
|------|----------|----------|
| AI总导演 | 故事圣经、分镜脚本 | 01-输入处理, 05-分镜系统 |
| AI美术总监 | 风格决策、视觉设计、Prompt编写 | 02-风格系统, 03-人物系统, 04-场景系统 |
| AI技术主管 | 图像生成、一致性控制 | 06-一致性保障 |
| AI质检合规官 | 质量验收、合规审查 | 全模块 |
| AI项目协调员 | 项目调度、进度跟踪 | 全流程协调 |

详细内容请参阅 [09-角色/角色协作流程.md](./09-角色/角色协作流程.md)

## 核心痛点解决

| 痛点 | 解决方案 |
|------|----------|
| 角色一致性差 | 三视图参考图 + 特征锁定词表 + 版本管理 |
| 场景不稳定 | 场景全景参考 + 视觉锚点规范 |
| Prompt质量不稳定 | 标准化模板 + 风格关键词库 + 五段式结构 |
| 流程太慢 | 全自动化生成，用户仅需确认 |

## 质量保障机制

### 打分系统
- 单镜Prompt ≥ 75分合格
- 完整文档 ≥ 85分可发布

### 三层检查机制
1. **输出前自检**：核心项全部通过才能提交
2. **下游验收**：接收方检查交付物完整性
3. **质检抽检**：质检合规官执行打分

### 分级处理
| 级别 | 缺失处理 | 修复时限 |
|------|----------|----------|
| 🔴 核心项 | 阻塞流程，立即修复 | 2小时 |
| 🟡 推荐项 | 标记缺陷，限期修复 | 24小时 |
| 🟢 可选项 | 记录缺失，不阻塞 | 不限 |

详细内容请参阅 [09-角色/质检执行机制.md](./09-角色/质检执行机制.md)

## 使用流程

```
1. 准备小说文本（500-2000字）
      ↓
2. 按模板填写输入信息
      ↓
3. AI解析并推荐风格（5选1）
      ↓
4. 生成人物卡 + 三视图Prompt
      ↓
5. 生成场景卡 + 全景Prompt
      ↓
6. 生成分镜表 + 每镜Prompt
      ↓
7. 输出完整Markdown文档
      ↓
8. 使用Gemini网页版生成图像
```

## 核心约束

| 维度 | 约束 |
|------|------|
| 目标用户 | 个人创作者 |
| 生成工具 | Gemini 网页版（支持图片上传） |
| 输入规模 | 500-2000字小说片段 |
| 输出格式 | 完整 Markdown 文档 |
| 分镜数量 | 8-10镜/片段 |
| Prompt语言 | 双语（中+英） |
| 自动化程度 | 全自动，AI决策，用户确认 |
