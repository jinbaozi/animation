# D1 人物一致性审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：人物清单、人物四视图Prompt包

---

## 1. 审核要点

- 固定锚定完整性：人物全称+核心特征+锁定参数+兜底描述
- 特征无冲突：外貌、穿搭、配饰与定版卡100%匹配
- 人设行为匹配：动作、表情、台词风格符合人物人设
- 多人对戏区分度：同框人物有明确站位、特征区分

## 2. 规则引擎检测

### P0 检测模式
- 特征冲突：比对人物清单与VideoPrompt中的描述
- 关键词：黑长直/高马尾/眼镜/肤色/服装颜色

### P1 检测模式
- 特征模糊：缺少具体描述
- 配饰遗漏：定版配饰消失

## 3. LLM细审提示词

### 角色定义引用
- 人物清单：output/{项目名}/人物清单.md
- 人物四视图Prompt包：output/{项目名}/人物四视图Prompt包.md
- 定版卡参考：人物四视图中的角色定版描述

### 审核步骤

**Step 1: 固定锚定检查**
逐一检查VideoPrompt包中每个出现的角色，核对：
- 人物全称是否与人物清单一致
- 核心特征（脸型/发型发色/身高体型/标志性特征）是否与定版卡匹配
- 锁定参数（--cref、Character Consistency功能ID）是否正确使用
- 兜底描述是否完整（防止参考图失效时）

**Step 2: 特征冲突扫描**
对每个镜头中的角色描述，与定版卡进行逐项比对：
- [ ] 脸型：鹅蛋脸/瓜子脸/圆脸/方脸...
- [ ] 五官：眉形/眼形/鼻形/唇形...
- [ ] 发型发色：黑长直/高马尾/卷发...+颜色
- [ ] 身高体型：高大/矮小/纤细/丰腴...
- [ ] 标志性特征：胎记/疤痕/饰品...

**Step 3: 多人场景检查**
当同一镜头出现多个角色时，验证：
- 每个角色是否有明确站位描述（左/中/右、前/后）
- 各角色特征是否可明确区分（避免混淆）
- 角色间互动关系是否合理

**Step 4: 特征漂移检测**
扫描连续镜头间同一角色的特征变化：
- 列出所有变化点
- 判断是否有合理过渡或明确原因
- 无理由的特征变化视为P0问题

### 输出格式
```json
{
  "dimension": "D1",
  "fixed_anchor_score": "pass/fail",
  "feature_conflict_count": 0,
  "drift_count": 0,
  "issues": [

      "character": "角色名",
      "location": "镜头编号",
      "problem": "问题描述",
      "suggestion": "修改建议"
    }
  ],
  "final_score": 8
}
```

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全一致，无任何偏差 |
| 7-8 | 轻微偏差，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，人物失真 |
| 0-2 | 阻断性，角色完全不符 |
