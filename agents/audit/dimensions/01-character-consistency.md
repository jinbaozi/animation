# D1 人物一致性审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：人物清单、人物四视图Prompt包

---

## 1. 审核要点

- 固定锚定完整性：人物全称+核心特征+锁定参数+兜底描述
- 特征无冲突：外貌、穿搭、配饰与定版卡100%匹配
- 人设行为匹配：动作、表情、台词风格符合人物人设
- 多人对戏区分度：同框人物有明确站位、特征区分

## 2. 规则引擎检测

### P0 检测模式
- 特征冲突：比对人物清单与VideoPrompt中的描述
- 关键词：黑长直/高马尾/眼镜/肤色/服装颜色

### P1 检测模式
- 特征模糊：缺少具体描述
- 配饰遗漏：定版配饰消失

## 3. LLM细审提示

请对以下内容进行深度审核：
1. 人物特征是否与定版卡完全一致
2. 多人场景中各角色是否可明确区分
3. 动作和表情是否符合人物人设
4. 是否存在特征漂移（drift）

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全一致，无任何偏差 |
| 7-8 | 轻微偏差，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，人物失真 |
| 0-2 | 阻断性，角色完全不符 |
