# D2 场景一致性审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：场景清单、场景资产卡、VideoPrompt包中的场景描述

---

## 1. 审核要点

- 场景锚定完整性：场景全称+核心固定特征+兜底描述
- 世界观绝对合规：无违背世界观底层规则的元素
- 空间与光影连贯：时间/天气/光影方向/道具摆放连续
- 细节无矛盾：关键道具在前后镜头中一致

## 2. 规则引擎检测

### P0 检测模式
- 时代违禁元素：古风出现手机/电灯/汽车等
- 空间逻辑错误：角色位置突变

### P1 检测模式
- 光影突变：无过渡的明暗变化
- 道具消失：关键道具无理由消失
- 天气不一致：雨/晴/雪等天气突变

## 3. LLM细审提示词

### 场景定义引用
- 场景清单：output/{项目名}/场景清单.md
- 场景资产卡：output/{项目名}/场景资产卡.md
- VideoPrompt包：output/{项目名}/VideoPrompt包.md

### 审核步骤

**Step 1: 场景锚定检查**
逐一检查VideoPrompt包中每个场景，核对：
- 场景全称是否与场景清单一致
- 核心固定特征是否与场景资产卡匹配
- 兜底描述是否完整

**Step 2: 空间逻辑验证**
对连续镜头进行空间关系分析：
- 角色移动路线是否合理（室内→室外需有出口）
- 道具位置变化是否有合理说明
- 视角切换是否遵守轴线规则

**Step 3: 光影时间线审查**
构建时间-天气-光影矩阵：
- 列出每个镜头的 时间/天气/光影方向
- 检查相邻镜头间的变化是否有过渡
- 突变（无铺垫的白天→夜晚）标记为P1

**Step 4: 道具追踪**
关键道具全流程追踪：
- 列出所有关键道具
- 检查每个道具在连续镜头中的存在状态
- 消失且无合理说明的道具标记为P1

### 输出格式
```json
{
  "dimension": "D2",
  "scene_anchor_score": "pass/fail",
  "spatial_logic_issues": 0,
  "lightning_time_issues": 0,
  "prop_tracking_issues": 0,
  "issues": [...],
  "final_score": 8
}
```

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全一致，无任何偏差 |
| 7-8 | 轻微偏差，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，场景失真 |
| 0-2 | 阻断性，场景完全不符 |
