# D2 场景一致性审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：场景清单、场景资产卡、VideoPrompt包中的场景描述

---

## 1. 审核要点

- 场景锚定完整性：场景全称+核心固定特征+兜底描述
- 世界观绝对合规：无违背世界观底层规则的元素
- 空间与光影连贯：时间/天气/光影方向/道具摆放连续
- 细节无矛盾：关键道具在前后镜头中一致

## 2. 规则引擎检测

### P0 检测模式
- 时代违禁元素：古风出现手机/电灯/汽车等
- 空间逻辑错误：角色位置突变

### P1 检测模式
- 光影突变：无过渡的明暗变化
- 道具消失：关键道具无理由消失
- 天气不一致：雨/晴/雪等天气突变

## 3. LLM细审提示

请对以下内容进行深度审核：
1. 场景描述是否与场景资产卡一致
2. 空间关系是否合理（尤其跨镜头时）
3. 光影/天气/时间是否连贯
4. 道具摆放是否一致

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全一致，无任何偏差 |
| 7-8 | 轻微偏差，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，场景失真 |
| 0-2 | 阻断性，场景完全不符 |
