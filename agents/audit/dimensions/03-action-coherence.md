# D3 动作连贯性审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：增强分镜执行表、VideoPrompt包

---

## 1. 审核要点

- 动作承接性：单镜头动作起点与上一镜头终点完全承接
- 物理与人体合理性：动作符合物理规则与人体工学
- 对戏互动逻辑：双方视线/站位/动作互动关系明确

## 2. 规则引擎检测

### P0 检测模式
- 物理错误：反关节动作、不可能的速度/高度
- 物体消失：手持物体突然消失

### P1 检测模式
- 动作承接断裂：落幅→起幅不连贯
- 人体工学错误：不符合正常活动范围

## 3. LLM细审提示

请对以下内容进行深度审核：
1. 连续镜头间动作是否自然承接
2. 动作是否符合物理规律
3. 肢体交互是否合理

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全连贯，无任何断裂 |
| 7-8 | 轻微问题，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，动作失真 |
| 0-2 | 阻断性，动作完全不合理 |
