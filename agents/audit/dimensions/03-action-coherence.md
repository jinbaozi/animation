# D3 动作连贯性审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：增强分镜执行表、VideoPrompt包

---

## 1. 审核要点

- 动作承接性：单镜头动作起点与上一镜头终点完全承接
- 物理与人体合理性：动作符合物理规则与人体工学
- 对戏互动逻辑：双方视线/站位/动作互动关系明确

## 2. 规则引擎检测

### P0 检测模式
- 物理错误：反关节动作、不可能的速度/高度
- 物体消失：手持物体突然消失

### P1 检测模式
- 动作承接断裂：落幅→起幅不连贯
- 人体工学错误：不符合正常活动范围

## 3. LLM细审提示词

### 动作定义引用
- 增强分镜执行表：output/{项目名}/增强分镜执行表.md
- 序列衔接与继承表：output/{项目名}/序列衔接与继承表.md
- VideoPrompt包：output/{项目名}/VideoPrompt包.md

### 审核步骤

**Step 1: 动作承接性检查**
对每个镜头的起幅与上一镜头的落幅进行比对：
- 列出每个镜头的动作起点描述
- 列出上一镜头的动作终点描述
- 判断承接是否自然（允许合理省略过渡）

**Step 2: 物理合理性验证**
检查每个动作描述：
- 高度：人类正常弹跳高度≤1米
- 速度：人类正常移动速度
- 重量：物体重量与角色体力匹配
- 角度：反关节角度≤15度

**Step 3: 物体追踪**
手持/交互物体进行追踪：
- 列出所有交互物体
- 检查物体在连续镜头中的存在状态
- 消失的物体需有明确交代（如放下/丢弃）

**Step 4: 肢体交互验证**
多角色场景的肢体交互：
- 视线方向是否匹配对话关系
- 伸手/触碰动作的目标位置是否合理
- 拥抱/阻挡等动作的空间关系是否正确

```json
  "object_tracking_issues": 0,
  "issues": [...],
  "final_score": 8
}
```

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全连贯，无任何断裂 |
| 7-8 | 轻微问题，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，动作失真 |
| 0-2 | 阻断性，动作完全不合理 |
