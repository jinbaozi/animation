# D4 剧情符合度审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：剧本、基础分镜执行表、增强分镜执行表

---

## 1. 审核要点

- 核心剧情点匹配：100%完成分镜大纲中的核心剧情任务
- 剧情逻辑无矛盾：无违背前后剧情的设定
- 节奏与叙事匹配：镜头时长/动作密度/景别运镜匹配叙事节奏
- 伏笔回收匹配：伏笔/回收镜头中关键元素明确

## 2. 规则引擎检测

### P0 检测模式
- 核心剧情遗漏：分镜大纲任务未完成
- 剧情逻辑矛盾：前后设定冲突

### P1 检测模式
- 节奏不匹配：拖沓或仓促
- 伏笔未回收：关键元素无后续

## 3. LLM细审提示

请对以下内容进行深度审核：
1. 是否完成核心剧情任务
2. 叙事逻辑是否通顺
3. 节奏是否合理
4. 伏笔是否都有回收

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全符合，无任何偏差 |
| 7-8 | 轻微偏差，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，剧情失真 |
| 0-2 | 阻断性，剧情完全不符 |
