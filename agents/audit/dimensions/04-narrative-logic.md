# D4 剧情符合度审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：剧本、基础分镜执行表、增强分镜执行表

---

## 1. 审核要点

- 核心剧情点匹配：100%完成分镜大纲中的核心剧情任务
- 剧情逻辑无矛盾：无违背前后剧情的设定
- 节奏与叙事匹配：镜头时长/动作密度/景别运镜匹配叙事节奏
- 伏笔回收匹配：伏笔/回收镜头中关键元素明确

## 2. 规则引擎检测

### P0 检测模式
- 核心剧情遗漏：分镜大纲任务未完成
- 剧情逻辑矛盾：前后设定冲突

### P1 检测模式
- 节奏不匹配：拖沓或仓促
- 伏笔未回收：关键元素无后续

## 3. LLM细审提示词

### 剧情定义引用
- 剧本：output/{项目名}/剧本.md
- 基础分镜执行表：output/{项目名}/基础分镜执行表.md
- 增强分镜执行表：output/{项目名}/增强分镜执行表.md

### 审核步骤

**Step 1: 核心剧情点匹配**
逐一核对分镜大纲中的核心任务：
- 列出剧本中的核心剧情点
- 列出分镜大纲中的任务列表
- 确认每个核心剧情点都有对应镜头

**Step 2: 剧情逻辑验证**
检查前后剧情设定一致性：
- 人物状态变化是否有说明（受伤/获得道具...）
- 时间线是否合理（白天→夜晚需有过程）
- 地点切换是否有合理理由

**Step 3: 叙事节奏评估**
镜头密度与叙事节奏匹配：
- 高潮段落应有更多镜头
- 过渡段落应精简
- 单调段落（如长对话）需有镜头变化

**Step 4: 伏笔回收检查**
- 列出所有埋下的伏笔
- 确认每个伏笔都有后续回收
- 未回收伏笔标记为P1

### 输出格式
```json
{
  "dimension": "D4",
  "core_plot_match": "100%/X%",
  "logic_issues": 0,
  "pacing_issues": 0,
  "setup_payoff_issues": 0,
  "issues": [...],
  "final_score": 8
}
```

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全符合，无任何偏差 |
| 7-8 | 轻微偏差，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，剧情失真 |
| 0-2 | 阻断性，剧情完全不符 |
