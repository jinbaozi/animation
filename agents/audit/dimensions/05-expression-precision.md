# D5 表情精准度审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：VideoPrompt包、增强分镜执行表

---

## 1. 审核要点

- 微表情描述精准：面部肌肉状态、眼神细节
- 情绪与表情强绑定：内心活动与外显表情一致
- AU动作单元应用：使用专业表情描述词汇

## 2. 规则引擎检测

### P1 检测模式
- 表情模糊：仅用"开心/难过"等泛词
- 眼神缺失：无表情时眼神描述缺失

## 3. LLM细审提示

请对以下内容进行深度审核：
1. 微表情是否精准（眼部肌肉/嘴角弧度/眉毛）
2. 情绪与表情是否匹配
3. 是否使用了专业表情词汇

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全精准，无任何偏差 |
| 7-8 | 轻微偏差，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，表情失真 |
| 0-2 | 阻断性，表情完全不符 |
