# D5 表情精准度审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：VideoPrompt包、增强分镜执行表

---

## 1. 审核要点

- 微表情描述精准：面部肌肉状态、眼神细节
- 情绪与表情强绑定：内心活动与外显表情一致
- AU动作单元应用：使用专业表情描述词汇

## 2. 规则引擎检测

### P1 检测模式
- 表情模糊：仅用"开心/难过"等泛词
- 眼神缺失：无表情时眼神描述缺失

## 3. LLM细审提示词

### 表情定义引用
- VideoPrompt包：output/{项目名}/VideoPrompt包.md
- 增强分镜执行表：output/{项目名}/增强分镜执行表.md

### 审核步骤

**Step 1: 微表情关键词扫描**
对每个表情描述进行AU动作单元分析：
- 眼部：眉毛上扬/下压、眼睑开合程度、瞳孔大小
- 嘴部：嘴角上扬/下压、嘴唇张开程度
- 整体：面部肌肉紧张/放松程度

**Step 2: 情绪-表情匹配验证**
检查内心活动与外显表情的一致性：
- 列出每个镜头的内心活动描述
- 核对表情描述是否匹配该情绪
- 不匹配（如：悲伤情绪+微笑）标记为P1

**Step 3: 专业词汇使用评估**
检查是否使用了专业表情词汇：
- 模糊词（开心/难过）需有进一步描述
- 应包含具体面部肌肉状态描述
- 眼神方向和注视目标需明确

**Step 4: 表情连续性追踪**
检查连续镜头间的表情变化：
- 列出同一角色在连续镜头中的表情变化序列
- 判断变化是否有情绪递进的合理性
- 突兀的表情变化（如大笑→面无表情）需有明确原因
- 情绪递进是否自然：悲伤累积、喜悦升级等

### 输出格式
```json
{
  "dimension": "D5",
  "micro_expression_accuracy": "high/medium/low",
  "emotion_expression_match": "match/mismatch",
  "professional_vocabulary_usage": "good/needs_improvement",
  "issues": [...],
  "final_score": 8
}
```

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全精准，无任何偏差 |
| 7-8 | 轻微偏差，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，表情失真 |
| 0-2 | 阻断性，表情完全不符 |
