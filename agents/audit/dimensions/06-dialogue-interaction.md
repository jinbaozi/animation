# D6 对戏互动审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：增强分镜执行表、VideoPrompt包

---

## 1. 审核要点

- 视线匹配：对话双方视线方向正确
- 站位关系：角色间空间关系明确
- 肢体接触：互动动作有物理合理性
- 情绪传染：情绪在角色间传递有逻辑

## 2. 规则引擎检测

### P1 检测模式
- 视线不匹配：对话视线错位
- 站位冲突：同框位置矛盾
- 情绪传染缺失：情绪传递无逻辑

## 3. LLM细审提示

请对以下内容进行深度审核：
1. 对话双方视线是否匹配
2. 站位关系是否合理
3. 情绪传染是否符合逻辑

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全匹配，无任何问题 |
| 7-8 | 轻微问题，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，互动失真 |
| 0-2 | 阻断性，互动完全不符 |
