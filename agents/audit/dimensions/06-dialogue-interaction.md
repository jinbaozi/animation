# D6 对戏互动审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：增强分镜执行表、VideoPrompt包

---

## 1. 审核要点

- 视线匹配：对话双方视线方向正确
- 站位关系：角色间空间关系明确
- 肢体接触：互动动作有物理合理性
- 情绪传染：情绪在角色间传递有逻辑

## 2. 规则引擎检测

### P1 检测模式
- 视线不匹配：对话视线错位
- 站位冲突：同框位置矛盾
- 情绪传染缺失：情绪传递无逻辑

## 3. LLM细审提示词

### 互动定义引用
- 增强分镜执行表：output/{项目名}/增强分镜执行表.md
- VideoPrompt包：output/{项目名}/VideoPrompt包.md

### 审核步骤

**Step 1: 视线匹配验证**
对每个对话镜头检查：
- 列出说话者和听话者
- 判断视线方向是否正确（A看B时，B应在A的视野范围内）
- 视线错位标记为P1

**Step 2: 站位关系分析**
对同框角色进行空间分析：
- 左右关系：是否符合轴线规则
- 前后关系：遮挡关系是否合理
- 上下关系：身高差是否合理

**Step 3: 肢体接触验证**
检查有肢体接触的场景：
- 伸手动作的起点和终点是否合理
- 拥抱/拍肩等动作的力度和姿势描述
- 身体接触的合理性（陌生人vs熟人）

**Step 4: 情绪传染追踪**
多角色情绪传染链：
- 列出情绪变化的触发点
- 检查情绪传递是否有时序合理性
- 情绪传染逻辑错误标记为P1

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全匹配，无任何问题 |
| 7-8 | 轻微问题，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，互动失真 |
| 0-2 | 阻断性，互动完全不符 |
