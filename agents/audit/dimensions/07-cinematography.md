# D7 运镜专业度审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：增强分镜执行表、VideoPrompt包

---

## 1. 审核要点

- 运镜与景别明确：景别+核心运镜方式，一个镜头仅一个核心运镜
- 运镜符合叙事逻辑：运镜服务于剧情
- 画质与光影统一：画质参数/光影风格与全片基调匹配
- 镜头语言合规：无越轴、无空间逻辑混乱

## 2. 规则引擎检测

### P1 检测模式
- 运镜缺失：无景别/运镜描述
- 越轴问题：违反轴线规则
- 参数不统一：画质/光影风格突变

## 3. LLM细审提示

请对以下内容进行深度审核：
1. 运镜是否服务于叙事
2. 是否符合专业镜头语言
3. 画质/光影是否统一

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全专业，无任何问题 |
| 7-8 | 轻微问题，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，运镜失真 |
| 0-2 | 阻断性，运镜完全不符 |
