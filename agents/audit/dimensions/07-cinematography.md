# D7 运镜专业度审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：增强分镜执行表、VideoPrompt包

---

## 1. 审核要点

- 运镜与景别明确：景别+核心运镜方式，一个镜头仅一个核心运镜
- 运镜符合叙事逻辑：运镜服务于剧情
- 画质与光影统一：画质参数/光影风格与全片基调匹配
- 镜头语言合规：无越轴、无空间逻辑混乱

## 2. 规则引擎检测

### P1 检测模式
- 运镜缺失：无景别/运镜描述
- 越轴问题：违反轴线规则
- 参数不统一：画质/光影风格突变

## 3. LLM细审提示词

### 运镜定义引用
- 增强分镜执行表：output/{项目名}/增强分镜执行表.md
- VideoPrompt包：output/{项目名}/VideoPrompt包.md
- rules/运镜知识.md

### 审核步骤

**Step 1: 景别运镜完整性检查**
对每个镜头检查：
- 景别描述：特写/近景/中景/远景/全景
- 运镜方式：推/拉/摇/移/跟/固定
- 每个镜头仅允许一个核心运镜

**Step 2: 轴线规则验证**
检查镜头间的轴线关系：
- 同一场景的镜头是否遵守180度轴线
- 正反打镜头的过肩关系是否正确
- 轴线混乱标记为P1

**Step 3: 叙事服务评估**
检查运镜是否为叙事服务：
- 推镜头是否用于强调重要元素
- 拉镜头是否用于展现环境或释放情绪
- 无意义的随机运镜标记为P2

**Step 4: 画质光影统一性检查**
检查画质参数一致性：
- 色调：暖/冷/中性是否统一
- 光影风格：自然光/戏剧光是否连贯
- 画质风格：写实/风格化是否一致

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全专业，无任何问题 |
| 7-8 | 轻微问题，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，运镜失真 |
| 0-2 | 阻断性，运镜完全不符 |
