# D8 世界观合规审核模块

> 版本：v1.0 | 日期：2026-04-06
> 审核对象：全量产物

---

## 1. 审核要点

- 时代背景合规：古代/现代/未来等设定一致
- 文化细节合规：服饰/手势/习俗符合设定
- 物理规则合规：魔法/科幻元素符合设定手册
- 风格统一性：光影/色彩/画质/运镜风格统一

## 2. 规则引擎检测

### P0 检测模式
- 时代错误：古代出现现代物品
- 文化禁忌：违背设定中的文化规则

### P1 检测模式
- 物理规则违背：魔法/科幻元素不符合设定
- 风格不统一：光影/色彩/运镜风格突变

## 3. LLM细审提示

请对以下内容进行深度审核：
1. 是否符合设定中的世界观
2. 文化细节是否正确
3. 物理规则是否自洽
4. 整体风格是否统一

## 4. 评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 完全合规，无任何问题 |
| 7-8 | 轻微问题，不影响观感 |
| 5-6 | 显著问题，需要修复 |
| 3-4 | 严重问题，世界观失真 |
| 0-2 | 阻断性，世界观完全不符 |
