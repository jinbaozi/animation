## D1 人物一致性规则

### P0 模式（阻断性）
- 人物特征冲突：定版特征与实际描述不符（如"黑长直"变为"高马尾"）
- 眼镜消失：定版有眼镜的角色后续镜头无眼镜
- 服装颜色冲突：定版颜色与描述不符

### P1 模式（显著瑕疵）
- 特征描述模糊：仅用"漂亮/帅气"等模糊词
- 配饰遗漏：定版配饰在后续镜头消失
- 体型变化：未说明原因的体型显著变化

### 规则表达式
```
特征关键词：脸型/发型发色/身高体型/标志性特征
冲突检测：比对人物清单与VideoPrompt包中的描述
```

## D2 场景一致性规则

### P0 模式（阻断性）
- 时代违禁元素：古风出现手机/电灯等现代物品
- 空间逻辑错误：角色突然出现在不合理的位置

### P1 模式（显著瑕疵）
- 光影突变：白天→夜晚无过渡
- 道具消失：前序镜头道具后续无理由消失
- 天气不一致：前序下雨后续晴天

### 规则表达式
```
场景标签：室内/室外/时间/天气/光影方向
道具追踪：关键道具必须全程可追踪
```

## D3 动作连贯性规则

### P0 模式（阻断性）
- 物理错误：反关节动作、"原地起跳3米"等
- 物体消失：手持物体突然消失

### P1 模式（显著瑕疵）
- 动作承接断裂：起点终点不连贯
- 人体工学错误：不符合人体正常活动范围

### 规则表达式
```
时间戳：验证动作起点/终点
物理关键词：高度/速度/重量
```

## D4 剧情符合度规则

### P0 模式（阻断性）
- 核心剧情遗漏：分镜大纲中的核心任务未完成
- 剧情逻辑矛盾：前后矛盾

### P1 模式（显著瑕疵）
- 节奏不匹配：镜头时长与叙事节奏不符
- 伏笔未回收：埋下的伏笔无回收

### 规则表达式
```
任务标签：分镜大纲中的核心任务点
伏笔标记：关键元素必须有回收
```

## D5 表情精准度规则

### P1 模式（显著瑕疵）
- 表情模糊：仅写"开心/难过"无微表情
- 眼神缺失：无表情时眼神描述

### 规则表达式
```
表情关键词：眼部肌肉/嘴角弧度/眉毛动作
AU动作单元：专业表情描述词汇
```

## D6 对戏互动规则

### P1 模式（显著瑕疵）
- 视线不匹配：对话双方视线错位
- 站位冲突：同框角色位置矛盾
- 情绪传染缺失：情绪传递无逻辑

### 规则表达式
```
站位标签：左右/前后/上下关系
视线方向：左看/右看/对视
```

---

## D7 运镜专业度规则

### P1 模式（显著瑕疵）
- 运镜缺失：无景别/运镜描述
- 越轴问题：违反轴线规则
- 参数不统一：画质/光影风格突变

### 规则表达式
```
景别范围：特写/近景/中景/远景/全景
运镜方式：推/拉/摇/移/跟/固定
画质参数：分辨率/风格/色调
```

## D8 世界观合规规则

### P0 模式（阻断性）
- 时代错误：古代出现现代物品
- 文化禁忌：违背设定中的文化规则

### P1 模式（显著瑕疵）
- 物理规则违背：魔法/科幻元素不符合设定
- 风格不统一：光影/色彩/运镜风格突变

### 规则表达式
```
违禁词正则：现代/科技/实拍类词汇
世界观标签：古代/现代/未来/奇幻/科幻
```

## 规则引擎执行逻辑

### Phase 1: 规则引擎预检（8维度并行）
1. 读取产物文件
2. 对每个维度应用对应规则
3. 标记：通过 / 疑问 / P0

### Phase 2: LLM细审（仅对疑问项）
1. 仅对"疑问"项调用LLM
2. LLM输出详细问题分析
3. 综合给出评分

### 输出格式
```json
{
  "dimension": "D1",
  "rule_result": "pass|question|p0",
  "llm_analysis": "...",
  "score": 8,
  "issues": [{"level": "P0", "description": "...", "location": "...", "suggestion": "..."}]
}
```

## 评分计算公式

### 综合评分计算

```
综合评分 = Σ(各维度评分 × 权重) / Σ权重

权重分配：
- D1 人物一致性: 20% (核心角色表现)
- D2 场景一致性: 15% (视觉基础)
- D3 动作连贯性: 15% (物理真实感)
- D4 剧情符合度: 15% (叙事核心)
- D5 表情精准度: 10% (表演细节)
- D6 对戏互动: 10% (角色交互)
- D7 运镜专业度: 10% (视觉表达)
- D8 世界观合规: 5% (设定遵守)
```

### 维度评分调整规则

1. **P0问题降级规则**
   - 存在1个P0问题：该维度评分≤5
   - 存在2个及以上P0问题：该维度评分≤3

2. **P1问题降级规则**
   - 存在3个及以上P1问题：该维度评分-2
   - 存在5个及以上P1问题：该维度评分-4

3. **P2问题加分规则**
   - 无P2问题：+0.5（仅当其他评分已达9-10时）

### 最终评级确定

| 综合评分 | 评级 | 处理方式 |
|----------|------|----------|
| ≥9.0 | 优秀 | 可直接进入制作 |
| 7.0-8.9 | 良好 | 微调后进入制作 |
| 5.0-6.9 | 合格 | 修复P0/P1后进入制作 |
| 3.0-4.9 | 不合格 | 重大修改后重新审核 |
| <3.0 | 阻断性 | 必须重新生成 |

### P0/P1/P2计数规则

**P0计数**：每个P0问题独立计数
**P1计数**：同类P1问题合并计数（如多处"表情模糊"计为1个P1类）
**P2计数**：建议项，不计入评分但影响最终建议
