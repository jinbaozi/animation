# Step 1: 人物分析

> 执行角色：AI美术技术总监
> 所属阶段：Phase 2a

---

## 执行步骤

### 1.1 接收人物清单

1. 接收 `人物清单.md`
2. 识别需要生成四视图的角色
3. 区分主角、配角、龙套

### 1.2 建立视觉档案

为每个角色建立视觉档案，包含：

| 字段 | 内容示例 |
|------|----------|
| 角色名称 | 白浅 |
| 脸型 | 鹅蛋脸 |
| 肤色 | 病态苍白 |
| 眼睛 | 杏核眼，眼神忧郁 |
| 身形 | 纤细单薄 |
| 发型 | 黑色长发及腰 |
| 服装 | 素雅白色长裙 |
| 配饰 | 腰间淡蓝色丝带，简单发簪 |
| 风格关键词 | 动画风格，8K高清 |

### 1.3 输出要求

- 主角必须生成完整的4视图
- 配角视情况生成2-4视图
- 龙套至少生成正面全身

### 1.4 注意事项

- 参考 `rules/审美偏好.md` 中的用户偏好设定
- 检查 `rules/风格一致性.md` 确保风格匹配
- 所有角色必须使用纯白背景
