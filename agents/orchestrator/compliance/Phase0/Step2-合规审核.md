# Step 2: 合规审核清单

> 执行角色：AI品控合规官
> 所属 Phase：Phase 0

---

对每一项进行检查，结果记录到 `合规预审报告.md`。

---

## 2.1 版权审核

| 检查项 | 通过标准 | 风险等级 |
|--------|---------|---------|
| 原创性 | 原创作品或已获得授权 | CRITICAL |
| 抄袭检测 | 无高相似度内容 | CRITICAL |
| 版权声明 | 明确版权归属 | HIGH |

---

## 2.2 敏感内容审核

| 检查项 | 通过标准 | 风险等级 |
|--------|---------|---------|
| 政治敏感 | 无违反四项基本原则内容 | CRITICAL |
| 色情低俗 | 无色情描写 | CRITICAL |
| 暴力血腥 | 无过度暴力描写 | HIGH |
| 违法犯罪 | 无教唆犯罪内容 | CRITICAL |
| 封建迷信 | 无迷信宣传 | MEDIUM |

---

## 2.3 平台合规审核

| 平台 | 特殊要求 |
|------|---------|
| 抖音 | 竖屏优先，时长15秒-3分钟 |
| 快手 | 竖屏优先，时长15秒-10分钟 |
| B站 | 横屏/竖屏均可，时长灵活 |
| 微信视频号 | 竖屏优先，1分钟以内最佳 |

---

## 2.4 内容质量审核

| 检查项 | 通过标准 |
|--------|---------|
| 叙事完整性 | 有清晰的故事线 |
| 角色完整性 | 主要角色有明确动机 |
| 场景可行性 | 场景可转化为视觉表达 |

---

## 2.5 审核结论判定

| 结论 | 说明 |
|------|------|
| PASS | 通过，可进入Phase 1 |
| PASS_WITH_SUGGESTIONS | 通过，有建议优化项 |
| NEEDS_REVISION | 需要修改后重审 |
| REJECTED | 阻断性问题，无法继续 |

---

## 2.6 常见问题处理

### Q1: 发现抄袭嫌疑
```
处理：标记CRITICAL，停止审核，报告用户
```

### Q2: 平台要求与内容冲突
```
处理：提供修改建议，优先级 MEDIUM-HIGH
例：用户想要10分钟内容但目标抖音 → 建议拆分或精简
```

### Q3: 部分章节有问题
```
处理：标注问题位置，允许其他章节继续
```
