# Step 3: 评分标准

> 执行角色：AI品控合规官
> 所属 Phase：Phase 0

---

## 3.1 评分维度

对每个维度进行0-10分评分：

```
评分维度：
- 版权合规性：___/10
- 内容安全性：___/10
- 平台适配性：___/10
- 叙事完整性：___/10
- 角色丰满度：___/10
- 场景可行性：___/10

综合评分：___/10
```

---

## 3.2 评分标准说明

### 版权合规性 (0-10)

| 分数 | 标准 |
|------|------|
| 9-10 | 完全原创或已获完整授权 |
| 6-8 | 有轻微相似但可证明原创 |
| 3-5 | 存在争议，需进一步确认 |
| 0-2 | 确认抄袭或无授权 |

### 内容安全性 (0-10)

| 分数 | 标准 |
|------|------|
| 9-10 | 无任何敏感内容 |
| 6-8 | 有轻微擦边内容但可控 |
| 3-5 | 有明显敏感内容需修改 |
| 0-2 | 存在CRITICAL级别问题 |

### 平台适配性 (0-10)

| 分数 | 标准 |
|------|------|
| 9-10 | 完全符合目标平台要求 |
| 6-8 | 基本符合，稍作调整即可 |
| 3-5 | 需要较大调整 |
| 0-2 | 与平台要求严重不符 |

### 叙事完整性 (0-10)

| 分数 | 标准 |
|------|------|
| 9-10 | 故事线完整，有明确起承转合 |
| 6-8 | 故事线基本完整，有小缺陷 |
| 3-5 | 故事线有较大缺失 |
| 0-2 | 无清晰故事线 |

### 角色丰满度 (0-10)

| 分数 | 标准 |
|------|------|
| 9-10 | 主要角色动机明确，性格立体 |
| 6-8 | 角色基本丰满，有少量缺失 |
| 3-5 | 角色塑造有较大提升空间 |
| 0-2 | 角色扁平，缺乏塑造 |

### 场景可行性 (0-10)

| 分数 | 标准 |
|------|------|
| 9-10 | 所有场景均可视觉化表达 |
| 6-8 | 大部分场景可行，少量需简化 |
| 3-5 | 部分场景难以视觉化 |
| 0-2 | 场景过于抽象或不可能实现 |

---

## 3.3 综合评分计算

综合评分 = (版权合规性 + 内容安全性 + 平台适配性 + 叙事完整性 + 角色丰满度 + 场景可行性) / 6
