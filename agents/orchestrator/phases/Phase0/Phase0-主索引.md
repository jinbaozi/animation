---

## 执行概述

| 项目 | 内容 |
|------|------|
| Phase | Phase 0 |
| 执行角色 | AI品控合规官 |
| 输入 | 小说文本、改编要求、目标平台、项目名 |
| 输出 | 合规预审报告.md |
| 执行时长 | 约10-30分钟（取决于文本长度） |

---

## 执行前提

- [ ] 用户已提供原始小说文本
- [ ] 用户已明确目标平台（抖音/快手/B站等）
- [ ] 用户已说明改编要求（如有）

## 执行流程

```
用户提交任务
    │
    ▼
Step 0: 图谱查询（通过 MCP 查询合规规则）
    │
    ▼
Step 1: 接收与解析
    │
    ▼
Step 2: 合规审核清单
    │
    ▼
Step 3: 评分标准
    │
    ▼
Step 4: 问题分类
    │
    ▼
Step 5: 生成报告
    │
    ▼
输出：合规预审报告.md
```

---

## 输出文件

`合规预审报告.md` - 包含基本信息、合规评分、问题清单、审核结论、修改建议和下一步行动。

---

## 返工机制

- **返工触发**：用户修改后重新提交
- **返工上限**：连续3次返工
- **升级处理**：3次后仍无法通过，报告用户无法制作
