# Step 0: 图谱查询 — 合规规则获取

> 执行角色：AI品控合规官
> 所属 Phase：Phase 0
> **强制步骤**：执行任何合规审核前，必须先通过图谱查询获取规则

---

## 0.1 连接 MCP Server

通过 `mcp_config.json` 连接 graphify MCP server。

---

## 0.2 强制查询 — 合规规则

**Query 1: 禁用词正则表达式**
```
查询：Seedance2 项目禁止清单中禁用词正则表达式是什么？国风动漫风格项目应避免哪些词汇？
```
**预期返回**：
- 禁用词正则：`(?i)(影视|电影|摄像|胶片|摄影|古风写实|写实CG|游戏CG|影视质感|影视级|电影级)`
- 禁用原因：国风动漫风格项目禁止出现写实/影视相关词汇

**Query 2: 禁止行为清单**
```
查询：Seedance2 提示词生成前，品控合规官需要检查哪些禁止行为？
```
**预期返回**：禁止行为清单中的所有条目，包括：
- 禁止使用人称代词（她/他/Young woman）
- 禁止同一时间段多个动作冲突
- 禁止运镜与动作矛盾
- 禁止模糊运镜描述
- 禁止手部精细动作（超过5个手指）
- 禁止文字/字幕内容描述
- 禁止同屏超过2个主要人物
- 禁止风格标签冲突
- 禁止场景/服装/道具突变
- 禁止跳过动作三阶段（蓄力/执行/收回）
- 禁止对话时视线不看对方

**Query 3: 生成前8项自检**
```
查询：Seedance2 提示词生成前的8项自检清单是什么？
```
**预期返回**：
1. 是否使用角色名而非人称代词？
2. 是否每个时间段只描述一个主动作？
3. 运镜描述是否具体（不用模糊词汇）？
4. 光线描述是否具体（不用"好看光"等模糊词）？
5. 风格标签是否≤2个？
6. 是否避免了"手"的精细动作描写？
7. 是否≤2个主要人物同屏？
8. 是否通过禁用词正则检查？

**Query 4: 平台合规规则**
```
查询：抖音、快手、B站、微信视频号的内容合规规则有什么差异？
```
**预期返回**：各平台的特殊要求（竖屏/横屏、时长限制、审核偏好）

## 0.3 图谱溯源记录

每次查询后，记录返回结果中的 `source_location` 字段，格式：

```markdown
## 图谱查询溯源记录

| 查询项 | 来源节点 | source_location |
|--------|---------|----------------|
| 禁用词正则 | 禁用词正则表达式 | rules/Seedance2/Seedance2-禁止清单.md |
| 禁止行为清单 | 禁止行为清单 | rules/Seedance2/Seedance2-禁止清单.md |
| 生成前8项自检 | 生成前8项自检 | rules/Seedance2/Seedance2-禁止清单.md |
| 平台合规 | 平台内容合规规范 | rules/平台内容合规规范.md |
```

此溯源记录需附加在最终合规预审报告中。

---

## 0.4 验证图谱覆盖度

执行图谱查询后，通过以下问题验证返回的合规规则是否与源文件一致：

```
graphify query "Seedance2 禁止清单中关于禁用词正则的核心规则是什么？"
```

如返回结果与 rules/Seedance2/Seedance2-禁止清单.md 不一致，则图谱可能未同步，需先执行 `/graphify` Skill 增量更新图谱。

---

## 0.5 进入 Step 1

完成图谱查询并获取所有合规规则后，携带查询结果进入 Step 1: 接收与解析。

**携带物**：
- 禁用词正则表达式（用于Step 2审核）
- 禁止行为清单（用于Step 2审核）
- 生成前8项自检清单（用于Step 2审核）
- 平台合规规则（用于Step 2审核）
- 图谱查询溯源记录（附加在最终报告中）
