## 落幅格式规范（v1.1 新增）

### 落幅字段结构

每个镜头的"落幅"字段必须包含以下信息，格式为：

```
[落幅，{载体}，{时长}，{说明}]
```

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| 落幅 | 固定标识符 | `落幅` |
| 载体 | 落幅所在的画面主体 | `面部特写` / `眼神` / `手部` / `弓弦颤动` |
| 时长 | 落幅持续秒数 | `4秒` / `3-5秒` |
| 说明 | 情绪或叙事目的 | `震惊确认` / `希望重燃` |

### 落幅格式示例

```
✅ 正确格式：
[落幅，眼神，4秒，震惊确认]
[落幅，手部特写，3秒，力量提升验证]
[落幅，面部特写，5秒，情绪余震]

❌ 错误格式（仅有描述性文字，无结构）：
展示村庄全景，引入世界观          ← 缺少载体和时长
系统觉醒的震撼瞬间                ← 缺少载体和时长
```

### 落幅时长规则

| 情绪类型 | 最小时长 | 最大时长 | 体感目标 |
|---------|---------|---------|---------|
| 震惊/惊喜 | 3秒 | 5秒 | 观众完成一次屏息→呼气 |
| 悲伤/释然 | 4秒 | 6秒 | 观众完成一次完整呼吸循环 |
| 紧张/期待 | 2秒 | 3秒 | 保持张力，不释放 |
| 坚定/充实 | 3秒 | 4秒 | 建立信心传导 |
| 愤怒/爆发 | 2秒 | 3秒 | 截断式落幅，保持冲击 |

### 必须标注落幅的镜头类型

以下情况**必须**在落幅字段中标注 `[落幅，载体，时长，说明]`：

| 必须标注的场景 | 理由 |
|-------------|------|
| 情绪转折点（第1集系统觉醒等） | 高冲击力时刻，需定格 |
| 金手指/系统提示出现 | 观众需要时间理解新信息 |
| 导师关键台词结束 | 情绪余震需要落幅承载 |
| 战斗/动作戏的关键帧 | 力量感需要视觉沉淀 |
| 所有"震惊"、"惊喜"、"释然"情绪镜头 | 情绪释放需要落幅 |

### 禁止的落幅格式

| 禁止 | 示例 | 说明 |
|------|------|------|
| 仅有描述文字 | `展示村庄全景，引入世界观` | 无结构，无时长 |
| 仅有情绪词 | `震惊确认` | 无载体，无时长 |
| 无落幅标注 | `无` / 空 | 关键情绪镜头不得无落幅 |

## 常见问题处理

### Q1: 落幅起幅不匹配
```
原因：相邻镜头画面不连贯
解决：调整镜头顺序或修改描述
```

### Q2: 轴线混乱
```
原因：越轴拍摄导致空间混乱
解决：重新规划镜头角度，使用中性镜头过渡
```

### Q3: 剪辑点不明确
```
原因：动作/对话衔接点模糊
解决：精确定位到帧，使用描述性语言
```

## 返工机制

| 触发条件 | 处理方式 |
|---------|---------|
| 衔接质量问题、运镜设计不合理 | 调整镜头顺序或修改描述 |
| 落幅字段无结构化格式 | **必须按`[落幅，载体，时长，说明]`格式重写** |
| 关键情绪镜头无落幅时长 | **补充标注后交付** |
| 镜头衔接跳跃 | 重新规划镜头角度 |
| 轴线混乱 | 使用中性镜头过渡 |
| 剪辑点不明确 | 精确定位到帧 |
| **返工上限**：3次 | |
