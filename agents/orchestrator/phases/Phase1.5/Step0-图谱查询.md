## 0.2 强制查询 — Phase 1.5 核心规则

**Query 1: 运镜公式**
```
查询：Seedance2 镜头设计中，运镜公式有哪些？
```
**预期返回**：运镜公式（组合运镜公式、基础运动镜头、情绪表达镜头等）

**Query 2: 镜头衔接规则**
```
查询：分镜表中相邻镜头的衔接应注意哪些规则？
```
**预期返回**：镜头衔接的起幅→落幅原则、运镜连续性要求

**Query 3: 枢纽审核职责（v1.1新增）**
```
查询：Phase 1.5输出增强分镜执行表时，需要对Phase 1进行哪些审核？
```
**预期返回**：
- 叙事一致性审核
- 轴线合规性审核
- 视线连续性审核
- 情绪节奏审核
- 视觉重心审核

**Query 4: 运镜知识**
```
查询：运镜知识规则中，镜头序列设计有什么具体要求？
```
**预期返回**：运镜知识规则中的关键要求（来自 rules/运镜知识.md）

**Query 5: 导演级运镜技术**
```
查询：Seedance2 中的导演级运镜技术有哪些？
```
**预期返回**：导演级运镜库中的高级运镜技巧
