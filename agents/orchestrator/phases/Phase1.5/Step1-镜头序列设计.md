# Step 1: 镜头序列设计

## Step 1.0: 上游输入验证（v1.1新增）

### 验证前提

在开始 Phase 1.5 之前，**必须**通过编排师执行上游 Phase 1 验证：

```
Phase 1 输出验证清单：
├── [ ] 基础分镜执行表.md 存在
├── [ ] 剧本.md 存在
├── [ ] 人物清单.md 存在
├── [ ] 场景清单.md 存在
├── [ ] 镜头数量验证：
│   ├── actual_shots = 统计实际镜头编号数量
│   ├── target_shots = ceil(总字数/80)
│   └── actual_shots >= target_shots ? 否则打回重做
├── [ ] 占位符检测：
│   ├── 扫描 "\d+-\d+\s*\|" 模式（范围占位）
│   ├── 扫描 "\.{3,}" 模式（省略号占位）
│   └── 发现任何占位符 → 打回 Phase 1 补充
└── [ ] 量化指标追踪表存在
```

### 验证决策

| 上游状态 | 编排师决策 | 执行角色 |
|---------|-----------|----------|
| 镜头数达标 + 无占位符 + 有追踪表 | ✅ 放行，进入 Step 1.1 | 编排师 |
| 镜头数达标 + 无占位符 + 无追踪表 | ⚠️ 放行，补充追踪表 | 镜头序列设计师 |
| 镜头数不达标 或 发现占位符 | ❌ **打回 Phase 1** | 编排师 |

> **注意：** Phase 1 是人工门禁节点，AI 不得绕过人工判断自行继续。但 AI 门禁（占位符检测、数量验证）可在此阶段自动执行。

### 审核问题标注规范

| 审核项 | 问题标注 | 说明 |
|:---|:---|:---|

```markdown
### 审核结论
```

## Step 1.1: 接收与分析

1. 接收 Phase 1 所有输出文件（通过上游验证后）
2. 分析每个场景的镜头序列设计需求
3. 确定每个镜头的专业运镜术语

## Step 1.2: 识别场景类型

根据8种场景类型，为每个场景选择合适的模板：

| 场景类型 | 核心特征 | 主要运镜技巧 |
|---------|---------|-------------|
| 对话场景 | 两人交流 | 180度轴线、正反打 |
| 动作戏 | 打斗追逐 | 跟随拍摄、快切 |
| 情感戏 | 情绪表达 | 慢镜头、特写 |
| 悬疑惊悚 | 紧张氛围 | 晃动镜头、低调光 |
| 蒙太奇转场 | 时间压缩 | 跳切、叠化 |
| 独白内心戏 | 心理描写 | 主观镜头、慢速 |
| 奇幻视觉奇观 | 视觉效果 | 特效合成、运动镜头 |
| 日常氛围治愈系 | 温馨生活 | 稳定镜头、自然光 |

## Step 1.3: 应用运镜知识

为每个镜头添加专业运镜术语：

```markdown
# 运镜术语参考（详见 templates/knowledge/）

## 镜头角度
- 鸟瞰（Bird's Eye）：从正上方拍摄
- 仰视（Low Angle）：从下往上拍摄
- 俯视（High Angle）：从上往下拍摄
- 平视（Eye Level）：与眼睛齐平

## 镜头运动
- 推镜头（Dolly In）：靠近主体
- 拉镜头（Dolly Out）：远离主体
- 摇镜头（Pan）：水平旋转
- 跟镜头（Follow）：跟随主体移动

## 剪辑术语
- 正反打（Shot/Reverse Shot）：两人对话的标准拍法
- 180度轴线规则：保持对话双方的空间关系
- OTS（Over the Shoulder）：过肩镜头
```

## Step 1.4: 落幅标注（v1.1 新增）

> **来源**：director-role.md 默会知识 — 保底线第1-3条

### 落幅字段结构

每个镜头的"落幅"字段**必须**包含结构化标注，格式为：

```
[落幅，{载体}，{时长}，{说明}]
```

### 落幅载体选择规则

| 情绪类型 | 推荐落幅载体 | 说明 |
|---------|------------|------|
| 压抑/隐忍 | **手部特写** | 拳头攥紧、指节发白，手比脸诚实 |
| 释放/惊喜/开心 | **面部特写** | 眼神、嘴角，最直接的情绪窗口 |
| 震惊/意外 | **眼睛特写** | 瞳孔放大，观众通过眼神完成共情同步 |
| 坚定/决心 | **身体中景** | 站姿挺直，肩膀下沉，重心稳定 |
| 疲惫/沉思 | **远景/空镜** | 环境承载情绪，避免过度聚焦 |
| 系统/GUI出现 | **画面中心** | 蓝光边框+特写，固定时长建立认知 |

### 落幅时长规则

| 情绪类型 | 时长范围 | 体感目标 |
|---------|---------|---------|
| 震惊/惊喜 | 3-5秒 | 完成一次屏息→呼气 |
| 悲伤/释然 | 4-6秒 | 完成完整呼吸循环 |
| 紧张/期待 | 2-3秒 | 保持张力不释放 |
| 坚定/充实 | 3-4秒 | 信心传导 |
| 愤怒爆发 | 2-3秒 | 截断式落幅保持冲击 |

### 落幅标注示例

| 镜头场景 | 情绪 | 正确标注 |
|---------|------|---------|
| 系统面板展开 | 震惊 | `[落幅，画面中心，4秒，系统激活震撼]` |
| 命中靶心 | 惊喜 | `[落幅，眼神，3秒，成功确认]` |
| 嘲讽台词结束 | 失落 | `[落幅，手部特写，3秒，压抑情绪]` |
| 导师收徒 | 感动 | `[落幅，面部特写，5秒，情绪余震]` |
| 哥布林出现 | 紧张 | `[落幅，眼睛特写，2秒，紧张锁定]` |

### 禁止的落幅标注

| 禁止类型 | 错误示例 | 正确写法 |
|---------|---------|---------|
| 无载体 | `[落幅，4秒，震惊]` | `[落幅，眼神，4秒，震惊确认]` |
| 无时长 | `[落幅，眼神，震惊确认]` | `[落幅，眼神，4秒，震惊确认]` |
| 纯描述文字 | `展示村庄全景，引入世界观` | `[落幅，远景，4秒，引入世界观]` |
| 空值 | `无` | 替换为结构化标注 |

### 必须标注落幅的镜头类型

| 必须标注的场景 | 理由 |
|-------------|------|
| 情绪转折点（系统觉醒等） | 高冲击力时刻，需定格 |
| 金手指/系统提示出现 | 观众需要时间理解新信息 |
| 导师关键台词结束 | 情绪余震需要落幅承载 |
| 战斗/动作戏的关键帧 | 力量感需要视觉沉淀 |
| 所有"震惊"、"惊喜"、"释然"情绪镜头 | 情绪释放需要落幅 |
