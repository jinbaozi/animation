# Step 2: 序列衔接表

> **v1.1 新增：** 上游输入验证 + 增强分镜全量要求

## Step 0: 上游输入验证（新增）

### 验证前提

在开始 Phase 1.5 之前，**必须**验证上游 Phase 1 产出：

```
Phase 1 输出验证清单：
├── [ ] 基础分镜执行表.md 存在
├── [ ] 镜头数量验证：
│   ├── actual_shots = 统计实际镜头编号数量
│   ├── target_shots = ceil(总字数/80)
│   └── actual_shots >= target_shots ? 否则打回重做
├── [ ] 占位符检测：
│   ├── 扫描 "\d+-\d+\s*\|" 模式
│   ├── 扫描 "\.{3,}" 模式
│   ├── 扫描 "(待补充|TBD|TODO|见后文)" 模式
│   └── 发现任何占位符 → 打回 Phase 1 补充
└── [ ] 量化指标追踪表存在
```

### 验证决策

| 上游状态 | 决策 |
|---------|------|
| 镜头数达标 + 无占位符 + 有追踪表 | ✅ 进入 Step 2.1 |
| 镜头数达标 + 无占位符 + 无追踪表 | ⚠️ 生成追踪表，继续执行 |
| 镜头数不达标 或 发现占位符 | ❌ **打回 Phase 1 补充**，不得自行降级处理 |

### 验证执行角色

此验证由**编排师**在 Phase 1.5 开始前执行，不由镜头序列设计师执行。

## Step 2.1: 生成增强分镜执行表（全量要求）

在 Phase 1 的22字段基础上，添加运镜专业字段：

```markdown
# 增强分镜执行表（全量增强）

| # | 场景编号 | 场景类型 | 运镜方式 | 镜头语言 | 落幅 | 起幅 | 剪辑点 | ...(Phase1字段) |
|---|---------|---------|---------|---------|------|------|-------|------------------|
| 001 | S01 | 对话场景 | 中景→特写 | 正反打，夜华看向白浅 | 夜华面部特写 | 白浅反应镜头 | 对白结束后1秒 | ... |
```

### 全量增强要求（新增）

**增强分镜必须是全量增强，不是精选：**
- 全量增强 = Phase 1 的每一个镜头都必须有对应的增强镜头
- 禁止只增强"关键镜头"而跳过其他镜头
- Phase 1 有 338 个镜头 → Phase 1.5 必须输出 338 个增强镜头

**增强分镜质量要求：**
- 每个镜头必须有完整的运镜方式、镜头语言、落幅、起幅、剪辑点
- 不能用"同前"或"沿用"等省略写法
- 不能出现范围占位（如镜头编号"范围：1-10"）

**新增字段说明**：

| 字段 | 名称 | 说明 | 示例 |
|------|------|------|------|
| 23 | 运镜方式 | 专业运镜描述 | 中景→特写 |
| 24 | 镜头语言 | 场景叙事意图 | 夜华深情凝视白浅 |
| 25 | 落幅 | 镜头结束画面 | 夜华面部特写 |
| 26 | 起幅 | 镜头开始画面 | 白浅反应镜头 |
| 27 | 剪辑点 | 最佳剪辑时机 | 对白结束后1秒 |
| 28 | 覆盖物 | 前后镜头关系 | 切入夜华独白 |

## Step 2.2: 生成序列衔接与继承表

记录镜头之间的衔接关系：

```markdown
# 序列衔接与继承表

## 衔接规则
- 落幅→起幅：必须视觉匹配或逻辑连贯
- 情绪连贯：相邻镜头情绪差异不超过一个等级
- 运动连贯：主体运动方向一致

## 衔接记录

| 当前镜头 | 落幅 | 下一镜头 | 起幅 | 衔接类型 | 衔接质量 |
|---------|------|---------|------|---------|---------|
| 001 | 夜华面部特写 | 002 | 白浅反应镜头 | 正反打 | OK |
| 002 | 白浅微笑 | 003 | 桃花飘落 | 情绪延伸 | OK |
| 003 | 桃花飘落 | 004 | 天兵出现 | 场景转换 | OK |
```

## Step 2.3: 场景模板应用

为每个场景应用对应的模板规则：

### 对话场景模板规则
```
- 180度轴线保持一致
- 正反打镜头交替
- 包含反应镜头（Reaction Shot）
- OTS镜头用于强调
```

### 动作戏模板规则
```
- 动作匹配剪辑
- 跟随拍摄为主
- 快切用于紧张时刻
- 包含切出镜头（Cutaway）
```

### 情感戏模板规则
```
- 慢推/慢拉镜头
- 特写强调情绪
- 留白剪辑
- 音乐节奏配合
```
