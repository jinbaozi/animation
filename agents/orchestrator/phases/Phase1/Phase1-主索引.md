> 创建日期：2026-04-04

---

## 执行概述

| 项目 | 内容 |
|------|------|
| Phase | Phase 1 |
| 执行角色 | AI内容总导演 |
| 输入 | 合规预审报告.md（Phase 0 通过） |
| 输出 | StoryIR.md + 剧本.md + 基础分镜执行表.md + 人物清单.md + 场景清单.md |
| 执行时长 | 约30-60分钟（取决于文本复杂度） |

---

## 执行前提

- [ ] Phase 0 合规审核通过（PASS 或 PASS_WITH_SUGGESTIONS）
- [ ] 图谱已同步（执行前需通过 `/graphify` Skill 确认 rules/ 已在图谱中）
- [ ] 已了解目标平台要求

## 返工机制

- **返工触发**：输出质量不达标
- **常见返工原因**：
  - 镜头数量过少（内容被压缩）
  - 人物描述不完整
  - 场景描述不具体
- **返工上限**：3次
