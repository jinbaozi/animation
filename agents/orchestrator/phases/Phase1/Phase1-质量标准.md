## 占位符检测规则（新增）

### 禁止出现的占位符模式

| 模式 | 示例 | 检测正则 |
|------|------|----------|
| 省略号占位 | `...` | `\.{3,}` |
| "待补充"类 | `待补充`、`TBD`、`TODO` | `(待补充\|TBD\|TODO\|见后文\|省略)` |
| 范围占位 | `253-338 \| ...` | `\d+-\d+\s*\\|` |
| 简略描述 | `详细内容见下方` | `(详细内容\|详见\|参考).*` |

### 检测步骤

1. 执行正则扫描
2. 如发现任何占位符，**必须展开为具体描述**
3. 严禁使用范围占位符（如"253-338号镜头"）代替逐个镜头描述

### 占位符判定规则

**如果一个镜头描述符合以下任一条件，则判定为占位符：**
- 镜头编号为范围（如 `253-338`）而非具体编号
- 描述中包含"..."、"省略"、"待补充"、"TODO"等模糊词
- 动作/台词字段内容过于简略（如只有"训练"、"日常"等词）

## 剧本验收标准（v1.2 新增）

### 剧本定义

**剧本 ≠ 分集大纲**。剧本是供 AI 视频生成使用的完整表演文本，分集大纲是供人类理解剧情的结构说明。两者可以共存，但剧本不得以分集大纲格式替代。

### 剧本格式要求

剧本.md 必须满足以下全部条件：

| # | 要求 | 检测方法 | 达标条件 |
|---|------|---------|---------|
| 1 | 每个场景包含实际对话 | 扫描 `{角色名}：` 或 `{角色名}"` 模式 | 每集出现次数 ≥ 10 |
| 2 | 对话使用角色名称开头 | 禁止出现 `她/他/某人` 开头 | 0 处 |
| 3 | 每个主要场景有视觉环境描写 | 扫描场景名称后的具体描写文字 | 每场景 ≥ 1 句 |
| 4 | 关键情绪转折点有具体台词 | 检查情绪曲线标注处的对话 | 每转折点 ≥ 1 句台词 |
| 5 | 无"核心事件列表"格式 | 扫描 `核心事件` 关键词 | 0 处 |
| 6 | 无"情绪曲线"作为主体描述 | 扫描 `情绪曲线` 关键词 | 0 处 |

### 禁止出现的剧本格式

以下格式任一出现，判定为不合格剧本，必须返工：

| 禁止模式 | 示例 | 说明 |
|---------|------|------|
| 纯事件列表 | `核心事件：1. xxx 2. xxx 3. xxx` | 只有事件编号，无对话和描写 |
| 纯情绪曲线 | `压抑→希望→失落→震惊` | 只有情绪标签，无具体内容 |
| 场景标签罗列 | `场景1：面包房内景 - 场景2：广场` | 只有场景标签，无环境描写 |
| 角色标签罗列 | `人物：吴为、老约翰、多尔` | 只有人物名称列表，无台词无描写 |

### 验证步骤

1. 执行正则扫描：`\{角色名\}：` 或 `\{角色名\}"`
2. 统计出现次数 < 每集 10 句 → 返工
3. 扫描 `核心事件`、`情绪曲线`、`场景：.*-` → 发现任一 → 返工
4. 检查场景描写是否存在 → 不存在 → 返工

## 剧本-分镜表一致性要求（v1.2 新增）

| # | 一致性要求 | 验证方法 |
|---|-----------|---------|
| 1 | 剧本中每个场景的台词，与分镜执行表中对应镜头的"对话"字段一致 | 交叉比对 |
| 2 | 分镜执行表中的"对话"字段，不得包含剧本中未出现的台词 | 差集检测 |
| 3 | 剧本的场景环境描写，必须能在分镜执行表的"场景描述"字段中找到对应描述 | 关键词匹配 |

### 一致性返工触发条件

| 触发条件 | 处理方式 |
|---------|---------|
| 剧本有台词但分镜表无对应"对话"字段 | 补充分镜表对话字段 |
| 分镜表有对话但剧本中无对应台词来源 | 从剧本补充或标记为AI创作说明 |
| 剧本场景描写与分镜表场景描述严重不符 | 修正剧本或分镜表，确保一致 |

每个 Phase 1 输出**必须**在 `基础分镜执行表.md` 末尾包含：

```markdown
## 量化指标追踪

| 指标 | 目标值 | 实际值 | 达标 | 备注 |
|:---|:---|:---|:---|:---|
| 分镜完整率 | ≥100% | XXX/YYY | ✓/✗ | ceil(总字数/80) |
| 占位符数量 | 0 | N | ✓/✗ | |
| 人物覆盖率 | 100% | N/N | ✓/✗ | |
| 场景覆盖率 | ≥90% | N/N | ✓/✗ | |
```

## 禁止出现

- 人称代词（她/他）用于主要角色描述
- 禁用词（见 `rules/风格一致性.md`）
- 过于笼统的描述（如"她很美"）
- **任何形式的占位符（见上方检测规则）**

## 返工机制

| 触发条件 | 处理方式 |
|---------|----------|
| 分镜完整率 < 100% | 必须补充缺失镜头 |
| 发现占位符 | 必须展开为具体描述 |
| 量化追踪表缺失 | 拒绝交付，补全后重提 |
| 剧本对话数量不达标（< 10句/集） | 必须补充实际台词，返工 |
| 剧本出现禁止格式（核心事件列表/情绪曲线/场景标签罗列） | 必须按剧本格式重写，不得以大纲格式交付 |
| 剧本-分镜表不一致 | 修正不一致处，确保双向追溯 |
