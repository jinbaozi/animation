# Step 0: 图谱查询 — 内容改编规则获取

> 执行角色：AI内容总导演
> 所属 Phase：Phase 1
> **强制步骤**：执行任何剧本改编前，必须先通过图谱查询获取规则
> **v1.1更新**：新增人设拆解小节要求（供Phase 2a使用）

## 0.1 连接 MCP Server

通过 `mcp_config.json` 连接 graphify MCP server。

---

## 0.2 强制查询 — Phase 1 核心规则

**Query 1: 八场景类型**
```
查询：AI Animation Drama 中的八场景类型是哪八个？各适用于什么情况？
```
**预期返回**：八场景类型定义及适用情况：
- 对话场景：两人以上交流
- 动作戏：打斗、追逐
- 情感戏：爱情、亲情
- 悬疑惊悚：紧张、恐怖
- 蒙太奇转场：时间压缩
- 独白内心戏：心理描写
- 奇幻视觉奇观：魔法、变身
- 日常氛围治愈系：日常生活

**Query 2: 人设拆解小节（v1.1新增）**
```
查询：Phase 1人物清单输出时，需要包含哪些人设拆解内容？
```
**预期返回**：
- 关键特征词（≤10词/角色）
- 服装阶段拆解（矿奴期/觉醒后/战斗装等）
- 表情记忆点
- 道具关键特征

**Query 3: 场景模板索引**
```
查询：剧本改编时，不同场景类型应该参考哪些模板？
```
**预期返回**：各场景类型对应的模板路径：
- `templates/scene/对话场景序列.md`
- `templates/scene/动作戏序列.md`
- `templates/scene/情感戏序列.md`
- `templates/scene/悬疑惊悚序列.md`
- `templates/scene/蒙太奇转场.md`
- `templates/scene/独白内心戏序列.md`
- `templates/scene/奇幻视觉奇观序列.md`
- `templates/scene/日常氛围治愈系序列.md`

**Query 4: 审美偏好规则**
```
查询：用户审美偏好规则中，剧本改编有什么要求？
```
**预期返回**：审美偏好中的剧本改编要点（来自 rules/审美偏好.md）

**Query 5: 风格一致性规则**
```
查询：风格一致性规则中，剧本改编阶段需要避免哪些问题？
```
**预期返回**：风格一致性中的禁止项（来自 rules/风格一致性.md）
