# Step 1 - 接收准备

> 版本：v1.0.0
> 执行角色：AI内容总导演
> 所属 Phase：Phase 1

---

## 1.1 接收 Phase 0 输出

1. 接收 Phase 0 输出的 `合规预审报告.md`
2. 确认合规审核状态为 PASS 或 PASS_WITH_SUGGESTIONS
3. 如为 PASS_WITH_SUGGESTIONS，记录建议内容

### 1.1.1 上游输入验证（新增）

在开始 Phase 1 之前，**必须**验证上游 Phase 0 产出：

```
Phase 0 输出验证清单：
├── [ ] 合规预审报告.md 存在
├── [ ] 审核状态 = PASS（不允许 PASS_WITH_SUGGESTIONS 降级）
├── [ ] 综合评分 ≥ 7.5/10
└── [ ] BLOCK 问题数 = 0
```

**验证不通过的决策：**

| 状态 | 决策 |
|------|------|
| 合规预审报告.md 不存在 | ❌ 阻塞，等待 Phase 0 完成 |
| 审核状态 ≠ PASS | ❌ 阻塞，等待用户处理 |
| 综合评分 < 7.5 | ⚠️ 警告，用户确认后继续 |
| BLOCK 问题数 > 0 | ❌ 阻塞，修复后重新审核 |

> **注意：** Phase 0 是人工门禁节点，AI 不得绕过人工判断自行继续。

---

## 1.2 分析小说文本结构

分析小说文本结构，识别以下关键要素：

### 主线剧情
- 核心故事线
- 主要冲突
- 关键情节点

### 支线剧情
- 辅助故事线
- 人物背景补充
- 情感铺垫

### 人物关系
- 主要角色及其关系
- 角色出场顺序
- 重要对手戏

### 场景分布
- 内景/外景比例
- 场景转换频率
- 核心场景识别

---

## 1.3 确定改编策略

根据分析结果，确定改编方案：

| 决策项 | 考虑因素 | 输出 |
|--------|---------|------|
| 是否需要改编 | 原著是否超过平台时长限制 | 是/否 |
| 改编幅度 | 压缩比、内容保留优先级 | 小/中/大 |
| 重点保留内容 | 无法删除的核心情节 | 列表 |

---

## 1.4 执行前提确认

在开始 Step 1 之前，确认以下前提条件已满足：

- [ ] Phase 0 合规审核通过（PASS 或 PASS_WITH_SUGGESTIONS）
- [ ] 已阅读 `rules/审美偏好.md`
- [ ] 已阅读 `rules/风格一致性.md`
- [ ] 已了解目标平台要求

---

## 1.5 交付物

Step 1 完成后，输出：

- **改编策略文档**：包含改编幅度、内容取舍决定
- **结构分析备忘录**：主线/支线/人物/场景的初步分析
