# Step 2 - 剧本改编

> 版本：v1.0.0
> 执行角色：AI内容总导演
> 所属 Phase：Phase 1

---

## 2.1 剧本生成概述

根据小说生成结构化剧本，遵循统一的剧本格式规范。

---

## 2.2 剧本格式规范

```markdown
# 剧本

> 项目：{项目名称}
> 版本：v1.0
> 日期：{YYYY-MM-DD}

---

## 第一幕/章

### 场景 1.1

**场景**：{场景名称}
**时间**：{时间设定}
**人物**：{出场人物}

**内容**：

{对话/动作/旁白}

---
```

---

## 2.3 剧本生成步骤

### 步骤 2.3.1 确定剧本结构

- 按小说章节/幕划分剧本结构
- 每个场景独立编号（如 1.1, 1.2, 2.1）
- 明确场景边界

### 步骤 2.3.2 填写场景元数据

每个场景必须包含：

| 字段 | 说明 | 示例 |
|------|------|------|
| 场景编号 | 唯一标识 | 1.1 |
| 场景名称 | 场景标题 | 天宫大殿 |
| 时间设定 | 日/夜/晨/昏 | 日 |
| 出场人物 | 主要角色名单 | 白浅、夜华 |

### 步骤 2.3.3 编写场景内容

根据场景类型选择内容模式：

| 场景类型 | 内容模式 | 参考模板 |
|---------|---------|---------|
| 对话场景 | 对话为主，动作描写为辅 | `templates/scene/对话场景序列.md` |
| 动作戏 | 动作描写为主，对话精简 | `templates/scene/动作戏序列.md` |
| 情感戏 | 情感表达为主，台词细腻 | `templates/scene/情感戏序列.md` |
| 悬疑惊悚 | 悬念营造，节奏紧凑 | `templates/scene/悬疑惊悚序列.md` |
| 蒙太奇转场 | 时间压缩，镜头快速切换 | `templates/scene/蒙太奇转场.md` |
| 独白内心戏 | 心理描写为主 | `templates/scene/独白内心戏序列.md` |
| 奇幻视觉奇观 | 特效描述，视觉冲击力 | `templates/scene/奇幻视觉奇观序列.md` |
| 日常氛围治愈系 | 氛围营造，生活细节 | `templates/scene/日常氛围治愈系序列.md` |

---

## 2.4 剧本质量要求

### 必须包含

- [ ] 完整的场景编号体系
- [ ] 每个场景的时间设定
- [ ] 每个场景的出场人物列表
- [ ] 对话内容（使用实际角色名，禁止使用"她/他"）
- [ ] 场景分隔标记（---）

### 禁止出现

- 人称代词（她/他）用于主要角色描述
- 占位符（如 {待填写}）
- 过于笼统的描述（如"她很美"）

## 2.5 交付物

Step 2 完成后，输出：

- **剧本.md**：必须是**完整剧本格式**，而非分集大纲

### 剧本格式强制要求

| 要求 | 说明 |
|------|------|
| 每集实际对话 ≥ 10 句 | 对话必须是可拍摄的表演文本，非事件概述 |
| 每场景 ≥ 1 句视觉环境描写 | 场景描写必须具体，如"狭窄面包房，黄铜烤炉冒着热气" |
| 关键情绪转折点必须有台词 | 情绪变化处必须用具体台词表现，不能只用标签 |
| 禁止以大纲格式替代 | "核心事件 + 情绪曲线" 不是剧本，是大纲 |
| 对话行数 ≥ 场景数 × 3 | 确保每个场景有足够的对话支撑 |

### 禁止的交付物格式

以下任一格式的剧本.md一律判定为不合格，必须重写：

- [ ] `核心事件：1. xxx 2. xxx 3. xxx`（纯事件列表）
- [ ] `情绪曲线：压抑→希望→失落→震惊`（纯情绪标签）
- [ ] `场景：面包房内景 - 面包房门口 - 广场`（纯场景标签罗列）
- [ ] 无实际对话内容，仅有场景编号和描述

### 剧本与分镜表的依赖关系

```
剧本.md（来源）
    ↓ 台词/动作描写
基础分镜执行表.md（派生）
```

- 剧本.md 是 Phase 2b VideoPrompt 的台词来源
- 分镜表的"对话"字段必须从剧本复制，不得另行创作
- 如分镜表需要补充台词，必须从剧本补充，而非自行创作
