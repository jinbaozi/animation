## 3.5 分镜完整率验证（新增）

### 3.5.1 镜头数量公式

```
target_shots = ceil(total_word_count / 80)
```

**示例**：27,000字 → ceil(27000/80) = 338个镜头

### 3.5.2 分镜表行数验证

完成分镜设计后，**必须**执行以下验证：

1. **统计实际镜头数**：
   ```bash
   # 统计分镜表中的镜头行数（不含表头和分隔行）
   grep "^|" output/基础分镜执行表.md | wc -l
   ```

2. **对比目标数量**：
   ```python
   actual_shots = 实际输出的镜头编号数量
   target_shots = ceil(total_word_count / 80)

   if actual_shots < target_shots:
       print(f"❌ 分镜完整率不达标: {actual_shots}/{target_shots} ({actual_shots/target_shots*100:.1f}%)")
       # 必须补充缺失的镜头
   else:
       print(f"✅ 分镜完整率达标: {actual_shots}/{target_shots}")
   ```

3. **占位符检测**：
   ```python
   # 检测占位符模式
   placeholder_patterns = [
       r"\.{3}",           # "..."
       r"待补充",           # "待补充"
       r"TBD",             # TBD
       r"TODO",           # TODO
       r"见后文",           # "见后文"
       r"省略",             # "省略"
       r"\d+-\d+\s*\|",   # "253-338 | ..." 范围占位
   ]

   for pattern in placeholder_patterns:
       matches = find_matches(pattern, content)
       if matches:
           print(f"❌ 发现占位符: {pattern} → {matches}")
           # 必须展开为具体描述
   ```
