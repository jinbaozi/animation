## 版本联动规则（v1.2新增）

### 问题场景

当Phase 1的输出在后续被修复（如人物清单/场景清单内容更新），
Phase 2a的输出可能与Phase 1的最新状态不一致。

### 解决方案

Phase 2a输出时，必须在文件头部标注：

```markdown
> 依据：人物清单.md vX.X | 场景清单.md vX.X
> 生成时间：YYYY-MM-DD
```

### 联动触发条件

当以下任一情况发生时，**自动触发**Phase 2a输出文件的版本一致性检查：

| 触发条件 | 检查内容 |
|---------|---------|
| 人物清单.md版本更新 | 验证所有12个角色的四视图是否与新版本一致 |
| 场景清单.md版本更新 | 验证所有8个场景资产卡是否与新版本一致 |
| Phase 1.5增强分镜执行表更新 | 验证场景资产卡的色调是否与新分镜表一致 |

### 编排师职责

编排师在Phase 1修复后，**必须**向Phase 2a执行角色发送"版本联动检查"提醒，
由AI美术技术总监确认是否需要重新生成四视图或场景资产卡。

### 版本联动触发规则（Q2修复）

当人物清单.md中出现以下关键词时，自动触发多版本四视图生成：

| 关键词 | 触发条件 |
|--------|----------|
| "初始"/"后期"/"一个月后"/"成长" | 该角色需要初始版+后期版两套四视图 |
| "变化"/"改变"/"不同阶段" | 该角色需要多版本四视图 |

## 返工机制

| 触发条件 | 处理方式 |
|---------|---------|
| 角色数量不匹配（遗漏龙套） | 补充缺失角色的四视图 |
| 人物属性不一致（遗漏胡须/木杖等） | 重新生成该角色四视图 |
| 场景布局矛盾（约翰家两室vs三室） | 更新场景资产卡至最新 |
| S05合并未标注 | 补充合并说明 |
| 人物清单版本更新 | 执行版本联动检查 |

**返工上限**：3次

### 返工机制扩展

| 触发条件 | 处理方式 |
|---------|---------|
| 人物清单标注状态变化但四视图只有单版本 | 补充缺失版本 |
| 多版本四视图关键特征不一致 | 重新生成并保持一致性 |
