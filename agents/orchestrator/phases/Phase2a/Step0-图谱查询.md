## 0.2 强制查询 — Phase 2a 核心规则

**Query 1: 人物四视图格式**
```
查询：人物四视图格式的具体要求是什么？四个视图分别是哪些？
```
**预期返回**：人物四视图格式要求：
- 四个视图：正面全身、侧面全身、背面全身、面部特写
- 全部纯白背景，无阴影
- 每个角色（包括龙套）必须有四视图

**Query 2: 纯中文规则（v1.3新增）**
```
查询：Phase 2a人物四视图生成中，是否必须使用纯中文Prompt？
```
**预期返回**：
- 人物四视图Prompt包必须为纯中文
- 禁止中文句子夹英文（如"中国风少年，Chinese xianxia style"）
- 英文关键词仅供AI图像识别参考，可用括号注释形式标注

**Query 3: 版本联动要求（v1.3新增）**
```
查询：Phase 2a输出的文件头部需要标注哪些版本信息？
```
**预期返回**：
- 人物清单版本号
- 场景清单版本号
- 版本联动变更说明

**Query 4: 龙套角色独立四视图（v1.3新增）**
```
查询：龙套角色是否必须有独立四视图？有哪些要求？
```
**预期返回**：
- 有特征差异的龙套必须有独立四视图（如追杀队修士vs城主府修士）
- 需体现具体特征差异（玄色劲装绣黑龙纹 vs 黑色劲装银纹）

**Query 5: 风格一致性规则**
```
查询：Phase 2a 人物四视图生成中，风格一致性规则有哪些？
```
**预期返回**：风格一致性规则（禁止词、风格标签约束等）

**Query 6: 人物一致性控制**
```
查询：跨镜头人物一致性如何控制？有哪些检查项？
```
**预期返回**：人物一致性控制方法、跨镜头一致性检查清单

**Query 7: 禁止词正则**
```
查询：Seedance2 项目中，生成人物四视图时应避免哪些禁用词？
```
**预期返回**：禁用词正则 `(?i)(影视|电影|摄像|胶片|摄影|古风写实|写实CG|游戏CG|影视质感|影视级|电影级)`
