## Step 3.0: 上游输入验证（v1.2新增）

> **重要：** 场景资产卡必须与场景清单.md的最新版本完全一致。

### 验证前提

在开始场景资产卡生成之前，**必须**通过以下验证：

```
Phase 1 输出验证清单：
├── [ ] 场景清单.md 存在
├── [ ] 场景清单版本 ≥ 上次Phase 2a执行后的最新版本
├── [ ] 场景数量验证：
│   ├── 场景资产卡数量 = 场景清单场景总数（必须8个全量）
│   └── 不得遗漏任何场景
├── [ ] 场景布局一致性（逐场景对照）：
│   ├── 约翰家布局 → 必须与场景清单.md 一致（三室一厅）
│   ├── S05小树林 → 确认是否已合并至S04（如合并，场景资产卡需标注）
│   └── 其他场景的房间/区域描述 → 与场景清单一致
├── [ ] 色调一致性：
│   └── 场景资产卡的色调定义 → 必须与增强分镜执行表的色调一致
└── [ ] 量化指标追踪表存在
```

### 场景布局一致性逐场景检查表

| 场景 | 场景清单布局 | 场景资产卡布局 | 一致性 |
|------|-------------|---------------|--------|
| 约翰家 | 三室一厅（客厅+约翰卧室+杂物间→吴为房间） | 需核对 | ✓/✗ |
| S05小树林 | 合并至S04，标注为概念存档 | 需核对是否标注合并 | ✓/✗ |
| 广场角落 | 黑暗角落，系统觉醒处 | 需核对 | ✓/✗ |

### 验证决策

| 上游状态 | 执行角色决策 |
|---------|------------|
| 所有检查项通过 | ✅ 放行，进入场景资产卡生成 |
| 场景数量不匹配 | ❌ 补充缺失场景的资产卡 |
| 场景布局不一致 | ❌ 更新场景资产卡至场景清单.md最新版本 |
| 场景清单版本落后于当前最新 | ❌ 更新至最新版本后重新验证 |

## Prompt生成规则

### 核心要素

1. **环境**：具体场景位置和类型
2. **细节**：建筑装饰特征
3. **氛围**：情绪和光线
4. **风格**：动画风格，8K高清

### 质量控制（v1.2强化）

- [ ] **8个场景全部有场景资产卡**（含S05的概念存档标注）
- [ ] **场景布局与场景清单.md完全一致**（特别是约翰家三室一厅）
- [ ] **S05小树林必须标注合并说明**
- [ ] 场景描述具体清晰
- [ ] 包含环境、光线、氛围
- [ ] 色调与增强分镜执行表一致（不得使用笼统的"暖色调"）
- [ ] 可转化为视觉表达
- [ ] 无禁用词
- [ ] **生成后必须回填：依据的场景清单版本号**
