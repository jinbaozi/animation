> 执行角色：AI美术技术总监

> **v1.1更新**：增加shot数量检查、中英对照完整性、格式A合规性

---

## 1. VideoPrompt检查清单

- [ ] Shot数量 = 338（与增强分镜执行表一致）
- [ ] 中文版每个shot有5个时间段（0-3s/3-6s/6-9s/9-12s/12-15s）
- [ ] 英文版每个shot有5个时间段
- [ ] 中英文基本信息表字段一致
- [ ] 中英双轨完整（同一镜头的中英文版本）
- [ ] 无禁用词（影视质感、电影级、古风写实等）
- [ ] 运镜术语专业且正确
- [ ] 场景类型与内容匹配
- [ ] 起幅→落幅连续性已文档化
- [ ] 内容符合增强分镜执行表（不得模板重复）
- [ ] 格式A合规（带基本信息表）

## 3. 质量评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 338个shot全部基于增强分镜执行表生成，中英文内容一致，格式A合规 |
| 7-8 | 338个shot大部分符合，有少量模板重复或细节缺失 |
| 5-6 | 存在较多模板重复，或shot数量不足338 |
| <5 | 严重问题，需要返工 |
