## 1. VideoPrompt检查清单

- [ ] **核心镜头覆盖率 ≥80%**（增强分镜镜头数×80%）
- [ ] 中文版每个shot有5个时间段（0-3s/3-6s/6-9s/9-12s/12-15s）
- [ ] 英文版每个shot有5个时间段
- [ ] 中英文基本信息表字段一致
- [ ] 中英双轨完整（同一镜头的中英文版本）
- [ ] 无禁用词（影视质感、电影级、古风写实、cinematic、photorealistic等）
- [ ] 运镜术语专业且正确
- [ ] 场景类型与内容匹配
- [ ] 起幅→落幅连续性已文档化
- [ ] 内容符合增强分镜执行表（不得模板重复）
- [ ] 格式A合规（带基本信息表）
- [ ] 版本头部标注覆盖率

---

## 2. 覆盖率要求（v2.0新增）

### 覆盖率计算公式

```
actual_shots = len(增强分镜执行表)
minimum_required = ceil(actual_shots * 0.8)
```

### 镜头优先级排序

| 优先级 | 镜头类型 | 必须生成 |
|--------|---------|---------|
| P0 | 核心叙事镜头 | ✅ 必须 |
| P0 | 情绪高潮镜头 | ✅ 必须 |
| P1 | 奇幻视觉奇观镜头 | ✅ 必须 |
| P1 | 动作戏关键帧 | ✅ 必须 |
| P2 | 过渡镜头 | 尽量生成 |
| P3 | 远景空镜 | 可用模板 |

### 覆盖率判定

| 覆盖率 | 判定 | 处理 |
|--------|------|------|
| ≥80% | ✅ 合格 | 可直接交付 |
| 50%-79% | ⚠️ 需补充 | 补充缺失的核心镜头 |
| <50% | ❌ 不合格 | 打回重做，必须达到80% |

## 4. 质量评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 覆盖率≥80%，全部基于增强分镜执行表生成，中英文内容一致，格式A合规 |
| 7-8 | 覆盖率≥80%，大部分符合，有少量模板重复或细节缺失 |
| 5-6 | 覆盖率<80%，或存在较多模板重复 |
| <5 | 严重问题，需要返工 |
