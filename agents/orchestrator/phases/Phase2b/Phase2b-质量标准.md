> 执行角色：AI美术技术总监
> 所属阶段：Phase 2b

## 1. VideoPrompt检查清单

- [ ] **Prompt Export IR 覆盖率 100%**（覆盖 Shot IR 全部镜头）
- [ ] **核心 VideoPrompt 覆盖率 100%**（覆盖 Prompt Export IR 全部核心导出）
- [ ] 中文版每个shot有5个时间段（0-3s/3-6s/6-9s/9-12s/12-15s）
- [ ] 英文版每个shot有5个时间段
- [ ] 中英文基本信息表字段一致
- [ ] 中英双轨完整（同一镜头的中英文版本）
- [ ] 无禁用词（影视质感、电影级、古风写实、cinematic、photorealistic等）
- [ ] 运镜术语专业且正确
- [ ] 场景类型与内容匹配
- [ ] 起幅→落幅连续性已文档化
- [ ] 内容符合增强分镜执行表（不得模板重复）
- [ ] 格式A合规（带基本信息表）
- [ ] 版本头部标注覆盖率
- [ ] 人物描述与人物资产卡一致
- [ ] 场景描述与场景资产卡一致

## 2. 覆盖率要求

### 覆盖率计算公式

```
actual_shots = len(增强分镜执行表)
minimum_required = actual_shots
```

### 镜头优先级排序（仅用于用户确认的精简交付模式）

| 优先级 | 镜头类型 | 必须生成 |
|--------|---------|---------|
| P0 | 核心叙事镜头 | ✅ 必须 |
| P0 | 情绪高潮镜头 | ✅ 必须 |
| P1 | 奇幻视觉奇观镜头 | ✅ 必须 |
| P1 | 动作戏关键帧 | ✅ 必须 |
| P2 | 过渡镜头 | 尽量生成 |
| P3 | 远景空镜 | 可用模板 |

### 覆盖率判定

| 覆盖率 | 判定 | 处理 |
|--------|------|------|
| 100% | ✅ 合格 | 可进入 Audit Gate |
| 80%-99% | ⚠️ 精简交付 | 仅在用户确认并写入 manifest 时允许 |
| <80% | ❌ 不合格 | 打回重做 |

## 4. 质量评分标准

| 评分 | 标准 |
|------|------|
| 9-10 | 覆盖率100%，全部基于 Prompt Export IR 导出，中英文内容一致，资产卡一致 |
| 7-8 | 覆盖率100%，有少量细节缺失但不影响主流程 |
| 5-6 | 覆盖率不足或存在较多模板重复 |
| <5 | 严重问题，需要返工 |
