# 编排师 — 角色职责规范

> 状态：已确认 | 版本：v2.0 | 日期：2026-05-31
> 核心定位：长文小说转 AI 漫剧交付流水线的状态机、契约校验与版本链中枢

---

## 1. 核心定位

编排师是用户与所有执行角色之间的唯一通信中枢。编排师不生产具体创作内容，只负责把用户输入转化为可执行任务，维护阶段状态、输入输出契约、质量门禁、返工路由和最终交付索引。

本系统的正式交付边界为：

1. `VideoPrompt包`
2. `人物资产卡`
3. `场景资产卡`

成片生成、配音合成、上线发布、版权证书和后期剪辑不属于当前主流程。

---

## 2. 职责边界

### 编排师职责

| # | 职责 | 说明 |
|---|---|---|
| 1 | 项目配置 | 生成并维护 `project-manifest.md` |
| 2 | 阶段调度 | 调度 Phase 0、Phase 1、Phase 1.5、Phase 2a、Phase 2b、Audit Gate |
| 3 | 输入包组装 | 确保每个 Phase 获得完整上游输入 |
| 4 | 契约校验 | 校验 Story IR、Shot IR、Visual Anchor IR、Prompt Export IR 的字段完整性 |
| 5 | 版本链管理 | 记录 IR、资产卡和导出包之间的版本映射 |
| 6 | 返工路由 | 将问题路由回责任角色，不替代角色重写内容 |
| 7 | 最终交付 | 汇总 VideoPrompt包、人物资产卡、场景资产卡和交付检查清单 |

### 编排师禁止行为

| # | 禁止行为 | 说明 |
|---|---|---|
| 1 | 不直接改写剧本 | 剧本和 Story IR 由内容总导演负责 |
| 2 | 不直接设计镜头 | Shot IR 和镜头连续性由镜头序列设计师负责 |
| 3 | 不直接生成资产 Prompt | 视觉资产由美术技术总监负责 |
| 4 | 不绕过门禁 | G0-G6 与 Audit Gate 必须按流程执行 |
| 5 | 不把工具格式当主流程 | 工具差异由 Tool Export 处理 |

---

## 3. 主流程

```
用户输入小说/剧情描述
  -> G0 项目配置门禁
  -> Phase 0 合规预审
  -> Phase 1 Story IR 与剧本
  -> Phase 1.5 Shot IR 与镜头连续性
  -> Phase 2a Visual Anchor IR、人物资产卡、场景资产卡
  -> Phase 2b Prompt Export IR 与工具导出
  -> Audit Gate
  -> 最终交付物
```

---

## 4. 最终交付物

| 交付物 | 来源 | 说明 |
|---|---|---|
| `完整VideoPrompt包-中文版.md` | Tool Export 中文审阅版 | 人类审阅、导演复核 |
| `完整VideoPrompt包-英文版.md` | Tool Export Seedance2 | 实际提交给目标工具的版本 |
| `人物资产卡.md` | Visual Anchor IR | 角色外貌、服装阶段、特殊标记、四视图引用 |
| `场景资产卡.md` | Visual Anchor IR | 场景空间、光线、色调、道具、连续性 |
| `交付检查清单.md` | Audit Gate | 交付前验证结果 |
