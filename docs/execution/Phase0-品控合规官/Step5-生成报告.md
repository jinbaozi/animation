# Step 5: 生成报告

> 执行角色：AI品控合规官
> 所属 Phase：Phase 0

---

## 5.1 报告格式

生成 `合规预审报告.md`，包含以下部分：

---

### 5.1.1 基本信息

```markdown
## 基本信息

| 项目 | 内容 |
|------|------|
| 小说标题 | {标题} |
| 字数 | {N}字 |
| 章节数 | {N}章 |
| 目标平台 | {平台} |
| 审核时间 | {时长} |
```

---

### 5.1.2 合规评分

```markdown
## 合规评分

- 版权合规性：{N}/10
- 内容安全性：{N}/10
- 平台适配性：{N}/10
- 叙事完整性：{N}/10
- 角色丰满度：{N}/10
- 场景可行性：{N}/10

**综合评分：{N}/10**
```

---

### 5.1.3 问题清单

```markdown
## 问题清单

### CRITICAL 问题（如有）

| # | 问题描述 | 位置 | 建议修改 |
|---|---------|------|---------|
| 1 | ... | ... | ... |

### HIGH 问题（如有）

| # | 问题描述 | 位置 | 建议修改 |
|---|---------|------|---------|
| 1 | ... | ... | ... |
```

---

### 5.1.4 审核结论

```markdown
## 审核结论

| 结论 | 说明 |
|------|------|
| PASS | 通过，可进入Phase 1 |
| PASS_WITH_SUGGESTIONS | 通过，有建议优化项 |
| NEEDS_REVISION | 需要修改后重审 |
| REJECTED | 阻断性问题，无法继续 |
```

---

### 5.1.5 修改建议

```markdown
## 修改建议

{如有问题，提供具体修改建议}
```

---

### 5.1.6 下一步

```markdown
## 下一步

- [ ] 如结论为 PASS：可进入 Phase 1
- [ ] 如结论为 NEEDS_REVISION：等待用户修改后重新提交
```

---

## 5.2 报告输出位置

`合规预审报告.md` 应与原始小说文件放在同一目录下。
