# Phase 1 - 质量标准

> 版本：v1.0.0
> 执行角色：AI内容总导演
> 所属 Phase：Phase 1

---

## 通过条件

- [ ] 剧本完整覆盖小说主线
- [ ] 分镜表不少于 `ceil(总字数/80)` 个镜头
- [ ] 每个角色有人物卡片
- [ ] 每个场景有场景描述
- [ ] 无占位符残留

---

## 禁止出现

- 人称代词（她/他）用于主要角色描述
- 禁用词（见 `rules/风格一致性.md`）
- 过于笼统的描述（如"她很美"）
