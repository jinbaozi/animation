# Phase 1.5 质量标准

## 通过条件

- [ ] 每个场景有明确的运镜设计
- [ ] 镜头衔接流畅，无跳跃
- [ ] 序列衔接与继承表完整
- [ ] 落幅→起幅连续性验证通过

## 剪辑检查清单

- [ ] 180度轴线规则遵守
- [ ] 正反打逻辑正确
- [ ] 动接动、静接静
- [ ] 情绪节奏合理

---

## 常见问题处理

### Q1: 落幅起幅不匹配
```
原因：相邻镜头画面不连贯
解决：调整镜头顺序或修改描述
```

### Q2: 轴线混乱
```
原因：越轴拍摄导致空间混乱
解决：重新规划镜头角度，使用中性镜头过渡
```

### Q3: 剪辑点不明确
```
原因：动作/对话衔接点模糊
解决：精确定位到帧，使用描述性语言
```

## 返工机制

- **返工触发**：衔接质量问题、运镜设计不合理
- **常见返工原因**：
  - 镜头衔接跳跃
  - 轴线混乱
  - 剪辑点不明确
- **返工上限**：3次
