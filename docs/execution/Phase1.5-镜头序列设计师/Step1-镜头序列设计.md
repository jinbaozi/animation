# Step 1: 镜头序列设计

## Step 1.1: 接收与分析

1. 接收 Phase 1 所有输出文件
2. 分析每个场景的镜头序列设计需求
3. 确定每个镜头的专业运镜术语

## Step 1.2: 识别场景类型

根据8种场景类型，为每个场景选择合适的模板：

| 场景类型 | 核心特征 | 主要运镜技巧 |
|---------|---------|-------------|
| 对话场景 | 两人交流 | 180度轴线、正反打 |
| 动作戏 | 打斗追逐 | 跟随拍摄、快切 |
| 情感戏 | 情绪表达 | 慢镜头、特写 |
| 悬疑惊悚 | 紧张氛围 | 晃动镜头、低调光 |
| 蒙太奇转场 | 时间压缩 | 跳切、叠化 |
| 独白内心戏 | 心理描写 | 主观镜头、慢速 |
| 奇幻视觉奇观 | 视觉效果 | 特效合成、运动镜头 |
| 日常氛围治愈系 | 温馨生活 | 稳定镜头、自然光 |

## Step 1.3: 应用运镜知识

为每个镜头添加专业运镜术语：

```markdown
# 运镜术语参考（详见 templates/knowledge/）

## 镜头角度
- 鸟瞰（Bird's Eye）：从正上方拍摄
- 仰视（Low Angle）：从下往上拍摄
- 俯视（High Angle）：从上往下拍摄
- 平视（Eye Level）：与眼睛齐平

## 镜头运动
- 推镜头（Dolly In）：靠近主体
- 拉镜头（Dolly Out）：远离主体
- 摇镜头（Pan）：水平旋转
- 跟镜头（Follow）：跟随主体移动

## 剪辑术语
- 正反打（Shot/Reverse Shot）：两人对话的标准拍法
- 180度轴线规则：保持对话双方的空间关系
- OTS（Over the Shoulder）：过肩镜头
```
