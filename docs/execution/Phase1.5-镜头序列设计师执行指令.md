## 3. 执行步骤

### Step 1: 接收与分析

1. 接收 Phase 1 所有输出文件
2. 分析每个场景的镜头序列设计需求
3. 确定每个镜头的专业运镜术语

### Step 2: 识别场景类型

根据8种场景类型，为每个场景选择合适的模板：

| 场景类型 | 核心特征 | 主要运镜技巧 |
|---------|---------|-------------|
| 对话场景 | 两人交流 | 180度轴线、正反打 |
| 动作戏 | 打斗追逐 | 跟随拍摄、快切 |
| 情感戏 | 情绪表达 | 慢镜头、特写 |
| 悬疑惊悚 | 紧张氛围 | 晃动镜头、低调光 |
| 蒙太奇转场 | 时间压缩 | 跳切、叠化 |
| 独白内心戏 | 心理描写 | 主观镜头、慢速 |
| 奇幻视觉奇观 | 视觉效果 | 特效合成、运动镜头 |
| 日常氛围治愈系 | 温馨生活 | 稳定镜头、自然光 |

### Step 3: 应用运镜知识

为每个镜头添加专业运镜术语：

```markdown
# 运镜术语参考（详见 templates/knowledge/）

## 镜头角度
- 鸟瞰（Bird's Eye）：从正上方拍摄
- 仰视（Low Angle）：从下往上拍摄
- 俯视（High Angle）：从上往下拍摄
- 平视（Eye Level）：与眼睛齐平

## 镜头运动
- 推镜头（Dolly In）：靠近主体
- 拉镜头（Dolly Out）：远离主体
- 摇镜头（Pan）：水平旋转
- 跟镜头（Follow）：跟随主体移动

## 剪辑术语
- 正反打（Shot/Reverse Shot）：两人对话的标准拍法
- 180度轴线规则：保持对话双方的空间关系
- OTS（Over the Shoulder）：过肩镜头
```

### Step 5: 生成序列衔接与继承表

记录镜头之间的衔接关系：

```markdown
# 序列衔接与继承表

## 衔接规则
- 落幅→起幅：必须视觉匹配或逻辑连贯
- 情绪连贯：相邻镜头情绪差异不超过一个等级
- 运动连贯：主体运动方向一致

## 衔接记录

| 当前镜头 | 落幅 | 下一镜头 | 起幅 | 衔接类型 | 衔接质量 |
|---------|------|---------|------|---------|---------|
| 001 | 夜华面部特写 | 002 | 白浅反应镜头 | 正反打 | OK |
| 002 | 白浅微笑 | 003 | 桃花飘落 | 情绪延伸 | OK |
| 003 | 桃花飘落 | 004 | 天兵出现 | 场景转换 | OK |
```

### Step 6: 场景模板应用

为每个场景应用对应的模板规则：

#### 对话场景模板规则
```
- 180度轴线保持一致
- 正反打镜头交替
- 包含反应镜头（Reaction Shot）
- OTS镜头用于强调
```

#### 动作戏模板规则
```
- 动作匹配剪辑
- 跟随拍摄为主
- 快切用于紧张时刻
- 包含切出镜头（Cutaway）
```

#### 情感戏模板规则
```
- 慢推/慢拉镜头
- 特写强调情绪
- 留白剪辑
- 音乐节奏配合
```

## 5. 常见问题处理

### Q1: 落幅起幅不匹配
```
原因：相邻镜头画面不连贯
解决：调整镜头顺序或修改描述
```

### Q2: 轴线混乱
```
原因：越轴拍摄导致空间混乱
解决：重新规划镜头角度，使用中性镜头过渡
```

### Q3: 剪辑点不明确
```
原因：动作/对话衔接点模糊
解决：精确定位到帧，使用描述性语言
```
