# Phase 2a 质量标准

> 执行角色：AI美术技术总监
> 所属阶段：Phase 2a

---

## 人物四视图检查清单

- [ ] 每个角色有4个视角（正面/侧面/背面/面部特写）
- [ ] 全部纯白背景，无阴影
- [ ] 无水印、无文字
- [ ] 风格一致（符合项目风格定义）
- [ ] 无禁用词（影视质感、电影级、古风写实等）
- [ ] 服装描述前后一致
- [ ] 主角/配角/龙套区分合理

## 场景资产卡检查清单

- [ ] 场景描述具体清晰
- [ ] 包含环境、光线、氛围要素
- [ ] 可转化为视觉表达
- [ ] 无禁用词
- [ ] 与分镜执行表中的场景匹配

## 文件命名规范

- 人物四视图Prompt包：`{角色名}-四视图Prompt包.md`
- 场景资产卡：`场景资产卡.md`
