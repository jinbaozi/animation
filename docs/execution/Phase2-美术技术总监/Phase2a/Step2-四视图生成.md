# Step 2: 生成人物四视图Prompt

> 执行角色：AI美术技术总监
> 所属阶段：Phase 2a

---

## 四视图格式（MANDATORY）

| 视图 | 角度 | 描述 |
|------|------|------|
| 正面全身 | 0度 | 正面站立，双手自然下垂 |
| 侧面全身 | 90度 | 侧面站立，展示轮廓 |
| 背面全身 | 180度 | 背面站立，展示背部设计 |
| 面部特写 | 面部 | 高清面部细节，眼睛、嘴唇特写 |

---

## Prompt生成规则

### 核心要素

1. **背景**：纯白背景，无阴影
2. **风格**：动画风格，8K高清
3. **一致性**：同一角色四视图风格必须统一
4. **无文字**：不含水印、文字、logo

### 生成顺序

1. 正面全身（建立基础形象）
2. 侧面全身（展示轮廓）
3. 背面全身（展示背部设计）
4. 面部特写（高清面部细节）

### 质量控制

- [ ] 同一角色四视图风格一致
- [ ] 服装描述前后对应
- [ ] 无禁用词（参考 rules/风格一致性.md）
- [ ] 纯白背景要求严格遵守
