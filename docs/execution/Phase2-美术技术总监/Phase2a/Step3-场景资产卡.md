# Step 3: 生成场景资产卡

> 执行角色：AI美术技术总监
> 所属阶段：Phase 2a

---

## 场景资产卡格式

```markdown
# 场景资产卡

## 场景：{场景名称}

### 场景描述
{环境描述}

### 视觉Prompt
Prompt: {用于生成的Prompt}
```

---

## 场景描述要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 环境类型 | 室内/室外/混合 | 室内场景 |
| 场景名称 | 具体地点 | 天宫大殿 |
| 视觉特征 | 建筑/装饰细节 | 金碧辉煌，雕梁画栋，龙柱耸立 |
| 氛围 | 情绪基调 | 庄重氛围，仙气缭绕 |
| 光线 | 光照描述 | 日光从穹顶洒落 |

---

## Prompt生成规则

### 核心要素

1. **环境**：具体场景位置和类型
2. **细节**：建筑装饰特征
3. **氛围**：情绪和光线
4. **风格**：动画风格，8K高清

### 质量控制

- [ ] 场景描述具体清晰
- [ ] 包含环境、光线、氛围
- [ ] 可转化为视觉表达
- [ ] 无禁用词
