# Step 3: 生成VideoPrompt

> 执行角色：AI美术技术总监
> 所属阶段：Phase 2b

---

## 生成流程

### 1. 镜头分析

1. 阅读增强分镜执行表中的镜头描述
2. 确定镜头类型（对话/动作/情感/悬疑等）
3. 确定运镜方式（推/拉/摇/移/跟/固定等）

### 2. 时间分配

1. 将15秒镜头分配到5个时间段
2. 确保每个时间段有明确内容
3. 起幅→落幅需连贯

### 3. 双轨生成

1. 同时生成中文和英文Prompt
2. 内容必须一致（同一镜头）
3. 英文Prompt面向国际化模型优化
4. 中文Prompt面向国内模型优化

### 4. 质量检查

- [ ] 时间分段正确（每段3秒）
- [ ] 中英双轨完整
- [ ] 无禁用词
- [ ] 运镜术语专业
- [ ] 场景类型匹配

|------|---------|------|

| 全景 | Wide shot / Full shot | 全身 |
| 推镜头 | Dolly in / Camera push in | 接近主体 |
| 拉镜头 | Dolly out / Camera pull out | 远离主体 |
| 摇镜头 | Pan | 水平/垂直摇动 |
| 移镜头 | Tracking shot | 跟随移动 |
| 跟镜头 | Follow shot | 跟随主体 |
| 过肩镜头 | Over the shoulder | 双人对话 |
| 定场镜头 | Establishing shot | 建立场景 |
