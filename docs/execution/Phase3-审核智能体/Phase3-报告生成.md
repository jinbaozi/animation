# Phase3: 报告生成

> Phase 3-审核智能体第四步

---

## 目标

汇总审核结果，生成结构化审核报告。

## 执行步骤

### 4.1 汇总评分

整合8维度审核结果，计算综合评分。

### 4.2 问题分级

按P0/P1/P2三级分类整理所有发现问题：

| 级别 | 含义 | 处理 |
|------|------|------|
| P0 | 必须修复 | 阻断性问题 |
| P1 | 建议修复 | 重要问题 |
| P2 | 可选修复 | 优化建议 |

### 4.3 生成修复建议

针对每个P0/P1问题，提供具体修复建议。

### 4.4 输出报告

报告输出至 `review/{项目名}-audit-{日期}.md`

## 报告结构

1. 执行摘要
2. 评分汇总（8维度）
3. 问题清单（P0/P1/P2）
4. 维度详细分析
5. 修复优先级建议
6. 附录
