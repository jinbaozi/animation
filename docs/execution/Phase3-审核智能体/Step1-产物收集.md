# Step1: 产物收集

> Phase 3-审核智能体第一步

---

## 目标

读取所有产物文件，构建审核上下文。

## 执行步骤

### 1.1 确认产物存在

检查 output/{项目名}/ 目录下是否存在以下文件：

| 产物 | 文件名 |
|------|--------|
| 剧本 | 剧本.md |
| 基础分镜 | 基础分镜执行表.md |
| 增强分镜 | 增强分镜执行表.md |
| 序列衔接 | 序列衔接与继承表.md |
| 人物清单 | 人物清单.md |
| 人物四视图 | 人物四视图Prompt包.md |
| 场景清单 | 场景清单.md |
| 场景资产 | 场景资产卡.md |
| 视频提示词 | VideoPrompt包.md |

### 1.2 读取产物内容

逐个读取产物文件，将内容加载到审核上下文中。

### 1.3 构建审核上下文

汇总所有产物信息，为后续规则预检和LLM细审提供完整的素材基础。
