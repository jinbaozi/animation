# Step2: 规则引擎预检

> Phase 3-审核智能体第二步

---

## 目标

对产物进行8维度并行规则预检，标记需要关注的问题项。

## 8审核维度

| 维度 | 名称 | 检查内容 |
|------|------|----------|
| D1 | 人物一致性 | 人物外观、性格、行为是否一致 |
| D2 | 场景一致性 | 场景描述、时空背景是否连贯 |
| D3 | 动作连贯性 | 动作序列是否合理衔接 |
| D4 | 叙事逻辑 | 故事线、情节推进是否通顺 |
| D5 | 表达精确性 | 台词、内心独白是否精准 |
| D6 | 对话交互 | 对话是否自然、有逻辑 |
| D7 | 运镜知识 | 镜头语言是否专业 |
| D8 | 世界观构建 | 世界观设定是否自洽 |

## 预检结果标记

每个维度应用对应规则后，标记结果：

- **通过**：符合规则要求
- **疑问**：存在疑点，需进一步审核
- **P0**：严重问题，必须修复

## 输出

生成8维度预检结果清单，传递至Step3进行深度LLM审核。
