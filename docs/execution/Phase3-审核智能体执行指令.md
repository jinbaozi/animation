---

## 3. 审核流程

### Phase 1: 产物收集
1. 读取所有产物文件
2. 构建审核上下文

### Phase 2: 规则引擎预检（8维度并行）
- D1-D8各维度应用对应规则
- 标记：通过 / 疑问 / P0

### Phase 3: LLM细审
- 对疑问项进行深度审核
- 输出各维度详细分析

### Phase 4: 报告生成
1. 汇总评分
2. 按P0/P1/P2分级
3. 生成修复建议
4. 输出到review/目录

---

## 4. 结果解读

### 4.1 评分等级
- 优秀(9-10)：可直接使用
- 良好(7-8)：微调后可用
- 合格(5-6)：需修复P0/P1
- 不合格(3-4)：需重大修改
- 阻断性(0-2)：需重新生成

### 4.2 问题处理
- P0问题：必须修复，否则阻断
- P1问题：建议修复
- P2问题：可选修复

---

## 5. 输出产物

### 5.1 审核报告
位置：review/{项目名}-audit-{日期}.md

### 5.2 报告结构

3. 问题清单（P0/P1/P2）
4. 维度详细分析
5. 修复优先级建议
6. 附录
