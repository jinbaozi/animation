## 1. 核心概念

### 为什么要使用摄影机/镜头提示词

在AI图像生成中，指定相机类型或镜头型号会让AI调整：
- **构图 (Composition)** - 焦距和视角
- **色调 (Color Tone)** - 色彩科学和影调
- **景深 (Depth of Field)** - 虚化效果
- **光晕衰减 (Light Falloff)** - 边缘光线衰减
- **畸变 (Distortion)** - 镜头畸变特征

### 最佳实践

**堆叠组合策略** - 将摄影机、镜头、胶片风格组合使用：

```
DSLR photo with an 85mm lens, shot on Kodak Portra 400, soft window light.
```

**光线优先策略** - 描述光线成因而非效果：

```
错误: "add blue streaks" (效果优先)
正确: "bright pinpoint practical light, thin atmospheric haze" (成因优先)
```

| **R** | Resolution | `8K, high resolution, detailed` |
| **A** | Additional | `film grain, vintage lens` |
| **M** | Mood | `melancholic, dramatic, joyful` |
| **E** | Effect | `bokeh, lens flare, anamorphic` |

## 10. 常见错误与注意事项

### 10.1 常见错误

| 错误 | 正确做法 |
|------|----------|
| 仅写 "cinematic" | 指定具体摄影机/镜头型号 |
| 仅写 "beautiful" | 描述具体光线和色彩 |
| "add blue streaks" | 描述光源成因 |
| 提示词过长 | 保持50-150字，结构清晰 |
| 忽略比例 | 16:9, 2.39:1等 |
| 单次生成期望完美 | 生成3-5个变体 |

### 10.2 注意事项

1. **变体是标准流程** - 专业VFX流程中，首帧很少是最终帧
2. **光线成因优先** - 描述物理成因，而非最终效果
3. **组合使用** - 相机+镜头+胶片+光线组合使用
4. **考虑AI模型特性** - 不同模型对相同提示响应不同
5. **比例匹配** - 提示语言与目标比例匹配

### 10.3 AI视频特殊注意

- 不要写小说长度提示
- 不要忽略比例设置
- 不要跳过相机方向
- 期望有瑕疵，计划生成3-5次
