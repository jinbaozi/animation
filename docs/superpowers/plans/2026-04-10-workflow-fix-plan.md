- [ ] **Step 1: 添加角色铺垫规则章节（Q4）**

在文档末尾"## 返工机制"章节后、"## 版本历史"前，添加：

```markdown
## 角色铺垫规则（Q4修复）

**强制要求**：任何角色在第一次正式登场前，必须满足以下条件之一：

1. 之前有该角色的铺垫镜头（远处/声音）
2. 之前有其他角色提及该角色
3. 角色自我介绍/自报家门

**禁止**：角色无任何铺垫直接出现在对话或重要场景中

### 角色首次出现标注（Q4修复）

剧本.md中每个角色首次出现时必须标注引入方式：

| 引入方式 | 标注格式 | 说明 |
|----------|----------|------|
| 直接登场 | `[首次出现]` | 角色在场景中直接出现 |
| 远处出现 | `[远处出现]` | 角色在背景/远处出现 |
| 声音暗示 | `[声音出现]` | 角色未露面但有声音 |
| 他人提及 | `[被提及]` | 其他角色提到该角色 |

**示例**：
- 沃特从后厨探出头来 `[首次出现]`
- 远处广场传来老约翰的哨声 `[声音出现]`

### 镜头序列检查（Q4修复）

- [ ] 每个角色首次出现前是否有铺垫（远处/声音/提及）
- [ ] 角色首次正式登场前是否有至少1个铺垫镜头
- [ ] 铺垫镜头与正式登场镜头的场景/时间是否连贯
```

- [ ] **Step 2: 添加镜头段落结构章节（Q5）**

在同一位置（版本历史前），继续添加：

```markdown
## 镜头段落结构（Q5修复）

基础分镜执行表.md 必须包含**段落层**结构：

| 层级 | 名称 | 说明 |
|------|------|------|
| 段 | 段落 | 12-15秒的完整镜头段落 |
| 镜 | 镜头 | 段内的独立镜头，3-5秒 |

**段落结构示例**：
```
段1: [0:00-0:15] 面包房日常工作
  镜1-1: [0:00-0:03] 沃特从后厨探头
  镜1-2: [0:03-0:08] 吴为揉面特写
  镜1-3: [0:08-0:15] 沃特嘲讽吴为
```

## 镜头时间预算规则（Q5修复）

| 规则 | 要求 |
|------|------|
| 单镜头时长 | 3-5秒 |
| 单段落时长 | 12-15秒 |
| 每段镜头数 | 3-5个镜头 |
| 段落总数 | 根据总时长计算：总时长/13秒（平均） |

### 镜头段落检查（Q5修复）

- [ ] 分镜表是否包含段落层结构
- [ ] 单镜头时长是否在3-5秒范围内
- [ ] 单段落时长是否在12-15秒范围内
- [ ] 段落是否按场景/事件边界划分
- [ ] 段落之间是否有合理的转场衔接
```
