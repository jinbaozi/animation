# Agents 目录重构设计文档

> 状态：v1.0 | 日期：2026-04-06
> 目标：将角色文件统一重组到 agents/ 目录，实现模块化管理

---

## 1. 背景与目标

### 1.1 现状问题

| 问题 | 描述 |
|------|------|
| 角色文件分散 | 5个角色文件位于根目录，与 agents/ 目录分离 |
| 结构不一致 | audit-agent 已在 agents/ 下，但编排师角色未对齐 |
| 引用路径混乱 | 跨目录引用导致路径不清晰 |

### 1.2 设计目标

1. **统一结构** — 编排师作为父目录，01-04 作为子模块
2. **参照 audit-agent** — 与现有 audit-agent 架构保持一致
3. **备份优先** — 原始文件移至 bak/ 目录备份
4. **引用内聚** — 所有执行文档和规则文件统一在 agents/ 下

---

## 4. 引用路径更新

### 4.1 需要更新的文件

| 文件 | 更新内容 |
|------|---------|
| `CLAUDE.md` | 更新 agents/ 路径引用 |
| `docs/路径规范.md` | 更新执行文档路径 |
| `agents/orchestrator/orchestrator.md` | 更新 Phase 执行路径引用 |
| `agents/audit/audit-agent.md` | 更新 dimensions/rules 相对路径 |

### 4.2 更新原则

- 入口文件（`orchestrator.md`、`audit-agent.md`）使用相对路径引用同目录或子目录
- 不再跨目录引用（如 `rules/` → `agents/orchestrator/Seedance2/`）
