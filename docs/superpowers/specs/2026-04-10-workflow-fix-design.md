## 背景

在审查项目"开局一张弓装备就变强"的产出物后，发现5个系统性问题，这些问题的根因在于工作流文档缺乏明确的规范和检查机制。

| # | 问题描述 | 根因分析 | 修复范围 |
|---|----------|----------|----------|
| Q1 | 四视图Prompt全是英文 | `四视图模板.md` 缺乏强制语言要求 | 工作流文档 |

## 修复方案

### Q1: 四视图模板.md - 强化中文Prompt要求

**文件路径**：`agents/orchestrator/phases/Phase2a/四视图模板.md`

**修改内容**：

1. 增加强制检查项（新增章节）
```markdown
## 语言检查（强制）

- [ ] **必须包含中文描述段落**：每个四视图Prompt必须包含至少20个连续中文字符
- [ ] **禁止直接输出英文Prompt**：Prompt主体描述必须使用中文
- [ ] **运镜术语保留英文**：景别、运动方式等术语可保留英文原词
```

2. 增加负面约束（新增章节）
```markdown
## 禁止项

- **禁止**：直接输出英文Prompt作为主体描述
- **禁止**：仅提供英文Prompt而无中文对照
- **禁止**：中文描述少于整体Prompt的50%
```

3. 更新示例格式
- 所有示例Prompt改为中文主体描述
- 英文仅用于运镜术语

### Q2: Phase2a-质量标准.md - 双版本四视图要求

**文件路径**：`agents/orchestrator/phases/Phase2a/Phase2a-质量标准.md`

**修改内容**：

1. 新增版本联动触发规则
```markdown
### 版本联动触发规则（Q2修复）

当人物清单.md中出现以下关键词时，自动触发多版本四视图生成：

| 关键词 | 触发条件 |
|--------|----------|
| "初始"/"后期"/"一个月后"/"成长" | 该角色需要初始版+后期版两套四视图 |
| "变化"/"改变"/"不同阶段" | 该角色需要多版本四视图 |
```

2. 新增清单检查项
```markdown
### 人物状态变化检查（Q2修复）

- [ ] 检查人物清单中是否标注有状态变化的角色（如：吴为-初始/一个月后）
- [ ] 如有标注，验证该角色是否有对应数量的四视图版本
- [ ] 验证不同版本间关键特征一致性（面部轮廓、体型基础）
```

3. 更新返工机制
```markdown
### 返工机制扩展

| 触发条件 | 处理方式 |
|---------|---------|
| 人物清单标注状态变化但四视图只有单版本 | 补充缺失版本 |
| 多版本四视图关键特征不一致 | 重新生成并保持一致性 |
```

### Q3: 双轨生成.md - 格式校验与目录分离

**文件路径**：`rules/双轨生成.md`

**修改内容**：

1. 新增格式校验规则
```markdown
## 内容校验规则（Q3修复）

### 中文版格式校验

| 检查项 | 要求 |
|--------|------|
| 中文字符数 | 必须超过200个中文字符 |
| 英文术语占比 | 不超过整体内容的30% |
| Seedance Prompt | **必须为英文**，不得混入中文描述 |

### 英文版格式校验

| 检查项 | 要求 |
|--------|------|
| 中文字符数 | 不得超过50个（角色名除外） |
| Seedance Prompt | 纯英文 |
```

2. 分离目录结构（更新现有章节）
```markdown
## 目录结构（Q3修复）

```
output/{项目名}/05-Phase2b-Prompt生成/
├── 视频Prompt包-中文版/              # 强制性目录：人类可读
│   └── 视频Prompt包.md              # 中文描述+英文术语
└── 视频Prompt包-英文版/             # 强制性目录：提交给Seedance
    └── VideoPrompt.md                # 纯英文Prompt
```

**注意**：两个目录必须同时存在，内容必须一一对应。
```

3. 新增触发条件
```markdown
## 触发条件（Q3修复）

- 每个Phase 2b产出必须通过内容校验
- 两个目录（中文/英文）必须同时创建
- 中文版中文字符数不足200时，视为不合格
```

### Q4: Phase1-质量标准.md - 角色引入规范

**文件路径**：`agents/orchestrator/phases/Phase1/Phase1-质量标准.md`

**修改内容**：

1. 新增角色首次出现标注规则
```markdown
### 角色首次出现标注（Q4修复）

剧本.md中每个角色首次出现时必须标注引入方式：

| 引入方式 | 标注格式 | 说明 |
|----------|----------|------|
| 直接登场 | `[首次出现]` | 角色在场景中直接出现 |
| 远处出现 | `[远处出现]` | 角色在背景/远处出现 |
| 声音暗示 | `[声音出现]` | 角色未露面但有声音 |
| 他人提及 | `[被提及]` | 其他角色提到该角色 |

**示例**：
- 沃特从后厨探出头来 `[首次出现]`
- 远处广场传来老约翰的哨声 `[声音出现]`
```

2. 新增镜头序列检查项
```markdown
### 镜头序列检查（Q4修复）

- [ ] 每个角色首次出现前是否有铺垫（远处/声音/提及）
- [ ] 角色首次正式登场前是否有至少1个铺垫镜头
- [ ] 铺垫镜头与正式登场镜头的场景/时间是否连贯
```

3. 新增强制铺垫规则
```markdown
## 角色铺垫规则（Q4修复）

**强制要求**：任何角色在第一次正式登场前，必须满足以下条件之一：

1. 之前有该角色的铺垫镜头（远处/声音）
2. 之前有其他角色提及该角色
3. 角色自我介绍/自报家门

**禁止**：角色无任何铺垫直接出现在对话或重要场景中
```

### Q5: Phase1-质量标准.md - 镜头段落结构

**文件路径**：`agents/orchestrator/phases/Phase1/Phase1-质量标准.md`

**修改内容**：

1. 新增段落层结构
```markdown
### 镜头段落结构（Q5修复）

基础分镜执行表.md 必须包含**段落层**结构：

| 层级 | 名称 | 说明 |
|------|------|------|
| 段 | 段落 | 12-15秒的完整镜头段落 |
| 镜 | 镜头 | 段内的独立镜头，3-5秒 |

**段落结构示例**：
```
段1: [0:00-0:15] 面包房日常工作
  镜1-1: [0:00-0:03] 沃特从后厨探头
  镜1-2: [0:03-0:08] 吴为揉面特写
  镜1-3: [0:08-0:15] 沃特嘲讽吴为
```

2. 新增时间预算规则
```markdown
## 镜头时间预算规则（Q5修复）

| 规则 | 要求 |
|------|------|
| 单镜头时长 | 3-5秒 |
| 单段落时长 | 12-15秒 |
| 每段镜头数 | 3-5个镜头 |
| 段落总数 | 根据总时长计算：总时长/13秒（平均） |
```

3. 新增质量检查项
```markdown
### 镜头段落检查（Q5修复）

- [ ] 分镜表是否包含段落层结构
- [ ] 单镜头时长是否在3-5秒范围内
- [ ] 单段落时长是否在12-15秒范围内
- [ ] 段落是否按场景/事件边界划分
- [ ] 段落之间是否有合理的转场衔接
```

## 不包含的修复范围

本规格**仅修复工作流文档**，不包含：

- output目录中现有产出物的修复
- 已生成的剧本、分镜、四视图、VideoPrompt的重新生成

output文件修复将在工作流文档修复后，作为独立任务处理。
