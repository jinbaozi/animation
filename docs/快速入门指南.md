### 5个执行角色

| 角色 | Phase | 职责 |
|------|-------|------|
| 品控合规官 | Phase 0 | 审核小说合规性 |
| 内容总导演 | Phase 1 | 生成剧本和分镜表 |

| 美术技术总监 | Phase 2a/2b | 生成视觉Prompt |

## 第二步：准备你的小说

### 格式要求

```
✅ 支持格式：.txt, .md
✅ 编码：UTF-8
✅ 语言：中文
✅ 字数：建议1000-50000字
```

### 示例结构

```markdown
# 我的小说

第一章：相遇

夜华站在天宫大殿，看着缓缓走来的白浅...

第二章：表白

"三生三世，我只要你。"夜华深情地说...
```

### 准备好后

1. 明确目标平台（抖音/快手/B站/微信视频号）
2. 如有改编需求，准备好说明
3. 记住小说文件路径

## 第三步：开始 Phase 0 - 合规预审

### 执行流程

1. **提交小说**给编排师
2. **等待审核**（约10-30分钟）
3. **接收报告**：`合规预审报告.md`

### 合规预审报告示例

```markdown
# 合规预审报告

| 项目 | 结果 |
|------|------|
| 综合评分 | 8/10 |
| 结论 | PASS |

## 问题清单
（无CRITICAL问题）

## 下一步
✅ 可进入 Phase 1
```

### 可能的结果

| 结论 | 含义 | 下一步 |
|------|------|--------|
| PASS | 完全通过 | 进入Phase 1 |
| PASS_WITH_SUGGESTIONS | 通过，有优化建议 | 可进入Phase 1 |
| NEEDS_REVISION | 需要修改 | 修改后重新提交 |
| REJECTED | 阻断性问题 | 无法继续 |

## 第四步：Phase 1 - 剧本分镜

### 执行流程

1. **等待剧本生成**（约30-60分钟）
2. **接收输出**：
   - `剧本.md` - 故事文本
   - `基础分镜执行表.md` - 镜头清单
   - `人物清单.md` - 角色档案
   - `场景清单.md` - 场景描述

### 基础分镜表示例

```markdown
| # | 场景 | 人物 | 动作/台词 | 情绪 | 摄影机 |
|---|------|------|----------|------|-------|
| 001 | 天宫大殿 | 夜华、白浅 | 夜华向白浅表白 | 甜蜜 | 中景 |
| 002 | 天宫大殿 | 白浅 | 白浅微笑回应 | 感动 | 特写 |
```

## 第五步：Phase 1.5 - 镜头序列

### 执行流程

1. **等待镜头设计**（约30-45分钟）
2. **接收输出**：
   - `增强分镜执行表.md` - 含专业运镜
   - `序列衔接与继承表.md` - 镜头衔接

### 增强分镜表示例

```markdown
| # | 运镜方式 | 镜头语言 | 落幅 | 起幅 | 剪辑点 |
|---|---------|---------|------|------|-------|
| 001 | 中景→特写 | 正反打，深情凝视 | 夜华面部特写 | 白浅反应 | 对白结束后1秒 |
```

## 第六步：Phase 2a - 人物四视图

### 执行流程

1. **等待Prompt生成**（约60分钟）
2. **接收输出**：
   - `人物四视图Prompt包.md` - 每个角色的4视角Prompt
   - `场景资产卡.md` - 场景视觉描述

### 人物四视图示例

```markdown
## 角色：白浅

### 正面全身
Prompt: 动画风格，纯白背景，白浅，正面全身...

### 侧面全身
Prompt: 动画风格，纯白背景，白浅，侧面全身...

### 背面全身
Prompt: 动画风格，纯白背景，白浅，背面全身...

### 面部特写
Prompt: 动画风格，纯白背景，白浅，面部特写...
```

## 常见问题

### Q1: Phase 0 失败怎么办？

**A**: 查看 `合规预审报告.md` 中的问题清单，按建议修改后重新提交。

```markdown
## 问题示例
| 严重度 | 问题 | 建议修改 |
|--------|------|---------|
| CRITICAL | 存在版权风险段落 | 删除或替换 |
| HIGH | 部分章节过于暴力 | 柔和处理 |
```

### Q2: 返工是什么意思？

**A**: 当某个Phase输出质量不达标时，需要返回修改。系统允许最多连续3次返工。

### Q3: 如何判断输出质量？

**A**: 查看每个Phase的输出模板，每个都有质量检查清单。

### Q4: 遇到问题找谁？

**A**: 找编排师。编排师是唯一的中枢，负责协调所有问题。

### Q5: 每个Phase需要多久？

| Phase | 预计时长 | 实际可能 |
|-------|---------|---------|
| Phase 0 | 10-30分钟 | 取决于字数 |
| Phase 1 | 30-60分钟 | 取决于复杂度 |
| Phase 1.5 | 30-45分钟 | 取决于镜头数 |
| Phase 2a | 约60分钟 | 取决于角色数 |
| Phase 2b | 约60分钟 | 取决于镜头数 |
