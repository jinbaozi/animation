## 3. 引用格式规范

### 3.1 相对路径 vs 绝对路径

**项目内引用使用相对路径**：
```markdown
# 推荐
[角色职责](../01-AI内容总导演-角色职责规范.md)
[规则索引](../rules/00-index.md)

# 不推荐
[角色职责](/Users/godxu/.../01-AI内容总导演-角色职责规范.md)
```

### 3.2 外部引用格式

```markdown
<!-- 外部链接 -->
<!-- 无 -->
```

### 3.3 引用检查清单

在提交文档前，检查：
- [ ] 所有 `[xxx.md](path)` 引用指向存在的文件
- [ ] 不使用 `01-角色/` 前缀
- [ ] 不使用 `02-基准模版/` 前缀
- [ ] 不使用 `docs/execution/` 前缀（已迁移至 `agents/orchestrator/`）
- [ ] 不使用 `agents/orchestrator/Seedance2/` 前缀（已迁移至 `rules/Seedance2/`）
- [ ] 相对路径正确（../ 表示上一级）
