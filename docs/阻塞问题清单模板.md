# 阻塞问题清单模板

> 版本：v1.0.0
> 创建日期：2026-04-04
> 用途：Phase 执行过程中遇到无法继续的问题时使用

---

## 模板头部

```markdown
# 阻塞问题清单

| 项目 | 内容 |
|------|------|
| 项目名称 | {项目名称} |
| 报告日期 | {YYYY-MM-DD} |
| 报告人 | {角色名称} |
| Phase | {Phase编号} |
| 返工次数 | {第N次返工} |
| 问题总数 | {N} |
| 阻塞级别 | CRITICAL / HIGH / MEDIUM |
```

---

## 问题记录表

```markdown
## 问题列表

### 问题 #{序号}

| 字段 | 内容 |
|------|------|
| 问题ID | BLOCK-{Phase}-{序号} |
| 严重度 | CRITICAL / HIGH / MEDIUM / LOW |
| 类型 | 缺失信息 / 格式错误 / 逻辑错误 / 外部依赖 / 其他 |
| 位置 | {文件路径} 或 {文档章节} |
| 描述 | {问题详细描述} |
| 影响 | {对后续Phase的影响} |
| 建议解决方式 | {如何解决此问题} |
| 所需资源 | {需要什么资源/信息/支持} |
| 预计解决时间 | {估算时间} |
| 状态 | OPEN / IN_PROGRESS / RESOLVED |
```

---

## 示例

```markdown
# 阻塞问题清单

| 项目 | 内容 |
|------|------|
| 项目名称 | 三生三世十里桃花 |
| 报告日期 | 2026-04-04 |
| 报告人 | AI内容总导演 |
| Phase | Phase 1 |
| 返工次数 | 第1次返工 |
| 问题总数 | 2 |
| 阻塞级别 | HIGH |

---

## 问题列表

### 问题 #1

| 字段 | 内容 |
|------|------|
| 问题ID | BLOCK-P1-001 |
| 严重度 | HIGH |
| 类型 | 缺失信息 |
| 位置 | 人物清单 |
| 描述 | 女主角"白浅"缺少年龄设定，导致无法准确描写人物状态 |
| 影响 | 影响分镜表中对该角色的动作设计 |
| 建议解决方式 | 向用户补充询问角色年龄、性格特点等基础设定 |
| 所需资源 | 用户补充设定信息 |
| 预计解决时间 | 10分钟 |
| 状态 | OPEN |

### 问题 #2

| 字段 | 内容 |
|------|------|
| 问题ID | BLOCK-P1-002 |
| 严重度 | CRITICAL |
| 类型 | 格式错误 |
| 位置 | 场景清单 |
| 描述 | 场景"天宫"未标注是室内还是室外，影响运镜设计 |
| 影响 | Phase 1.5 镜头序列设计无法进行 |
| 建议解决方式 | 补充场景环境设定 |
| 所需资源 | 场景环境描述 |
| 预计解决时间 | 5分钟 |
| 状态 | OPEN |
```

```markdown
| 解决方式 | {如何解决} |

| 备注 | {补充说明} |

---
```

---

## 使用说明

1. **触发条件**：当 Phase 执行遇到无法自行解决的问题时，生成此文档
2. **上报流程**：报告人 → 编排师 → 用户
3. **解决追踪**：每个 OPEN 问题必须跟踪到 RESOLVED
4. **返工上限**：连续3次返工仍无法解决，升级处理
