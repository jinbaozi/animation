### 角色体系（星型拓扑）

| 角色 | Entry Point | Phase | 核心职责 |
|------|-------------|-------|----------|
| 编排师 | `agents/orchestrator/orchestrator.md` | - | 用户 ↔ 执行角色协调 |

### Phase 执行流

```
用户提交任务
    │
    ▼
Phase 0（品控合规官）→ Phase 1（内容总导演）→ Phase 1.5（镜头序列设计师）
                                                              │
                                                              ▼
                                              Phase 2a（美术技术总监）
                                                              │
                                                              ▼
                                              Phase 2b（美术技术总监）→ 完成
```

### 禁止事项

| 规则 | 禁用原因 |
|------|---------|
| 禁止使用人称代词（她/他） | 必须使用具体角色名 |
| 禁止混合风格描述 | 风格一致性是逻辑问题 |
| 禁止缺失角色四视图 | 所有角色（含龙套）必须有4视图 |
| 禁止内容严重缺失 | 数千字小说不能只有2-3条序列 |
| 禁止违反Seedance2禁用词 | 见 `knowledge/seedance2/03-禁止清单.md` |

| 文档 | 用途 |

### Seedance2 核心能力

1. **纯文本生成** - Text-to-Video
2. **一致性控制** - @图片引用系统
3. **相机与动作复刻** - 运镜+动作参考
4. **创意模板/特效复刻** - VFX Replication
5. **故事补全** - Story Completion
6. **视频延长** - Video Extension
7. **声音控制** - 音画同步
8. **一镜到底** - One-Take Long Shot
9. **视频编辑** - 角色替换
10. **音乐节拍同步** - Music Beat Sync

### Seedance2 提示词架构

**五维架构法**：
1. 技术基底（分辨率、帧率、色彩空间）
2. 镜头运动（推拉摇移跟）
3. 视觉元素（主体、场景、道具）
4. 光影系统（色温、方向、氛围）
5. 质感约束（胶片颗粒、柔焦）

**万能模板**：
```
Subject: [主体描述]
Action: [具体动作描述]
Camera: [景别] + [运镜方式] + [角度]
Style: [视觉锚点]，[光线]，[色彩倾向]
Constraints: [排除列表]，[帧率/节奏]
```

## 关键约束

### 镜头数量公式

```
target_shots ≈ ceil(total_word_count / 80)
```

### 人物四视图格式

必须包含4个视角：正面全身、侧面全身、背面全身、面部特写
所有角色（含龙套）必须有4视图

### VideoPrompt 时间分段

| 段 | 时长 |
|----|------|
| 第一段 | 0-3s |
| 第二段 | 3-6s |
| 第三段 | 6-9s |
| 第四段 | 9-12s |
| 第五段 | 12-15s |

### Seedance2 最佳提示词长度

**中文30-100词**，过长反而让模型注意力分散
