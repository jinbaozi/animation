# 规则体系总结

> 本文件汇总所有规则的精华要点，便于快速查阅

## 核心规则速查

### 输出前必查

1. **风格一致性**：检查 `rules/风格一致性.md` 禁用词正则
2. **角色审美**：应用 `rules/审美偏好.md` 中用户选择的审美标准
3. **视频格式**：遵循 `rules/视频格式.md` 的时间戳分段规则
4. **镜头数量**：`rules/输出验证.md` 中的镜数计算公式

## 规则详解

### 1. 风格一致性.md

**禁用词正则**：
```
(?i)(影视|电影|摄像|胶片|摄影|古风写实|写实CG|游戏CG|影视质感|影视级|电影级)
```

**强制规则**：
- 如果项目是"国风动漫" → 绝对不能使用"古风写实"、"影视质感"等
- 风格一致性是逻辑问题，不是偏好问题

### 2. 审美偏好.md

三种审美标准（用户可配置）：

| 类型 | 说明 |
|------|------|
| 病弱审美 | 强调脆弱感、病态美 |
| 健康审美 | 强调活力、健康感 |
| 中性审美 | 平衡风格 |

### 3. 运镜知识.md

**7种基础运镜**：

| 运镜类型 | 提示词 |
|----------|--------|
| 推镜 | 缓慢推近 / 推至特写 |
| 拉镜 | 缓慢拉远 / 后拉至全景 |
| 横摇 | 向左横摇 / 右摇90度 |
| 竖摇 | 镜头上移 / 下推 |
| 环绕 | 轻微环绕 / 半圈环绕 |
| 跟拍 | 稳定跟拍 / 侧面跟拍 |
| 固定机位 | 固定镜头 / 中景固定 |

**核心组合公式**：`推近 → 环绕 → 拉远`（产品类视频最稳定结构）

### 4. 视频格式.md

**VideoPrompt 时间分段**：

| 段 | 时长 |
|----|------|
| 第一段 | 0-3s |
| 第二段 | 3-6s |
| 第三段 | 6-9s |
| 第四段 | 9-12s |
| 第五段 | 12-15s |

**每段内容规则**：
- 动作/内心活动/台词（根据场景类型选择）
- 必须包含镜头描述

### 5. 双轨生成.md

中英文提示词必须同时生成，存储在平行目录

### 6. 质量门禁.md

**10阶段门禁系统**：
- 每个Phase结束时进行质量检查
- 含量化验收标准

### 7. 输出验证.md

**镜头数量公式**：
```
target_shots ≈ ceil(total_word_count / 80)
```

**禁止事项**：
- 禁止使用人称代词（她/他）— 必须使用具体角色名
- 禁止混合风格描述
- 禁止缺失角色四视图（所有角色含龙套必须有4视图）
- 禁止内容严重缺失（数千字小说不能只有2-3条序列）
