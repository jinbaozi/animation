# 场景模板指南

> 汇总8种场景类型的模板特点、特色列和使用方法

---

## 标准分镜表格式（8列）

所有场景模板必须使用以下8列格式：

```
镜号 | 场景类型 | 景别 | 运动方式 | 时长 | 叙事功能 | 特色列 | 画面描述
```

| 列名 | 说明 | 示例 |
|------|------|------|
| 镜号 | 镜头序号 | 01, 02, 03... |
| 场景类型 | 场景类型名称 | 对话场景, 情感戏, 动作戏... |
| 景别 | 景别大小 | Wide, Medium, Close, 特写... |
| 运动方式 | 镜头运动 | Fixed, Dolly Push, Dolly Pull, Follow... |
| 时长 | 镜头时长（秒） | 3s, 5s, 0.3s... |
| 叙事功能 | 镜头叙事作用 | 建立, 过肩, Reaction, 收尾... |
| 特色列 | **场景专用特色列**（见下表） | 语法标注, 技巧, 动作... |
| 画面描述 | 完整画面描述 | 含角色、动作，光影等 |

---

## 场景类型详解

### 1. 对话场景序列

**特色列**：语法标注

**核心要素**：
- 轴线管理（180度规则）
- 视线匹配（Match on Action）
- 过肩镜头（Over-the-Shoulder）

**模板**：`templates/scene/对话场景序列.md`

### 2. 动作戏序列

**特色列**：动作

**核心要素**：
- 蓄力 → 出拳 → 格挡 → 反击 节奏
- 镜头节奏与动作节奏同步
- 多角度切换增强动感

**模板**：`templates/scene/动作戏序列.md`

### 3. 情感戏序列

**特色列**：镜头序列

**核心要素**：
- 镜头序列类型：推进式、后退式、环绕式
- 情绪放大技巧
- 表情特写

**模板**：`templates/scene/情感戏序列.md`

### 4. 悬疑惊悚序列

**特色列**：技巧

**核心要素**：
- Jump Scare 时机
- Dutch Angle 倾斜构图
- 声音暗示
- 快速切换增强紧张感

**模板**：`templates/scene/悬疑惊悚序列.md`

### 5. 蒙太奇转场

**特色列**：蒙太奇类型

**核心要素**：
- 时间压缩（Time Compression）
- 平行叙事（Parallel Editing）
- 匹配剪辑（Match Cut）

**模板**：`templates/scene/蒙太奇转场.md`

### 6. 独白内心戏序列

**特色列**：外化方案

**核心要素**：
- 环境映射（内心外化到环境）
- 微动作（细微肢体语言）
- 物件代理（用物品象征情绪）

**模板**：`templates/scene/独白内心戏序列.md`

### 7. 奇幻视觉奇观序列

**特色列**：阶段

**四阶段结构**：
1. Normal_World（正常世界）
2. First_Sign（初现征兆）
3. Manifestation（显化爆发）
4. Aftermath（余韵收尾）

**模板**：`templates/scene/奇幻视觉奇观序列.md`

### 8. 日常氛围治愈系序列

**特色列**：感官标注

**五感设计**：
- 视觉（色彩、光影）
- 听觉（背景音、氛围音）
- 触觉（质感、温度）
- 味觉（食物、饮品）
- 嗅觉（花香、环境气味）

**模板**：`templates/scene/日常氛围治愈系序列.md`

## 镜头数量计算

```
target_shots ≈ ceil(total_word_count / 80)
```

**说明**：每80字约等于1个镜头
