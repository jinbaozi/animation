## @引用系统

### 基础语法

```
@图片1 作为首帧，参考 @视频1 的运镜方式，使用 @音频1 作为背景音乐
```

### 权重控制

```
@图片1 中的角色（外观权重90%），在 @图片2 的场景中，做出与 @视频1 相同的动作（动作权重70%）
```

### 多模态限制

- 最多9张图片
- 最多3个视频
- 最多3个音频
- 总计最多12个文件

## 运镜体系

### 7种基础运镜

| 运镜类型 | 提示词 | 用途 |
|----------|--------|------|
| 推镜 | 缓慢推近 / 推至特写 | 强调细节 |
| 拉镜 | 缓慢拉远 / 后拉至全景 | 揭示环境 |
| 横摇 | 向左横摇 / 右摇90度 | 展示空间 |
| 竖摇 | 镜头上移 / 下推 | 角色登场 |
| 环绕 | 轻微环绕 / 半圈环绕 | 立体展示 |
| 跟拍 | 稳定跟拍 / 侧面跟拍 | 沉浸感 |
| 固定机位 | 固定镜头 / 中景固定 | 对话 |

### 进阶组合运镜

| 组合 | 提示词 | 场景 |
|------|--------|------|
| 推拉结合 | 先特写推近 → 再拉远至全景 | 悬念揭示 |
| 跟拍+环绕 | 跟拍人物行走 → 镜头绕到正面 | 视角转换 |
| 升降+横摇 | 航拍上升同时向右横摇 | 宏大场景 |

### 电影级术语

| 术语 | 中文提示词 | 效果 |
|------|------------|------|
| Dolly Zoom | 希区柯克变焦 | 空间扭曲感 |
| One-Take | 一镜到底 | 全程不切镜 |
| Dutch Angle | 荷兰角倾斜构图 | 不安/紧张 |
| Slow Motion | 升格慢动作 | 仪式感 |

## 景别体系

**六级景别**：极特写 → 特写 → 近景 → 中景 → 全景 → 大远景

**经典叙事序列**：大远景 → 中景 → 特写（先建立环境，再引入主体，最后聚焦细节）

## 避坑清单

| 错误 | 正确 |
|------|------|
| "高质量""电影感" | 4K UHD, 24fps, 浅景深, 暖金色调 |
| 超过3个镜头 | 使用`[Shot 1]...[Shot 2]...`结构 |
| 忽略负面提示词 | No watermarks, no text overlays |
| 主体描述放末尾 | 主体描述放开头（模型对前20-30词加权最重） |
| 英文提示词 | 全程使用中文提示词 |

## 局限性

- AI痕迹在某些场景明显
- 光影质感有时不够自然
- 复杂打斗物理碰撞有破绽
- 微表情无法精准呈现
- 专业制片级别分辨率尚需提升

**建议**：定位为"创意助手"而非"成品输出工具"
