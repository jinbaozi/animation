## 核心认知

### 核心理念：意图优先，而非精确控制

Seedance 2.0的核心原则：**意图优先于精确控制（Intent Over Precision）**

传统AI视频模型要求创作者用冗长的提示词"微管理"每一个细节，但Seedance 2.0不同——你只需要告诉模型**你想要什么**以及**它应该有什么感觉**，用`@references`来"展示而非告知"。

**核心公式**：清晰的创作意图 + 精准的参考素材 + 结构化的提示词 = 导演级AI视频

### 三个关键认知转变

**转变一：从"甲方思维"到"导演思维"**
- ❌ 不要写："一个美女在海边散步，高清画质，电影感"
- ✅ 导演会写："35mm镜头，中景跟拍，侧逆光下女主角从沙滩走向海水，裙摆被海风轻轻掀起，镜头缓慢推近至面部特写，眼神望向远方地平线"

**转变二：从"越长越好"到"精准为上"**
- 实测表明，Seedance 2.0在**中文30-100词的短提示词**下表现显著更好

**转变三：从"全靠文字"到"能参考就参考"**
- 能用图片定义角色就不要用文字描述
- 能用视频指定运镜就不要用文字堆砌

## 能力矩阵：十大核心生成能力

### 2.1 纯文本生成（Text-to-Video）

示例提示词：
```
一个中年男人下班后疲惫地走在街上，脚步变缓，最后停在家门口。脸部特写镜头，男人深呼吸，调整情绪，收起负面情绪变得轻松。然后特写翻找钥匙，插入门锁。进入家里后，小女儿和一只宠物狗欢快地跑过来拥抱。室内非常温馨，全程自然对话。
```

### 2.2 一致性控制（Consistency Control）

**核心语法**：
```
@图片1 中的角色，穿着 @图片2 中的服装，在 @图片3 的场景中，[动作描述]
```

**实战提示词**：
```
@图片1 中的女性角色，穿着 @图片2 中的白色连衣裙，站在 @图片3 中的京都古街道上。她缓缓转身，镜头从全景推近到中景，微风拂过裙摆和发丝。电影感暖色调，浅景深，4K。
```

### 2.3 相机与动作复刻（Camera & Motion Replication）

**核心语法**：
```
参考 @视频1 的运镜方式和动作节奏，将 @图片1 中的角色替换入场景中
```

**实战提示词**：
```
把 @视频1 中的男主角换成 @图片1，完全参考 @视频1 的所有运镜、分镜、特效以及主角的动作和面部表情
```

### 2.4 创意模板/特效复刻（VFX Replication）

**实战提示词**：
```
参考 @视频1 的转场节奏和视觉特效风格，将 @图片1 的产品展示内容按照相同节奏进行呈现。保持动效流畅度、色彩风格和光影质感完全一致。
```

### 2.5 故事补全（Story Completion）

**实战提示词**：
```
基于 @图片1 中的角色设定和 @图片2 的故事板分镜，自动补全完整剧情。生成一段15秒的叙事短片，包含三个镜头：第一个镜头引入场景，第二个镜头展示冲突，第三个镜头给出结局。全程保持角色一致性，自然过渡。
```

### 2.6 视频延长（Video Extension）

**核心语法**：
```
延长 @视频1 5秒，保持原有风格、角色和运镜节奏一致
```

**实战提示词**：
```
将 @视频1 向后延长8秒，接续原有镜头语言，角色动作自然过渡到下一个场景。使用 @音频1 作为背景音乐持续播放。
```

### 2.7 声音控制（Sound Control）

**实战提示词**：
```
@图片1 中的角色，说出台词："欢迎来到我的世界"，嘴型与 @音频1 中的语音完全同步。自然的面部表情变化，眼神交流感。中景固定镜头，柔和补光。
```

### 2.8 一镜到底（One-Take Long Shot）

**实战提示词**：
```
一镜到底长镜头：从室内昏暗的书房开始，镜头缓慢推向书桌，然后平滑右转穿过门廊，进入明亮的客厅。全程不切镜，焦点从近处的书本自然过渡到远处窗外的景色。35mm广角，稳定器跟拍，4K HDR。
```

### 2.9 视频编辑（Video Editing）

**实战提示词**：
```
用 @图片1 中的角色替换 @视频1 中的主角，保持背景、道具和其他角色完全不变。动作和表情自动适配新角色特征。
```

### 2.10 音乐节拍同步（Music Beat Sync）

**实战提示词**：
```
根据 @音频1 的音乐节拍同步画面节奏。每次重鼓点切换一个镜头，每次旋律高潮处进行快速推镜。共4个节拍点对应4次画面切换。炫光粒子效果随节拍律动。4K，高饱和度。
```

## 提示词终极框架

### 3.1 五维提示词架构法

| 层次 | 说明 |
|------|------|
| 第一层：技术基底 | 设定视频的"硬件参数"——分辨率、帧率、色彩空间、动态模糊等 |
| 第二层：镜头运动 | 明确相机的运动轨迹——推拉摇移跟、升降环绕、视角选择 |
| 第三层：视觉元素 | 描述画面中的具体内容——主体、场景、道具、特效 |
| 第四层：光影系统 | 定义光源的色温、方向、对比度、氛围 |
| 第五层：质感约束 | 控制画面质感——胶片颗粒、噪点、柔焦、色彩倾向 |

### 3.2 五维架构实战案例

**案例：霓虹赛博朋克城市穿梭**

```
〖技术基底〗8K UHD (7680×4320), HDR10+高动态范围, 48fps高帧率, 全局动态模糊强度0.7, 镜头畸变控制-轻微桶形畸变, 色彩空间: Rec.2020广色域, 噪点控制: 胶片颗粒感35mm film grain

〖镜头运动〗FPV无人机视角, 低空贴地飞行(高度1.5米), 速度感60km/h, 穿越狭窄巷道时侧倾角度15°, 镜头轻微晃动模拟手持呼吸感

〖视觉元素〗高密度全息广告牌(中文+霓虹日文混合), 潮湿地面反射率90%, volumetric fog体积雾浓度中等, 雨夜环境(中雨, 雨滴拖尾明显)

〖光影系统〗主光源: 冷青色LED招牌(色温8000K), 补光: 暖洋红霓虹(色温2700K), 高对比度明暗比1:8, 边缘光勾勒人物轮廓

〖质感约束〗No watermarks, no text overlays, no jump cuts, fluid motion
```

## 运镜大师课

### 4.1 基础运镜模块库（7种核心运动）

| 运镜类型 | 提示词 | 用途 |
|----------|--------|------|
| 推镜 | 缓慢推近 / 推至特写 | 强调细节、聚焦重点 |
| 拉镜 | 缓慢拉远 / 后拉至全景 | 揭示环境、收尾释放 |
| 横摇 | 向左横摇 / 右摇90度 | 展示空间、建立场景 |
| 竖摇 | 镜头上移 / 下推 | 角色登场、空间揭示 |
| 环绕 | 轻微环绕 / 半圈环绕 | 立体展示主体 |
| 跟拍 | 稳定跟拍 / 侧面跟拍 | 沉浸感、动作追随 |
| 固定机位 | 固定镜头 / 中景固定 | 对话、纪实风格 |

**核心组合公式**：`推近 → 环绕 → 拉远` —— 这是产品类视频最稳定的结构。

### 4.2 进阶组合运镜

| 组合方式 | 提示词示例 | 适用场景 |
|----------|------------|----------|
| 推拉结合 | 先特写推近 → 再拉远至全景 | 悬念揭示 |
| 跟拍+环绕 | 跟拍人物行走 → 镜头绕到正面 | 视角转换 |
| 升降+横摇 | 航拍上升同时向右横摇 | 宏大场景 |
| 手持晃动 | 轻微抖动增强临场感 | 真实感/纪录片 |
| 主观视角 | 第一人称POV沉浸视角 | 代入感 |
| 低角度仰拍 | 低角度仰视跟拍 | 英雄感/气势感 |

### 4.3 电影级专业运镜术语

| 术语 | 中文提示词 | 效果 |
|------|------------|------|
| Dolly Zoom | 希区柯克变焦 | 空间扭曲感 |
| One-Take | 一镜到底 | 全程不切镜 |
| Dutch Angle | 荷兰角倾斜构图 | 不安/紧张氛围 |
| Slow Motion | 升格慢动作 | 关键瞬间仪式感 |
| Match Cut | 匹配剪辑 | 视觉元素无缝转场 |
| Spiral Shot | 螺旋环绕 | 能量爆发/奇幻感 |

### 4.4 景别控制与叙事序列

**六级景别**：极特写 → 特写 → 近景 → 中景 → 全景 → 大远景

**经典叙事序列**：大远景 → 中景 → 特写 —— 先建立环境，再引入主体，最后聚焦细节。

### 4.5 万能运镜公式

```
[主体描述] + [环境氛围] + [光影风格] + [运镜指令] + [画面质感] + [稳定约束]
```

**公式实战示例**：
```
[主体描述] 红色未来概念跑车，流线型车身。车辆极速飞驰，漂移过弯，激起水雾
[环境氛围] 赛博朋克城市雨夜，霓虹灯牌闪烁，地面湿润反光
[光影风格] 蓝紫撞色霓虹光，强烈明暗对比，电影感
[运镜指令] FPV无人机第一视角，高速跟拍，俯冲
[画面质感] 4K超清，高对比度，画面流畅不抖
[稳定约束] 无闪烁卡顿，无画面撕裂，highly detailed
```

```
Scientific documentary style, ultra macro detail.
```

### 场景七：角色动作复刻

**适用场景**：AI二创、表情包制作、趣味短视频

```
将 @视频1 中的动作、运镜、表情神态完整映射到 @图片1 的角色上。角色面部特征严格保持与 @图片1 一致，服装纹理、身体比例不变。动作流畅自然，物理规律合理，不穿模不崩脸。

参考权重：角色外观权重90%，动作参考权重70%，背景环境权重50%。全程保持光影统一。
```

**关键技巧**：通过调整"影响权重"可以在保真度和创意空间之间找到平衡。

### 6.1 完整创作工作流

**第一阶段：选题与稀缺性设计**

## 避坑指南与常见问题

### 7.1 提示词避坑清单

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| "高质量""电影感" | 过于抽象，模型无法精确理解 | 4K UHD, 24fps电影帧率, 浅景深, 暖金色调 |
| 一次性描述超过3个镜头 | 模型注意力分散，容易丢失一致性 | 使用`[Shot 1]...[Shot 2]...`结构化分镜 |
| 忽略负面提示词 | 生成视频可能出现水印、文字 | No watermarks, no text overlays |
| 主体描述放在提示词末尾 | 模型对前20-30词加权最重 | 主体描述放在开头第一句 |
| 使用英文提示词 | 中文提示词效果更好 | 全程使用中文提示词（30-100词最佳） |
| 忽视景别描述 | 镜头呆板，缺乏叙事节奏 | 明确指定"全景"、"中景"、"特写" |

### 7.2 使用时段与排队优化

| 时段 | 排队情况 | 建议 |
|------|----------|------|
| 高峰时段（白天） | 排队人数可达4万+，预计等待2-3小时 | 错峰提交 |
| 错峰时段（凌晨/清晨/午后） | 5秒视频仅需4分钟即可生成 | 效率最佳 |

### 7.3 版权与内容合规

- 真实人物面部上传功能已于2月15日暂停
- 知名IP角色、动漫人物、流媒体原创角色的内容过滤收紧
- **合规建议**：使用AI生成原创角色，避免使用明确版权的角色名称和IP元素

### 7.4 当前局限性

- AI痕迹在某些场景中仍然明显
- 光影质感有时不够自然
- 物理碰撞在复杂打斗中可能存在破绽
- 微表情无法精准呈现
- 专业制片级别的分辨率和法律可靠性尚需提升

**应对策略**：将Seedance 2.0定位为"创意助手"而非"成品输出工具"——用AI生成基础素材，再通过人工精修达到专业标准。

### 7.5 常见问题FAQ

**Q1：提示词应该写多长？**
A：实测表明，Seedance 2.0在中文30-100词的提示词下表现最佳。过长反而会让模型注意力分散。

**Q2：如何提高角色一致性？**
A：在提示词开头明确锚定主体，并使用`@图片1`参考功能。模型对前20-30词的加权最重。

**Q3：可以生成多长的视频？**
A：单次生成4-15秒。超过15秒的视频可以通过"延长"功能分段生成后拼接。

**Q4：如何让运镜更流畅？**
A：使用明确的运镜术语（如`缓慢推近`、`稳定跟拍`）而非抽象的"动态感"。组合运镜时每次最多叠加2个。

**Q5：为什么有时候生成的视频有水印/字幕？**
A：在提示词中加入`No watermarks, no text overlays`作为负面约束。
