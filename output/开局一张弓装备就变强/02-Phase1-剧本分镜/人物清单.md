# 人物清单 - 《开局一张弓装备就变强》

**Phase 1 产出物**

## 主要人物

### 1. 吴为（马斯）

| 属性 | 内容 |
|------|------|
| **年龄** | 16岁 |
| **性别** | 男 |
| **身份** | 黑面包村村民、穿越者、老约翰的弟子 |
| **外貌特征** | 初始状态：瘦削、营养不良、面黄肌瘦、身高175cm体重不到120斤 |
| **外貌特征** | 一个月后：身体健壮、肌肉初显、精神饱满 |
| **性格特点** | 坚韧不拔、知恩图报、坦诚直接、不卑不亢、有自己的原则 |
| **核心动机** | 不想一辈子当面包工，想要在这个有超凡力量的世界闯出一片天 |
| **核心矛盾** | 拥有金手指但装备太差，渴望变强但身体素质跟不上 |

**属性面板变化：**

| 阶段 | 力量 | 敏捷 | 体质 | 感知 | 精神 | 魅力 |
|------|------|------|------|------|------|------|
| 初始 | 4 | 5 | 4 | 5 | 5 | 4 |
| 一个月后 | 5 | 5 | 5 | 5 | 5 | 4 |

**技能列表：**

| 技能 | 等级 | 状态 |
|------|------|------|
| 基础箭术 | 3级 | 见习级 |
| 基础剑术 | 2级 | 见习级 |
| 基础枪术 | 1级 | 见习级 |
| 突刺一剑 | 未掌握 | - |
| 剑术格挡 | 未掌握 | - |

**人设拆解小节（供Phase 2a使用）：**

- **体型**：初始瘦弱型（后期可发展为肌肉型）
- **服装**：初始破旧工人服（后期为战士皮甲）
- **配饰**：无特殊配饰
- **表情特征**：坚毅的眼神、不服输的嘴角
- **动作特征**：拉弓姿势标准、剑术动作干净利落
- **色彩倾向**：暖色调（面包房的暖光）→冷色调（战士的冷静）

### 2. 老约翰

| 属性 | 内容 |
|------|------|
| **年龄** | 中年（约40-50岁） |
| **性别** | 男 |
| **身份** | 黑面包村村训教官、曾经的冒险者、吴为的老师 |
| **外貌特征** | 断了左手、瞎了左眼、独眼、疤痕累累但目光锐利 |
| **性格特点** | 外冷内热、教学严格、经验丰富、尊重他人选择 |
| **核心动机** | 保护村庄、培养下一代、传承自己的梦想 |
| **核心矛盾** | 以残躯守护村庄，希望徒弟超越自己 |

**背景故事：**
- 曾是强大的冒险者，掌握三个单手剑技能
- 一次任务失败导致失去左眼和左手，退役回村
- 据说曾是全村最强大的人
- 对吴为有极高的期待

**教学特点：**
- 白天教剑术，晚上让吴为自己练箭术
- 善于因材施教，给吴为补充营养
- 第一次实战就带吴为上战场

**人设拆解小节（供Phase 2a使用）：**

- **体型**：硬汉型、肌肉发达但有残缺
- **服装**：皮甲、战士装扮
- **配饰**：左手是假肢？或空袖
- **表情特征**：独眼锐利、严厉时可怕、温柔时罕见
- **动作特征**：单手剑术精湛、动作干净老练
- **色彩倾向**：暗色调（老练沉稳）

### 3. 多尔

| 属性 | 内容 |
|------|------|
| **年龄** | 约17-18岁 |
| **性别** | 男 |
| **身份** | 黑面包村村民、弓箭训练者、吴为的朋友 |
| **外貌特征** | 普通身材、相貌平平 |
| **性格特点** | 热情好为人师、容易得意、爱面子、但心地善良 |
| **核心动机** | 想要证明自己的价值、想要像霍利一样有天赋 |
| **核心矛盾** | 知道自己没有天赋但不愿意承认 |

**关键行为：**
- 主动教吴为基础箭术（虽然自己也没完全掌握）
- 经常说"老约翰教学也就图一乐，真教学得看他多尔"
- 对吴为的快速进步感到惊讶和些许嫉妒

**人设拆解小节（供Phase 2a使用）：**

- **体型**：普通青年体型
- **服装**：村民便装
- **配饰**：无
- **表情特征**：得意时嘴角上扬、被比下去时撇嘴
- **动作特征**：射箭姿势不太标准、喜欢指指点点
- **色彩倾向**：暖色调（普通人）
