## 场景详细描述

### S01 - 面包房

| 属性 | 内容 |
|------|------|
| **场景名称** | 乔治面包房 |
| **集数** | 第1集、第5集 |
| **场景类型** | 内景 |
| **时间段** | 日间为主 |

**视觉环境：**
- 昏暗的面包房内，炉火映照着陈旧的木桌
- 空气中弥漫着粗粮和炉火的气息
- 简陋的擀面板、烤炉、黑面包成品
- 乔治面包房的黑面包以硬度和难吃著称

**场景布置：**
- 擀面板位于画面中心
- 烤炉在角落，火焰摇曳
- 门口透进一线光

**主要事件：**
- 第1集：吴为在面包房工作，沃特嘲讽他
- 第5集：吴为向乔治告别，收拾行李离开

**人物动线：**
- 吴为：擀面板→与沃特对话→离开
- 沃特：后厨→与吴为对话
- 乔治：柜台→与吴为对话→送别

---

### S02 - 黑面包村广场

| 属性 | 内容 |
|------|------|
| **场景名称** | 黑面包村广场 |
| **集数** | 第1、4、7、8集 |
| **场景类型** | 外景 |
| **时间段** | 夜间为主 |

**视觉环境：**
- 广场约五六百平方米，泥土地面
- 一根根火炬立在广场上，是夜间唯一有光亮的地方
- 广场中央是老约翰训练村民的地方
- 周围是黑面包村的民房

**场景布置：**
- 广场中央：篝火、训练区域
- 边缘：弓箭区、长枪区、剑术区
- 周围：民房、火炬

**主要事件：**
- 第1集：吴为第一次参加村训，被老约翰敷衍
- 第4集：老约翰收吴为为徒
- 第7集：吴为白天练剑、晚上练箭
- 第8集：村民报告哥布林来袭

**人物动线：**
- 吴为：广场入口→弓箭区→老约翰面前→离开
- 老约翰：广场中央→吴为面前→离开
- 村民：围观的训练状态

---

### S03 - 广场弓箭区

| 属性 | 内容 |
|------|------|
| **场景名称** | 广场弓箭训练区 |
| **集数** | 第2、3集 |
| **场景类型** | 外景 |
| **时间段** | 夜间 |

**视觉环境：**
- 广场边缘的火炬光芒摇曳
- 几个简陋的草靶竖立在区域内
- 弓箭架上挂着练习弓
- 月光与火光交织

**场景布置：**
- 草靶三个，距离约10米
- 弓箭架在角落
- 有两个已有人在训练（霍利、多尔）

**主要事件：**
- 第2集：吴为触碰弓触发系统
- 第3集：多尔教吴为基础箭术

**人物动线：**
- 吴为：入口→弓箭架→练习区→离开
- 多尔：练习区→吴为身边→教学位置
- 霍利：专注练习区（不参与对话）

| **集数** | 第2集 |

### S05 - 老约翰家

| 属性 | 内容 |
|------|------|
| **场景名称** | 老约翰的石头房子 |
| **集数** | 第5、6集 |
| **场景类型** | 内景 |
| **时间段** | 日间、夜间 |

**视觉环境：**
- 不大的石头房子，约七八十平方米
- 两室一厅的格局
- 右边的房间原本放杂物，正在被整理
- 老约翰的房间有他保养的皮甲和单手剑

**场景布置：**
- 客厅：简单家具、炉火
- 右边房间：吴为的卧室，约二三十平米
- 老约翰房间：皮甲和单手剑展示

**主要事件：**
- 第5集：老约翰带吴为搬家，讲解职业者体系
- 第6集：吴为发现狗头人法杖

**人物动线：**
- 老约翰：客厅→杂物间→整理房间
- 吴为：跟随→看自己房间→看老约翰房间

### S06 - 村口

| 属性 | 内容 |
|------|------|
| **场景名称** | 黑面包村村口 |
| **集数** | 第8、9集 |
| **场景类型** | 外景 |
| **时间段** | 晨间 |

**视觉环境：**
- 村围墙正在进行修缮
- 环村的陷阱在检查中
- 村民们在忙碌
- 晨雾还未完全散去

**场景布置：**
- 村口大门位置
- 围墙：木头和石头结构
- 陷阱：简易的坑洞和尖刺

**主要事件：**
- 第8集：村民报告哥布林来袭
- 第9集：老村长给吴为发放装备

**人物动线：**
- 老约翰：广场→村口→带吴为离开
- 老村长：村口→迎接老约翰→发放装备
- 吴为：跟随老约翰→接收装备

### S07 - 小树林边缘

| 属性 | 内容 |
|------|------|
| **场景名称** | 灰烬森林边缘小树林 |
| **集数** | 第9、10集 |
| **场景类型** | 外景 |
| **时间段** | 日间 |

**视觉环境：**
- 灰烬森林边缘的小树林
- 阳光透过树叶洒落
- 有哥布林活动的痕迹
- 战场在树林边缘

**场景布置：**
- 树林入口
- 吴为占据的树（约10米外）
- 老约翰摔倒的位置
- 哥布林包围圈

**主要事件：**
- 第9集：吴为树上射箭，四箭连发
- 第10集：吴为补刀哥布林，发现刺青

**人物动线：**
- 老约翰：树林→跑出→摔倒→被包围
- 吴为：爬树→射箭→下树→补刀
- 哥布林：树林→追击→被射杀
