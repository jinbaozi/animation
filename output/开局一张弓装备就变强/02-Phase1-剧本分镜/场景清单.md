## 详细场景描述

### 场景1：黑面包村广场（核心场景）

| 属性 | 内容 |
|------|------|
| 场景名称 | 黑面包村广场 |
| 英文名 | Black Bread Village Square |
| 集数 | 第1-5集均有出现 |
| 场景类型 | 户外/训练场 |
| 重要度 | **核心场景** |

**环境描述**：
- 广场大小：约500-600平方米
- 照明：夜晚有火炬照明，是村庄夜晚唯一有光亮的地方
- 地面：泥土或石板地面
- 周围：可能有简单的训练器械

**场景要素**：
| 要素 | 描述 | 视觉重点 |
|------|------|---------|
| 火炬 | 广场边缘立着多根火炬 | 温暖光源 |
| 靶架 | 木制箭靶，10米距离 | 训练标识 |
| 开阔地 | 用于长枪训练 | 空间感 |
| 约翰位置 | 中央端坐位置 | 权威象征 |

**时间段**：
- 白天：人少，主要用于个人训练
- 夜晚：主要训练时间，村民聚集

**色调建议**：
- 白天：自然光，偏暖黄色调
- 夜晚：火炬橙红色调，温暖但有冒险感

### 场景4：灰烬森林边缘

| 属性 | 内容 |
|------|------|
| 场景名称 | 灰烬森林边缘 |
| 英文名 | Grey Forest Edge |
| 集数 | 第4-5集 |
| 场景类型 | 户外/冒险 |
| 重要度 | **核心场景** |

**环境描述**：

- 特点：灰烬森林的边缘地带

| 要素 | 描述 | 视觉重点 |
|------|------|---------|
| 树木 | 高大树木，可攀爬 | 战术价值 |

| 地面 | 落叶和泥土 | 自然感 |

- 吴为可爬树占据高点

- 哥布林易设伏击

**色调建议**：
- 冷色调为主

- 传达"危险与机遇并存"
