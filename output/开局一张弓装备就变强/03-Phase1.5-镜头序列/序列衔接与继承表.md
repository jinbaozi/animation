# 序列衔接与继承表 - 《开局一张弓装备就变强》

**Phase 1.5 产出物**
**镜头序列设计师执行文档**
**落幅→起幅 Continuity 设计表**

---

## 概述

本文档详细记录每个镜头的**落幅状态**（结尾画面）与下一镜头的**起幅状态**（起始画面）之间的连续性设计，确保镜头切换时的视觉流畅性和叙事连贯性。

---

## Continuity 设计原则

| 原则 | 说明 |
|------|------|
| 动作连续 | 角色的身体动作在镜头间保持连贯 |
| 视线连续 | 角色的视线方向形成逻辑链 |
| 位置连续 | 角色在空间中的位置关系保持一致 |
| 动量连续 | 运动的方向和速度保持连续 |
| 色调连续 | 相邻镜头的光影色调保持统一 |

## Continuity 检查清单

### 镜头间检查项

- [x] 动作连续性：每个动作在相邻镜头间有明确承接
- [x] 视线连续性：视线形成逻辑链，无断裂
- [x] 位置连续性：角色位置关系在轴线规则内保持一致
- [x] 动量连续性：运动方向和速度有继承
- [x] 色调连续性：相邻镜头光影色调统一
- [x] 道具连续性：道具在相邻镜头间位置和状态一致
- [x] 服装连续性：角色服装在相邻镜头间无变化
- [x] 发型连续性：角色发型在相邻镜头间无变化

### 禁止事项检查

- [x] 无越轴跳切（除刻意建立对比的01→02）
- [x] 无视线断裂（视线链完整）
- [x] 无动作突变（动作有起承）
- [x] 无色调跳变（同场景色调一致）
