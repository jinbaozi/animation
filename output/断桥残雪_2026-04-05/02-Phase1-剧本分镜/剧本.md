## 场景 S01：西湖断桥·重逢

**场景类型**：情感戏 + 对话场景
**时间**：大雪纷飞的寒冬
**核心情绪**：久别重逢的深情与克制

| 节奏 | 内容 |
|------|------|
| **起** | 沈清辞独自立于断桥之上，大雪纷飞，青衣斗篷在风中猎猎 |
| **承** | 陆云深的声音从身后传来，沈清辞缓缓转身 |
| **转** | 陆云深走近，解下大氅替她披上，提及三年前等待 |
| **合** | 沈清辞落泪坦白当年不告而别。陆云深承诺真相。二人相拥 |

**对白**：
```
陆云深：「清辞。」
沈清辞：「云深……」
陆云深：「你的手怎么这样凉。」
陆云深：「三年前你走的时候，我曾在断桥上等了三天三夜。」
沈清辞：「我不是故意不辞而别的。」
陆云深：「我知道。你父亲是被冤枉的。」
沈清辞：「云深，你不怕吗？」
陆云深：「怕。但怕失去你，胜过怕死。」
```

## 场景 S02：金銮殿内外·翻案

**场景类型**：对话场景 + 情感戏
**时间**：大雪（三日后的朝会日）
**核心情绪**：正义伸张后的释然与深情

| 节奏 | 内容 |
|------|------|
| **起** | 陆云深在金銮殿上呈递密信，参奏赵世杰 |
| **承** | 沈清辞跪在殿外雪中等候，双手合十祈祷 |
| **转** | 圣旨下达，冤案昭雪。陆云深走出殿门 |
| **合** | 陆云深拉起沈清辞，雪停云开，二人相拥 |

**对白**：
```
陆云深：「臣陆云深，参当朝丞相赵世杰贪赃枉法、构陷忠良、欺君罔上！」
沈清辞（殿外）：「沈家，终于等到这一天了。」
陆云深：「案子翻过来了。从今以后，再也没有人能赶走你。」
沈清辞：「谢谢你……谢谢你为我做的一切。」
陆云深：「我做的不够。三年前没能护住你，这三年每天都在后悔。」
```
