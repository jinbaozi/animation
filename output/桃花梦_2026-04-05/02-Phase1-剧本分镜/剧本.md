## 场景 S01：十里桃林·初遇

**场景类型**：情感戏 + 对话场景
**时间**：黄昏
**核心情绪**：久别重逢的深情与克制

| 节奏 | 内容 |
|------|------|
| **起** | 白浅独自立于桃树下，花瓣飘落，病态苍白却美得令人心碎 |
| **承** | 夜华的声音从身后传来，白浅缓缓转身，两人对视 |
| **转** | 夜华走近，拂去白浅发间花瓣，发出共度此生的邀约 |
| **合** | 白浅眼眶泛红，微微点头，浅笑。风起，花瓣将二人笼罩 |

**对白**：
```
夜华：「三生三世，我寻了你五万年。」
白浅：「夜华……」
夜华：「浅浅，你可愿与我共度此生？」
```

## 场景 S02：十里桃林·表白

**场景类型**：情感戏 + 对话场景
**时间**：黄昏（延续）
**核心情绪**：深情告白，永恒的承诺

| 节奏 | 内容 |
|------|------|
| **起** | 夜华握住白浅冰凉的手，皱眉 |
| **承** | 夜华将白浅的手贴在胸口，承诺温暖 |
| **转** | 白浅回应，坦白等待 |
| **合** | 夜华拥白浅入怀。桃花纷飞，时间静止 |

**对白**：
```
夜华：「你的手还是这样凉。」
白浅：「习惯了。」
夜华：「从今以后，我会让你温暖。这里，永远为你而跳。」
白浅：「夜华，我等了你很久。」
夜华：「我知道。三生三世，我们再也不会分开。」
```
