## 核心规则速查

### 输出前必查

1. **风格一致性**：检查 `风格一致性.md` 禁用词正则
2. **角色审美**：应用 `审美偏好.md` 中用户选择的审美标准
3. **视频格式**：遵循 `视频格式.md` 的时间戳分段规则
4. **镜头数量**：`输出验证.md` 中的镜数计算公式
5. **交付边界**：最终交付必须包含 `VideoPrompt包`、`人物资产卡`、`场景资产卡`

### 禁止事项

| 规则 | 禁用原因 |
|------|---------|
| 禁止使用人称代词（她/他） | 必须使用具体角色名 |
| 禁止混合风格描述 | 风格一致性是逻辑问题，不是偏好 |
| 禁止缺失角色四视图 | 所有角色（含龙套）必须有4视图 |
| 禁止内容严重缺失 | 数千字小说不能只有2-3条序列 |
| 禁止硬编码项目数量 | 角色数、场景数、镜头数必须来自 project manifest 和上游 IR |
