# Seedance 2.0 禁止清单

> 版本：v2.0 | 日期：2026-04-05
> **强制执行**：所有VideoPrompt生成前必须通过本清单检查

---

## 8.1 禁用词检查（MANDATORY）

在生成任何Prompt前，必须通过以下正则检验：

```
(?i)(影视|电影|摄像|胶片|摄影|古风写实|写实CG|游戏CG|影视质感|影视级|电影级)
```

国风动漫风格项目禁止出现以上词汇。

---

## 8.2 禁止行为清单

| 禁止行为 | 原因 | 替代方案 |
|---------|------|---------|
| 使用"她/他/Young woman"等人称代词 | Seedance 2.0无法正确识别代词指向 | 始终使用角色名 |
| 同时描述内心活动和台词 | 冲突，无法同时传达 | 根据场景类型二选一 |
| 多个动作在同一时间段 | 动作冲突，生成质量差 | 每个时间段聚焦1个主动作 |
| 镜头运动与动作运动矛盾 | 视觉混乱 | 确保运镜与动作方向一致 |
| 使用"动态镜头"等模糊描述 | Seedance 2.0无法解析 | 使用具体运镜术语如"低角度跟拍" |
| 描述手部精细动作（超过5个手指） | Seedance 2.0手部生成不稳定 | 避免描述具体手指数或手部精细操作 |
| 描述文字/字幕内容 | 无法生成可读文字 | 用音效/旁白替代 |
| 超过2个主要人物同屏 | 角色一致性急剧下降 | 限制同屏人物≤2人 |
| 风格标签冲突 | 视觉混乱 | 统一使用国风动漫风格 |
| 场景/服装/道具突变 | 一致性断裂 | 每段镜头保持描述一致 |
| 跳过动作阶段（无蓄力/无收回） | 动作不连贯不业 | 每个动作写全三阶段 |
| 对话时人物不看对方 | 违反交流基本规则 | 确保视线在对话中锁定对方 |
| 表情/动作与剧情不符 | 人物行为不合理 | 表情/动作匹配当前情绪 |

---

## 8.3 生成前8项自检（MANDATORY）

生成任何Prompt前必须检查：

- [ ] 是否使用角色名而非人称代词？
- [ ] 是否每个时间段只描述一个主动作？
- [ ] 运镜描述是否具体（不用模糊词汇）？
- [ ] 光线描述是否具体（不用"好看光"等模糊词）？
- [ ] 风格标签是否≤2个（不超过2个风格词）？
- [ ] 是否避免了"手"的精细动作描写？
- [ ] 是否≤2个主要人物同屏？
- [ ] 是否通过禁用词正则检查？
