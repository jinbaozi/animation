## 一、核心提示词结构

### 五要素公式（基础）

```
[主体] + [动作/变化] + [场景/环境] + [运镜/镜头] + [风格/质感]
```

### 完整叙事公式（12-15s视频推荐）

```
[主体身份+外观] + [场景环境+时间光线] + [运镜方式]

[时序分段0:00-0:03]:
  动作：{具体动作+表情+身体语言}
  台词/内心：{二选一，契合剧情}
  镜头：{景别+运镜方式+速度}
  光线：{光源+色温+阴影}

[时序分段0:03-0:06]: ... 同上
[时序分段0:06-0:09]: ... 同上
[时序分段0:09-0:12]: ... 同上（可选）
[时序分段0:12-0:15]: ... 同上（可选）

负面词：--no {列出禁用元素}
```

## 二、人物对话与互动技巧

### 2.1 视线规则（MANDATORY）

| 场景状态 | 视线规则 | Prompt写法（英文参考） |
|---------|---------|---------------------|
| 对人对视 | 说话者眼睛注视对方，倾听者目光聚焦对方 | `looking directly into对方的eyes，目光交汇` |
| 单方开口 | 说话者看向对方，对方目光回应 | `gazing at对方，说话时目光不偏离对方` |
| 群体对话 | 说话者目光依次扫过在场人物 | `looking from一人到另一人，视线均匀分配` |
| 深情对视 | 两人目光锁定，瞳孔微放大 | `eyes locked on each other, pupils slightly dilated` |
| 躲避视线 | 一方说话，另一方躲避目光 | `speaking but looking away, avoiding direct eye contact` |
| 权威注视 | 上位者俯视审视下位者（配合俯拍） | `looking down with authority, piercing gaze` |

**关键规则：对话时眼睛一定要看着说话的对象，不能看旁边、看天或闭眼（除非剧情需要闭眼表达情绪）。**

### 2.2 表情/动作与剧情的匹配（MANDATORY）

| 剧情场景 | 正确表情/动作 | ❌ 禁止表情/动作 |
|---------|-------------|----------------|
| 女神邀请吃饭 | 欣喜、期待、微微微笑、身体向前倾 | 双手插兜、无所谓表情、冷漠站立 |
| 被表白/求婚 | 眼睛湿润、微微脸红、手微微颤抖 | 面无表情、双臂交叉、冷淡点头 |
| 愤怒争吵 | 眉头紧皱、声音提高、手指颤抖指向对方 | 微笑、双手抱胸、无所谓态度 |
| 悲伤离别 | 泪水滑落、肩膀颤抖、紧紧抓着对方衣袖 | 平静挥手、微笑告别、转身就走 |
| 恐惧/惊吓 | 瞳孔放大、猛然惊退、呼吸急促、身体发抖 | 平静站立、慢慢走来 |
| 惊讶/不可思议 | 嘴巴微张、睁大双眼、身体后退一步 | 面无表情、慢慢点头 |
| 得意/傲慢 | 嘴角上扬、下巴微抬、双臂抱胸、居高临下 | 低头弯腰、语气谦恭 |
| 温柔抚慰 | 轻抚对方的手、轻声细语、身体微微前倾 | 远远站着、大音量说话 |

### 2.3 对话节奏与动作衔接

```
正确模板：
  0-3s：A开口说话，身体向前迈步
  3-6s：B回应A，A目光转向B
  6-9s：A微笑回应，B脸红低头
  9-12s：两人相视而笑，距离拉近

错误模板：
  0-3s：A说话（没有任何动作铺垫）
  3-6s：B突然说话（A瞬间从说话到闭嘴，没有过渡）
  6-9s：两人都说话（同时说话，无主次）
```

**关键规则：说话必须有动作作为铺垫或伴随，不能仅张嘴说话。每段对话的切换要自然连贯。**

## 三、动作戏与武术指导技巧

### 3.1 武术动作的连贯性（MANDATORY）

**核心原则：每一个动作都要有"起势-过程-收势"三个阶段，禁止跳过收势直接进入下一个动作。**

| 武术动作 | 三阶段描述 | 错误示例 |
|---------|-----------|---------|
| 出拳 | 蓄力收拳 → 出拳打击 → 收回拳头 | 出拳后手悬在空中不做回收 |
| 刺枪/剑 | 后撤蓄力 → 向前刺/切 → 抽回武器 | 刚刺出长枪直接又刺一枪 |
| 踢腿 | 提膝蓄力 → 踢出 → 落地站稳 | 踢完后身体悬空不落地 |
| 翻跟斗 | 下蹲蓄力 → 翻滚一周 → 起身落地 | 翻一半就切换到下一个动作 |
| 跃起 | 屈膝 → 飞跃空中 → 着地缓冲 | 突然出现在空中起跳没有过程 |

### 3.2 武术动作的Prompt写法

```
[出拳场景 - 错误写法]
  动作：一拳打出，打在对方脸上
  问题：没有蓄力、没有收回、没有受力反应

[出拳场景 - 正确写法]
  0-3s：A身体重心下蹲，右拳向后蓄力
  3-6s：A猛然向前出拳，拳风呼啸
  6-9s：拳头击中B的肩膀，B身体猛然一震后退
  9-12s：A收回右拳，恢复战斗姿态
```

### 3.3 打斗场景的运镜选择

| 打斗阶段 | 运镜方式 | Prompt写法（英文参考） |
|---------|---------|----------------------|
| 对峙蓄力 | 缓慢推进 + 荷兰角倾斜 | `slow dolly in, dutch angle, tension building` |
| 出招瞬间 | 快速跟拍 + 格挡震动 | `rapid tracking, impact shake on contact` |
| 武器交锋 | 剑光划过 + 低角度仰拍 | `weapon slash tracking, low angle, sparks flying` |
| 近身搏斗 | 打斗跟随 + 手持晃动 | `combat close follow, handheld shake` |
| 技能释放 | 手部特写 + 极速后拉 | `hand close-up, rapid pull back to wide` |
| 命中判定 | 震退震动 + 慢动作 | `impact recoil, slow motion, body reaction` |
| 收招对峙 | 环绕摇镜 + 减速凝滞 | `orbiting camera, decelerating to halt` |

### 3.4 专业武术动作要点

1. **发力源于腰**：动作从腰部发力，传导到手臂/腿
2. **重心转移可见**：每一步出拳/踢腿都要有重心移动
3. **受力反应真实**：被打中人要有身体反应（震动/后退/踉跄）
4. **呼吸节奏可见**：剧烈打斗中呼吸急促，动作间隙有喘息

## 四、一致性控制技巧

### 4.1 人物一致性

| 一致性维度 | 控制方法 | Prompt写法 |
|-----------|---------|-----------|
| 服装 | 每个分镜都描述完整服装 | `wearing [完整服装描述]`，不能简化为"她" |
| 发型 | 描述发型+长度+颜色 | `long black hair cascading to waist`，每个镜头一致 |
| 妆容 | 描述肤色+化妆 | `pale complexion, light makeup` |
| 身材 | 描述体型+身高范围 | `delicate slender figure, average height` |
| 神态 | 匹配剧情的情绪状态 | 不能上一秒微笑下一秒面无表情 |

### 4.2 场景一致性

| 一致性维度 | 控制方法 | 示例 |
|-----------|---------|------|
| 时间 | 同一场景内时间段一致 | 黄昏场景不能突然变正午光线 |
| 季节 | 植物/落叶匹配季节 | 桃林场景不能突然变成秋叶 |
| 天气 | 雨/雪/风的状态一致 | 花瓣正在飘落不能突然无风 |
| 道具 | 角色手持物品不变 | 手中握着的剑不能突然变成书 |
| 位置 | 角色在场景中的位置连续 | 从桃林左侧走到右侧，不能瞬移 |

### 4.3 跨镜头一致性检查清单

```
□ 人物名称在所有镜头中一致（不使用她/他/Young woman等代词）
□ 服装描述在所有镜头中完整一致
□ 发型、妆容描述一致
□ 场景描述中时间和季节一致
□ 道具物品在相邻镜头中不消失或突变
□ 角色位置有合理的连续移动（不瞬移）
□ 光线和色调在同一场景内保持协调
□ 情绪表达有渐进变化（不突变）
```

### 4.4 一致性问题的常见陷阱

| 陷阱类型 | 现象 | 原因 | 修复方法 |
|---------|------|------|---------|
| 服装突变 | 上一镜穿盔甲，下一镜换布衫 | 描述过于简化 | 每镜都写完整服装描述 |
| 道具消失 | 手中握着剑，下一镜头空了 | 未描述手持道具 | 在动作描述中加入手持道具 |
| 位置跳变 | 角色在左侧，下一镜头右侧 | 未描述位置移动 | 加入移动动作描述 |
| 情绪跳跃 | 上镜悲伤落泪，下镜大笑 | 分段之间无过渡 | 加入情绪过渡描述 |
| 光线突变 | 黄昏逆光变正午顺光 | 场景描述不完整 | 每段都写光线描述 |

## 五、叙事与故事化技巧

### 5.1 叙事结构（起承转合）

| 阶段 | 时间段 | 镜头功能 | 运镜建议 |
|------|--------|---------|---------|
| 起（开场） | 0-3s | 建立场景、引入主角、定调情绪 | 远景/全景，缓慢拉远或推进 |
| 承（展开） | 3-6s | 展开剧情、引入配角或冲突 | 中景，跟随角色行动 |
| 转（转折） | 6-9s | 情感高潮、剧情逆转、冲突爆发 | 特写/近景，快速推进或剧烈运镜 |
| 合（收束） | 9-12s+ | 情绪回落、留下悬念 | 全景/远景，缓慢拉远 |

### 5.2 情绪曲线设计

```
浪漫情感戏情绪曲线：
  0-3s: ★★☆☆☆ (平静/孤独) → 远景建立孤独感
  3-6s: ★★★☆☆ (期待/紧张) → 中景，角色目光寻找
  6-9s: ★★★★☆ (惊喜/紧张) → 近景，相遇/表白
  9-12s: ★★★★★ (高潮/感动) → 特写，情感爆发
  12-15s: ★★★★☆ (圆满/温馨) → 拉远，相拥收尾

动作打斗情绪曲线：
  0-3s: ★★☆☆☆ (平静/蓄力) → 远景，对峙建立紧张
  3-6s: ★★★★☆ (爆发) → 中景，出招，快速跟拍
  6-9s: ★★★★★ (高潮) → 特写+震动，命中判定
  9-12s: ★★★☆☆ (喘息/余波) → 近景，双方反应
```

### 5.3 镜头叙事技巧

| 技巧 | 适用场景 | Prompt写法 |
|------|---------|-----------|
| 预兆暗示 | 悬疑/惊悚开场 | `远景中模糊的黑色人影一闪而过` |
| 视线揭示 | 角色发现某物 | `角色沿视线方向转头，目光聚焦在目标上` |
| 环境烘托 | 烘托角色情绪 | `暴风雨中角色孤独站立，闪电照亮面部` |
| 对比蒙太奇 | 展示时间流逝或变化 | `从春日盛花过渡到秋风落叶` |
| 细节放大 | 关键道具/情感瞬间 | `极度特写颤抖的手，缓缓握住某物` |

## 六、分镜与运镜选择技巧

### 6.1 场景类型→运镜推荐速查表

| 场景类型 | 首选运镜 | 禁用运镜 |
|---------|---------|---------|
| 对话场景 | 过肩镜头 + 正反打 + 缓慢推进 | 快速甩镜、剧烈晃动 |
| 情感戏 | 缓慢推进/拉远 + 眼泪滑落特写 + 环绕 | 快速推镜、震动、荷兰角 |
| 动作打斗 | 打斗跟随 + 格挡震动 + 剑光划过 | 长镜压抑、凝视长镜头 |
| 悬疑惊悚 | 模糊转清 + 荷兰角 + 旋转晕眩 | 推进亲密、弧形绕摄 |
| 奇幻魔法 | 魔法释放 + 粒子消散 + 变身环绕 | 狙击视角、手灵动 |
| 内心独白 | 长镜压抑 + 模糊转清 + 呼吸同步 | 极速推进、打斗跟随 |
| 追逐逃跑 | 潜行微动 + 穿梭运动 + 渐进加速 | 旋转晕眩、倾斜失衡 |
| 回忆闪回 | 回忆叠化 + 碎片剪辑 + 时间倒流 | 快速推镜、格挡震动 |

### 6.2 景别选择规则

| 景别 | 适用情况 | 不适宜情况 |
|------|---------|-----------|
| 远景/大远景 | 场景建立、孤独感、规模展示 | 对话、表情表达、细节刻画 |
| 全景 | 展示全身形象、角色与环境关系 | 情绪表达、脸部细节 |
| 中景 | 对话、日常叙事、行为展示 | 面部微表情、极远环境 |
| 中近景 | 对话升温、情绪传递 | 全身展示、环境交代 |
| 近景/特写 | 情感高潮、脸部表情、细节刻画 | 环境交代、全身动作 |
| 大特写 | 极度微表情、瞳孔/嘴唇/手部细节 | 任何需要展示全身的场景 |

### 6.3 镜头衔接规则

**落幅→起幅原则：相邻两景之间，前一个镜头的"结束状态"（落幅）要和下一个镜头的"开始状态"（起幅）匹配。**

| 衔接类型 | 示例 | 效果 |
|---------|------|------|
| 环境延续 | S01桃林全景 → S02桃林花瓣特写 | 自然的视觉引导 |
| 视线引导 | S02白浅目光望向某处 → S03夜华出场 | 建立因果联系 |
| 动作连续 | S05夜华走近 → S06双人近景 | 动作不被切断 |
| 景别变化 | S06双人近景 → S07白浅微笑特写 | 节奏变化但不跳跃 |
| 情绪渐进 | S07感动 → S08细节温情 → S09深情 | 情绪递进而非跳跃 |

### 7.4 物理真实感增强

| 物理元素 | Prompt写法 | 效果 |
|----------|-----------|------|
| 重力 | `fabric falling back to ground after jump`, `hair settling after turning` | 运动后的自然回复 |
| 动量惯性 | `body leaning forward during run`, `momentum carrying the swing forward` | 运动中的惯性体现 |
| 衣物物理性 | `sleeves rippling as arm swings`, `skirt flowing with each step` | 布料运动跟动力学 |
| 环境互动 | `petals caught in the turbulence of the swing`, `dust kicked up by footsteps` | 角色与环境的互动 |
| 光影跟随 | `shadows shifting with movement`, `light catching on the blade as it turns` | 运动与光影同步 |

## 八、禁止内容清单

### 8.1 禁用词检查（MANDATORY）

在生成任何Prompt前，必须通过以下正则检验：

```
(?i)(影视|电影|摄像|胶片|摄影|古风写实|写实CG|游戏CG|影视质感|影视级|电影级)
```

国风动漫风格项目禁止出现以上词汇。

### 8.2 禁止行为清单

| 禁止行为 | 原因 | 替代方案 |
|---------|------|---------|
| 使用"她/他/Young woman"等人称代词 | Seedance 2.0无法正确识别代词指向 | 始终使用角色名 |
| 同时描述内心活动和台词 | 冲突，无法同时传达 | 根据场景类型二选一 |
| 多个动作在同一时间段 | 动作冲突，生成质量差 | 每个时间段聚焦1个主动作 |
| 镜头运动与动作运动矛盾 | 视觉混乱 | 确保运镜与动作方向一致 |
| 使用"动态镜头"等模糊描述 | Seedance 2.0无法解析 | 使用具体运镜术语如"低角度跟拍" |
| 描述手部精细动作（超过5个手指） | Seedance 2.0手部生成不稳定 | 避免描述具体手指数或手部精细操作 |
| 描述文字/字幕内容 | 无法生成可读文字 | 用音效/旁白替代 |
| 超过2个主要人物同屏 | 角色一致性急剧下降 | 限制同屏人物≤2人 |
| 风格标签冲突 | 视觉混乱 | 统一使用国风动漫风格 |
| 场景/服装/道具突变 | 一致性断裂 | 每段镜头保持描述一致 |
| 跳过动作阶段（无蓄力/无收回） | 动作不连贯不业 | 每个动作写全三阶段 |
| 对话时人物不看对方 | 违反交流基本规则 | 确保视线在对话中锁定对方 |
| 表情/动作与剧情不符 | 人物行为不合理 | 表情/动作匹配当前情绪 |

### 8.3 生成前8项自检（MANDATORY）

生成任何Prompt前必须检查：

- [ ] 是否使用角色名而非人称代词？
- [ ] 是否每个时间段只描述一个主动作？
- [ ] 运镜描述是否具体（不用模糊词汇）？
- [ ] 光线描述是否具体（不用"好看光"等模糊词）？
- [ ] 风格标签是否≤2个（不超过2个风格词）？
- [ ] 是否避免了"手"的精细动作描写？
- [ ] 是否≤2个主要人物同屏？
- [ ] 是否通过禁用词正则检查？

## 九、建议技巧

### 9.1 叙事建议

1. **开场要"慢"**：前3秒用远景/全景慢速建立场景，让观众有代入感
2. **高潮要"快"**：情感爆发/动作冲突用快速运镜和特写/近景
3. **结尾要"远"**：最后3秒拉远，给观众回味空间
4. **用光线讲故事**：同一场景不同时段用不同光线表达情绪变化
5. **留白很重要**：不是每段都必须有台词/内心，沉默有时最有力

### 9.2 运镜建议

1. **运动不要叠加**：角色移动时运镜保持简单（固定/慢推），角色静止时运镜可以稍复杂
2. **运镜服务于情绪**：恐惧用荷兰角+旋转，浪漫用推进+环绕，不要用错工具
3. **组合运镜要适度**：一段Prompt中运镜描述≤2个，多则混乱
4. **前后运镜对比**：推入表达聚焦，拉远表达释放，形成节奏

### 9.3 一致性建议

1. **使用角色卡**：为每个角色写一份视觉描述，每次引用完整描述或关键特征
2. **场景模板**：同一场景的不同镜头复用环境描述，只变化角色动作
3. **分段检查**：写完后逐段对照，确保相邻段落的要素不突变

### 9.4 Seedance 2.0 特有功能建议

1. **@引用语法**：可传入最多9张图片、3个参考视频、3个参考音频
   - `@Video1` 参考动作/运镜/节奏
   - `@Image1` 参考角色外观/场景外观
   - 动作与运镜可解耦：`reference @Video1 for movement, reference @Video2 for camera`
2. **分段时间戳**：推荐使用 `[0:00-0:03]` 格式精确控制每3秒的画面内容
3. **时长选择**：9秒以上推荐分三段描述，不要一段写完

## 十一、NotebookLM深度技巧（2026-04-05实时查询补充）

> 本节内容来源于NotebookLM知识库实时查询（URL: `https://notebooklm.google.com/notebook/f56bd450-598b-4a97-938c-ae8b9c77ab2e`），为本指南最权威的来源之一。

### 11.1 对话场景的导演级技巧

**过肩镜头（Over-the-Shoulder）—— Seedance 2.0对话场景首选运镜**

在对话场景中，使用"肩部视角/过肩镜头"，即从一个人的身后取景，透过其肩部看向另一个人。这能体现角色间的空间关系和视线交互。

```
Prompt写法：
  镜头：Over-the-shoulder shot, from [说话者A] behind shoulder looking at [说话者B]
```

**移焦（Rack Focus）—— 单镜头内展示注意力转移**

为了在单镜头内展现对话焦点的变化：
```
Prompt写法：
  镜头：Rack focus from [前景人物] thoughtful expression to [背景中的某物体/人物]
  示例："将焦点从前景中人物若有所思的表情，转移到其身后墙上的一张照片"
```

**中景用于对话（Medium Shot，腰部以上）**

对话时通常使用中景，显示腰部以上，在细节和环境之间取得平衡。
```
Prompt写法：
  镜头：Medium shot, both characters visible from waist up, engaged in conversation
```

### 11.2 微动作系统（Micro-movements）

**核心原则：提示词不能只写模糊的形容词（如"悲伤"），必须将其拆解为具体、可执行的细微动作。**

| 情绪 | 错误写法（太模糊） | 正确写法（微动作） |
|------|-------------------|--------------------|
| 沉思 | `thinking deeply` | `neutral expression but with subtle micro-movements suggesting inner contemplation, eye-lights flicker gently twice` |
| 温柔 | `gently touching` | `fingertips barely graze the cheek, pause for a beat, then slowly slide down` |
| 紧张 | `nervous` | `hands fidget with the hem of the sleeve, eyes dart briefly to the side then return` |
| 感动 | `touched` | `lips part slightly, a single tear forms but does not fall, eyes shimmer` |

**Seedance 2.0运动幅度设置：**

- **推荐设置为Medium（中等）**
- 太高：画面容易崩坏变形
- 太低：缺乏动感，画面静止
- 如果生成的动作过于夸张，**优先修改提示词**（如将"轻轻闪烁两次"改为"微微闪烁一次"），而不是盲目重新生成

**景别配合情绪的硬性规则：**

- 情感爆发的戏份**务必**使用**特写（Close-up）或极近特写（ECU）**来聚焦瞳孔、泪水等面部细节
- 大场面则用远景（Wide shot）
- **切忌全程使用中景**，否则情绪会很平淡

### 11.3 动作戏避坑指南

**AI视频模型目前的局限性：**

1. **必须拆解为单一动作**：不要在一段提示词中写入一套连招，必须将角色动作拆解到可执行的单一动作
2. **主攻"微动态"**：动作幅度不要太大。AI生成"微动态"（头发飘动、衣服随风摆动、眨眼、光影变化）最有质感且最不容易崩坏
3. **借助特效掩盖**：在玄幻或武打短剧中，可以利用AI生成的光影特效、魔法渲染来增强视觉张力，从而弥补肢体动作的不足

**动作幅度对比：**
```
❌ 过于复杂（AI难以处理）：
  "夜华连续三刺剑法，第一刺被挡，第二刺破防，第三刺击中对方"

✅ 拆解为单一动作（推荐）：
  0-3s：夜华握剑后撤，重心下沉，准备出击
  3-6s：夜华猛然向前突刺一剑
  6-9s：剑尖击中敌人，剑身剧烈震动
```

### 11.4 一致性保障：图生视频垫图法

**这是Seedance 2.0保持角色一致性的最重要技术。**

1. **首帧参考图垫图**：先用图像模型（如Midjourney通过`--cref`参数或NanoBanana 2）生成极其稳定的人物三视图和场景图
2. **在Seedance中必须上传这张图作为首帧图片**，否则角色一定会发生形变
3. **忽略静态，专写动态**：由于模型已经能"看到"你上传的首帧参考图，视频提示词中**不需要重复描述角色的长相或场景静态布局**。提示词应100%专注于动态变化（动作、运镜、光影流转）
4. **统一光效关键词**：为了防止场景切换时风格割裂，在同一个场景的所有分镜提示词中，**必须加上相同的光效关键词**，如`cinematic lighting`、`volumetric lighting`等

```
一致性保障三步法：

步骤1：生成角色首帧参考图
  Midjourney: --cref [角色图] --v 5 --v2

步骤2：在Seedance中上传首帧图
  → 提示词不再需要写角色外观描述
  → 提示词只写：动作 + 运镜 + 光影流转

步骤3：统一光效关键词（全场景）
  → 每个镜头的Prompt末尾都加上：cinematic lighting, volumetric light
```

### 11.5 "AI魔改"政策红线

**坚决不能踩内容合规红线：**

1. **严禁对以下题材进行颠覆性篡改、"魔性"解构、恶搞或低俗化改编：**
   - 四大名著
   - 经典影视IP
   - 历史题材
   - 革命题材
   - 英模人物

2. **视频内容禁止：**
   - 渲染血腥暴力
   - 猎奇低俗
   - 违背公序良俗

3. **必须在显著位置标注"AI生成"字样**

### 11.6 Negative Prompt正确写法

**不要用带有指令性语法的词汇（如"不要显示墙"、"没有多余的手指"），而应直接输入你不想看到的客观名词。**

```
❌ 错误写法（指令性）：
  --no dont show walls, no extra fingers, remove blurred background

✅ 正确写法（客观名词）：
  --no walls, deformed hands, extra fingers, blurred background, text, watermark
```

### 11.7 关键建议合集

| 建议项目 | 具体操作 | 原因 |
|---------|---------|------|
| **使用英文提示词** | Seedance 2.0及大多数主流视频模型对英文的理解远好于中文 | 生成结果质量更高 |
| **单镜头时长控制在4-5秒** | 极限不超过10-15秒。视频太长极易导致画面变形、动作崩坏、出现幻觉 | AI模型注意力有限 |
| **优先修改提示词而不是重新生成** | 如果生成的动作过于夸张，修改提示词降低幅度描述 | 重新生成浪费token且不保证改善 |
| **动作幅度用Medium** | Seedance 2.0专用设置 | 防止画面崩坏 |
| **提示词≤150词** | 不要堆砌冗长描述 | 模型注意力有限 |
