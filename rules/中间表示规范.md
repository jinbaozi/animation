# 中间表示规范

> 状态：v1.0 | 日期：2026-05-31
> 作用：定义 Story IR、Shot IR、Visual Anchor IR、Prompt Export IR 的字段契约。

---

## 1. 总原则

所有最终 `VideoPrompt包` 必须从 `Prompt Export IR` 导出。`Prompt Export IR` 必须可追溯到 `Visual Anchor IR`、`Shot IR` 和 `Story IR`。

`人物资产卡` 与 `场景资产卡` 是正式交付物，不是中间临时文件。两者由 `Visual Anchor IR` 派生，并在最终交付目录中保留。

---

## 2. Project Manifest

每个项目必须先生成 `00-项目配置/project-manifest.md`。

必填字段：

| 字段 | 说明 |
|---|---|
| project_name | 项目名 |
| source_file | 原始小说或剧情描述路径 |
| total_word_count | 总字数 |
| target_platforms | 抖音、快手、B站、视频号等 |
| target_tools | Seedance2、即梦、豆包等 |
| style_profile | 风格锁定结果 |
| delivery_scope | `VideoPrompt包`、`人物资产卡`、`场景资产卡` |
| target_shots | `ceil(total_word_count / 80)`，可按复杂度调整 |
| target_sequences | 由目标工具时长和镜头数推算 |
| character_count | 来自人物清单，不得硬编码 |
| scene_count | 来自场景清单，不得硬编码 |
| tool_profiles | 各目标工具的时间戳、语言、负面词和参考图规则 |

---

## 3. Story IR

Story IR 是叙事事实源，由 AI内容总导演负责。

必须包含：

| 字段 | 说明 |
|---|---|
| source_coverage | 原文章节/段落覆盖记录 |
| plot_events | 核心事件列表 |
| characters | 人物、关系、目标、变化 |
| scenes | 场景编号、地点、时间、氛围、道具 |
| dialogue_provenance | 台词来源：原文、改写、新增 |
| emotion_beats | 情绪压强、前摇、释放、余震 |
| volume_plan | 目标镜头数、序列数、重点场景权重 |

Story IR 不包含最终 VideoPrompt、工具特定时间戳、四视图 Prompt 或场景资产 Prompt。

---

## 4. Shot IR

Shot IR 是镜头事实源，由 AI镜头序列设计师负责。

必须包含：

| 字段 | 说明 |
|---|---|
| shot_id | 全局唯一镜号 |
| scene_id | 对应 Story IR 场景 |
| scene_type | 8 种场景类型之一 |
| narrative_function | 建立、推进、反应、转折、落幅 |
| subject | 具体角色名或场景主体，禁止代词 |
| action | 可见、可执行动作 |
| gaze | 视线方向、眼神落点 |
| framing | 景别 |
| camera_motion | 运镜 |
| start_frame | 起幅状态 |
| end_frame | 落幅状态 |
| continuity | 服装、光线、位置、道具、运动方向 |

Shot IR 不包含完整人物资产 Prompt、完整场景资产 Prompt 或工具导出格式。

---

## 5. Visual Anchor IR

Visual Anchor IR 是视觉一致性事实源，由 AI美术技术总监负责。

必须包含：

| 字段 | 说明 |
|---|---|
| character_anchors | 人物资产卡、四视图、服装阶段、特殊标记 |
| scene_anchors | 场景资产卡、空间布局、光线、色调、道具 |
| style_anchor | 风格锁定关键词和禁用词 |
| prop_anchors | 关键道具、武器、法器、UI元素 |
| reference_map | 首帧图、AD Reference 或参考图编号 |
| version_map | 资产卡与 Story IR、Shot IR 的版本映射 |

覆盖要求：

- 人物资产卡覆盖率 100%。
- 场景资产卡覆盖率 100%。
- 人物四视图覆盖率 100%。
- 所有数量来自 `project-manifest.md`、人物清单和场景清单，不得写死。

---

## 6. Prompt Export IR

Prompt Export IR 是所有工具导出的唯一来源，由 AI美术技术总监与 Prompt 适配器共同负责。

必须包含：

| 字段 | 说明 |
|---|---|
| shot_id | 对应 Shot IR |
| subject_anchor | 主体锚定 |
| scene_anchor | 场景锚定 |
| action_unit | 单拍动作或微动作 |
| gaze_unit | 视线和眼神 |
| camera_unit | 景别、角度、运镜 |
| lighting_unit | 光源、色温、方向 |
| style_anchor | 风格锚点 |
| continuity | 起幅到落幅、上一镜到下一镜 |
| reference_map | AD Reference 或参考图映射 |
| negative_constraints | 负面约束 |
| tool_profiles | 目标工具导出规则 |

覆盖要求：核心交付模式下 Prompt Export IR 覆盖 Shot IR 100%。精简交付模式必须由用户明确确认，并在 manifest 中记录范围。
