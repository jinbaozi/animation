# 剧本格式规范（元级规则）

> 版本：v1.0.0
> 日期：2026-04-10
> **性质：** 元级规则（优先级高于执行流程，高于模板）

---

## 1. 剧本 vs 分集大纲

| 属性 | 剧本 | 分集大纲 |
|------|------|---------|
| 核心内容 | 角色台词 + 场景描写 | 核心事件 + 情绪曲线 |
| 对话 | 实际台词，可供 AI 视频生成 | 无或碎片化 |
| 场景 | 具体环境描写 | 场景标签 |
| 情绪表达 | 通过台词/动作/表情表现 | 通过情绪标签标注 |
| 用途 | Phase 2b VideoPrompt 的台词来源 | 仅供人类理解剧情结构 |
| 可拍摄性 | 可直接转化为视频提示词 | 需二次创作才能生成视频 |

---

## 2. 强制要求

### 2.1 剧本必须是剧本

| 要求 | 说明 |
|------|------|
| 每集对话 ≥ 10 句 | 每集剧本必须包含至少 10 句实际角色对话 |
| 每场景描写 ≥ 1 句 | 每个场景必须有具体的视觉环境描写 |
| 禁止大纲格式 | 不得以"核心事件列表"代替剧本正文 |
| 禁止标签替代 | 不得以"情绪曲线"代替具体台词 |
| 禁止空场景 | 不得只有场景编号而无任何内容 |

### 2.2 剧本是分镜表的前置依赖

```
Phase 1 产出物流程：

小说文本
    ↓
剧本.md（先行产出，用于验证格式）
    ↓ 台词
基础分镜执行表.md（从剧本提取，不得另行创作）
    ↓
Phase 1.5 / Phase 2b（继承剧本内容）
```

### 2.3 分镜执行表不得替代剧本

| 分镜表的"对话"字段 | 剧本.md 对话字段 |
|--------------------|------------------|
| 来源：剧本.md | 先行产出 |
| 用途：分镜提示词参考 | 用途：VideoPrompt 台词来源 |
| 字数：短句/碎片 | 字数：完整台词，可带动作标注 |

## 3. 剧本格式模板

```markdown
# 剧本

> 项目：{项目名称}
> 版本：v1.0
> 日期：{YYYY-MM-DD}
> 格式：完整剧本（非大纲）

---

## 第一集：{集标题}

### 场景 1.1：{场景名称}

**场景**：{具体环境描写，如"狭窄面包房，黄铜烤炉冒着热气，墙上挂着熏黑的长剑"}}
**时间**：{日/夜/晨/昏}
**人物**：{出场角色名称}

**内容**：

{角色名}：{台词}
{角色名}：{台词}
{动作描写}：{具体表演动作}

---

### 场景 1.2：{场景名称}

**场景**：{具体环境描写}
**时间**：{时间}
**人物**：{出场角色}

**内容**：

{角色名}：{台词}
...
```

## 4. 禁止出现的格式

| 禁止模式 | 示例 | 判定为 |
|---------|------|--------|
| 纯核心事件列表 | `核心事件：1. 觉醒 2. 天赋 3. 弟子` | 大纲，非剧本 |
| 纯情绪曲线 | `情绪曲线：压抑→希望→失落→震惊→兴奋` | 大纲，非剧本 |
| 纯场景标签罗列 | `场景：面包房内景 / 广场 / 弓箭训练区` | 大纲，非剧本 |
| 纯人物标签罗列 | `人物：吴为、老约翰、多尔、沃特` | 清单，非剧本 |
| 占位符 | `{待补充台词}`、`...` | 不合格 |

## 5. 质量门禁

Phase 1 产出剧本.md 时，必须通过以下验证：

### 5.1 格式验证

```
✅ 通过条件：
- 扫描 {角色名}： 出现次数 ≥ 10句/集
- 无 "核心事件"、"情绪曲线"、"场景：XXX -" 模式
- 每个场景有 ≥ 1 句视觉描写

❌ 不合格，返工：
- 出现禁止模式任一
- 对话数量不达标
- 场景描写为空
```

### 5.2 一致性验证

```
✅ 通过条件：
- 剧本台词 → 分镜表"对话"字段：可追溯
- 分镜表"对话"字段 → 剧本台词：有来源
- 场景描写一致：剧本场景 = 分镜表场景描述
```

---

## 6. 违反处理

| 违反场景 | 处理方式 |
|---------|---------|
| 剧本使用大纲格式交付 | 拒绝交付，要求按剧本格式重写 |
| 对话数量不达标 | 补充台词至达标，不允许以"可以用分镜表补救"为由放行 |
| 剧本-分镜表不一致 | 修正剧本，确保剧本为来源，分镜表为派生 |
| 缺少场景描写 | 补充具体视觉描写，不允许以场景标签替代 |
