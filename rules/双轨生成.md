# 双轨生成

> 状态：v3.0 | 日期：2026-04-17
> **核心定位**：中文 = 人类叙事/分镜设计参考；英文 = 提交给 Seedance 2.0 的唯一有效 Prompt
> **v3.0更新**：人物四视图/场景资产卡必须为纯中文，Phase 2b VideoPrompt覆盖率≥80%

---

## 内容校验规则（Q3修复）

### 中文版格式校验

| 检查项 | 要求 |
|--------|------|
| 中文字符数 | 必须超过200个中文字符 |
| 英文术语占比 | 不超过整体内容的30% |
| Seedance Prompt | **必须为英文**，不得混入中文描述 |

### 英文版格式校验

| 检查项 | 要求 |
|--------|------|
| 中文字符数 | 不得超过50个（角色名除外） |
| Seedance Prompt | 纯英文 |

---

## 语言定位

| 版本 | 用途 | 使用者 | 提交给 Seedance |
|------|------|--------|----------------|
| **纯中文版** | 叙事/分镜设计/内容审查参考 | 人类（编排师/导演） | ❌ 不使用 |
| **纯英文版** | Seedance 2.0 实际提交 Prompt | AI 引擎 / Seedance | ✅ 唯一有效 |
| **双语对照版** | 内容一致性校验 | 品控合规官审查 | ❌ 不直接使用 |

> **关键原则**：Seedance 2.0 对英文的理解和转换率远高于中文。
> 中文版仅用于人类阅读和分镜设计验证，实际生成视频必须使用英文 Prompt。

## 语言纯净度规则

| 检查项 | 纯中文版 | 纯英文版 |
|--------|---------|---------|
| 运镜关键词 | 中文 | 英文（如 `dolly push`, `whip pan`） |
| 负面 Prompt | 中文枚举名词 | 英文枚举名词 |
| @引用标注 | 中文 | 英文 |
| 主体描述 | 中文人名 | 中文人名（保留原名）+ 英文描述 |
| 镜头编号/时间戳 | 阿拉伯数字 | 阿拉伯数字（保持一致） |

**禁止混合使用：**
- 纯中文版不能出现 3 个以上连续英文字母（运镜术语缩写除外，如 POV、OTS）
- 纯英文版不能出现 3 个以上连续中文字符（角色名保留中文除外）

## 纯中文规则（v3.0新增）

### 必须使用纯中文的文件类型

| 文件类型 | 要求 | 说明 |
|---------|------|------|
| 人物四视图Prompt包 | ✅ 纯中文 | 全部中文，不含英文提示词 |
| 场景资产卡 | ✅ 纯中文 | 全部中文，不含英文提示词 |
| 人物描述/场景描述 | ✅ 纯中文 | 中文撰写，AI图像识别关键词也用中文 |

### 英文关键词处理方式

> **注意**：如AI图像生成工具仅支持英文关键词，可在描述后以注释形式标注英文关键词参考：
>
> ```
> 中国少年修士，眼神坚定，破旧粗布衣衫（注释：关键词参考：young Chinese cultivator, determined eyes）
> ```

### 禁止的中英混杂模式

| 禁止模式 | 错误示例 | 正确写法 |
|---------|---------|---------|
| 中文句子中夹英文 | `中国风少年，Chinese xianxia style` | `中国风少年，国风仙侠风格` |
| 中英混合关键词 | `ethereal mist, 灵气氤氲` | `灵气氤氲` |
| 英文句子夹中文 | `thin build, 瘦削身形` | `瘦削身形` |

## VideoPrompt覆盖率要求（v3.0新增）

### 覆盖率标准

| Phase | 覆盖率要求 | 说明 |
|-------|-----------|------|
| Phase 2b | ≥80% | 增强分镜镜头数×80% |

### 镜头优先级排序

生成VideoPrompt时，按以下优先级筛选：

| 优先级 | 镜头类型 | 理由 |
|-------|---------|------|
| P0 | 核心叙事镜头 | 推动剧情发展的关键镜头 |
| P0 | 情绪高潮镜头 | 情感爆发/转折点 |
| P1 | 奇幻视觉奇观镜头 | 特效展示，需要详细描述 |
| P1 | 动作戏关键帧 | 战斗高潮 |
| P2 | 过渡镜头 | 可用标准化模板 |
| P3 | 远景空镜 | 场景交代，可用标准化描述 |

### 覆盖率计算公式

```
actual_coverage = len(generated_prompts) / len(enhanced_storyboard_shots)
target_coverage = 0.8

if actual_coverage < target_coverage:
    # 必须补充缺失镜头
    missing = ceil(target_coverage * total_shots) - len(generated_prompts)
```

| 阶段 | 内容 | 说明 |

## 交叉校验规则

中英文内容必须逐条对照，确保以下字段完全对应：

- [ ] 镜头编号（S001, S002...）一致
- [ ] 时间戳（[0:00-0:04], [0:04-0:08]...）一致
- [ ] 角色名称一致
- [ ] 动作/事件描述语义对齐（不要求逐字翻译，但物理动作必须一致）
- [ ] AD Reference 编号映射一致
- [ ] 风格关键词对应（中文"电影感光影" → 英文 "cinematic volumetric lighting"）
- [ ] 音效标注对应
