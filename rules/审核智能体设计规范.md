# AI拟真人短剧提示词质量审核智能体设计方案

> 状态：已设计 | 版本：v1.0 | 日期：2026-04-06

---

## 1. 背景与目标

### 1.1 背景

当前项目（animation-v3）已建立5角色星型拓扑架构，包含AI品控合规官和质量门禁系统（10阶段）。然而，现有品控体系主要聚焦于流程合规性，缺乏对最终产出物的**深度内容质量审核**能力。

用户提供的5大审核维度体系（世界观构建与剧情符合度、结构化文本架构与场景一致性、人物一致性的绝对控制、多角色对戏调度、物理空间关系与表情精准映射、时间轴动作连贯性、影视级运镜调度与光影矩阵）以及8大核心维度审核框架（人物一致性、场景一致性、动作连贯性、剧情符合度、表情与表演质量、对戏互动、运镜摄影、世界观符合度），为建立独立审核智能体提供了完整的理论基础。

### 1.2 目标

设计一个**独立于品控合规官的第三方审核智能体**，在所有Phase执行完成后自动触发，对全流程产物进行LLM驱动的批量审核，输出结构化审核报告。

### 1.3 定位

| 属性 | 说明 |
|------|------|
| **角色类型** | Claude Code专用子智能体（项目级别，不做全局配置） |
| **触发时机** | 全任务完成后自动触发 |
| **执行方式** | LLM辅助批量审核，无需人工干预 |
| **审核范围** | 全流程产物（剧本/分镜/四视图/VideoPrompt包） |
| **输出形式** | 结构化审核报告 |
| **报告位置** | `review/` 目录 |

## 2. 架构设计

### 2.1 整体架构

采用**编排器 + 维度模块**的分层架构：

```
agents/audit-agent.md (主编排器)
  ├── agents/audit/dimensions/
  │   ├── 01-character-consistency.md      # 人物一致性审核
  │   ├── 02-scene-consistency.md          # 场景一致性审核
  │   ├── 03-action-coherence.md           # 动作连贯性审核
  │   ├── 04-narrative-logic.md           # 剧情符合度审核
  │   ├── 05-cinematography.md            # 运镜与画面审核
  │   └── 06-world-building.md            # 世界观合规审核
  └── agents/audit/templates/
      └── audit-report.md                  # 报告模板
```

### 2.2 各维度审核内容

#### 维度1：人物一致性审核

**审核对象**：人物清单、人物四视图Prompt包

**审核要点**：
- 固定锚定完整性：人物全称+核心特征+锁定参数+兜底描述
- 特征无冲突：外貌、穿搭、配饰与定版卡100%匹配
- 人设行为匹配：动作、表情、台词风格符合人物人设
- 多人对戏区分度：同框人物有明确站位、特征区分

**关键锚点**：
- 人物唯一ID
- 固定外貌参数（脸型/五官/发型发色/标志性特征/身高体型）
- 固定穿搭/配饰
- 参考图/角色锁定参数（--cref、Character Consistency功能ID）

#### 维度2：场景一致性审核

**审核对象**：场景清单、场景资产卡、VideoPrompt包中的场景描述

**审核要点**：
- 场景锚定完整性：场景全称+核心固定特征+兜底描述
- 世界观绝对合规：无违背世界观底层规则的元素
- 空间与光影连贯：时间/天气/光影方向/道具摆放连续
- 细节无矛盾：关键道具在前后镜头中一致

#### 维度3：动作连贯性审核

**审核对象**：增强分镜执行表、VideoPrompt包

**审核要点**：
- 动作承接性：单镜头动作起点与上一镜头终点完全承接
- 物理与人体合理性：动作符合物理规则与人体工学
- 对戏互动逻辑：双方视线/站位/动作互动关系明确
- 表情与情绪强绑定：微表情/面部肌肉状态/眼神细节精准

#### 维度4：剧情符合度审核

**审核对象**：剧本、基础分镜执行表、增强分镜执行表

**审核要点**：
- 核心剧情点匹配：100%完成分镜大纲中的核心剧情任务
- 剧情逻辑无矛盾：无违背前后剧情的设定
- 节奏与叙事匹配：镜头时长/动作密度/景别运镜匹配叙事节奏
- 伏笔回收匹配：伏笔/回收镜头中关键元素明确

#### 维度5：运镜与画面审核

**审核对象**：增强分镜执行表、VideoPrompt包

**审核要点**：
- 运镜与景别明确：景别+核心运镜方式，一个镜头仅一个核心运镜
- 运镜符合叙事逻辑：运镜服务于剧情
- 画质与光影统一：画质参数/光影风格与全片基调匹配
- 镜头语言合规：无越轴、无空间逻辑混乱

#### 维度6：世界观合规审核

**审核对象**：全量产物

**审核要点**：
- 时代背景合规：古代/现代/未来等设定一致
- 文化细节合规：服饰/手势/习俗符合设定
- 物理规则合规：魔法/科幻元素符合设定手册
- 风格统一性：光影/色彩/画质/运镜风格统一

## 3. 审核流程

### 3.1 执行流程

```
1. 触发条件
   └─ 所有Phase执行完成（检测到 output/{项目名}/ 存在）

2. 产物收集
   ├─ 剧本.md
   ├─ 基础分镜执行表.md
   ├─ 增强分镜执行表.md
   ├─ 序列衔接与继承表.md
   ├─ 人物清单.md
   ├─ 人物四视图Prompt包.md
   ├─ 场景清单.md
   ├─ 场景资产卡.md
   └─ VideoPrompt包.md

3. 并行维度审核
   ├─ 维度1：人物一致性
   ├─ 维度2：场景一致性
   ├─ 维度3：动作连贯性
   ├─ 维度4：剧情符合度
   ├─ 维度5：运镜与画面
   └─ 维度6：世界观合规

4. 报告汇总
   ├─ 评分汇总（6维度评分）
   ├─ 问题清单（P0/P1/P2分级）
   └─ 修改建议

5. 报告输出
   └─ review/{项目名}-audit-{日期}.md
```

### 3.2 评分体系

每个维度采用10分制：

| 评分 | 等级 | 说明 |
|------|------|------|
| 9-10 | 优秀 | 完全符合审核标准，可直接使用 |
| 7-8 | 良好 | 轻微偏差，微调后可用 |
| 5-6 | 合格 | 存在显著问题，需要修复 |
| 3-4 | 不合格 | 存在严重问题，需要重新生成 |
| 0-2 | 阻断性 | 问题导致无法使用，必须重新生成 |

### 3.3 问题分级

| 等级 | 含义 | 处理方式 |
|------|------|----------|
| P0 | 阻断性 | 阻止进入下一阶段，必须修复 |
| P1 | 显著瑕疵 | 应在下一阶段前修复 |
| P2 | 优化项 | 建议修复，可选执行 |

## 6. 与现有体系的关系

### 6.1 与AI品控合规官的区别

| 维度 | AI品控合规官 | 独立审核智能体 |
|------|--------------|----------------|
| **定位** | 流程合规+质量门禁 | 深度内容质量复审 |
| **触发** | Phase 0（前置） | 所有Phase完成后（后置） |
| **重点** | 合规性/流程合规 | 人物/场景/动作/剧情/运镜/世界观 |
| **执行** | 人工确认+部分AI辅助 | LLM自动批量审核 |
| **输出** | 合规预审报告 | 6维度结构化审核报告 |

### 6.2 协同关系

```
Phase 0 → Phase 1 → Phase 1.5 → Phase 2a → Phase 2b
    │                                      │
    └───────── AI品控合规官 ────────────────┘
                                              │
                          ┌───────────────────┘
                          ▼
                    独立审核智能体（自动触发）
                          │
                          ▼
                    review/审核报告
```
