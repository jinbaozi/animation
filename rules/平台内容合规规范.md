# 平台内容合规规范

> 状态：v1.1 | 日期：2026-04-09
> **强制执行**：强制加载于所有阶段，Phase 0 品控合规官必须执行
> **支持平台**：抖音、豆包（火山引擎）等国内AI内容平台

---

## 一、总则

本规范整合了抖音平台和豆包平台的内容合规要求，强制加载于所有阶段。AI品控合规官在Phase 0执行时必须进行全面检查。

---

## 二、禁止内容分类

### 2.1 政治安全类（CRITICAL - 立即阻断）

| 禁止项 | 说明 |
|--------|------|
| 反对宪法基本原则 | 反对四项基本原则 |
| 危害国家安全 | 泄露国家秘密、颠覆国家政权、破坏国家统一 |
| 损害国家荣誉 | 损害国家形象、荣誉和利益 |
| 歪曲英烈 | 歪曲、丑化、亵渎、否定英雄烈士及其事迹和精神 |
| 煽动叛乱 | 煽动非法集会、结社、游行、示威、聚众扰乱社会秩序 |
| 领土主权 | 不完整中国地图、敏感地区相关内容 |

**处置方案**：立即阻断，不得进入下一阶段

---

### 2.2 暴力恐怖类（CRITICAL - 立即阻断）

| 禁止项 | 说明 |

| 血腥暴力 | 传播血腥暴力惊悚的游戏、图片等引人不适的内容 |
| 暴力犯罪 | 歪曲/丑化/亵渎/否定英雄烈士 |
| 极端主义 | 借助国家重大活动、英烈等进行商业营销宣传 |

**注**：仙侠/玄幻的法术打斗属于艺术加工，**允许**

### 2.7 知识产权类（HIGH - 建议修改）

| 禁止项 | 说明 |
|--------|------|
| 侵权内容 | 侵犯他人的姓名权、肖像权、声音权、名誉权、隐私权、个人信息权益 |
| 知识产权侵权 | 侵犯著作权、专利权、商标权、商业秘密，诱导生成和传播知识产权侵权内容 |

### 2.14 AI生成内容专项规范（HIGH - 标注提醒）

| 规范项 | 说明 |
|--------|------|

## 三、合规检查流程

Phase 0（品控合规官）强制执行本规则：

1. **内容预审**：审查原始小说/剧本内容
2. **角色设计审查**：审查角色四视图描述
3. **镜头序列审查**：审查场景序列内容
4. **Prompt审查**：审查生成的VideoPrompt内容
5. **AI内容标注检查**：检查AI生成内容是否有适当的标注说明

---

## 四、违规处置方案

| 严重级别 | 处置方案 |
|---------|---------|
| CRITICAL | 立即阻断，停止执行，进入修复流程 |
| HIGH | 建议修改，由编排师决定是否修改后继续 |
| MEDIUM | 标注提醒，可选择性修改 |
