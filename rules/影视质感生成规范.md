## 1. 摄影机型号提示词

### 1.1 ARRI Alexa 系列

ARRI Alexa 是好莱坞最主流的数字摄影机，以其柔和、高动态范围和肤色还原著称。

| 型号 | 特点 | 提示词示例 |
|------|------|-----------|
| **ARRI Alexa Mini** | 紧凑设计，影视标准 | `ARRI Alexa Mini, LogC3, ARRI Look Library` |
| **ARRI Alexa 35** | 最新代，REVEAL色彩科学 | `ARRI Alexa 35, REVEAL Color Science, LogC4` |
| **ARRI Alexa 65** | 65mm大画幅，电影质感 | `ARRI Alexa 65, large format, cinematic depth` |
| **ARRI Alexa LF** | Large Format全画幅 | `ARRI Alexa LF, Large Format, subtle grain` |

**ARRI 色彩科学关键词：**
- `ARRI Wide Gamut` — ARRI广色域色彩空间
- `LogC3` / `LogC4` — ARRI对数色彩曲线
- `REVEAL Color Science` — ARRI最新色彩科学
- `ARRI Texture` — ARRI纹理特性
- `мягкие тона кожи` (俄语:柔和肤色) — 强调肤色还原

**提示词组合示例：**
```
ARRI Alexa, anamorphic lens, emotional scene at night, rain, soft light
ARRI Alexa 35, 16:9 aspect, soft skin tones, wide dynamic range, cinematic color science
```

## 4. 变形宽银幕镜头

### 4.1 变形镜头特点

变形镜头 (Anamorphic Lens) 产生独特的：
- **水平光晕/条纹 (Horizontal Flares)** — 高光处的蓝色/白色水平条纹
- **椭圆形散景 (Oval Bokeh)**
- **2.39:1 宽银幕比例**

### 4.2 变形镜头提示词

| 类型 | 提示词 |
|------|--------|
| **2x变形** | `2x anamorphic lens, horizontal flares, 2.39:1 aspect ratio` |
| **1.5x变形** | `1.5x anamorphic, squeeze effect, cinemascope` |
| **蓝色光晕** | `blue anamorphic flares, horizontal light streaks` |
| **变形散景** | `anamorphic bokeh, oval out-of-focus highlights` |

### 4.3 具体变形镜头型号

| 镜头 | 提示词 |
|------|--------|
| **Cooke Anamorphic** | `Cooke Anamorphic /i, Special Flair coating, blue flares` |
| **Panavision Anamorphic** | `Panavision anamorphic, classic Hollywood look` |
| **Sigma Cine Altair** | `Sigma Cine Altair anamorphic, modern anamorphic` |
| **Atlas 2x** | `Atlas 2x anamorphic, horizontal flares, budget anamorphic` |

### 4.4 变形镜头拍摄技巧

**正确方式 — 光源优先：**
```
错误: "add blue streaks" (效果优先)
正确: "bright pinpoint practical light, thin atmospheric haze, anamorphic lens"
```

**结构化提示词模板：**

| 字段 | 描述 | 示例 |
|------|------|------|
| Light Source | 光源成因 | "Point-source LED", "High-intensity streetlamp" |
| Atmosphere | 散射介质 | "Thin volumetric haze", "Subtle dust motes" |
| Lens/Glass | 光学特征 | "Coated anamorphic glass", "Horizontal streak" |
| Composition | 构图 | "Low-angle tracking shot", "Dutch angle" |
| Aspect Ratio | 比例 | "2.39:1 cinema scope" |

## 6. AI平台提示词技巧

### 6.1 Sora / Runway Gen-3 / Kling (可灵) / Veo 3

| 技巧 | 描述 |
|------|------|
| 运镜优先 | 在提示词开头指定 camera movement |
| 动作拆解 | 将动作拆解为单一微动态 (Micro-Dynamics) |
| 光影变化 | 描述光线随时间的变化 |
| 避免重复 | 不在视频提示词中重复首帧已有的静态信息 |

### 6.2 Camera Movement 关键词库

| 分类 | 关键词 |
|------|--------|
| 稳定移动 | `Steadicam`, `tracking shot`, `push-in`, `pull out` |
| 手持感 | `handheld`, `dynamic movement`, `micro-jitters` |
| 戏剧化 | `Dutch angle`, `whip pan`, `dolly zoom` |
| 空间感 | `arc shot`, `crane shot`, `aerial`, `drone shot` |
| 对焦 | `rack focus`, `shift focus` |

### 6.3 AI视频模型特性

| 模型 | 擅长 | 弱点 |
|------|------|------|
| **Sora 2 Pro** | 逼真场景、复杂叙事 | 手和脸可能不一致 |
| **Kling 2.5** | 快速迭代、运动质量 | 色彩调色较不电影化 |
| **Veo 3** | 电影质量、相机运动 | 生成时间较长 |

## 8. 影视质感组合公式

### 8.1 FRAME 公式

**F.R.A.M.E = Focus & Shot + Resolution + Additional + Mood + Effect**

| 字母 | 含义 | 示例 |
|------|------|------|
| **F** | Focus & Shot | `portrait, close-up, wide shot` |
| **R** | Resolution | `8K, high resolution, detailed` |
| **A** | Additional | `film grain, vintage lens` |
| **M** | Mood | `melancholic, dramatic, joyful` |
| **E** | Effect | `bokeh, lens flare, anamorphic` |

### 8.2 影视质感组合示例

**公式：**
```
[摄影机] + [镜头] + [灯光] + [胶片风格] + [调色]
```

**示例1：电影级人像**
```
ARRI Alexa 65 + Zeiss Master Prime 85mm + Rembrandt lighting +
shot on Kodak Portra 400 + teal and orange color grading
```

**示例2：复古科幻**
```
RED Komodo + Anamorphic lens + volumetric fog +
shot on Cinestill 800T + bleach bypass grading
```

**示例3：自然纪录片**
```
Sony Venice 2 + Cooke S4/i + natural window light +
shot on Kodak Vision3 5219 + documentary color science
```

### 8.3 影视质感与Seedance 2.0公式的融合

**扩展版统一公式：**
```
[运镜/景别] + [摄影机/镜头] + [主体] + [动作/微动作] + [视线/眼神] + [环境] + [灯光] + [胶片/调色] + [风格关键词]
```

**示例：**
```
Over-the-shoulder shot, ARRI Alexa 35 with Zeiss Supreme Prime 50mm.
沈清婉 in pale blue silk robes, fingers trembling slightly on the teacup rim.
Eyes locked on 萧景瑜's face, gaze steady. A crooked wooden table with
a cracked porcelain bowl, rain dripping through the window. Moonlight
streaming from upper left, Rembrandt lighting. Shot on Kodak Portra 400,
warm skin tones. Teal and orange color grade, cinematic, 8K, photorealistic.
```
