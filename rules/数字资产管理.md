## 2. 版本保留规则

### 2.1 版本数量要求

| 阶段 | 保留版本数 | 说明 |
|:---|:---|:---|
| 制作中 | 至少3个 | 当前版本 + 2个历史版本 |
| 交付后 | 至少5个 | 最终版本 + 4个历史版本 |

### 2.2 命名后缀规则

| 类型 | 格式 | 说明 |
|:---|:---|:---|
| 正式版本 | `v1`, `v2`, `v3`... | 通过质量验收的版本 |
| 草稿版本 | `v1_draft`, `v2_draft`... | 未通过的中间版本 |

### 2.3 覆盖保护

- 最终交付版本命名后**禁止覆盖**
- 返工修改前必须先备份当前版本
- 删除旧版本前需确认有更新的版本存在

## 3. 版本回滚机制

### 3.1 回滚触发条件

| 情况 | 处理方式 |
|:---|:---|
| 当前版本发现严重问题 | 回滚到上一个稳定版本 |
| 需要对比版本差异 | 保留最近3个版本供对比 |
| 超过版本保留上限 | 删除最旧的非关键版本 |

### 3.2 回滚操作流程

```
1. 发现问题
       │
       ▼
2. 确认当前版本编号（如 v3）
       │
       ▼
3. 回滚到上一版本（如 v2）
       │
       ▼
4. 记录回滚原因
       │
       ▼
5. 继续制作
```

## 4. 色彩一致性追踪

### 4.1 色彩参数记录要求

每个 Phase 2a 输出时，必须记录以下色彩参数：

```markdown
## 色彩参数记录

### 角色色彩参数

| 角色名称 | 主色调 | 色温(K) | 氛围 | 参考色板 |
|:---|:---|:---|:---|:---|
| 夜华 | 冷蓝+银白 | 6500K | 仙冷 | #E8F0FF |
| 白浅 | 暖白+淡粉 | 5500K | 柔暖 | #FFF5F0 |

### 场景色彩参数

| 场景名称 | 主色调 | 色温(K) | 氛围 | 参考色板 |
|:---|:---|:---|:---|:---|
| 天宫大殿 | 金红+深蓝 | 4500K | 庄重神秘 | #FFD700 + #1A237E |
| 桃花林 | 粉白+嫩绿 | 5200K | 柔美温馨 | #FFB7C5 + #90EE90 |
```

### 4.2 色彩一致性检查

后续 Phase 输出时，必须核对色彩参数：

- [ ] 人物四视图与色彩参数记录一致
- [ ] 场景资产卡与色彩参数记录一致
- [ ] VideoPrompt中的光影描述符合色彩参数
