# 视频格式

> 状态：v1.0 | 日期：2026-04-04
> **强制执行**：所有VideoPrompt必须遵循此格式（Seedance 2.0 / 即梦）

---

## 结构公式

**Structure Formula:** `[主体] + [场景] + [时序分段] + [风格] + [音效]`

---

## 时间分段格式

**Time Segments:** 0-3s | 3-6s | 6-9s | 9-12s | 12-15s (for 12-15s videos)

---

## 三元素规则

**Each time segment MUST contain 3 core elements (动作/内心活动/台词 三选一与剧情契合 + 镜头):**

```
0-3s:
  动作：{具体动作描述}
  台词：{角色说的话（引号内），无声台词用旁白或无声描述}  # 与剧情契合时保留
  镜头：{景别+运镜方式}
```

**规则：内心活动与台词二选一保留，与剧情契合为准**
- 动作戏/打斗戏 → 保留台词（更有张力）
- 情感戏/内心戏 → 保留内心活动（更深刻）
- 只需保留一项，无需两者兼备

---

## 完整格式示例

```
[主体]
古风国漫少女沈清婉，16岁丞相府嫡女

[场景]
丞相府闺房内景，雕花架子床，青碧色帐幔

[时序分段]

0-3s:
  动作：少女猛然睁眼，水下气泡模糊镜头，身体挣扎
  内心活动：窒息感、恐惧、拼命想浮上去
  台词：（无声，水下）
  镜头：面部特写，快速推进

3-6s:
  动作：视线逐渐清晰，一张哭泣的脸从虚到实焦点转换
  内心活动：困惑，这是哪里？谁在哭？
  台词：（模糊）"小姐...小姐您醒了..."
  镜头：低机位仰拍焦点从虚到实

[风格]
古风国漫，8K质感，电影感光影，紧张悬疑氛围

[音效]
0-3s: 水下气泡声，呼吸急促
3-6s: 哭泣声渐强，弦乐渐入
```

---

## 禁止事项

- ❌ 同时保留内心活动和台词（除非两者都有独特价值）
- ❌ 只有动作没有台词或内心活动（缺少角色表达）
- ❌ Generic pronouns instead of character names

---

## 关键约束

1. **时代一致性**：所有Prompt必须匹配小说历史时代（服装、建筑、道具）
2. **简体中文**：所有Prompt使用简体中文
3. **时间标签**：使用 [0:00-0:03], [0:03-0:06] 等格式（Seedance 2.0 要求）
4. **角色名强制**：禁止使用人称代词（她/他/Young woman），必须使用具体名字
5. **统一编号**：所有镜头使用 S001, S002 等格式

---

## 时间戳格式要求

**统一使用 `[0:00-0:03]` 格式（Seedance 2.0 要求）**

| 正确格式 | 错误格式 | 说明 |
|---------|---------|------|
| `[0:00-0:03]` | `[0-3s]` | 必须使用冒号和连字符 |
| `[0:03-0:06]` | `[3s-6s]` | 禁止使用秒数后缀 |
| `[0:06-0:09]` | `[6-9s]` | 禁止省略前导零 |
| `[0:09-0:12]` | `[9-12秒]` | 禁止使用中文单位 |

## 抖音平台技术规格

### 视频参数

| 参数 | 抖音要求 | 推荐值 |
|------|---------|--------|
| 分辨率 | 9:16竖屏 | 1080x1920 / 720x1280 |
| 帧率 | 25-30fps | 30fps |
| 码率 | 5-15 Mbps | 10Mbps |
| 编码 | H.264 / H.265 | H.264 |
| 时长 | 15s-3分钟 | 根据场景选择 |
| 文件格式 | MP4 | MP4 |

### 封面图参数

- 分辨率：9:16 (1080x1920)
- 格式：PNG / JPG
- 文件大小：< 5MB

### 音频参数

- 采样率：48kHz
- 声道：立体声
- 格式：AAC

### AI标识要求

- 片头：显示"AI生成"水印（3秒）
- 片尾：字幕标注"本视频由AI辅助生成"
- 元数据：包含 `[AI_GENERATED]` 字段
