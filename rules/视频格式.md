# 视频格式

> 状态：v2.0 | 日期：2026-04-05
> **强制执行**：所有工具导出版本必须从 `PromptExportIR.md` 派生；Seedance 2.0 / 即梦格式差异由 Tool Export 处理

---

## 核心结构公式

**统一公式**（所有 Prompt 必须按此顺序）：

```
[运镜/景别] + [主体] + [动作/微动作] + [视线/眼神] + [环境] + [灯光] + [风格关键词]
```

详见 `rules/运镜知识.md` 中的完整公式详解。

**结构公式**（VideoPrompt 文档组织）：

```
[主体锚定] + [场景锚定] + [首帧参考/AD映射] + [时序分段] + [风格] + [音效]
```

以上字段必须先写入 `PromptExportIR.md`，不得从剧本或分镜直接跳过 IR 生成最终工具 Prompt。

## 关键变更说明（v2.0）

| 变更项 | v1.0 | v2.0 | 原因 |
|--------|------|------|------|
| 主体描述 | "古风国漫少女沈清婉，16岁" | 具体服饰+体态+微动作 | Seedance 2.0 需要可执行物理细节 |
| 动作描述 | "窒息感、恐惧、拼命想浮上去" | 肌肉/骨骼/生理三层面拆解 | 抽象情绪词无效 |
| 环境描述 | "丞相府闺房内景，雕花架子床" | 病态级细节（光线/物品/天气/动态） | 防止 AI 自由发挥导致不一致 |
| 镜头时长 | 3s 分段 | ≥4s 分段 | Seedance 2.0 最小有效生成 4s |

| 镜头 | "面部特写，快速推进" | "extreme close-up, slow push-in to face" | 运镜词必须英文 |

## 首帧参考与 AD Reference（MANDATORY）

### 首帧参考规则

每个 VideoPrompt 序列**必须**上传一张稳定的参考图：
- **角色主导镜头** → 上传该角色的设定图（正面/最能表现特征的姿势）
- **环境主导镜头** → 上传该场景的静态环境设定图
- **多人多场景** → 上传所有相关角色 + 环境参考图

### AD Reference 语法

```
AD image 1 = 沈清婉 character reference
AD image 2 = 萧景瑜 character reference
AD image 3 = 丞相府闺房 environment reference

A young woman in pale blue silk robes (AD image 1) sits across from a man
in dark robes (AD image 2) at a carved wooden table. Moonlight streams
through the lattice window of the 丞相府 bedroom (AD image 3).
```

**格式规则：**
- 每张参考图必须编号（`AD image N`）
- Prompt 中提到对应主体时必须引用编号
- 参考图与正文之间的对应关系不能模糊

## 时间分段格式

**Time Segments:** ≥4s 为一个逻辑分段（如 0:00-0:04, 0:04-0:08, 0:08-0:12, 0:12-0:16 for 16s sequences）

> **重要说明**：Seedance 2.0 单镜头建议 4-5 秒，超过 5 秒会指数级增加变形风险。
> 下面的时间分段是**逻辑引导**，用于组织多镜头序列的叙事节奏，不是要求 Seedance 2.0 在单条视频中精确执行每个分段。
> 实际使用时，每个分段生成一条独立的 Seedance 2.0 视频。

---

## 四元素规则

**每个时序分段 MUST 包含以下 4 个元素：**

```
[0:00-0:04]:
  主体：{角色具体名+服饰/体态细节}
  动作：{具体可执行物理动作，肌肉/骨骼/生理三层面}
  视线：{眼睛看着谁/什么方向}
  镜头：{景别英文+运镜方式英文}
```

**内心活动与台词规则：**
- 动作戏/打斗戏 → 保留台词（更有张力）
- 情感戏/内心戏 → 保留内心活动（更深刻）
- 只需保留一项，无需两者兼备
- **台词和内心活动不作为 Seedance 2.0 的 Prompt 输入**，仅用于后期配音和分镜设计参考

## 完整格式示例（v2.0 标准版）

```
================================================================
[镜头编号] S001
================================================================

[主体锚定]
沈清婉, 16-year-old 丞相府嫡女, pale blue silk robes with silver cloud
pattern embroidery, jade hairpin through her dark hair, slender pale frame,
oval face with almond-shaped eyes

[场景锚定]
丞相府闺房内，月光从雕花窗棂斜射入室，照亮空气中漂浮的尘埃微粒,
青碧色帐幔有一角被风吹起微微飘动，雕花架子床上散落着一支木簪和半卷诗经,
地面是打磨过的青石板，墙角有半盆未熄灭的炭火

[首帧参考]
AD image 1 = 沈清婉 character reference (front-facing character sheet)
AD image 2 = 丞相府闺房 environment reference (static room layout)

[时序分段]

[0:00-0:04]:
  主体：沈清婉 (AD image 1) lying on the carved wooden bed
  动作：eyes wide open suddenly, pupils dilating, rapid shallow chest breathing,
        arms flailing upward, fingers splayed, silk sheets tangling around wrists
  视线：eyes staring upward at the canopy, unfocused, panicked
  镜头：Extreme close-up, static locked-off camera, slight handheld micro-jitter

[0:04-0:08]:
  主体：沈清婉 (AD image 1) sitting up in bed, robes disheveled
  动作：hands gripping the bed edge tightly, knuckles white, chest heaving,
        hair falling loose over shoulders, head turning sharply toward the window
  视线：eyes darting from the canopy to the window, then back, searching
  镜头：Medium close-up, slow push-in toward her face, rack focus from
        foreground sheets to her expression

[0:08-0:12]:
  主体：沈清婉 (AD image 1) standing at the window
  动作：one hand pressed against the window frame, the other hand clutching
        her chest, shoulders rising and falling with each breath
  视线：eyes gazing out the window at the moonlit garden, expression softening
        from panic to melancholic wonder
  镜头：Over-the-shoulder shot from behind, shallow depth of field, moonlight
        rim-lighting her silhouette

[风格]
Chinese animation style, 8K resolution, cinematic volumetric lighting,
pale blue and silver color palette, moonlit atmosphere, ethereal,
shallow depth of field, fine detail rendering, soft bloom highlights

[音效]
0:00-0:04: 急促呼吸声，丝绸摩擦声
0:04-0:08: 心跳声渐强，床架吱呀声，远处隐约更鼓
0:08-0:12: 呼吸声渐缓，窗外蟋蟀声，微风拂动帐幔声
```

================================================================
[Shot ID] S001 — Segment [0:04-0:08]

Medium close-up. 沈清婉 (AD image 1), pale blue silk robes disheveled, sitting

## 禁止事项

- ❌ 同时保留内心活动和台词（除非两者都有独特价值）
- ❌ 只有动作没有视线/眼神描述（缺少角色空间定位）
- ❌ 通用代词代替角色名（she/he/young woman/the girl）
- ❌ 抽象情绪词作为动作描述（"恐惧"、"窒息感"、"愤怒"）
- ❌ 单个 Prompt 里写组合动作（"出拳后回旋踢再刺"）
- ❌ 不上传首帧参考图
- ❌ 使用否定动词写负提示（"no"、"do not"）
- ❌ 中文 Prompt 提交给 Seedance 2.0（仅限设计参考用）

---

## 关键约束

1. **时代一致性**：所有 Prompt 必须匹配小说历史时代（服装、建筑、道具）
2. **角色名强制**：禁止使用人称代词（她/他/Young woman），必须使用具体名字
3. **统一编号**：所有镜头使用 S001, S002 等格式
4. **动作四阶段**：每个动作描述必须包含起幅→运动→落幅→回收
5. **时长约束**：每个分段 ≥4 秒（Seedance 2.0 最小有效生成时长）
6. **视线强制**：每个分段必须有眼睛/视线状态描述
7. **环境细节**：场景锚定必须包含至少 3 项病态级细节（见运镜知识.md）
8. **AD Reference**：上传多张参考图时必须使用 AD 语法映射

## 时间戳格式要求

**使用 `[0:00-0:04]` 格式作为逻辑引导标识**

| 正确格式 | 错误格式 | 说明 |
|---------|---------|------|
| `[0:00-0:04]` | `[0-4s]` | 使用冒号和连字符 |
| `[0:04-0:08]` | `[4s-8s]` | 禁止使用秒数后缀 |
| `[0:08-0:12]` | `[8-12s]` | 禁止省略前导零 |

> **注意**：时间戳是叙事逻辑引导，不要求 Seedance 2.0 毫秒级精确执行。
> 每个分段对应一个独立的 Seedance 2.0 视频生成。

## 抖音平台技术规格

### 视频参数

| 参数 | 抖音要求 | 推荐值 |
|------|---------|--------|
| 分辨率 | 9:16竖屏 | 1080x1920 / 720x1280 |
| 帧率 | 25-30fps | 30fps |
| 码率 | 5-15 Mbps | 10Mbps |
| 编码 | H.264 / H.265 | H.264 |
| 时长 | 15s-3分钟 | 根据场景选择 |
| 文件格式 | MP4 | MP4 |

### 封面图参数

- 分辨率：9:16 (1080x1920)
- 格式：PNG / JPG
- 文件大小：< 5MB

### 音频参数

- 采样率：48kHz
- 声道：立体声
- 格式：AAC

### AI标识要求

- 片头：显示"AI生成"水印（3秒）
- 片尾：字幕标注"本视频由AI辅助生成"
- 元数据：包含 `[AI_GENERATED]` 字段

### 平台规范版本跟踪

- 最后更新：2026-04-05
- 建议每季度审查更新
