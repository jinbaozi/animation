## Phase 3：成片合成（AI视频质量审核体系）

### AI视频质量审核标准

#### 人物一致性审核

| 检查项 | 标准 | 评分 |
|--------|------|------|
| 面部特征描述 | 至少5项具体描述（脸型、眼型、鼻型、唇形、肤色） | >0.85 Pass |
| 体型特征描述 | 身高、体型、独特标记完整 | >0.85 Pass |
| 服装描述 | 颜色、材质、关键配饰一致 | >0.85 Pass |
| 参考图生成 | 4-view定妆照已完成 | 必须 |

**评分标准：** >0.85为Pass，0.7-0.85为Conditional需修复，<0.7为Fail需重新生成

#### 场景一致性审核

| 维度 | 必须锁定项 | 允许变动项 |
|------|-----------|-----------|
| 空间 | 室内/室外、场景类型 | 具体摆设 |
| 光线 | 主色调（暖/冷/自然）、时间段 | 天气细节 |
| 色调 | 整体色系 | 局部色彩 |
| 时间 | 白天/夜晚/黎明/黄昏 | 具体时间点 |
| 天气 | 晴/阴/雨/雪 | 湿度细节 |

**评分等级：**
- A级（90-100）：完全一致，无可察觉差异 → 直接使用
- B级（75-89）：细微差异，专业人士可察觉 → 微调后使用
- C级（60-74）：明显差异，需要修复 → 重新生成
- D级（<60）：完全不一致 → 废弃不用

#### 动作连贯性检查

| 检查项 | 问题描述 | 修复方法 |
|--------|---------|---------|
| 关节角度 | 手脚弯折超过生理极限 | 调整动作描述词 |
| 碰撞反馈 | 打击无物理响应 | 加入反应描述词 |
| 重量感 | 物体漂浮/穿透 | 加入物理约束词 |
| 连续动作 | 招式之间无过渡 | 加入动作连接词 |
| 武器交互 | 武器穿过身体 | 明确接触点描述 |

**连贯性评分公式：**
```
连贯性 = 物理合理性(30%) + 动作连续性(25%) + 视线轴线(20%) + 时序合理性(15%) + 空间位置(10%)
```

### 门禁检查项

- [ ] 人物一致性评分 >0.85
- [ ] 场景一致性评分 ≥B级
- [ ] 动作连贯性评分 ≥75分
- [ ] 剪辑一致性验证通过
- [ ] 音频视频同步检查通过

### 责任角色

## 附录A：量化验收标准（v1.0 新增）

> 基于 Obsidian 知识库"纯视觉叙事影片全流程管理方案 V3.5"对比审核新增

### A.1 核心量化指标

| 指标 | 定义 | 达标标准 | 测量方法 | 责任角色 |
|:---|:---|:---|:---|:---|
| 分镜完整率 | 实际输出镜头数/理论最低镜头数 | ≥100% | ceil(总字数/80) | AI内容总导演 |
| 人物覆盖度 | 有四视图的角色数/人物清单总角色数 | 100% | 逐个核对 | AI美术技术总监 |
| 场景覆盖度 | 有资产卡的场景数/场景清单总场景数 | 100% | 逐个核对 | AI美术技术总监 |
| 风格一致性 | Prompt中禁用词出现次数 | 0次 | 正则扫描 | AI品控合规官 |
| 情绪节拍密度 | 每分钟情绪节拍数 | 3-8次 | 统计分析 | AI内容总导演 |
| 返工闭环率 | 返工后达标次数/总返工次数 | ≥80% | 记录追踪 | 编排师 |
| **人工抽检率** | AI审核后人工抽检比例 | **≥10%** | 随机抽样 | **AI品控合规官** |

> **说明：** 人工抽检率确保量化指标的有效性，避免AI自检的盲区。随机抽取10%的输出进行人工复核。
