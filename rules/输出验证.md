## 验证清单

When checking actual output (e.g., `output/` directory), verify:

```
□ File paths in navigation index match actual file locations
□ All characters in storyboard have complete character cards
□ All character cards have: reference image prompts (全身正面/侧面/特写)
□ Compare similar items: do all characters have same level of detail?
□ Verify cross-references: file A points to file B, does B exist?
□ Check for missing配角 (supporting characters like 春桃)
□ Verify each scene card matches the actual scenes in storyboard
□ Total duration matches sum of individual shot durations
□ Shot count = ceil(total_word_count / 80) = ~77 shots for 6175 words
  - 80 words/shot is REFERENCE, not strict rule
  - Actual can be ±30% based on scene complexity
  - BUT: total content MUST NOT be missing (4 shots for 6175 words is WRONG)
□ Video sequence count: for `output/` batch runs, estimate **ceil(shots / 4)** (12s×4 shots) or **ceil(shots / 5)** (15s×5) **12–15s sequences**; do **not** default to one sequence per chapter or only 2–3 sequences for multi-thousand-word input — plot omission and continuity breaks otherwise
□ Adjacent sequences must document **落幅→起幅** continuity (wardrobe, light, position) per sequence chain
```

---

## 镜数计算公式（MANDATORY）

**镜数参考**: `target_shots ≈ ceil(total_word_count / 80)`（汉字字数；80 字/镜为参考基准，可按场次复杂度 ±30%）。

**12–15s 视频序列**通常含 **4–5 镜/条** → `target_sequences ≈ ceil(target_shots / 4)`（15s×5 镜时可用 `/5`）。

## 常见陷阱

### 1. "File exists" ≠ "Complete"

- A character card might exist but lack reference prompts
- A scene card might exist but miss key props from script

### 2. Interface mismatch

- Navigation index points to wrong path
- Upstream expects certain format that downstream doesn't provide

### 3. Inconsistent detail level

- Character A has full reference prompts, Character B has only text
- Scene A has 5 key props, Scene B has none

### 4. Missing配角

- Only main characters get full treatment
- Supporting characters (丫鬟/小厮) are silently omitted

### 5. Shot count not calculated

- Never calculated: 6175 ÷ 80 = ~77 shots expected
- Output had only 4 shots → 严重内容缺失
- "Optional rule" → ignored execution
- 80字是参考基准，可动态调整，但总内容不能缺失
