# 风格一致性规范（总纲）

> **更新说明（2026-04-04）**: 风格配置已迁移至 `rules/风格/` 子目录。
> 本文件作为总纲，提供风格选择指导。

---

## 核心原则

**Core Principle**: All outputs MUST be consistent with the project's defined style - no contradictions.

**Why This Matters**:
- Inconsistent style = LOGIC ERROR, not a preference issue
- If project is "国风动漫", describing characters as "古风写实" is a contradiction
- All outputs must reinforce the same style, not conflict with each other

## 风格选择流程

1. 用户在项目初始化时选择目标风格
2. 系统加载对应风格文件的禁止词表和锚点
3. 所有Prompt生成时应用风格规则

## 风格互斥表

**Before outputting ANY prompt or content, verify:**

| If project style is... | Then NEVER use... |
|----------------------|-------------------|
| 国风动漫 | 古风写实、影视质感、影视级画质 |
| 拟真人 | 水墨晕染、国风线条、动漫质感 |

---

## 必做检查

- [ ] Identify the project's defined style (check style lock confirmation or project definition)
- [ ] ALL prompts use consistent style keywords
- [ ] Character prompts, scene prompts, and video prompts all match the project style
- [ ] NO mixed keywords appearing in wrong style context
- [ ] Task/scene prompts follow the selected style's anchor words; do **not** paste only technical lines (e.g. 8K / 电影级棚拍) when they contradict the locked style

---

## 禁用词正则（通用检查）

```
(?i)(影视|电影|摄像|胶片|摄影|古风写实|写实CG|游戏CG|影视质感|影视级|电影级)
```

**Before outputting ANY prompt, run this regex to ensure no forbidden words appear.**

> 注意：各风格的详细禁止词表请参考 `rules/风格/` 目录下对应风格文件。

## 附加禁用词（通用）

### 画质与水印

```
blurry, pixelated, low resolution, jpeg artifacts, watermark, text, logo, signature
```

### 人体逻辑

```
extra limbs, mutated hands, bad anatomy, two heads, disfigured
```

### 漫画分镜排除

```
multiple views, 2koma, 4koma (四格漫画)
```
