## 标准分镜表格式（8列）

> ⚠️ **所有场景模板必须使用以下8列格式**

```
镜号 | 场景类型 | 景别 | 运动方式 | 时长 | 叙事功能 | 特色列 | 画面描述
```

| 列名 | 说明 | 示例 |
|------|------|------|
| 镜号 | 镜头序号 | 01, 02, 03... |
| 场景类型 | 场景类型名称 | 对话场景, 情感戏, 动作戏... |
| 景别 | 景别大小 | Wide, Medium, Close, 特写... |
| 运动方式 | 镜头运动 | Fixed, Dolly Push, Dolly Pull, Follow... |
| 时长 | 镜头时长（秒） | 3s, 5s, 0.3s... |
| 叙事功能 | 镜头叙事作用 | 建立, 过肩, Reaction, 收尾... |
| 特色列 | **场景专用特色列**（见下表） | 语法标注, 技巧, 动作... |
| 画面描述 | 完整画面描述 | 含角色、动作、光影等 |

### 各场景特色列对照

| 场景类型 | 特色列 | 说明 |
|----------|--------|------|
| 对话场景 | 语法标注 | 轴线、视线匹配、OTS等 |
| 情感戏 | 镜头序列 | 镜头序列类型 |
| 悬疑惊悚 | 技巧 | Jump Scare, Dutch Angle等 |
| 动作戏 | 动作 | 蓄力、出拳、格挡等 |
| 奇幻视觉奇观 | 阶段 | Normal_World, First_Sign, Manifestation, Aftermath |
| 蒙太奇转场 | 蒙太奇类型 | 时间压缩、平行叙事、匹配剪辑 |
| 独白内心戏 | 外化方案 | 环境映射、微动作、物件代理 |
| 日常氛围治愈系 | 感官标注 | 视觉、听觉、触觉、味觉、嗅觉 |
