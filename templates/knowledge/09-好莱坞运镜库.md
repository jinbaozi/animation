# 好莱坞运镜库

## 概述

本运镜库收录好莱坞级通用动态运镜技巧，为AI镜头序列设计师提供专业级运动方式参考。所有技巧均适用于AI视频生成。

---

## 基础运动方式

### 六大基础运动类型

| 运动类型 | 英文 | 定义 | 视觉效果 | 适用场景 |
|---------|------|------|---------|---------|
| 推镜 | Dolly Push | 摄像机向前移动靠近主体 | 逼近感、压力感、强调 | 情感戏、悬疑、对话 |
| 拉镜 | Dolly Pull | 摄像机向后移动远离主体 | 释放感、孤独感、揭示 | 情感戏、悬疑、奇幻 |
| 摇镜 | Pan | 摄像机水平旋转 | 扫描、搜索、跟随 | 所有场景 |
| 移镜 | Track | 摄像机横向移动 | 跟随、展示空间 | 动作、追逐、日常 |
| 跟镜 | Follow | 摄像机跟随主体移动 | 代入感、临场感 | 动作、追逐、对话 |
| 升降 | Crane/Jib | 摄像机垂直上下移动 | 规模感、宏观→微观 | 奇幻、动作、情感 |

### 基础运动详解

#### 1. Dolly Push（推镜）

**定义**：摄像机沿Z轴向前移动，逐渐靠近主体。

**效果**：
- 产生逼近感和心理压力
- 引导观众注意力集中
- 强调重要细节或表情

**参数**：
| 速度 | 效果 |
|------|------|
| 极慢推（5-8s） | 压抑、逼近、悬疑 |
| 正常推（2-4s） | 自然强调 |
| 快速推（0.5-1s） | 突然强调、震惊 |

**示例**：
- [3s] 缓慢Dolly Push从Wide→Medium，人物逐渐占据画面，紧张感递增
- [1s] 快速Dolly Push到Close，突然揭示重要细节

#### 2. Dolly Pull（拉镜）

**定义**：摄像机沿Z轴向后移动，逐渐远离主体。

**效果**：
- 释放感、孤独感
- 揭示环境全貌
- 情绪高潮后的平复

**参数**：
| 速度 | 效果 |
|------|------|
| 极慢拉（5-10s） | 释然、孤独、沉思 |
| 正常拉（2-4s） | 自然过渡 |
| 快速拉（0.5-1s） | 震惊、揭示 |

**示例**：
- [5s] 情感高潮后，极慢Dolly Pull从Close→Wide，角色在空旷场景中显得渺小
- [2s] 揭示镜头，拉开展示完整犯罪现场

#### 3. Pan（摇镜）

**定义**：摄像机固定在某点，水平或垂直旋转。

**类型**：
| 类型 | 说明 | 速度效果 |
|------|------|---------|
| 水平摇 | 左→右或右→左 | 快摇=紧张，慢摇=观察 |
| 垂直摇 | 上→下或下→上 | 下摇=压抑，上摇=希望 |
| 斜摇 | 对角线方向 | 不稳定感 |

**速度参数**：
| 速度 | 效果 |
|------|------|
| 极慢摇（5s+） | 搜索、观察、压抑 |
| 正常摇（2-3s） | 自然跟随 |
| 快速摇（0.3-0.5s） | 紧张、震惊、Whip Pan |

#### 4. Track/移镜

**定义**：摄像机沿X轴（横向）或Y轴移动跟随主体。

**类型**：
| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 横向移 | 左↔右移动 | 行走、并列展示 |
| 纵向移 | 前↔后移动 | 深入探索 |
| 弧形移 | 曲线路径 | 环绕展示 |

**速度效果**：
| 速度 | 效果 |
|------|------|
| 缓慢移动 | 沉思、观察 |
| 正常移动 | 自然跟随 |
| 快速移动 | 紧迫、追逐 |

#### 5. Follow/跟镜

**定义**：摄像机跟随主体移动，保持恒定距离。

**类型**：
| 类型 | 说明 | 效果 |
|------|------|------|
| 正跟 | 摄像机在前，主体向后 | 引领感、目标感 |
| 背跟 | 摄像机在后，主体向前 | 未知感、悬念 |
| 侧跟 | 摄像机在侧方平行移动 | 平行感、并列感 |

#### 6. Crane/Jib（升降）

**定义**：摄像机垂直上下移动。

**效果**：
| 运动方向 | 效果 |
|---------|------|
| 上升 | 宏观揭示、规模感、升华 |
| 下降 | 微观聚焦、深入、压抑 |
| 俯仰 | 情绪变化（仰望=希望，俯视=压抑）|

## 高级技巧

### 1. Dutch Angle（荷兰式倾斜）

**定义**：摄像机倾斜拍摄，创造不安感。

**使用规则**：
- 倾斜角度：15°-45°
- 适用于：紧张、恐怖、醉酒、内心混乱
- 不适用于：正常对话、平静场景

**示例**：
- [2s] Dutch Angle 30°，表现角色酩酊大醉
- [1s] Dutch Angle 20°，制造心理惊悚不安感

### 2. Speed Ramp（速度 ramping）

**定义**：镜头内速度变化（慢动作↔正常速度）。

**类型**：
| 类型 | 说明 |
|------|------|
| 慢入 | 正常→慢动作（强调关键瞬间） |
| 慢出 | 慢动作→正常（从定格恢复） |
| 慢入慢出 | 慢→更慢→正常（情绪积累→爆发） |

**适用场景**：
- 动作戏关键时刻
- 情感戏高潮
- 奇幻能力释放

**参数**：
| 速度变化点 | 时长 |
|-----------|------|
| 正常→慢 | 0.5-1s |
| 慢动作保持 | 1-3s |
| 慢→正常 | 0.5-1s |

### 3. Rack Focus（焦点切换）

**定义**：在同一镜头内切换焦点主体。

**效果**：
- 引导观众注意力
- 揭示新元素
- 创造双关构图

**使用规则**：
| 切换方式 | 效果 |
|---------|------|
| 前→后 | 揭示背景新元素 |
| 后→前 | 引开对前景的注意 |
| 双焦点 | 同时展示两主体 |

**示例**：
- [3s] 前景角色A说话，突然Rack Focus到背景窗户上的人影

### 4. Impact Frame（冲击帧）

**定义**：在动作impact瞬间插入黑帧或白帧。

**效果**：
- 强调冲击力
- 创造视觉冲击
- 时间感拉伸

**使用方式**：
| 类型 | 实现 | 效果 |
|------|------|------|
| 黑帧插入 | 0.1s黑帧 | 动作硬切、冲击力 |
| 白帧插入 | 0.1s白帧 | 闪光、震惊 |
| 降帧 | 动作瞬间降至12fps | 慢动作效果 |

### 5. Vertigo Effect（眩晕效果）

**定义**：推镜头同时拉远背景（zoom in + dolly out同步）。

**效果**：
- 产生空间扭曲感
- 适用于：眩晕、吸毒、时空扭曲
- 标志性镜头：《迷魂记》楼梯场景

**参数**：
| 同步比例 | 效果 |
|---------|------|
| 1:1同步 | 经典眩晕感 |
| 慢速同步 | 轻微不适感 |
| 快速同步 | 强烈眩晕、时空扭曲 |

## 创意手法

### 1. Split Diopter（分焦镜头）

**定义**：使用分焦镜片，使前景和后景同时清晰。

**效果**：
- 展示同时发生的双线叙事
- 创造画框内的空间深度
- 暗示两个世界的关联

**示例**：
- [4s] 前景角色在室内对话，后景窗外同时发生关键事件

### 2. Float Cam（漂浮摄影）

**定义**：摄像机缓慢漂浮移动，模拟漂浮感。

**效果**：
- 超凡脱俗感
- 梦境感
- 失重感

**适用场景**：
- 梦境、幻觉
- 仙侠悬浮
- 灵魂出窍

### 3. Cosmic Zoom（宇宙缩放）

**定义**：无限缩放穿越空间。

**效果**：
- 宏观→微观无缝转换
- 时空穿越感
- 宇宙感

**适用场景**：
- 回忆触发
- 星际穿越
- 意识流

### 4. 360°旋转

**定义**：摄像机环绕主体旋转360°。

**效果**：
- 眩晕感
- 情绪爆发
- 命运交织

## 节奏设计

### 推拉时机表

| 时机 | 运动类型 | 速度 | 效果 |
|------|---------|------|------|
| 重要台词前 | Dolly Push | 慢→中 | 积累压力 |
| 关键揭示 | Dolly Push | 快 | 突然冲击 |
| 情绪高潮后 | Dolly Pull | 慢 | 释放、沉淀 |
| 新空间揭示 | Dolly Pull | 中→快 | 揭示环境 |
| 紧张升级 | Pan快摇 | 快 | 扫描、不安 |
| 平静观察 | Pan慢摇 | 慢 | 搜索、沉思 |

### 组合运动库

| 组合 | 效果 | 适用场景 |
|------|------|---------|
| Dolly Push + Zoom In | 双重逼近 | 极度强调 |
| Dolly Pull + Zoom Out | 双重释放 | 情绪宣泄 |
| Track + Dutch Angle | 不稳定跟拍 | 追逐、逃亡 |
| Crane Up + Dolly Pull | 上升+拉远 | 升华揭示 |
| Pan + Rack Focus | 摇镜+焦点切换 | 搜索+揭示 |

### 情绪对应运动

| 情绪 | 推荐运动 |
|------|---------|
| 压抑 | 缓慢Dolly Push、下降 |
| 紧张 | 快速Pan、Dutch Angle |
| 孤独 | 极慢Dolly Pull、拉开 |
| 希望 | 上升、Zoom Out |
| 恐惧 | 不稳定手持、POV |
| 爱意 | 缓慢靠近、Dolly Push |
| 释然 | 缓慢Dolly Pull、上升 |
| 愤怒 | 快切、Speed Ramp |

## 手持摄影风格

### Handheld（手持）

**特点**：
- 轻微抖动
- 不稳定性
- 真实感

**参数**：
| 抖动程度 | 效果 |
|---------|------|
| 轻微 | 真实感、日常 |
| 中度 | 紧张、焦虑 |
| 强烈 | 恐慌、混乱 |

**适用场景**：
- 动作追逐
- 恐怖惊悚
- 真实感强的剧情

### Steadicam（斯坦尼康）

**特点**：
- 稳定平滑
- 流畅运动
- 专业感

**适用场景**：
- 长镜头
- 跟随拍摄
- 情感对话

---

## POV主观视角

### POV类型

| 类型 | 说明 | 效果 |
|------|------|------|
| 完全POV | 摄影机=角色眼睛 | 强沉浸感 |
| 过肩POV | 越过肩部看前方 | 观察感 |
| 主观反应 | 角色看向某物的反应 | 代入感 |

### POV使用规则

- POV后通常接角色反应镜头
- POV时长不超过3-4秒
- 保持视线一致性
