# 电影语法与剪辑规则

## 概述

本文件收录专业电影摄影语法和剪辑规则，为AI镜头序列设计师提供对话场景和剪辑层面的深度指导。包括轴线系统、正反打语言、匹配剪辑、OTS放置、覆盖率和交叉剪辑节奏六大核心模块。

---

## 一、180度轴线规则

### 1.1 轴线定义

**轴线（Axis of Action）**：连接两个或多个主要表演者的虚拟线，也称为"动作轴线"或"视线轴线"。

```
        摄像机区（180°内）
            ╱    ╲
           ╱      ╲
    角色A ──────●─────── 角色B
           ╲      ╱
            ╲    ╱
          越轴区（禁止拍摄）
```

**核心原则**：摄像机必须始终保持在轴线同一侧180°范围内拍摄，确保画面空间一致性。

### 1.2 轴线类型

| 轴线类型 | 定义 | 适用场景 |
|---------|------|---------|
| 视线轴线 | 连接两个角色的眼睛 | 对话场景 |
| 动作轴线 | 连接运动中的人物/物体 | 动作戏追逐 |
| 运动轴线 | 角色行进方向 | 行进、追逐 |

### 1.3 越轴后果

当摄像机越过轴线到另一侧拍摄时，会产生以下问题：

| 后果 | 表现 | 严重程度 |
|------|------|---------|
| 空间错乱 | 角色左右位置突然互换 | 严重 |
| 视线冲突 | 角色眼神方向不一致 | 严重 |
| 方向混乱 | 角色面向/背向关系混乱 | 中等 |
| 观众困惑 | 无法判断空间关系 | 中等 |

### 1.4 正确越轴方法

#### 方法一：角色移动越轴

```
步骤：
1. 拍摄角色A在画面左侧，面向右侧（轴线一侧）
2. 角色A移动，越过角色B的位置
3. 继续在新的轴线一侧拍摄
4. 现在可以在新的180°范围内拍摄
```

**示例**：
| 镜号 | 景别 | 画面描述 |
|------|------|---------|
| 01 | Wide | 角色A从画面左侧走向右侧，经过角色B |
| 02 | Medium | 角色A现在在右侧，位置关系自然转换 |
| 03 | OTS | 新的过肩镜头，角色左右关系保持一致 |

#### 方法二：特写过渡越轴

```
步骤：
1. 在轴线一侧拍摄特写（消除空间感）
2. 切换到另一侧拍摄
3. 空间关系已被"重置"
```

**示例**：
| 镜号 | 景别 | 画面描述 |
|------|------|---------|
| 01 | OTS-A | 角色A在左侧说话 |
| 02 | Close | 特写：角色A的眼睛/手部动作（空间感消失） |
| 03 | OTS-B | 切换到另一侧，角色A现在在右侧 |

#### 方法三：反应镜头过渡

```
步骤：
1. 拍摄第三方反应镜头（旁观者）
2. 切换到越轴后的角度
3. 旁观者的存在"合理化"了视角转换
```

**示例**：
| 镜号 | 景别 | 画面描述 |
|------|------|---------|
| 01 | OTS-A | A和B对话 |
| 02 | Close | 旁观者C的反应镜头 |
| 03 | OTS-B | 切换到另一侧，A和B位置已交换 |

#### 方法四：中性镜头过渡

```
步骤：
1. 插入中性角度镜头（与轴线平行或垂直）
2. 切换到越轴后的角度
```

**示例**：
| 镜号 | 景别 | 画面描述 |
|------|------|---------|
| 01 | OTS-A | A和B对话 |
| 02 | Wide | 俯拍全景（中性角度） |
| 03 | OTS-B | 切换到另一侧 |

### 1.5 轴线管理 checklist

```
□ 识别场景中的主要轴线（视线/动作/运动）
□ 确认所有摄像机位置在轴线同一侧
□ 检查角色视线方向是否一致
□ 越轴时使用上述四种方法之一过渡
□ 特写镜头可安全越轴（无空间感）
□ 三人场景需要明确主视角轴线
```

## 二、正反打语言（Shot Reverse-Shot）

### 2.1 正反打定义

**正反打（Shot Reverse-Shot）**：对话场景中在两个或多个角色之间切换拍摄的剪辑方式。

**正反打的核心**：
- 保持轴线一致性
- 匹配视线高度
- 遵循说话者顺序

### 2.2 视线顺序规则

#### 谁先看（Eyeline Order）

**规则**：画面中后出现的角色是接受视线的一方。

| 情况 | 视线顺序 | 逻辑 |
|------|---------|------|
| A说话→B听 | A看向B → B的反应 | 说话者主动发出信息 |
| A说完→B说话 | A的反应 → B看向A | 接受者变成发送者 |
| 第三方介入 | A和B → C的反应 | 旁观者反应 |

**错误示例**：
```
❌ A看向B → C的反应（C与A/B无关）
❌ B的反应 → A说话（先有反应后有原因）
```

**正确示例**：
```
✓ A说话（看向B） → B的反应
✓ B说话（看向A） → A的反应
```

#### 视线高度匹配（Eyeline Match）

**规则**：正反打镜头中，角色的眼睛位置应保持在画面大致相同的高度。

| 视线高度 | 效果 | 适用场景 |
|---------|------|---------|
| 完全齐平 | 平等、对抗感 | 谈判、对峙 |
| A高于B | A占优势 | 命令、训斥 |
| A低于B | B占优势 | 恳求、弱势 |

**AI生成注意事项**：
- 避免眼睛位置一高一低（除非有意为之）
- 特写时尤其注意视线高度
- 俯拍/仰拍会影响视线高度感知

### 2.3 标准对话序列

#### 基础对话序列

```
建立 → A说话(OTS-A) → B反应 → B说话(OTS-B) → A反应 → 循环
```

| 镜号 | 景别 | 镜头类型 | 画面描述 | 规则 |
|------|------|---------|---------|------|
| 01 | Wide | 建立 | 空间全貌 | - |
| 02 | OTS | 过肩-A | A说话，看向B | A在前景 |
| 03 | Close | 反应 | B倾听的表情 | 视线看向A |
| 04 | OTS | 过肩-B | B说话，看向A | B在前景 |
| 05 | Close | 反应 | A倾听的表情 | 视线看向B |
| 06 | ... | ... | 循环 | 重复2-5 |

#### 完整对话序列（含特写）

```
建立 → A-Master → A-OTS → B-Reaction → B-Master → B-OTS → A-Reaction → 循环
```

| 镜号 | 景别 | 镜头类型 | 用途 |
|------|------|---------|------|
| 01 | Wide | 建立 | 空间 |
| 02 | Medium | Master | A说话全身 |
| 03 | OTS | OTS-A | A过肩 |
| 04 | Close | Reaction | B反应 |
| 05 | Medium | Master | B说话全身 |
| 06 | OTS | OTS-B | B过肩 |
| 07 | Close | Reaction | A反应 |
| 08 | Close | 单人特写 | A强调 |

### 2.4 反应镜头类型

| 类型 | 时长 | 用途 | 示例 |
|------|------|------|------|
| 微反应 | 0.5-1s | 捕捉瞬间表情 | 眉头微皱、嘴角轻颤 |
| 完整反应 | 1-2s | 展示情绪过程 | 震惊→愤怒→平静 |
| 延迟反应 | 2-3s | 思考/犹豫 | 停顿、犹豫、决定 |
| 循环反应 | 1.5s×N | 情绪递进 | 越来越紧张 |

### 2.5 正反打常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 视线不一致 | 越轴未处理 | 使用特写过渡 |
| 高度不匹配 | 摄像机高度不一致 | 调整机位高度 |
| 距离跳变 | 景别变化过大 | 保持中→中→中节奏 |
| 节奏单调 | 始终相同序列 | 插入反应/特写变化 |

## 三、匹配剪辑（Match Cut）

### 3.1 匹配剪辑定义

**匹配剪辑（Match Cut）**：通过视觉或动作上的相似性连接两个镜头，创造流畅的时空转换。

**核心原则**：A镜头和B镜头之间存在某种视觉/动作对应关系，使切换看起来自然。

### 3.2 匹配剪辑类型

#### 3.2.1 动作匹配（Action Match）

**定义**：上一个镜头动作的结尾与下一个镜头动作的开头相匹配。

```
镜A：角色伸手拿剑 → 手握剑柄
镜B：手握剑挥出 → 剑已出鞘
```

**使用时机**：
- 动作连续性要求高的打斗
- 需要流畅的时空转换
- 强调动作的连贯性

**示例**：
| 镜号 | 景别 | 画面描述 | 匹配点 |
|------|------|---------|--------|
| 01 | Medium | A出拳 | 拳头伸出 |
| 02 | Close | B格挡 | 拳头到达 |

#### 3.2.2 物体匹配（Object Match）

**定义**：两个镜头中的相似物体形成对应。

```
镜A：茶杯特写
镜B：另一场景中的茶杯（时间转换）
```

**使用时机**：
- 场景转换
- 时间流逝
- 平行叙事

**示例**：
| 镜号 | 景别 | 画面描述 | 匹配点 |
|------|------|---------|--------|
| 01 | Close | 蜡烛特写，火焰摇曳 | 烛光 |
| 02 | Close | 另一房间，烛光熄灭 | 同一时刻 |

#### 3.2.3 构图匹配（Graphic Match）

**定义**：两个镜头具有相似的构图元素。

```
镜A：城市天际线
镜B：监狱栅栏（相似的线条结构）
```

**使用时机**：
- 对比/隐喻
- 强调主题关联
- 视觉呼应

#### 3.2.4 视线匹配（Eyeline Match）

**定义**：角色的视线方向引导到下一镜头。

```
镜A：角色抬头看
镜B：角色看到的内容
```

### 3.3  swing匹配

**Swing匹配**：动作过程中的镜头切换，使动作看起来更流畅。

**技术要点**：
- 在动作的"中间点"切换
- 避免在动作的开始或结束点切换
- 动作保持连续感

**示例**：
```
镜A：角色转身（从左到右，45°）
镜B：继续转身（从45°到90°）
镜C：出拳（90°到完成）
```

### 3.4 何时使用匹配剪辑

| 场景 | 推荐类型 | 效果 |
|------|---------|------|
| 打斗连续动作 | 动作匹配 | 流畅、紧凑 |
| 场景转换 | 物体匹配 | 自然过渡 |
| 时间流逝 | 物体/构图匹配 | 暗示变化 |
| 隐喻对比 | 构图匹配 | 深层含义 |
| 主观视角 | 视线匹配 | 沉浸感 |

## 四、OTS镜头放置

### 4.1 OTS定义

**OTS（Over the Shoulder）**：过肩镜头，摄像机越过一个角色的肩膀拍摄另一个角色。

**核心要素**：
- 前景角色肩部/头部占据画面一侧
- 后景角色是画面的焦点
- 建立两人空间关系

### 4.2 肩膀放置规则

#### 谁的肩膀在前

**规则**：当前说话者的肩膀放在前景。

| 情况 | OTS类型 | 画面描述 |
|------|---------|---------|
| A说话，看B | OTS-A | A的右肩在前，看到B |
| B说话，看A | OTS-B | B的左肩在前，看到A |

**示例**：
```
场景：A和B面对面交谈

镜02：A说话（OTS-A）
      画面：右侧肩膀是A的右肩
      画面：左侧是B在说话

镜04：B说话（OTS-B）
      画面：左侧肩膀是B的左肩
      画面：右侧是A在说话
```

#### 肩膀距离规则

| 距离 | 效果 | 适用场景 |
|------|------|---------|
| 宽OTS | 看到更多后景 | 空间感重要 |
| 标准OTS | 平衡感 | 标准对话 |
| 窄OTS | 亲密感 | 亲密对话、私密场景 |

### 4.3 OTS变体

#### 单人OTS（Single OTS）

- 只显示一个肩膀
- 后景角色是焦点
- 适用于第三方视角

**示例**：
```
画面：越过A的肩膀，看到B
前景：A的右侧肩背
焦点：B的表情
```

#### 双人OTS（Double OTS）

- 两个肩膀都在画面中
- 空间关系最清晰
- 适用于重要对话

**示例**：
```
画面：A和B都在画面中
前景：画面下方是两人的肩膀
焦点：两人的中间位置
```

#### 侧面OTS（Profile OTS）

- 摄像机在90°侧面
- 看到角色侧面
- 适用于侧面光线/轮廓

### 4.4 OTS使用时机

| 场景 | 推荐OTS | 理由 |
|------|---------|------|
| 标准对话 | OTS-A/B切换 | 建立关系 |
| 亲密对话 | 窄OTS | 亲密感 |
| 对峙/冲突 | 宽OTS+特写 | 紧张感 |
| 第三方旁观 | 单人OTS | 客观视角 |
| 空间展示 | 宽OTS | 环境信息 |

### 4.5 OTS checklist

```
□ 确认说话者的肩膀在前景
□ 确认后景角色在画面焦点
□ 视线通过肩膀上方/之间
□ 肩膀不要遮挡重要面部特征
□ 正反打时使用相反的OTS
```

## 五、覆盖率标准（Coverage Ratio）

### 5.1 覆盖率定义

**覆盖率（Coverage）**：为每个场景拍摄的不同角度/景别镜头的数量。

**计算方式**：覆盖率 = 拍摄镜头数 / 场景实际镜头数

### 5.2 场景类型覆盖率

| 场景类型 | 推荐覆盖率 | 最低覆盖率 | 最高覆盖率 |
|---------|-----------|-----------|-----------|
| 对话场景 | 6:1 - 8:1 | 4:1 | 10:1 |
| 动作戏 | 10:1+ | 8:1 | 15:1 |
| 情感戏 | 4:1 - 6:1 | 3:1 | 8:1 |
| 悬疑惊悚 | 6:1 - 10:1 | 4:1 | 12:1 |
| 日常氛围 | 3:1 - 5:1 | 2:1 | 6:1 |

### 5.3 对话场景覆盖率详解

#### 标准对话（6:1覆盖率）

```
总镜头：6个
实际内容：1个场景

覆盖方式：
- 1个建立（Wide）
- 2个过肩（OTS-A + OTS-B）
- 2个单人（Master-A + Master-B）
- 1-2个反应（Reaction）

这是最经济的对话覆盖方式。
```

#### 丰富对话（8:1覆盖率）

```
总镜头：8个
实际内容：1个场景

覆盖方式：
- 1个建立（Wide）
- 2个过肩（OTS-A + OTS-B）
- 2个单人（Master-A + Master-B）
- 2个反应（Reaction-A + Reaction-B）
- 1个特写（Close-up）
```

#### 完整对话（10:1覆盖率）

```
总镜头：10个
实际内容：1个场景

覆盖方式：
- 1个建立（Wide）
- 2个过肩（OTS-A + OTS-B）
- 2个单人（Master-A + Master-B）
- 2个反应（Reaction-A + Reaction-B）
- 2个特写（Close-up A + Close-up B）
- 1个侧面/角度变化
```

### 5.4 动作戏覆盖率详解

#### 动作戏高覆盖率原因

1. **动作速度**：动作快，需要更多角度捕捉
2. **剪辑需求**：不同角度使剪辑更流畅
3. **节奏变化**：避免视角单调
4. **安全性**：多角度便于选择最佳镜头

#### 动作戏覆盖率示例（12:1）

```
场景：角色A攻击角色B

覆盖镜头：
1. Wide 建立
2. Medium 蓄力
3. OTS-A 出拳
4. Close-A 拳头特写
5. Reaction-B 被打中
6. Medium-B 后退
7. OTS-B 反击
8. Close-B 反击动作
9. Reaction-A 被打中
10. Wide 双方分开
11. 特写 拳头/伤口
12. 反应 表情特写
```

### 5.5 情感戏覆盖率详解

#### 情感戏低覆盖率原因

1. **情绪连续性**：情感需要连贯，不宜频繁切换
2. **镜头时长**：情感镜头通常较长
3. **特写为主**：情感戏靠特写传达
4. **留白需求**：需要镜头"呼吸"空间

#### 情感戏覆盖率示例（4:1）

```
场景：角色A向角色B告白

覆盖镜头：
1. Wide 建立环境
2. Medium 靠近
3. Close 对视
4. 特写 告白的表情
```

### 5.6 覆盖率控制技巧

| 技巧 | 说明 |
|------|------|
| 建立只需1个 | 不需要多个建立镜头 |
| 反应镜头可复用 | 同一个反应镜头可多用 |
| 特写适度 | 不要每个镜头都是特写 |
| 角度变化 | 同一景别可换角度 |
| 优先保证关键镜头 | 核心对话要有充分覆盖 |

## 六、交叉剪辑节奏（Cross-cutting Rhythm）

### 6.1 交叉剪辑定义

**交叉剪辑（Cross-cutting）**：在两个或多个同时发生的场景/情节之间交替切换。

**核心目的**：
- 建立紧张感
- 制造悬念
- 平行叙事
- 节奏变化

### 6.2 交叉剪辑类型

#### 6.2.1 紧张建立节奏

**模式**：A场景 → B场景 → A场景 → B场景...（频率递增）

**示例**：
```
场景A：杀手逐渐靠近目标
场景B：目标毫无察觉

节奏：
1. A 3s 建立
2. B 3s 建立
3. A 2s 靠近
4. B 2s 毫无察觉
5. A 1.5s 靠近
6. B 1.5s 危险临近
7. A 1s 举起武器
8. B 回头（发现）
9. 冲突爆发
```

**节奏公式**：
```
初期：3s → 3s（等长）
中期：2s → 2s（缩短）
高潮：1s → 1s（快速切换）
爆发：0.5s 或 直接接入冲突
```

#### 6.2.2 释放节奏

**模式**：高潮 → 缓和 → 平静

**示例**：
```
场景：追逐后的喘息

节奏：
1. 最后一幕冲突（高潮）
2. 2s 静止
3. 3s 拉远
4. 4s 建立环境
5. 5s+ 留白
```

#### 6.2.3 平行叙事节奏

**模式**：A和B同时进行，逐步揭示关联

**示例**：
```
场景A：主角准备行动
场景B：反派准备行动

节奏：
1. A 建立
2. B 建立
3. A 准备
4. B 准备
5. A 出发
6. B 出发
7. A 到达
8. B 到达
9. 相遇/对决
```

### 6.3 节奏控制参数

| 节奏类型 | 初始间隔 | 递增幅度 | 最终间隔 |
|---------|---------|---------|---------|
| 紧张建立 | 3s | -0.5s | 0.5s-1s |
| 悬念营造 | 2s | -0.3s | 0.5s |
| 平行叙事 | 2-3s | 保持稳定 | 同步 |
| 情感释放 | 4s+ | +1s | 6s+ |

### 6.4 节奏与情绪对应

| 目标情绪 | 剪辑节奏 | 镜头时长 | 示例 |
|---------|---------|---------|------|
| 紧张 | 快→极快 | 短→更短 | 追逐、危机 |
| 悬念 | 中→快 | 中等 | 隐藏真相 |
| 浪漫 | 慢 | 长 | 告白、亲吻 |
| 悲伤 | 慢→更慢 | 长→更长 | 离别、失去 |
| 悬疑 | 中 | 中等 | 发现线索 |
| 动作 | 快 | 短 | 打斗、爆炸 |
| 温馨 | 中 | 中等 | 日常、治愈 |

### 6.5 节奏违规问题

| 问题 | 表现 | 解决 |
|------|------|------|
| 节奏拖沓 | 切换过慢 | 缩短镜头 |
| 节奏混乱 | 切换无规律 | 建立节奏模型 |
| 节奏断裂 | 镜头时长跳跃过大 | 平滑过渡 |
| 高潮不足 | 节奏未递增 | 加快后期节奏 |

## 七、音桥技巧（Sound Bridge）

### 7.1 音桥定义

**音桥（Sound Bridge）**：声音先于画面出现或延续到下一镜头，用于连接场景、创造流畅过渡的剪辑技术。

**核心作用**：
- 场景转换更流畅
- 保持叙事连贯性
- 引导观众注意力
- 创造时空连续感

### 7.2 音桥类型

#### 7.2.1 预入（Pre-lap）

**定义**：下一个场景的声音在当前镜头结束前就开始出现。

```
镜A：角色A说话（画面）
     ↓
     声音：角色B的声音开始（预入）
     ↓
镜B：角色B说话（画面）
```

**效果**：
- 暗示即将发生的情节
- 吸引观众注意力
- 创造悬念或期待

**示例**：
```
镜A：办公室，角色A挂断电话
     预入：门铃声逐渐响起
镜B：办公室门口，角色B出现
```

**使用场景**：
| 场景 | 预入内容 | 效果 |
|------|---------|------|
| 场景转换 | 环境音 | 自然过渡 |
| 角色转换 | 对话声音 | 悬念引入 |
| 情绪转换 | 音乐 | 情绪铺垫 |

#### 7.2.2 切出（Cutaway）

**定义**：画面切换但声音继续，延后视觉信息的揭示。

```
镜A：角色A说话
     ↓
镜B：无关画面（切出）
     ↓
镜A继续：角色A继续说话
```

**效果**：
- 隐藏关键信息
- 制造悬念
- 避免单调

**示例**：
```
镜A：角色A紧张地说"有人来了"
镜B：切出到空旷的走廊
镜C：回到角色A，等待门被打开
```

#### 7.2.3 分离剪辑（Split Edit / L-cut）

**定义**：声音和画面在不同时间点切换（声音先入或晚出）。

```
镜A：画面结束
     ↓
     声音：继续（切出到镜B画面）
     ↓
镜B：画面继续
```

**类型**：

| 类型 | 定义 | 示例 |
|------|------|------|
| L-cut | 声音从A延续到B画面 | 说话者的声音延续到听者的反应镜头 |
| J-cut | B场景的声音先于画面 | 先听到门打开声，再看到门被打开 |

**L-cut示例**：
```
镜A：角色A说话
     L-cut：声音延续
镜B：角色B的反应镜头（画面先入，声音已在A镜头开始）
```

**J-cut示例**：
```
     J-cut：脚步声先入
镜A：角色走进房间（画面晚于声音）
```

### 7.3 音桥应用场景

#### 7.3.1 场景转换

| 转换类型 | 音桥技术 | 效果 |
|---------|---------|------|
| 室内→室内 | L-cut | 流畅 |
| 室内→室外 | J-cut（先环境音） | 自然 |
| 过去→现在 | 音乐预入 | 过渡 |
| 现实→回忆 | 声音模糊处理 | 暗示 |

#### 7.3.2 对话连接

| 场景 | 技术 | 示例 |
|------|------|------|
| 说话→反应 | L-cut | A说话的声音延续到B的反应画面 |
| 反应→说话 | J-cut | B的呼吸/反应声先入，再切到B说话 |
| 第三方介入 | L-cut→J-cut | A说话→旁观者反应（声音延续）→旁观者说话 |

#### 7.3.3 情绪铺垫

| 情绪目标 | 技术 | 示例 |
|---------|------|------|
| 紧张 | 声音预入（J-cut） | 脚步声先入，人未到 |
| 神秘 | 模糊声音预入 | 听不清的低语 |
| 释然 | L-cut 渐出 | 对话结束，声音延续到空镜 |

### 7.4 音桥参数

| 参数 | 说明 | 取值 |
|------|------|------|
| 预入时长 | 声音先于画面的时间 | 0.5s-3s |
| 渐变时间 | 声音淡入淡出时间 | 0.3s-1s |
| 音量对比 | 新旧声音的音量关系 | 主:次 = 3:1 |

### 7.5 音桥 checklist

```
□ 场景转换时考虑音桥
□ 对话使用L-cut连接说话和反应
□ 悬念场景使用J-cut（声音先入）
□ 声音渐变使用淡入淡出
□ 音乐预入增强情绪
```

### 7.1 对话场景完整流程

```
Step 1: 识别轴线
    → 确定两个角色的位置关系
    → 明确视线方向

Step 2: 选择覆盖率
    → 标准对话：6:1
    → 重要对话：8:1
    → 关键情感：4:1

Step 3: 构建序列
    → 建立 → A过肩 → B反应 → B过肩 → A反应 → 循环

Step 4: 添加变化
    → 插入特写
    → 调整节奏
    → 匹配剪辑过渡

Step 5: 越轴检查
    → 确认所有镜头在轴线同一侧
    → 如需越轴，使用正确方法
```

## 九、屏幕方向规则（Screen Direction）

### 基本屏幕方向

```
左 → 右 = 正向移动（通常）
右 → 左 = 负向移动（需建立）
```

### 保持屏幕方向一致

| 规则 | 说明 |
|------|------|
| 同一场景内方向一致 | A从左向右走，后续镜头必须保持 |
| 建立方向后保持 | 角色进入画面后的移动方向 |
| 视线方向匹配 | 看左的人反应镜头也看左 |

### 屏幕方向与轴线

```
    A ←—————轴线————→ B
    |                      |
左机位                右机位
(看A时A在右)         (看B时B在右)

越轴后:
    A ←—————轴线————→ B
              |
         中间机位
    (看A时A在中/看B时B在中)
```
