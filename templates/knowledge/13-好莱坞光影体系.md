## 概述

本体系为AI美术技术总监提供好莱坞级别的专业布光规范，确保每个镜头都有合理的视觉逻辑支撑。

## 一、Motivated Lighting 有源布光原则

### 核心理念

**定义**：每个灯光必须有合理的"叙事内光源"（Diegetic Source）。没有光源的灯光被称为"Unmotivated Light"，会破坏视觉真实感。

### 光源类型表

| 光源 | 光质 | 方向 | 色温 | 情绪 |
|------|------|------|------|------|
| 阳光（窗外） | Directional | 侧光/逆光 | 5600K 日光 | 自然、室外 |
| 阴天 | Soft | 漫射 | 6500K 偏冷 | 压抑、平静 |
| 蜡烛 | Warm Soft | Omnidirectional | 1900K 极暖 | 浪漫、温馨、危险 |
| 台灯 | Warm Medium | 正面/侧面 | 2700K 暖 | 私密、安全 |
| 电视屏幕 | Cold Blue | 正面 | 7000K+ 冷蓝 | 科技、孤独 |
| 火光 | Flickering Warm | 低位/侧面 | 2000K 暖 | 危险、热情 |
| 月光 | Cool Blue | 逆光 | 4500K 冷蓝 | 浪漫、神秘 |
| 霓虹灯 | Colored | 侧面 | 混合 | 都市、赛博朋克 |

### 光源布局原则

```
【场景：你与蜡烛共处的房间】

主光：蜡烛 → 低位暖光，照射面部
补光：台灯（远处，低亮度）→ 填充阴影
轮廓光：窗外月光 → 背侧轮廓
眼神光：蜡烛反光 → 眼中光点

效果：温馨但略带神秘
```

## 二、Three-Point Lighting 三点布光系统

### 标准三点布光

| 灯光 | 位置 | 作用 | 亮度比例 |
|------|------|------|---------|
| **Key Light 主光** | 主体45°侧面/前方 | 主要照明，定义阴影 | 100%（基准） |
| **Fill Light 补光** | 对侧，较远 | 填充主光阴影 | 50%（柔和）/ 25%（硬） |
| **Back Light 轮廓光** | 主体正后方 | 分离主体与背景 | 50-100% |

### 主光位置变化

| 位置 | 角度 | 效果 |
|------|------|------|
| 正面光 | 0° | 平淡、纪实、无阴影 |
| 1/4光 | 30° | 自然、轻微立体 |
| 侧面光 | 45° | 经典肖像、戏剧感 |
| 半侧面 | 60° | 强烈明暗对比 |
| 侧光 | 90° | 极致对比、剑影效果 |
| 逆光 | 180° | 剪影、轮廓 |

### Key-to-Fill Ratio 关键补光比

| 比率 | 阴影程度 | 情绪 | 场景类型 |
|------|---------|------|---------|
| **1:1** | 无阴影（平光） | 纪实、审讯 | 新闻、采访 |
| **2:1** | 轻阴影 | 愉快、柔和 | 浪漫喜剧 |
| **4:1** | 中等阴影 | 中性、专业 | 商务对话 |
| **8:1** | 深阴影 | 紧张、戏剧 | 悬疑、惊悚 |
| **16:1** | 近黑 | 极端戏剧 | 黑色电影 |
| **∞:1** | 全黑（单光源） | 极端 noir | 恐怖、死亡 |

### AI生成提示词格式

```
布光: 三点布光，主光45°侧光，补光比4:1，轮廓光50%
光源: Key=窗外阳光(5600K)，Fill=反光板，Back=太阳逆光
情绪: 紧张、戏剧感
```

## 三、High Key & Low Key 高调与低调

### High Key 高调照明

| 特征 | 描述 |
|------|------|
| 整体亮度 | 高，整体曝光充足 |
| 阴影 | 浅或无，阴影细节可见 |
| 对比度 | 低，灰阶连续 |
| 色温 | 偏暖或中性 |
| 典型场景 | 喜剧、音乐剧、广告 |

**高调布光技巧**：
- 多光源，减少单光源阴影
- 使用反光板填充阴影
- 提高环境光照
- 减少主光与补光比

### Low Key 低调照明

| 特征 | 描述 |
|------|------|
| 整体亮度 | 低，深色为主 |
| 阴影 | 深，阴影几乎全黑 |
| 对比度 | 高，明暗分明 |
| 色温 | 可偏冷或戏剧性 |
| 典型场景 | 黑色电影、惊悚、恐怖 |

**低调布光技巧**：
- 单向主光，少补光
- 深色背景
- 使用黑色旗板吸收光线
- 边缘光分离主体

## 五、Color Script 色彩脚本规划

### 叙事色彩弧线

**定义**：整部影片的色彩随叙事发展而变化，形成情绪曲线。

### 标准色彩弧线

| 阶段 | 色调 | 饱和度 | 亮度 | 示例 |
|------|------|--------|------|------|
| **Act 1 建制** | 冷色/蓝色 | 低-中 | 中 | 青蓝、低饱和 |
| **Act 2 发展** | 逐渐变暖 | 中 | 中-高 | 黄绿、暖灰 |
| **Act 2 中点** | 暖色 | 中-高 | 高 | 橙黄、暖调 |
| **Act 3 高潮** | 饱和暖/红 | 高 | 高-中 | 红、高饱和 |
| **结局/余波** | 冷色/中性 | 中-低 | 中 | 回归冷调 |

### 类型化色彩方案

| 类型 | 主色调 | 辅助色 | 对比色 | 情绪 |
|------|--------|--------|--------|------|
| **Orange & Teal** | 橙色 | 青色 | 互补 | 好莱坞商业大片 |
| **Warm Vintage** | 暖黄 | 米色 | 棕褐 | 怀旧、复古 |
| **Desaturated Realism** | 灰色 | 冷蓝 | 低对比 | 纪实、剧情 |
| **High Contrast** | 黑色 | 白色 | 强烈 | 黑色电影 |
| **Earth Tones** | 棕色 | 绿色 | 米色 | 自然、历史 |

### AI生成提示词

```
色彩脚本: Act1冷蓝低饱和 → Act2渐暖 → Act3饱和暖色
色调: 整体偏暖青，高潮场景增加橙红
饱和度: 前期低(0.7) → 后期高(1.2)
```
