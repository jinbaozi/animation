# 好莱坞导演技法增强

## 概述

本体系为AI内容总导演提供好莱坞级别的导演技法规范，增强构图、叙事结构和视觉语言能力。

## 一、Master Shot master镜头体系

### Master Shot定义

**定义**：用于建立场景空间关系和角色位置的宽镜头，是场景的"锚点"。

### Master Shot类型

| 类型 | 景别 | 时长 | 用途 |
|------|------|------|------|
| **大远景** | Extreme Wide | 5-10s | 建立世界/地点 |
| **远景** | Wide | 4-6s | 建立场景类型 |
| **全景** | Full | 3-5s | 展示角色与空间 |
| **双人全景** | Medium Wide | 3-5s | 展示两人关系 |

### Master Shot时机

| 场景类型 | 是否需要Master | 镜头选择 |
|---------|---------------|---------|
| 新地点首次出现 | 必须 | Wide/远景 |
| 同一地点继续 | 可跳过 | - |
| 情绪/对话场景 | 建议使用 | Medium Wide |
| 动作场景 | 建议使用 | Wide |
| 时间跳转 | 必须 | Wide+时间标注 |

### Master Shot检查清单

```
□ 展示所有重要角色的位置
□ 建立空间关系（上下左右前后）
□ 确定轴线方向
□ 展示场景光源方向
□ 时长足够观众理解空间
□ 为后续镜头提供参照
```

## 二、Blocking 演员走位设计

### 画面分割原则

| 法则 | 描述 | 效果 |
|------|------|------|
| **三分法** | 画面横竖各三等分 | 经典平衡 |
| **黄金比例** | 0.618位置 | 自然和谐 |
| **中心构图** | 主体居中 | 强调/权威 |
| **边缘构图** | 主体偏向一侧 | 紧张/不平衡 |

### Looking Room & Headroom

**Looking Room（注视空间）**：
```
角色看向画面左侧 → 角色应偏右 → 左侧留空间
角色看向画面右侧 → 角色应偏左 → 右侧留空间
原因：视线方向应与画面重心平衡
```

**Headroom（头顶空间）**：
| 类型 | 头顶空间 | 适用 |
|------|---------|------|
| 紧头 | 头顶贴近画面边缘 | 压抑/紧张 |
| 正常头 | 头顶到画面1/4处 | 标准 |
| 多头 | 头顶留大量空间 | 孤独/渺小 |

### 演员位置数学

| 位置 | 景别 | 画面占比 | 关系强度 |
|------|------|---------|---------|
| 并排 | Wide | 两人均占1/4 | 平等 |
| 重叠 | Medium | 前后关系 | 亲密/主次 |
| 分离 | Wide | 各自占位 | 对立/距离 |

### 走位变化技巧

| 变化类型 | 效果 | 使用场景 |
|---------|------|---------|
| 靠近 | 亲密/关系发展 | 爱情/和好 |
| 远离 | 疏远/关系破裂 | 争吵/离别 |
| 交叉 | 关系转变 | 立场变化 |
| 环绕 | 动态关系 | 追逐/舞蹈 |

## 三、Screen Direction 屏幕方向规则

### 基本方向系统

```
左 → 右 = 正向运动（自然方向）
右 → 左 = 负向运动（需要建立）
```

### 方向一致性原则

| 规则 | 说明 |
|------|------|
| **建立方向** | 第一个镜头确定运动方向 |
| **保持方向** | 同一场景内保持该方向 |
| **冲突处理** | 方向矛盾时需建立新方向 |

### 方向与轴线

```
轴线: A ←————→ B

左机位:
  → 看到A在画面右侧
  → 看到B在画面左侧
  → A看B时，B在画面右侧

右机位:
  → 看到A在画面左侧
  → 看到B在画面右侧
  → A看B时，B在画面左侧
```

### 方向越轴处理

当需要越轴时：
1. 使用角色移动越过轴线
2. 切到中性镜头（侧面/特写）
3. 使用特写过渡

## 四、Depth of Field 景深叙事

### 景深与情绪

| 景深类型 | 描述 | 情绪效果 | 使用场景 |
|---------|------|---------|---------|
| **浅景深** | 主体清晰，背景虚化 | 强调/浪漫/梦幻 | 人像/特写 |
| **中景深** | 主体清晰，背景隐约 | 平衡/自然 | 标准对话 |
| **深景深** | 前后皆清晰 | 纪实/紧张/信息 | 群戏/环境 |

### 景深控制技巧

| 效果 | 方法 | AI提示词 |
|------|------|---------|
| 极浅 | 大光圈(1.4-2.8)，长焦 | 背景极致虚化 |
| 浅 | 中等光圈(4-5.6) | 轻微虚化 |
| 深 | 小光圈(8-11) | 前后清晰 |
| 极深 | 超小光圈(16-22) | 全部清晰 |

### 景深与叙事

```
【浅景深使用】
- 强调主体，消除干扰
- 创造梦幻/回忆感
- 引导观众视线
- 表现角色内心世界

【深景深使用】
- 建立空间关系
- 展示环境信息
- 创造紧张/纪实感
- 多人场景平衡
```

## 五、Atmospheric Perspective 大气透视

### 3D深度感建立

| 深度层次 | 特征 | 画面表现 |
|---------|------|---------|
| **前景** | 最清晰、最饱和 | 细节丰富、色彩鲜明 |
| **中景** | 中等清晰度 | 主体所在层 |
| **远景** | 最模糊、最不饱和 | 青色/蓝色偏移 |

### 大气透视效果

| 效果 | 原因 | AI提示词 |
|------|------|---------|
| **空气透视** | 大气散射 | 远处山峦呈青蓝色 |
| **灰尘雾** | 微粒散射 | 阳光中尘埃可见 |
| **薄雾** | 水汽散射 | 远处树木隐于雾中 |
| **霾** | 污染物散射 | 城市灰蒙蒙的远景 |

### 深度线索系统

| 线索类型 | 视觉表现 |
|---------|---------|
| **重叠** | 近处物体遮挡远处物体 |
| **相对大小** | 近大远小 |
| **线性透视** | 平行线汇聚 |
| **空气透视** | 远景偏蓝/模糊 |
| **纹理梯度** | 近处纹理清晰，远处模糊 |

## 六、Advanced Composition 高级构图

### 超越三分法

| 构图类型 | 描述 | 效果 | 使用场景 |
|---------|------|------|---------|
| **框架构图** | 用门窗等框住主体 | 聚焦/封闭感 | 窥视/囚禁 |
| **对角线** | 主体沿对角线 | 动态/张力 | 动作/冲突 |
| **三角形** | 三个元素形成三角 | 稳定/平衡 | 群戏/对话 |
| **螺旋/黄金螺旋** | 跟随自然螺旋 | 引导视线 | 唯美/强调 |

### 动态构图

| 类型 | 描述 | 效果 |
|------|------|------|
| **动态平衡** | 画面重心随动势 | 运动感 |
| **不对称平衡** | 不同元素平衡重量 | 张力 |
| **引导线** | 利用线条引导视线 | 聚焦 |

### Negative Space 负空间

| 效果 | 说明 | 使用场景 |
|------|------|---------|
| **孤独感** | 主体占小部分 | 失落/孤独 |
| **强调** | 周围留白突出主体 | 重要信息 |
| **呼吸感** | 画面不拥挤 | 平静/思考 |

## 七、Screen Geography 屏幕地理学

### 空间关系表达

| 关系 | 屏幕表现 | 情绪效果 |
|------|---------|---------|
| **亲密** | 两人靠近，镜头贴近 | 亲密/爱情 |
| **个人距离** | 手臂可触及 | 正常对话 |
| **社交距离** | 一臂长 | 正式/陌生 |
| **公共距离** | 远镜头 | 疏远/正式 |

### 屏幕区域划分

```
┌─────────────┐
│     上     │  力量/天空/希望
│  左   右  │  左: 过去/被动  右: 未来/主动
│     下     │  压抑/死亡/失败
└─────────────┘
```

### 戏剧性空间使用

| 空间使用 | 屏幕表现 | 戏剧效果 |
|---------|---------|---------|
| 角色从右入画 | 主动/进入 | 发展 |
| 角色从左入画 | 被动/离开 | 逃避 |
| 角色偏上 | 优势/控制 | 权力 |
| 角色偏下 | 劣势/被动 | 压抑 |
