# 好莱坞配音体系

## 概述

本体系为AI配音导演提供好莱坞级别的专业配音技巧规范，涵盖表演指导、ADR技术、声音设计和声音空间设计。

---

## 一、Voice Acting Direction 配音表演指导

### 身体动作转化声音

**核心理念**：声音是身体的延伸，表演指导应将身体动作转化为声音。

| 身体动作 | 声音表现 | 指导要点 |
|---------|---------|---------|
| 眼神 | 视线的"声音" | 通过音调变化表现"看向"某处 |
| 呼吸 | 情绪的身体节奏 | 紧张=浅快，平静=深慢 |
| 手势 | 声音的力度 | 用手势引导音量/力度 |
| 姿态 | 声音的空间感 | 挺直=响亮，蜷缩=压抑 |

### 表演三要素

| 要素 | 说明 | 声音表现 |
|------|------|---------|
| **内容** | 台词说什么 | 字词清晰度 |
| **方式** | 怎么说 | 语调/节奏 |
| **目的** | 为什么说 | 情感/意图 |

### 台词分层

| 层级 | 定义 | 示例 | 声音特点 |
|------|------|------|---------|
| **字面** | 台词的表面含义 | "我走了" | 中性 |
| **潜台词** | 实际含义 | "我对你很失望" | 讽刺/冷漠 |
| **内心** | 角色内心想法 | "我不想离开你" | 矛盾/痛苦 |

### 情感状态指南

| 情感 | 音调 | 音量 | 节奏 | 呼吸 |
|------|------|------|------|------|
| 愤怒 | 降低/压低 | 高 | 快 | 急促 |
| 悲伤 | 不稳定/颤抖 | 低 | 慢 | 断续 |
| 恐惧 | 高/尖锐 | 不稳定 | 不规则 | 浅/快 |
| 喜悦 | 高/明亮 | 中-高 | 快 | 深/稳定 |
| 爱意 | 柔和/温暖 | 中 | 慢 | 稳定/深 |
| 冷漠 | 平/单音 | 低 | 慢 | 浅 |

## 二、ADR Techniques ADR技术

### ADR定义

**ADR (Automatic Dialogue Replacement)**：自动对白替换，用于修复现场录音问题。

### ADR使用场景

| 场景 | 必要性 | 原因 |
|------|--------|------|
| 现场录音有噪声 | 必须 | 无法使用 |
| 词句错误 | 必须 | 内容修正 |
| 音调不匹配 | 建议 | 表演修正 |
| 音量不一致 | 可选 | 技术调整 |
| 远景/无嘴型镜头 | 不必要 | 无需匹配 |

### Room Tone 房间音

**定义**：场景"安静"时的环境底噪，用于填充剪辑间隙。

**Room Tone采集标准**：
```
采集时长：至少30秒
采集位置：演员同一位置
环境要求：无干扰，无风，无设备噪声
```

### Plosive Control 爆破音控制

| 爆破音 | 问题 | 解决方法 |
|--------|------|---------|
| P, B | 喷麦 | 增加距离/使用防喷罩 |
| T, D | 齿音过重 | 降低高频/使用齿音消除 |
| K, G | 喉音过重 | 调整距离/角度 |

### 距离感调整

| 镜头类型 | 建议距离 | 声音特点 |
|---------|---------|---------|
| 特写/Close | 15-30cm | 直接/清晰/存在的气息声 |
| 中景 | 30-60cm | 自然/轻微气息 |
| 远景 | 60cm-1m | 轻微混响/衰减 |
| 大远景 | 1m+ | 混响/距离感 |

## 三、Voice Casting 声音选角

### 音色类型

| 类型 | 特点 | 适合角色 |
|------|------|---------|
| **Soprano 花腔女高音** | 高/亮/灵活 | 年轻女性/仙子 |
| **Mezzo 女中音** | 中/温暖 | 成熟女性 |
| **Alto 女低音** | 低/深沉 | 年长女性/反串 |
| **Tenor 男高音** | 高/明亮 | 年轻男性/英雄 |
| **Baritone 男中音** | 中/温暖 | 成熟男性/主角 |
| **Bass 男低音** | 低/厚重 | 年长男性/反派 |

### 角色声音匹配

| 角色特征 | 声音特征 | 匹配要点 |
|---------|---------|---------|
| 年轻 | 高音/明亮 | 声线未成熟感 |
| 年长 | 低音/沉稳 | 声线成熟感 |
| 强壮 | 宽音域/有力 | 声音有力量 |
| 虚弱 | 细/气声 | 声音虚弱感 |
| 开朗 | 高/快节奏 | 声音活泼 |
| 忧郁 | 低/慢节奏 | 声音沉重 |

### 声音一致性规则

| 规则 | 说明 | 检查点 |
|------|------|--------|
| **音色一致** | 同一角色同一音色 | 声线不变 |
| **年龄匹配** | 声音年龄与角色匹配 | 青年/中年/老年 |
| **状态一致** | 角色状态变化声音变化 | 生病/疲劳/清醒 |
| **情绪对应** | 声音反映情绪 | 喜怒哀乐 |

## 四、Breath Control 呼吸控制

### 呼吸与情绪

| 情绪状态 | 呼吸特点 | 声音表现 |
|---------|---------|---------|
| **平静** | 深/慢/规律 | 稳定/清晰 |
| **紧张** | 浅/快/不规律 | 不稳定/颤抖 |
| **恐惧** | 浅/快/屏息 | 气声/喘息 |
| **愤怒** | 深/快/有力 | 压低/有力 |
| **悲伤** | 断续/叹气 | 断续/气音 |
| **惊讶** | 突然吸气 | 短促/高音 |
| **疲惫** | 浅/慢/叹气 | 虚弱/拖音 |

### 呼吸录音指导

| 类型 | 指导要点 | 使用场景 |
|------|---------|---------|
| **吸气** | 自然/不过度 | 句子开头 |
| **呼气** | 渐弱/叹气感 | 句子结尾 |
| **屏息** | 紧张/恐惧场景 | 惊悚 |
| **喘息** | 体力/情绪消耗 | 追逐/崩溃 |
| **叹气** | 放松/无奈 | 释然/疲惫 |

### 呼吸声音设计

```
【恐惧场景】
录音: 浅呼吸+偶尔吞咽声
后期: 添加心跳声增强紧张感
混音: 呼吸声略微前置

【愤怒场景】
录音: 深呼吸+压低声音
后期: 减少气息声，强调喉音
混音: 声音靠前，压低音乐
```

## 五、Room Echo Matching 空间回声匹配

### 空间类型

| 空间 | 混响时间 | 声音特点 | 提示词 |
|------|---------|---------|--------|
| **密室** | 0.2-0.5s | 干/直接 | 密闭小空间 |
| **普通房间** | 0.5-1.0s | 自然 | 室内环境 |
| **大厅** | 1.5-2.5s | 空间感 | 大厅/走廊 |
| **教堂** | 2.5-4.0s | 空灵 | 宗教/庄严 |
| **洞穴** | 4.0s+ | 深邃/回响 | 洞穴/山谷 |

### 混响参数

| 参数 | 说明 | 范围 |
|------|------|------|
| **Pre-delay** | 直达声与混响的间隔 | 5-50ms |
| **Decay** | 混响衰减时间 | 0.2-4s |
| **Damping** | 高频衰减 | 控制明亮度 |
| **Wet/Dry** | 混响/干声比例 | 10-80% |

### 空间匹配规则

| 镜头景别 | 建议混响 | 说明 |
|---------|---------|------|
| 特写 | 0-10% Wet | 亲密/直接 |
| 中景 | 10-30% Wet | 自然 |
| 远景 | 30-50% Wet | 建立空间 |
| 大远景 | 50%+ Wet | 深邃空间 |

### AI配音空间提示词

```
【室内近景对话】
混响: 干声为主，10%房间混响
空间感: 亲密感

【室外远景】
混响: 自然环境混响，30% Wet
空间感: 开放

【洞穴场景】
混响: 长混响，Decay 3s
空间感: 空旷/神秘
```

## 六、Voice Performance Timing 表演节奏

### 台词节奏类型

| 类型 | 语速 | 停顿 | 使用场景 |
|------|------|------|---------|
| **急促** | 极快 | 无/短停顿 | 紧张/激动 |
| **正常** | 中速 | 正常停顿 | 标准对话 |
| **缓慢** | 慢 | 长停顿 | 思考/疲惫 |
| **断句** | 不规则 | 强调性停顿 | 戏剧性 |

### 停顿类型

| 类型 | 时长 | 效果 | 示例 |
|------|------|------|------|
| **呼吸停顿** | 0.3-0.5s | 自然 | 句子间 |
| **思考停顿** | 0.5-1.5s | 犹豫 | 回忆/思考 |
| **戏剧停顿** | 1.5-3s | 强调 | 关键信息前 |
| **沉默** | 3s+ | 紧张/悬疑 | 高潮/死亡 |

### 表演速度曲线

```
【愤怒爆发】
开始: 中速 → 渐快 → 极快 → 爆发 → 突然停止

【悲伤崩溃】
开始: 正常 → 渐慢 → 断续 → 长停顿 → 沉默

【紧张对峙】
全程: 不规则快慢交替 → 突然极慢 → 爆发
```

## 七、Performance Intensity 表演强度

### 强度等级

| 等级 | 表现 | 声音特点 | 使用场景 |
|------|------|---------|---------|
| **1** | 最低 | 几乎耳语 | 极私密/害怕被发现 |
| **2** | 低 | 轻声/气声 | 私密对话 |
| **3** | 中低 | 自然轻声 | 亲密对话 |
| **4** | 中 | 正常对话 | 标准对话 |
| **5** | 中高 | 强调 | 说服/激动 |
| **6** | 高 | 大声但不喊 | 争论/坚定 |
| **7** | 极高 | 喊叫边缘 | 愤怒/恐惧 |
| **8** | 最高 | 尖叫/喊叫 | 极度恐惧/痛苦 |

### 强度渐变

| 类型 | 描述 | 场景 |
|------|------|------|
| **渐强** | 1→4→7 | 愤怒积累/紧张升级 |
| **渐弱** | 7→4→1 | 崩溃/能量耗尽 |
| **波浪** | 4→6→4→7→4 | 情绪起伏 |
| **突然** | 4→7(无过渡) | 震惊/爆发 |

## 八、Subtext Communication 潜台词表达

### 潜台词类型

| 类型 | 字面vs实际 | 声音表现 |
|------|-----------|---------|
| **讽刺** | 表面积极，实际消极 | 音调下压/冷漠 |
| **暗示** | 表面陈述，实际请求 | 犹豫/期待 |
| **掩饰** | 表面平静，实际激动 | 过度控制/颤抖 |
| **矛盾** | 语言与内心相反 | 声音断裂/不协调 |

### 潜台词表演技巧

```
【场景：角色A说"我很好"，实际并不好】

字面表演: 正常语调说"我很好"
          → 听众可能相信

潜台词表演: 停顿（1s）→ 音调略微下降
          → "我很好" → 轻微叹息
          → 听众感到A在掩饰
```

### 潜台词检查

```
□ 角色说的是字面意思还是潜台词？
□ 声音是否传达了真实情感？
□ 听众能感受到字面下的含义吗？
□ 声音与文字是否形成对比？
```

## 九、Multi-Character Dialogue 多角色对话

### 多角色录音原则

| 原则 | 说明 |
|------|------|
| **角色区分** | 每个角色音色/语调明显区分 |
| **空间关系** | 根据屏幕位置调整音量/混响 |
| **层次分明** | 说话者清晰，旁白适当降低 |
| **情绪一致** | 同一角色在不同对话中情绪连贯 |

### 群戏录音技巧

| 类型 | 录音方式 | 混音处理 |
|------|---------|---------|
| **同时录音** | 多角色同时表演 | 分离困难 |
| **分角色录音** | 各自单独录音 | 灵活但需匹配 |
| **分组录音** | 2-3人同时 | 平衡两者 |

### 对话重叠处理

| 处理方式 | 使用场景 | 声音效果 |
|---------|---------|---------|
| **完全重叠** | 抢话/激动 | 自然但可能听不清 |
| **部分重叠** | 一个结束一个开始 | 自然过渡 |
| **完全不重叠** | 礼貌/正式 | 清晰但可能不自然 |

## 十、Quick Reference 快速参考

### 声音三要素

1. **音调** - 高低 → 情绪/年龄
2. **音量** - 大小 → 力量/距离
3. **节奏** - 快慢 → 性格/情绪

### 情感声音映射

| 情感 | 音调 | 节奏 | 其他 |
|------|------|------|------|
| 愤怒 | 低→高 | 快 | 压低/有力 |
| 悲伤 | 不稳定 | 慢→断续 | 气声 |
| 恐惧 | 高/尖锐 | 不规则 | 颤抖 |
| 喜悦 | 高 | 快 | 明亮 |
| 爱意 | 中/柔 | 慢 | 温暖 |

### 呼吸速查

| 情绪 | 呼吸 | 录音重点 |
|------|------|---------|
| 紧张 | 浅/快 | 气息声 |
| 平静 | 深/慢 | 稳定 |
| 恐惧 | 浅/快/喘息 | 喘息声 |
| 愤怒 | 深/快 | 喉音 |

### 空间混响速查

| 景别 | 混响 | 距离感 |
|------|------|--------|
| 特写 | 干声 | 近 |
| 中景 | 轻微 | 自然 |
| 远景 | 中等 | 远 |

### ADR检查清单

```
□ Room Tone采集完整？
□ 爆破音控制良好？
□ 距离感匹配画面？
□ 音调与现场录音一致？
□ 情绪与前后连贯？
□ 无人工痕迹？
```
