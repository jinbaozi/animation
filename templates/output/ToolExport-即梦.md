# Tool Export: 即梦/豆包

> 用途：从 Prompt Export IR 导出即梦/豆包可用视频提示词
> 语言：按项目配置，默认中文审阅友好格式

## 导出规则

- 不允许与 Visual Anchor IR 冲突。
- 时间分段按 `project-manifest.md` 的工具 profile 执行。
- 中文描述必须保留具体角色名，禁止代词。
- 镜头语言可保留必要英文术语，但正文以中文为主。

## 校验清单

- [ ] 每个字段来自 Prompt Export IR
- [ ] 人物资产卡中的特殊标记未遗漏
- [ ] 场景资产卡中的空间、光线、道具未遗漏
- [ ] 中英文或术语混用比例符合项目规则
