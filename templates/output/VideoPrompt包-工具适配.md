# 视频 Prompt 模板 - 工具适配篇

> 状态：v2.0 | 日期：2026-04-05
> **作用**：各AI视频生成工具的参数差异、专用适配、即查即用。
> **适用**：Phase 2b AI美术技术总监根据项目选用的工具进行适配。

---

## 一、Seedance 2.0 专用参数说明

### 1.1 基础参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 分辨率 | 720p / 1080p | 优先1080p |
| 画幅 | 16:9 / 9:16 | 竖屏内容优先9:16 |
| 时长 | 4-15 seconds | 优先15s |
| 模式 | Text-to-Video / Image-to-Video | 图生视频保持角色一致性 |

### 1.2 专用格式要求

> ⚠️ **Seedance 2.0 强制要求**

#### 头部格式

```markdown
【Core Focus】:[主要动作/主题]
【Style】:[电影质量、视觉风格、特效]
【Duration】:[X秒]
【Scene】:[场景描述]
```

#### 时间戳格式（必须使用冒号4位）

```markdown
[00:00-00:05] Shot 1: [镜头名称]
Visuals: [角色/场景描述]
Action: [动作细节]
Special Effects Details: [特效细节]
```

#### 技术规格（必须添加在末尾）

```markdown
---
720p
9:16
15 seconds
```

### 1.3 运镜参数

| 运镜类型 | 英文术语 | Prompt用法 |
|----------|---------|-----------|
| 推进 | Dolly In / Push In | `缓慢推近(dolly in)` |
| 后拉 | Dolly Out / Pull Back | `缓慢拉出(dolly out)` |
| 环绕 | Orbit / Arc Shot | `360度平滑环绕拍摄` |
| 横摇 | Pan | `从左至右缓慢横摇` |
| 跟拍 | Tracking Shot | `平滑云台跟拍(smooth gimbal tracking)` |
| 手持 | Handheld | `手持摄影微晃感(subtle handheld sway)` |
| 甩镜 | Whip Pan | `快速甩镜转场` |

### 1.4 特效参数

| 效果类型 | Prompt关键词 |
|----------|-------------|
| 粒子光效 | particle light effects |
| 动态模糊 | motion blur |
| 焦平面转换 | focus transition |
| 体积光 | god rays / volumetric light |
| 水下气泡 | underwater bubbles |
| 落叶旋转 | falling leaves swirling |
| 烛光摇曳 | candlelight flickering |
| 尘埃飘浮 | dust particles floating |

### 1.5 风格控制

> ⚠️ **Seedance 2.0 擅长物理模拟，提及物理交互可增强效果**

| 物理效果 | Prompt示例 | 效果 |
|----------|-----------|------|
| 风吹发丝 | `微风轻拂，发丝随风飘动` | 头发自然飘动 |
| 水花飞溅 | `水花四溅，气泡上浮` | 流体物理模拟 |
| 衣物垂坠 | `衣袂随动作自然下垂` | 布料物理模拟 |
| 尘埃飘浮 | `尘埃在光束中缓缓飘浮` | 粒子系统 |
| 烛光摇曳 | `烛焰摇曳，光影跳动` | 光影动态 |

### 1.6 Seedance 2.0 专用后缀

```
适配Seedance2.0生成，运动参数适中，转场用硬切，画幅严格9:16，输出无黑边
```

### 1.7 Prompt最佳实践

> ⚠️ **来源**：参考 [YouMind Seedance 2.0 Prompts](https://youmind.com/seedance-2-0-prompts)

| 原则 | 说明 | 示例 |
|------|------|------|
| 1. 明确场景描述 | 开场即建立环境 | `古风闺房内景，晨曦透过窗棂` |
| 2. 指定镜头运动 | 使用专业术语 | `缓慢推近(slow dolly in)` |
| 3. 定义光影氛围 | 精确光源描述 | `烛光从床头柜发出，暖黄色调` |
| 4. 添加主体细节 | 角色外貌/动作 | `沈清婉苍白面容，柳叶眉微蹙` |
| 5. 利用物理模拟 | 提及物理交互 | `风吹发丝，水花飞溅` |

### 1.8 镜头语言优先级

| 优先级 | 要素 | 原因 |
|--------|------|------|
| P0 | 主体+动作 | 视觉核心 |
| P1 | 镜头运动 | 画面动感 |
| P2 | 光影氛围 | 情绪基调 |
| P3 | 风格细节 | 美学统一 |

## 二、可灵 3.0 专用参数说明

### 2.1 基础参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 分辨率 | 1080p / 720p | 优先1080p |
| 画幅 | 9:16 / 16:9 | 竖屏优先 |
| 时长 | 5-10 seconds | 推荐5s |
| 模式 | 文生视频 / 图生视频 | 图生视频保持角色一致性 |

### 2.2 专用格式

#### 文生视频

```
[景别+视角]，[场景环境]，[角色外貌]，[动作/表情]，[光影]，[运镜指令]，[风格画质]
```

#### 图生视频

```
[主体关键特征]，[动作描述（含起止状态）]，[运镜指令]
```

### 2.3 运镜参数

| 运镜类型 | Prompt用法 |
|----------|-----------|
| 推进 | `推进镜头`、`推近` |
| 后拉 | `拉远镜头`、`后拉` |
| 横摇 | `平移`、`横摇` |
| 跟拍 | `跟拍`、`跟随` |
| 环绕 | `环绕`、`旋转` |
| 固定 | `固定镜头`、`机位不动` |

### 2.4 光影参数

| 参数 | 说明 | 示例值 |
|------|------|--------|
| 色温 | 光源色温值 | 4500K（白天）、1900K（烛光） |
| 光源类型 | 主光源种类 | 自然光/白炽灯/烛光/月光 |
| 补光比 | 主光与补光比例 | 2:1/4:1/8:1 |
| 光源方向 | 主光照射方向 | 顶光/侧光/正面光/逆光/底光 |
| 光质 | 光线软硬程度 | 硬光/柔光/散射光 |

### 2.5 可灵 3.0 专用后缀

```
适配可灵AI生成，镜头运动自然，避免过度晃动，画幅9:16安全区适配
```

### 2.6 镜头运动参数

| 运动强度 | 说明 | 适用场景 |
|----------|------|---------|
| 微弱 | 轻微移动 | 特写、近景 |
| 适中 | 自然跟拍 | 对话、中景 |
| 强烈 | 大幅度运动 | 动作、追逐 |

## 三、即梦 专用参数说明

### 3.1 基础参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 分辨率 | 1080p / 720p | 优先1080p |
| 画幅 | 9:16 / 16:9 | 竖屏优先 |
| 时长 | 3-10 seconds | 推荐5s |
| 模式 | 文生视频 / 图生视频 | 支持@引用语法 |

### 3.2 @引用语法

| 语法 | 说明 | 示例 |
|------|------|------|
| @[角色标签] | 引用已上传角色参考图 | `@沈清婉` |
| @[场景标签] | 引用场景参考图 | `@闺房场景` |
| @[动作视频标签] | 引用动作参考视频 | `@行走动作` |
| @[音频标签] | 引用参考音频 | `@背景音乐` |

### 3.3 即梦 基础格式

```
[景别]，[场景环境]，[角色描述]，[动作]，[光影]，[运镜]，[风格]
```

### 3.4 即梦 完整示例

【镜头2】古风闺房，特写面部，

## 六、工具选择建议

### 6.1 按场景类型选择

| 场景类型 | 推荐工具 | 原因 |
|----------|----------|------|
| 动作戏/打斗 | Seedance 2.0 | 物理模拟强，动作流畅 |
| 情感戏/特写 | 即梦 | 人脸清晰，情感表达好 |
| 对话场景 | 可灵 3.0 | 稳定性好，节奏可控 |
| 奇幻特效 | Seedance 2.0 | 粒子特效强 |
| 日常氛围 | 可灵 3.0 | 自然感强 |

### 6.2 按时长选择

| 时长 | 推荐工具 |
|------|----------|
| 4-6s | 可灵 3.0 / 即梦 |
| 7-12s | 所有工具均可 |
| 12-15s | Seedance 2.0（推荐） |

### 6.3 按一致性要求选择

| 一致性要求 | 推荐工具 | 方法 |
|------------|----------|------|
| 高（角色不变） | 即梦 | @引用角色图 |
| 高（角色不变） | Seedance 2.0 | Image-to-Video |
| 中等 | 可灵 3.0 | 图生视频 |
| 低 | 所有工具 | 文生视频 |
