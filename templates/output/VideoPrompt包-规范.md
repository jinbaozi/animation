> 状态：v2.0 | 日期：2026-04-05
> **作用**：VideoPrompt 生成的强制规范、规则全集、字段标准。
> **适用**：Phase 2b AI美术技术总监执行阶段。

---

> **增强版**：本模板支持双平台（可灵/即梦）输出，包含表演调度规则和完整Prompt工程规范。

## 〇.5、动作/内心活动/台词三选一规则（铁律）

> ⚠️ **每个时间分段必须包含「动作/内心活动/台词」三选一，但内心活动与台词不可同时保留**

### 规则说明

| 场景类型 | 选择 | 原因 |
|---------|------|------|
| 动作戏/打斗戏 | **保留台词** | 台词更有张力，对话推动剧情 |
| 情感戏/内心戏 | **保留内心活动** | 内心活动更深刻，表达心理挣扎 |
| 悬疑惊悚 | **保留台词或内心活动** | 根据剧情张力需要选择 |
| 对话场景 | **保留台词** | 对话是核心叙事载体 |
| 独白内心戏 | **保留内心活动** | 内心独白是本质 |
| 日常治愈系 | **保留台词或内心活动** | 根据情绪氛围选择 |
| 蒙太奇转场 | **保留内心活动** | 省略对白，强调情绪节奏 |
| 奇幻视觉奇观 | **保留台词或内心活动** | 根据是否需要解说选择 |

### 禁止情况

| 错误类型 | 示例 | 问题 |
|---------|------|------|
| 同时保留内心活动和台词 | `内心活动：她很悲伤` + `台词："我很难过"` | 信息冗余，节奏拖沓 |
| 只有动作没有台词或内心活动 | 只有动作描述，无角色表达 | 缺少角色声音/心理 |

### 正确格式

```
0-3s：
  动作：沈清婉猛然睁眼，水下气泡模糊镜头，身体挣扎
  内心活动：窒息感、恐惧、拼命想浮上去
  台词：（无声，水下）

或（根据场景类型二选一）：

0-3s：
  动作：沈清婉猛然睁眼，水下气泡模糊镜头，身体挣扎
  内心活动：窒息感、恐惧、拼命想浮上去
  台词：（无）

或：

0-3s：
  动作：沈清婉猛然睁眼，水下气泡模糊镜头，身体挣扎
  台词：（无声，水下）
```

### 检测机制

在执行质量检查时：
- 每个时间分段必须明确标注「动作/内心活动/台词」三选一
- 内心活动和台词同时出现 → 报错
- 只有动作且无角色表达 → 报错

## 一、多镜头整合规则（12-15s）

### 整合原则

| 时长 | 镜头数 | 场景类型 |
|------|--------|----------|
| 12s | 4个镜头 | 对话/动作 |
| 15s | 5个镜头 | 情感/悬疑 |

### 镜头序列模板

| 顺序 | 景别 | 时长 | 镜头类型 | 叙事功能 |
|------|------|------|----------|----------|
| 1 | Wide/中景 | 3s | 建立 | 开场钩子 |
| 2 | 中景/近景 | 3s | 推进 | 叙事发展 |
| 3 | 近景/特写 | 3s | 核心 | 情绪/动作高潮 |
| 4 | 中景/近景 | 3s | 收尾 | 结尾钩子/过渡 |
| 5（可选） | Wide/中景 | 3s | 尾声 | 承上启下 |

### 镜头衔接规则

```
镜头1结束动作 → 镜头2起始动作：必须连贯
镜头2结束状态 → 镜头3起始状态：情绪/动作递进
镜头N落幅 → 镜头N+1起幅：构图/视线/运动方向呼应
```

## 二、人物名称规范（铁律）

### 禁止使用

| 错误写法 | 问题 |
|----------|------|
| 年轻女子 | 代词，不明确 |
| 他/她/他们 | 指代不明 |
| 主角/配角 | 过于笼统 |
| 那个人 | 无法识别 |

### 正确写法

| 正确写法 | 说明 |
|----------|------|
| 沈清婉紧闭双眼 | 具体人名+动作 |
| 林逸辰缓缓转头 | 具体人名+动作 |
| 苏晚晴手指颤抖 | 具体人名+动作 |

### 人名库示例

```
男性角色：林逸辰、顾北辰、沈墨白、萧云霆、叶北冥
女性角色：沈清婉、苏晚晴、林婉清、白晚吟、叶倾颜
反派角色：夜无痕、冥渊、血刹、冷夜寒
```

## 三、Seedance 2.0 Prompt模板基础

### 模板结构

```markdown
# 第{X}集 完整视频 Prompt（12-15s）

## 基础信息

| 字段 | 内容 |
|------|------|
| 集数 | 第{X}集 |
| 序列数 | 3个 |
| 总时长 | 45s（3序列×15s） |
| 场景 | {场景名} |
| 主要人物 | {人名1}、{人名2} |
| 场景类型 | 对话场景/动作戏/情感戏/悬疑惊悚/蒙太奇/独白内心戏/奇幻/日常 |
| 上游继承 | 见"上游集尾关键帧继承"章节 |

## 上游集尾关键帧继承（强制章节）

> ⚠️ **本章节必须填写**，用于确保当前集与上一集的画面连续性，避免跳帧/穿帮

### 继承检查清单

```
□ 人物服装是否与上一集结尾一致？
□ 发髻/发饰是否保持不变或有合理变化？
□ 场景光线是否自然延续（如从白天到傍晚需有过渡）？
□ 人物位置是否合理（不可能瞬间移动）？
□ 情绪是否自然延续（不能突然从高兴变悲痛）？
□ 关键道具是否继承（上一集拿着的扇子还在吗）？
```

### 连续性技术参数

| 参数 | 继承要求 | 说明 |
|------|----------|------|
| 色温继承 | ±500K | 与上一集结尾色温保持一致或微调 |
| 光线方向 | 保持一致 | 光源方向需符合物理逻辑 |
| 构图角度 | 呼应/延续 | 落幅与起幅构图需有视觉呼应 |
| 运动方向 | 顺延 | 人物运动方向需与上集结尾连贯 |

## 四、表演调度规则

### 铁律：消灭抽象情绪词

| 抽象词 | 物理描述 |
|--------|---------|
| 悲伤 | 眉头紧锁，眼眶泛红，嘴角向下拉，下颌微颤 |
| 愤怒 | 眉毛向内挤压，鼻翼张开，牙关紧咬 |
| 惊讶 | 眉毛高扬，眼睛睁大到看见完整虹膜，嘴唇微张 |
| 自然站立 | 双脚与肩同宽，脊柱挺直，重心均匀分布 |
| 强忍泪水微笑 | 嘴角向上拉出弧度但僵硬，眼眶泛红，眉头微挑 |
| 害怕 | 身体后仰，肩膀收缩，瞳孔放大，呼吸急促 |
| 紧张 | 手指无意识摩挲，吞咽动作频繁，视线游离 |

### 表演调度字段

- 面部：[表情的物理描述]
- 肢体：[身体朝向、重心、手部状态]
- 视线：[看向何处，焦点实/虚]
- 微动作：[呼吸、吞咽、眨眼频率]

## 九、强制连贯性规则（P0 强制）

> ⛔ **【P0强制标志】本章节所有规则均为P0级别禁止违规，违规则输出作废**

### 9.1 落幅→起幅强制衔接格式

**每个序列输出时，必须在开头包含「序列衔接信息」页**：

```markdown
## 序列衔接信息

**[本序列落幅]**（上一序列结束时画面）
- 沈清婉位置：床头 / 窗边软榻 / 站立
- 沈清婉服装：月白中衣 / 淡青外衫披着 / 外衫褪至腰间
- 光线/时间：[时间段]，色温[K]
- 重要道具状态：（手中持何物 / 床边有何物）
- 表情状态：平静 / 警觉 / 闭眼假寐
- 视线方向：望向窗外 / 低垂 / 闭目
- 春桃位置：床边 / 门边 / 梳妆台旁

**[下一序列起幅]**（本序列开始画面）
- 必须与上述落幅完全一致
- 仅允许：表情微变化、光线色温微调（±500K）
- 禁止：位置突变、服装突变、道具消失
```

### 9.2 道具状态追踪机制（⛔P0强制）

> ⛔ **每个序列输出时必须包含「道具状态链」，禁止遗漏**

**道具状态链格式**：

```markdown
## 道具状态链

| 道具 | 序列N开始 | 序列N结束 | 持有者变化 | 状态备注 |
|------|----------|----------|-----------|---------|
| 茶杯 | 春桃端着 | 沈清婉接过放床头柜 | 春桃→沈清婉→床头柜 | 茶水微温 |
| 药碗 | 沈清柔带来 | 沈清婉还给春桃 | 沈清柔→沈清婉→春桃 | 药已尽 |
```

**⛔P0强制规则**：
1. ⛔道具易手时必须有明确动作（"递给"、"接过"），禁止凭空出现
2. ⛔禁止道具在无交代情况下突然出现在某人手中
3. ⛔序列内道具状态变化必须标注
4. ⛔关键道具（药碗、茶杯）必须有完整来源→传递→去向链条
5. ⛔道具消失后再次出现必须说明原因

### 9.3 物理动作连续性规则（⛔P0强制）

> ⛔ **物理动作必须有起点→过程→终点，禁止动作跳跃**

**⛔禁止的物理逻辑错误**：

| 错误类型 | 违规示例 | 正确示例 |
|---------|---------|---------|
| 凭空持物 | 前镜头放手，后镜头直接端碗 | 放下→手空→再拿取（另一物） |
| 位置跳跃 | 床边站→突然门口 | 床边→走向门边→门口（需移动过程） |
| 动作中断 | 抬手一半→突然放下 | 抬手→停顿→放下（需完整弧线） |
|视线跳切 | 看左→突然看右 | 看左→平移视线→看右（需过渡） |

**时间段→光源强制对照表**：

| 时间段 | 允许光源 | 禁止光源 | 色温范围 |
|--------|---------|---------|---------|
| 清晨(6-9点) | 柔和日光、晨曦散射光 | 烛光、深夜氛围 | 4500K-5500K |
| 上午(9-12点) | 明亮日光、窗光斜照 | 烛光、昏暗 | 4500K-5600K |
| 午后(12-15点) | 午后日光、侧窗光 | 烛光（除非有室内点燃说明） | 4500K-5500K |
| 下午(15-18点) | 傍晚暖光、斜阳 | 烛光（除非有说明） | 3200K-4500K |
| 黄昏(18-20点) | 晚霞余晖、橙红光 | 明亮日光 | 2500K-3500K |
| 夜间(20-6点) | 月光、烛光、灯笼 | 日光 | 1900K-2200K |

**烛光使用额外规则**：
- 日间室内场景禁止使用烛光（除非有"室内已点灯"说明）
- 早晨刚醒场景：可用微弱晨光，不用烛光
- 午后窗光充足时：禁止点蜡烛

### 9.4 情绪递进设计要求

**揭露/觉醒等重大情绪转变必须分阶段呈现**：

```markdown
## 情绪递进设计（重大情绪场景必须填写）

**示例：揭露真相场景（18s）**

| 时间段 | 情绪 | 内心活动 | 物理表现 |
|--------|------|---------|---------|
| 0-4s | 惊愕 | （是她...） | 手指微微收紧 |
| 4-8s | 愤怒压抑 | （原来如此...这些年...） | 手指攥紧，眉头紧锁 |
| 8-12s | 痛苦 | （连大夫都不让请...） | 眼眶微红，闭眼深吸气 |
| 12-15s | 冷静决断 | （现在不是时候...） | 手指松开，睁眼冷凝 |
| 15-18s | 隐忍待机 | （记住了...） | 沉静如水，目光冷凝 |
```

**禁止的情绪跳跃**：
- ❌ 直接从"愤怒"跳到"决断"（无压抑过程）
- ❌ 直接从"困惑"跳到"坚定"（无觉醒过程）
- ❌ 直接从"悲痛"跳到"微笑"（无接受过程）

### 9.5 警觉触发链设计

**当角色产生警觉/警惕时，必须有渐进触发过程**：

```markdown
## 警觉触发链（出现警觉情绪时必须填写）

**示例：发现有人接近**

| 阶段 | 时间 | 表现 | 内心活动 |
|------|------|------|---------|
| 感知 | 0-1s | 眉头微蹙 | （有人在靠近...） |
| 判断 | 1-2s | 目光游移向门口 | （脚步声...是谁？） |
| 确认 | 2-3s | 眼神变得警觉 | （来者不善...） |
| 决策 | 3-4s | 决定装睡/回避 | （不能被发现...） |
```

**禁止的警觉跳跃**：
- ❌ 前一秒平静，下一秒突然"眼神警觉望向门外"（无感知过程）
- ❌ 无任何音效/脚步声暗示，直接警觉

## 十、常见跳跃式错误图谱

### 10.1 警觉触发链缺失（高频错误）

**错误模式**：直接跳到警觉结果，跳过感知和判断过程

```
❌ 错误模式：
0-3s：沈清婉平静喝茶
3-6s：沈清婉突然警觉望向门外（跳跃！缺少感知过程）

✅ 正确模式：
0-2s：眉头微蹙（感知异常）
2-4s：目光游移向门口（判断）
4-6s：眼神变得警觉（确认）
6s+：决定装睡/回避（决策）
```

### 10.2 情绪突变缺失过渡（高频错误）

**错误模式**：情绪从A直接跳到D，跳过B和C

```
❌ 错误模式：
揭露真相场景：
  0-4s：愤怒
  4-8s：（无内容）
  15-18s：冷静决断（跳跃！缺少压抑和接受过程）

✅ 正确模式：
0-4s：惊愕（是她...）→ 手指微微收紧
4-8s：愤怒压抑（原来如此...）→ 手指攥紧，眉头紧锁
8-12s：痛苦（好狠的心...）→ 眼眶微红，闭眼深吸气
12-15s：冷静决断（现在不是时候...）→ 手指松开，睁眼冷凝
```

### 10.3 道具凭空出现/消失（高频错误）

**错误模式**：道具在无交代情况下出现在某人手中或消失

```
❌ 错误模式：
序列1：春桃端着茶杯入室
序列2：沈清婉端起床边药碗（茶杯呢？凭空消失？）

✅ 正确模式：
序列1：春桃端着茶杯入室
序列1续：沈清婉接过茶杯放在床头矮几
序列2：沈清婉端起床边药碗（茶杯在矮几上，有交代）
```

### 10.4 位置瞬间移动（高频错误）

**错误模式**：角色从一个位置瞬间跳到另一个位置

```
❌ 错误模式：
序列1：春桃站在床边
序列2：春桃端茶杯小心翼翼走近（从床边到端茶杯？位置没变）

✅ 正确模式：
序列1：春桃站在床边
序列2：春桃从床边起身，走向梳妆台取茶杯...
序列3：春桃端茶杯小心翼翼走近
```

### 10.5 身份突然揭示（高频错误）

**错误模式**：监视者/反派身份最后突然揭示，观众无法预判

```
❌ 错误模式：
全程婆子行为像正常探望，直到离开才揭露是监视

✅ 正确模式：
0-4s：婆子探头张望 → 特写眼神游移（不是关切，是审视）
4-8s：春桃挡在床前 → 春桃表情紧张（确认有威胁）
8-11s：婆子环顾屋内 → 镜头扫过陈设（暗示在确认什么）
11-14s：婆子离开 → 内心活动：（完成监视）
```

### 10.6 计划模糊表达（高频错误）

**错误模式**：角色说"如此如此"，观众完全不知道计划内容

```
❌ 错误模式：
台词：（低声）"如此如此..."
问题：观众完全不知道计划内容

✅ 正确模式：
台词：（低声）"明日在亭子里...这般这般..."
内心活动：（眼中闪过聪慧光芒）
动作：手指在被上轻点（如画圈暗示布局）
```

### 10.7 光源矛盾（高频错误）

**错误模式**：日间场景出现烛光或夜间场景出现日光

```
❌ 错误模式：
午后室内场景：
  光源：窗外芭蕉叶轻动，午后柔和日光从窗棂透入
  同时：低位烛光，补光比8:1（矛盾！午后不应有烛光）

✅ 正确模式：
午后室内场景：
  光源：窗外侧光、窗光斜照、午后日光
  色温：4500K-5500K
```

### 10.8 物理动作中断（高频错误）

**错误模式**：动作有起点无终点，或中断后转向另一动作

```
❌ 错误模式：
抬手一半→突然放下（动作中断，无完整弧线）

✅ 正确模式：
抬手→停顿（犹豫）→放下（决策）
或者：
抬手→举拳（改变方向，需要说明原因）
```
