# 静态图 Prompt 模板

> **重要规范**：
> - 所有分镜尽量按照 **3s** 时长设计
> - 连续长镜头展示可适当增加时长（最长不超过5s）
> - 12-15s 视频通常包含 **4-5个分镜**
> **国风动漫**：须与《风格锁定确认书》及 [`古风国漫Prompt锚点与负面附录.md`](../../reference/古风国漫Prompt锚点与负面附录.md) 一致；**禁止**与确认书矛盾的「影视质感、古风写实」等表述。

### 注意事项

1. **分镜连贯性**：确保相邻分镜的人物位置、场景布局、光影方向一致
2. **时长分配**：优先使用3s，特殊场景（长镜头展示/高潮）可延长至4-5s
3. **Prompt可复制性**：每个分镜输出完整Prompt，可直接粘贴到nano banana等工具使用
4. **负面Prompt统一**：可使用统一的负面Prompt清单，减少重复
