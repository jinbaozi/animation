# 场景资产卡

> **重要**：本模板输出的Prompt可直接复制到 nano banana 等文生图工具中使用
>
> ⚠️ **强制要求**：建筑/道具/装饰必须符合Phase 0"小说背景设定"中的世界观

## 时代背景约束（必须遵守）

```
根据小说背景设定，确定以下内容：

- 建筑风格：[如：木质结构/飞檐翘角/雕梁画栋]
- 道具风格：[如：铜镜/妆奁/瓷器/书画]
- 装饰风格：[如：屏风/帷幔/灯笼/香炉]

禁止出现：
✗ 现代建筑（钢筋混凝土/玻璃幕墙）
✗ 现代物品（电灯/空调/塑料制品）
✗ 时代错配（唐代场景出现清代家具）
```

## 使用说明

1. **建立时机**：在Phase 2阶段，为每个主要场景建立资产卡
2. **关键物件**：标注必须出现在画面中的道具/家具/地标
3. **光源设定**：明确主光源类型、方向和色温，确保光影一致性
4. **动态环境**：描述持续运动的元素，增加场景真实感
5. **平台上传**：将生成的参考图上传至可灵Elements/即梦素材库

## 示例

```
═══════════════════════════════════════
场景资产卡：丞相府书房
═══════════════════════════════════════
【空间结构】
  类型：室内
  尺度感：典雅庄重
  主要特征：雕花木门，竹简书卷，青铜灯台，屏风隔断

【关键物件】
  物件1：红木书案，摆满竹简书卷
  物件2：青铜灯台，位于书案一侧
  物件3：山水屏风，位于房间尽头

【光源设定】
  主光源：青铜灯台（烛光）
  光源方向：从低处向上投射，形成柔和暖光效果
  色温倾向：暖黄色，烛光摇曳

【色彩氛围】
  主色调：暖黄
  辅助色：朱红、墨绿、玉白
  特殊处理：整体色调温润，营造雅致氛围

【动态环境】
  天气/时间：室内有雕花窗透入柔和日光，时间为白昼
  持续运动元素：烛火轻轻摇曳，空气中可见细微尘埃在光束中飘浮

【参考图Prompt】
  全景：典雅室内场景，雕花木门，竹简书卷，青铜灯台，山水屏风，烛光从低处投射，暖黄色光源，空气中可见尘埃颗粒，暖黄色调，高雅氛围
  中景（角色站位参考）：室内中景，红木书案位于画面中心，角色站立位置参考，烛光从侧方照射，面部有柔和阴影，背景虚化，动画光影

【平台引用标签】
  可灵Elements：[上传后填写]
  即梦@标签：[上传后填写]
═══════════════════════════════════════
```
