## 2. 时代与场景锚点（分镜/视频 Prompt 勾选）

填写时至少勾选 **建筑层级 + 室内陈设 + 照明**，与小说时代一致。

### 2.1 建筑与空间

| 维度 | 可选锚点（择一或组合） |
|------|------------------------|
| 形制 | 歇山顶/庑殿顶/硬山顶民居、白墙黛瓦、夯土边墙、园林月洞门、廊桥 |
| 铺装 | 青石板、碎石路、木板回廊、方砖漫地 |
| 禁忌 | 日式鸟居·神社、韩式屋脊、哥特尖拱、西式城堡主楼、现代玻璃幕墙大厦 |

### 2.2 家具与器物

| 类别 | 锚点示例 |
|------|----------|
| 灯具 | 宫灯、灯笼、烛台、油灯；**忌**水晶吊灯、现代吸顶灯 |
| 陈设 | 屏风、案几、罗汉床、妆奁、铜镜、瓷瓶、书卷 |
| 禁忌 | 现代沙发、塑料椅、电脑、手机（除非剧本明确穿越/现代戏） |

### 2.3 时代一致性

所有锚点须与 **AI 内容总导演** 给定朝代/架空设定一致；冲突时以人设表与世界观为准。

## 4. 负面附录（文生图 / 视频通用摘要）

**说明**：下列为摘要表；与 [`场景基准模版.md`](场景基准模版.md)「负面强约束」及品控「禁止词」**不得矛盾**。若确认书禁止「影视质感」，则下表**不得**与「电影感、摄影级」等混用。

## 5. Seedance 2.0 时间戳格式（⚠️ 2026-04-03 强制规则）

> **来源**：女帝虚空技能释放v1.0实操失败经验
> **问题**：`[0-2s]`、`[3-6s]` 等格式为人类可读格式，Seedance 2.0 不识别，只生成首帧
> **修复**：必须使用 `[0:00-0:03]` 冒号分隔的4位时间戳格式

### 5.1 错误格式（禁止使用）

```
[0-3s]          ← AI不识别，视为普通文本
[3-6s]          ← AI不识别，视为普通文本
[6-9s]          ← AI不识别，视为普通文本
```

### 5.2 正确格式（强制使用）

```
[0:00-0:03]     ← Seedance 2.0 有效时间戳
[0:03-0:06]     ← 冒号 + 4位数字
[0:06-0:10]
[0:10-0:13]
[0:13-0:15]
```

### 5.3 每段必须包含的内容

每个时间戳段内，**必须分行**明确以下要素：

```
[0:00-0:03]
镜头：[景别]+[运镜方式]+[运动速度]
动作：[具体物理动作描述，使用现在时态]
```

**禁止**：只写动作不写镜头，或只写镜头不写动作。

### 5.4 失败案例与修复对照

| v1.0（失败） | v2.0（正确） |
|-------------|-------------|
| `0-2s：凝视蓄力` | `[0:00-0:03]` |
| `动作：女帝垂眸凝视...` | `镜头：中景固定机位，缓慢推近（dolly in）` |
| （无时间戳格式） | `动作：女帝垂眸凝视太极阵图，指尖悬于阵眼上方...` |
| 镜头动作混写一整段 | 镜头+动作**分行**明确 |

## 6. 镜头术语中英 → 中文落版（供即梦/可灵）

内部设计可用英文术语，**写入模型 Prompt 时建议采用中文或下列对照**。

| 英文/缩写 | 中文落版（示例） |
|-----------|------------------|
| Wide Shot | 全景/大远景，交代环境 |
| Medium Shot | 中景，半身 |
| Close-up | 特写，面部或关键道具 |
| OTS (Over-the-Shoulder) | 过肩镜头，自 A 肩后拍 B |
| Dolly In / Push In | 缓慢推近 |
| Dolly Out / Pull Out | 缓慢拉远 |
| Pan | 摇镜，水平扫过 |
| Tilt | 俯仰摇镜 |
| Crane / Boom | 升降镜头，自低至高 |
| Tracking / Follow | 跟拍，随人物移动 |
| Fixed / Static | 固定机位 |
| Rack focus | 移焦，前清后糊或相反 |
