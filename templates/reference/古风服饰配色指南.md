## 二、朝代服饰特征

### 2.1 秦汉时期

**特征**：深衣为主，曲裾绕襟
**色彩**：
- 皇室：赤、黄为主
- 官员：青、黑为主
- 百姓：麻布素色

**Prompt关键词**：
```
曲裾深衣，绕襟三层，衣袖宽大
赤色曲裾，深衣蔽体
```

### 2.2 魏晋南北朝

**特征**：宽衣博带，飘逸脱俗
**色彩**：
- 士族：白、黑为主
- 女子：浅色为主

**Prompt关键词**：
```
宽衣博带，褒衣博袍
白衣飘飘，羽衣仙风
```

### 2.3 隋唐时期

**特征**：雍容华贵，胡汉融合
**色彩**：
- 皇室：大红、紫、金为主
- 贵族：多彩绚烂
- 女子：石榴裙、齐胸襦裙

**Prompt关键词**：
```
齐胸襦裙，石榴红裙
圆领袍，幞头
半臂，披帛
```

### 2.4 宋代

**特征**：清雅含蓄，简约内敛
**色彩**：
- 皇室：红、紫为主
- 士大夫：青、白为主
- 女子：淡雅青绿

**Prompt关键词**：
```
对襟襦裙，颜色淡雅
圆领袍，文雅
抹胸，宋裤
```

### 2.5 明代

**特征**：端庄华丽，制度严格
**色彩**：
- 皇室：明黄、大红
- 官员：绯、青、绿
- 女子：袄裙、比甲

**Prompt关键词**：
```
交领袄裙，马面裙
比甲，披风
补服，圆领袍
```

### 2.6 清代

**特征**：旗装为主，满汉融合
**色彩**：
- 皇室：明黄、大红
- 官员：朝服色彩严格
- 女子：旗装、汉装并行

**Prompt关键词**：
```
旗装，旗髻，旗鞋
坎肩，马褂
云肩，挽袖
```

## 五、身份穿搭公式

### 5.1 相府嫡女

**公式**：
```
主色（淡色）+ 辅色（浅紫/浅蓝）+ 点缀（白玉）
```

**示例**：
```
淡青色交领襦裙，外披浅紫色披帛
手腕戴白玉镯，耳坠明珠
```

### 5.2 相府庶女

**公式**：
```
主色（鲜艳但不过明）+ 辅色（粉/黄）+ 点缀（金）
```

**示例**：
```
鹅黄色对襟襦裙，粉色披帛
金步摇，耳坠金珠
```

### 5.3 贴身丫鬟

**公式**：
```
主色（青/浅绿）+ 辅色（深青）+ 无点缀/朴素
```

**示例**：
```
青色比甲，浅绿色中衣
无复杂配饰，朴素
```

### 5.4 大家闺秀

**公式**：
```
主色（沉稳）+ 辅色（深色）+ 点缀（翡翠/玉）
```

**示例**：
```
深紫色袄裙，黑色披风
翡翠禁步，玉簪
```

### 5.5 少年公子

**公式**：
```
主色（白/青）+ 辅色（浅蓝）+ 点缀（玉佩）
```

**示例**：
```
白色圆领袍，浅蓝色披帛
玉冠，腰佩玉环
```

### 5.6 中年官员

**公式**：
```
主色（深色）+ 辅色（官服色）+ 点缀（乌纱）
```

**示例**：
```
绯红色官服，青色外套
乌纱帽，补服
```

## 十一、正色与间色（颜色等级体系）

### 11.1 正色（五正色）

中国古代将五种颜色视为"正色"，象征正统与尊贵：

| 正色 | 象征 | 地位 | 适用 |
|------|------|------|------|
| 青（绿） | 东方、春季、生命 | 高贵 | 王公贵族 |
| 赤（红） | 南方、夏季、喜庆 | 尊贵 | 皇室、婚礼 |
| 黄 | 中央、秋季、权威 | 最高 | 皇帝专用 |
| 白 | 西方、纯洁 | 尊贵 | 皇室、丧服 |
| 黑（玄） | 北方、冬季、严肃 | 庄重 | 官员、祭祀 |

### 11.2 间色（混合色）

间色由两种正色混合而成，地位低于正色：

| 间色 | 构成 | 适用 |
|------|------|------|
| 绿 | 青+黄 | 平民常见 |
| 紫 | 赤+青 | 高官显贵 |
| 红（粉红） | 赤+白 | 女子、婚礼 |
| 碧 | 青+黑 | 官员 |
| 绛 | 赤+黑 | 贵妇 |

### 11.3 颜色等级穿着规则

```
【正色使用规则】
✓ 五爪龙纹 → 皇帝（明黄）
✓ 五爪蟒纹 → 亲王（紫色系）
✓ 四爪蟒纹 → 郡王（蓝色系）
✓ 仙鹤纹 → 一品文官（紫色）
✓ 锦鸡纹 → 二品文官（红色系）

【间色使用规则】
✓ 紫色 → 三品以上官员
✓ 绿色 → 五品以上官员
✓ 蓝色 → 七品以上官员
✓ 青色 → 平民可穿
```
