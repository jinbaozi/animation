## 二、禁止关键词（正则匹配）

### 影视类禁止词

```
影视|电影|摄像|胶片|摄影
```

### 写实类禁止词

```
古风写实|写实CG|游戏CG|影视质感
影视级|电影级|影视级画质|电影级渲染
```

### 真人感禁止词

```
真人皮肤|真实脸型|摄影级画质
```

## 四、8K使用规范

| 场景 | 推荐表述 | 禁止表述 |
|------|---------|---------|
| 国风动漫项目 | `动漫级质感` | `8K超高清` |
| 场景描述 | `高清` | `8K` |
| 通用 | `高质量` | `8K` |

**例外**：仅在明确输出到8K显示设备时才使用`8K`一词。
