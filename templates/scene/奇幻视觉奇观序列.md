# 奇幻视觉奇观序列

> **格式说明**：奇幻视觉使用标准分镜表格式（参见镜头序列模板.md），支持"外化方案"、"名台词/金句"列。

## 相关知识库

> ⚠️ **必读补充**：`Seedance2导演级运镜库.md` 中对应章节：
> - `魔法释放镜头` - 从手部特写极速向后拉远展现爆炸全景
> - `终极技拉升镜头` - 镜头极速向后上方拉升展现技能全貌
> - `维度折叠镜头` - 城市空间向上折叠弯曲
> - `分身残影镜头` - 运动残影，主体身后留下半透明重影
> - `水中慢动镜头` - 水下慢动作，带有高阻力运动感
> - `变身环绕镜头` - 快速环绕跟拍记录角色变身过程
> - `隧道穿越镜头` - 镜头在光影隧道中极速穿梭

## 核心原则

1. **风格锁定**：同一场景所有镜头必须追加统一的风格后缀，防止AI生成风格不一致
2. **仪式感引入**：超自然元素不能凭空出现，需要从正常世界渐进过渡
3. **尺度参照**：任何巨大/壮观的元素必须有人类尺度参照物

## 风格锁定后缀库

每个场景选择一个后缀，追加在每个镜头Prompt末尾，中途不得切换。

**古风国漫主项目**：优先使用下表「东方仙侠 / 国风玄幻」类；**禁止**在未立项为西幻支线时套用「西方奇幻、哥特、赛博」等后缀。详细锚点见 [`../../reference/古风国漫Prompt锚点与负面附录.md`](../../reference/古风国漫Prompt锚点与负面附录.md)。

| 风格 | 后缀 |
|------|------|
| 东方仙侠 | Chinese xianxia style, ethereal mist, jade and gold color palette, flowing silk ribbons, ink wash painting atmosphere, divine light rays |
| 国风玄幻（中文落版优先） | 中式玄幻，灵气质感，符箓纹样，丹火或剑气轨迹，青绿与朱砂配色，水墨晕染氛围，非西式魔法阵 |
| 西方奇幻 | Western high fantasy, medieval stone architecture, dramatic volumetric lighting, rich jewel tones, epic scale, detailed metalwork |
| 硬科幻 | Hard sci-fi aesthetic, clean geometric surfaces, holographic blue interfaces, minimalist architecture, sterile white lighting, chrome and glass |
| 赛博朋克 | Cyberpunk aesthetic, neon glow, rain-slicked streets, holographic advertisements, dense urban layering, magenta and cyan color scheme |
| 暗黑哥特 | Dark gothic aesthetic, dramatic chiaroscuro lighting, stone and iron textures, deep shadows, blood red and midnight blue accents, cathedral architecture |
| 梦幻超现实 | Surreal dreamscape, impossible geometry, soft pastel colors, floating elements, defying gravity, ethereal glow, painted quality |

### 中式玄幻正向词库（写入 Prompt 时优先）

符箓、剑诀、手印、灵气、灵力、丹火、剑气、阵纹（中式几何/八卦意象）、法宝、灵兽、劫云、天劫、洞天福地、结界（中式光幕，非六芒星阵）

### 西式奇幻负面提示（古风国漫项目）

在负面 Prompt 中追加（按需）：六芒星法阵、哥特尖拱大教堂、典型西式魔杖咒语特效、水晶球占卜（西幻范式）、精灵尖耳族群（非设定时）等——**与** [`古风国漫Prompt锚点与负面附录.md`](../../reference/古风国漫Prompt锚点与负面附录.md) §4 并用。

### 风格选择指南

- 东方仙侠 / 国风玄幻：修仙、古风、仙法、符箓、丹道、剑修
- 西方奇幻：骑士、魔法、史诗（**仅**剧本明确西幻世界时）
- 硬科幻：未来科技、太空、机器人
- 赛博朋克：都市、霓虹、人工智能
- 暗黑哥特：恐怖、吸血鬼、哥特
- 梦幻超现实：梦境、童话、意识流

## 超自然元素引入（四阶段）

### 阶段定义

| 阶段 | 名称 | 时长 | 内容 |
|------|------|------|------|
| 1 | Normal_World | 5-15s | 正常世界，建立基线，写实风格自然光 |
| 2 | First_Sign | 3-8s | 异常元素特写，角色注意到异常 |
| 3 | Manifestation | 5-15s | 超自然元素全貌展示 |
| 4 | Aftermath | 3-8s | 环境因超自然元素改变 |

### 引入风格

| 风格 | 节奏 | 适用场景 |
|------|------|---------|
| 渐进式 | 慢→慢→正常→慢 | 神秘敬畏感 |
| 突发式 | 正常→极快→慢 | 震惊恐怖感 |
| 仪式式 | 慢→加速→高潮→慢 | 召唤觉醒变身 |

### Normal_World 细节

- 展示正常世界，建立基线
- 写实风格，自然光
- 最后加入**细微异常暗示**（画面边缘微光/声音/温度变化）

### First_Sign 细节

- 异常元素特写（浅景深聚焦异常点）
- 角色注意到异常（表情/动作变化）
- 环境对异常的反应（风起/水面涟漪/灰尘飘动）

### Manifestation 细节

- 超自然元素全貌展示（广角仰拍增强规模）
- 细节特写（微距展示质感）
- 与人物/环境的尺度对比同框

### Aftermath 细节

- 环境因超自然元素改变（前后对比）
- 角色敬畏/震惊反应（仰拍面对奇观）

## 能力释放节奏（五阶段）

| 阶段 | 名称 | 时长 | 内容 | 节奏 | 镜头 |
|------|------|------|------|------|------|
| 1 | Charge蓄力 | 3-8s | 能量聚集特写+角色姿态变化+环境被影响 | 慢→逐渐加速 | 缓慢推进 |
| 2 | Peak顶点 | 0.5-2s | 能量最大值瞬间+角色眼神/表情特写 | 静止或极慢 | 固定或极慢推进 |
| 3 | Release释放 | 0.3-1s | 能量爆发广角+冲击波扩散 | 极快 | 快速拉远或震动 |
| 4 | Impact冲击 | 2-5s | 被影响的环境/对象+视觉后果+烟尘碎片 | 正常或慢动作 | 稳定或环绕 |
| 5 | Aftermath余波 | 3-5s | 角色释放后状态+环境新平衡+尘埃落定 | 缓慢 | 缓慢拉远 |

## 世界观展示策略

### 策略A：角色视角引导

```
角色进入新环境(POV/跟拍) → 注意到第一个异常 → 深入探索更多细节 → 全景揭示全貌
```

**优势**：代入感强

### 策略B：尺度递进

```
微观细节(地面纹理/植物) → 中观环境(建筑/地形/生物) → 宏观全貌(城市/大陆) → 超宏观(星系/宇宙)
```

**优势**：震撼层层递进

### 策略C：对比揭示

```
角色熟悉的旧世界元素 → 旧元素逐渐变形/被替代 → 新世界完全取代 → 角色在新世界中的渺小
```

**优势**：差异感强烈

### 世界观细节镜头类型

| 类型 | 说明 |
|------|------|
| Texture_Close | 材质特写（外星植物表面/魔法矿石纹理/机械齿轮质感） |
| Life_Shot | 生态镜头（奇异生物/发光植物/悬浮水滴） |
| Architecture_Wide | 建筑广角（悬浮城市/水下宫殿/树上村落） |
| Sky_Establishing | 天空建立（双月/极光/永恒黄昏/星环） |
| Scale_Reference | 尺度参照（人在巨型雕像脚下/行走在巨树根部） |

## 规模感营造技巧

| 技巧 | 方法 | 关键点 |
|------|------|--------|
| 人类参照 | 人物与巨大元素同框 | 人物必须清晰可见作为标尺 |
| 递进揭露 | 先特写局部→拉远→揭示完整规模 | 利用观众预期制造惊讶 |
| 垂直强调 | 极低仰拍/俯拍深渊/垂直运镜 | 竖屏内容特别有效 |
| 运动尺度 | 慢速经过巨大表面/快速飞越广阔空间 | 运镜速度与物体规模成反比 |
