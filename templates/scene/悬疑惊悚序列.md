## 相关知识库

> ⚠️ **必读补充**：`Seedance2导演级运镜库.md` 中对应章节：
> - `模糊转清镜头` - 焦点从模糊逐渐过渡到清晰（清醒/释然）
> - `倾斜构图镜头` - 荷兰角构图，表现不安或紧张
> - `旋转晕眩镜头` - 眩晕效果，镜头连续旋转
> - `后退揭示镜头` - 镜头后退展现广阔场景，适合开场
> - `鱼眼扭曲镜头` - 画面边缘球形扭曲，压抑/紧张
> - `镜头呼吸效果` - 轻微的焦距周期性变化，不安感

## 紧张感营造

### 镜头技巧

| 技巧 | 说明 |
|------|------|
| 慢速推进 | 逐渐靠近危险源 |
| 固定机位 | 增加不安感 |
| 暗光/单光源 | 限制视野 |
| 静音→突发 | 声音节奏 |
| 主观视角 | 增加代入感 |
| 浅景深 | 模糊背景，未知危险 |

### 紧张节奏

| 阶段 | 时长 | 技巧 |
|------|------|------|
| 铺垫 | 5-10s | 建立不安氛围 |
| 升级 | 3-5s | 暗示危险临近 |
| 临界 | 1-2s | 即将发生 |
| 释放 | 0.5s | 惊吓或解除 |

## Jump Scare 设计

### Jump Scare 结构

| 阶段 | 时长 | 内容 |
|------|------|------|
| 铺垫 | 3-8s | 紧张氛围 |
| 蓄力 | 1-2s | 暗示即将发生 |
| 惊吓 | 0.2-0.5s | 突然出现 |
| 恢复 | 2-3s | 反应镜头 |

### Jump Scare 技巧

- **声音配合**：突然音效+视觉惊吓
- **节奏停顿**：安静后的突然
- **视线引导**：引导观众看错误方向
- **虚假安全**：先给安全感再打破

### 最佳时机

- 观众放松警惕时
- 节奏突然停顿时
- 观众预期落空时

## 反转设计

### 反转类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 预期反转 | 预期A，实际B | 以为是好人→是坏人 |
| 安全反转 | 以为安全，实际危险 | 门后有人 |
| 身份反转 | 表面vs实际 | 真凶是XX |
| 结局反转 | 出乎意料的结尾 | 一切是梦 |

### 反转铺垫技巧

1. **误导线索**：给出错误信息
2. **转移注意**：让观众关注错误重点
3. **细节忽略**：隐藏关键线索
4. **情绪引导**：让观众产生错误预期

### 反转节奏

```
铺垫（建立预期）→ 确认（看似正确）→ 反转（惊讶）→ 揭示（真相）
```

## 视觉误导系统

### 误导类型

| 类型 | 方法 |
|------|------|
| 构图误导 | 焦点放在错误元素上 |
| 声音误导 | 配乐/音效引导情绪 |
| 剪辑误导 | 错误关联两个无关事件 |
| 角色视角 | 通过角色视线误导 |

### 误导→揭示结构

```
误导画面 → 真相画面 → 对比揭示
```

### 关键帧设计

- 第一次看：误导解释
- 回看：发现隐藏线索
- 揭示：重新理解

## 特殊情况处理

### 心理惊悚

- 内心独白vs画面不符
- 现实vs幻想混淆
- 人物精神状态表现

### 悬疑推理

- 线索特写
- 推理过程可视化
- 关键证据强调

### 惊悚氛围

- 连续短镜增加压迫感
- 极端特写
- 声音设计配合
- 色调统一（冷/暗）

### 恐怖类型

- 鬼/怪物设计
- 诅咒/仪式场景
- 密室/封闭空间
- 夜晚/黑暗环境
