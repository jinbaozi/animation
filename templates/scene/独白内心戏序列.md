# 独白内心戏序列

> **格式说明**：独白内心戏使用标准分镜表格式（参见镜头序列模板.md），必须使用"外化方案"列，支持"名台词/金句"列。

## 相关知识库

> ⚠️ **必读补充**：`Seedance2导演级运镜库.md` 中对应章节：
> - `长镜压抑镜头` - 一镜到底的连续长镜头，营造窒息感
> - `模糊转变镜头` - 画面慢慢失焦过渡到完全模糊（晕倒/迷茫）
> - `模糊转清镜头` - 焦点从模糊逐渐过渡到清晰锐利（清醒/释然）
> - `喘息跟拍镜头` - 镜头上下起伏与角色沉重呼吸同步
> - `颤抖特写镜头` - 极度特写颤抖部位，高频微小晃动
> - `瞳孔放大镜头` - 眼部极度微距特写，瞳孔放大

## 核心原则

AI生成微表情失败率极高。核心策略：**用环境、物件、光影代替面部表演传递心理状态**。

## 三层外化优先级

| 优先级 | 类型 | 难度 | 说明 |
|--------|------|------|------|
| 1 | 微动作外化 | 最易 | 手部、身体下意识动作 |
| 2 | 物件代理 | 中等 | 物件状态映射心理状态 |
| 3 | 环境映射 | 最稳 | 环境状态映射心理状态 |

**核心铁律**：优先使用外化，避免依赖AI微表情生成。

## 微动作外化库

| 心理状态 | 可拍摄微动作 |
|---------|-----------|
| 纠结 | 反复拧瓶盖、撕纸边、物品拿起又放下、鞋尖碾地 |
| 压抑 | 指甲掐掌心、指节握白杯子、咬紧下颌、屏住呼吸 |
| 释然 | 握拳慢慢松开、深深呼气白雾散开、攥着的物品轻轻放下、肩膀下沉放松 |
| 崩溃 | 手指颤抖、扫落桌上物品、双手抱头蹲下、撕碎纸/照片 |
| 顿悟 | 正在做的动作突然停住、缓缓抬头眼神聚焦、手中物掉落不去捡、嘴角慢慢上扬 |
| 自我怀疑 | 反复照镜子、擦掉又重写、走两步又折返、手摸向伤疤/旧物 |

### 微动作选择原则

- **可拍摄性**：AI容易生成的微动作
- **辨识度**：观众能看懂的心理表达
- **与场景融合**：自然发生，不刻意

## 物件代理库

| 心理状态 | 物件+画面 | 镜头建议 |
|---------|---------|---------|
| 关系即将破碎 | 杯子慢慢滑向桌边 | 特写，极慢推进 |
| 错过的机会 | 公交关门离去，角色站在站台 | 中景，固定机位 |
| 无法回头的决定 | 信封投入邮箱，手停在入口 | 特写，慢动作 |
| 内心混乱 | 墨水在水杯中扩散 | 大特写，俯拍 |
| 记忆消逝 | 冰块在掌心融化 | 特写，延时感 |
| 等待无果 | 手机屏幕始终没有新消息 | 特写，固定 |
| 失去希望 | 蜡烛熄灭 | 特写，轻吹 |

### 物件代理选择原则

- **象征性**：物件能代表心理状态
- **画面感**：物件状态变化易于拍摄
- **与场景关联**：物件存在于场景中

## 环境映射库

| 心理状态 | 环境选择 | 拍摄技巧 |
|---------|---------|---------|
| 孤独 | 空旷街道/广场/空房间 | 远景，人物极小 |
| 压抑 | 逼仄空间，天花板入画 | 广角变形，空间压缩 |
| 迷茫 | 大雾/十字路口/无尽走廊 | 低饱和，柔焦 |
| 希望 | 黑暗中一束光/破晓天际线 | 高对比，暖光侵入 |
| 自由 | 开阔海面/高处俯瞰/风中草地 | 超广角，运动感 |
| 回忆 | 旧地/空教室/褪色照片 | 柔焦，低饱和偏暖 |
| 绝望 | 暴风雨/荒漠/深渊 | 高对比，倾斜构图 |

### 环境映射选择原则

- **情绪匹配**：环境能直接传递情绪
- **拍摄稳定性**：AI能稳定生成
- **与角色关联**：角色在环境中合理

## 意象匹配表

| 意象 | 含义 | 适配状态 |
|-----|------|---------|
| 海浪 | 情绪起伏/无法控制 | 焦虑、失控、释然 |
| 落叶 | 失去/放手 | 失落、告别、释然 |
| 种子/嫩芽 | 新生/希望 | 决心、希望、蜕变 |
| 暴风雨 | 情绪爆发/净化 | 崩溃、愤怒、转折 |
| 晨光/黎明 | 觉醒/新开始 | 顿悟、决心、释然 |
| 十字路口 | 选择/迷茫 | 纠结、迷茫 |
| 破碎镜子 | 自我分裂/真相 | 自我怀疑、崩溃 |
| 关闭/开启的门 | 选择/终结/新开始 | 决心、告别、纠结 |
| 空站台/末班车 | 错过/等待 | 失落、孤独 |
| 蜡烛 | 脆弱希望/坚持 | 脆弱、坚持、失望 |
| 风铃 | 记忆的触发 | 怀念、回忆 |

### 意象使用规则

- 同一场景意象不超过2个
- 需与场景环境自然融合
- 意象不喧宾夺主

## 旁白穿插节奏

### 四种模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 旁白主导 | 旁白先起→画面进入 | 开场、引入内心世界 |
| 画面主导 | 画面先展示→旁白进入 | 沉浸式、氛围铺设 |
| 交替穿插 | 旁白段+画面→纯画面段 | 完整独白场景，最常用 |
| 高潮静默 | 情绪顶点旁白突然停止 | 情绪爆发点、顿悟瞬间 |

### 核心规则

- 每段旁白不超过15秒
- 纯画面段至少3秒
- 旁白说A，画面展示A的外化/意象（**互文**，而非图解）

### 旁白驱动程度

| 程度 | 描述 |
|------|------|
| 纯旁白驱动 | 画面完全跟随旁白 |
| 混合驱动 | 旁白与画面交替 |
| 无旁白纯视觉 | 完全靠外化表达 |

## 光影心理映射

| 心理状态 | 照明 | 色调 | 对比度 | 光源 |
|---------|------|------|--------|------|
| 压抑 | 低调，大面积阴影 | 灰蓝/冷绿 | 低 | 顶光或无明确光源 |
| 焦虑 | 不稳定（闪烁/摇晃） | 冷暖混杂偏黄绿 | 中高 | 多光源方向混乱 |
| 愤怒 | 强硬侧光 | 暖红高饱和 | 极高 | 低角度强光 |
| 平静/释然 | 柔和散射光 | 暖金/柔和中性 | 低 | 自然光黄金时段 |
| 顿悟 | 从暗到亮变化 | 从冷到暖过渡 | 逐渐增高 | 光线涌入 |
| 孤独 | 小范围冷光+大暗部 | 深蓝极低饱和 | 高 | 远处点光源 |

### 转折规则

- 心理转折时光影在3-5秒内逐渐变化
- 顿悟可用突然光变
- 光影变化需有场景内光源合理性

## 无旁白纯视觉五步结构

当场景没有旁白时，使用以下结构：

1. **Establish** (5-8s)：远景建立孤独感/中景展示角色状态
2. **Externalize** (8-15s)：微动作特写+物件代理
3. **Symbolize** (5-10s)：意象镜头穿插
4. **Transform** (5-8s)：光影变化+景别变化
5. **Resolve** (5-10s)：新状态的外化动作+环境变化
